# 自动备份当前不可用

自动备份保持关闭。backup inspect 只读返回 can_backup=false、request=null 和阻断原因；backup create 在访问源、取得锁或打开输出前固定拒绝，直接调用 Python 后端也拒绝。没有 force、环境变量、旧请求或自报能力的启用路径。正常 CLI 不为此启动 Python 工作进程。

Linux 阻断码为 BACKUP_LOCK_ISOLATION_UNVERIFIED；不支持的平台返回 BACKUP_PLATFORM_UNSUPPORTED。tool prepare-update 同样保持不可用。

普通写作、只读材料、原生更新和恢复仍使用原有流程。更新前须自行确认独立备份；材料清点不是原子快照，也不是备份。

## 保护边界

既有文件锁是协作式保护，不能承诺阻止同权限非协作进程修改锁或作品。过去的描述符、权限与并发实验不能作为自动备份已安全开放的证据。本版没有降低现有检查，也没有引入通用协调服务。

自动备份如需重新开放，应另行确认其保护边界和完整验收；本版保持关闭，不把该实验的全部写入适配列为普通写作功能前提。历史实验与验证记录单独保留。
