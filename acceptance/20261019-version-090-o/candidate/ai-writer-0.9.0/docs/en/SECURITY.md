# Security reporting

[中文](../../SECURITY.md)

Do not disclose exploit details, tokens or private manuscripts in public issues. Sensitive cases include arbitrary file access, path traversal, authorization or revision bypass, token exposure and manuscript disclosure.

If private vulnerability reporting is enabled, use “Report a vulnerability” on the repository Security page. Availability depends on the actual repository settings. Otherwise open only a public placeholder asking for a private contact, without technical details, and wait for the maintainer's response.

Privately provide the affected version/build, entry point, anonymous reproduction and impact. Ordinary bugs use the [bug guide](bug-reporting.md). No fixed response deadline is promised. The Chinese guide is authoritative.
