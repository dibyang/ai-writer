# 《东岸末班船》全书骨架（试验代理规划）

规模：三章、两卷。第1、3章各至少5000正文汉字，第2章至少3500正文汉字；标题、标点、数字不计。篇幅来自实际行动与生活后果，不靠重复核对拉长。

第一卷《谁来领》，第1—2章：由误放箱与两种“来拿”起步。先找回实物的保管链，再核实周岸为前一借用人、沈长年为下一借用人、沈禾只代领。卷末解决领用关系及两笔押金归属，不冒充工具已交到父亲手中。

第二卷《过河》，第3章：完成合作点收回、另借给沈长年及委托交接，沈禾赶合规末班，把箱交到西岸父亲手中。父亲按箱盖黄漆箭头的方向推正偏口再合箱，使开篇外观细节得到一次实际用途上的兑现。周岸留东岸、许蓉只接到转述，人物知情分别更新。收束在父女把箱搬到手推车上、安排次日的活，父亲旧事不强行结案。

叙事不把任何人写成谋占工具的坏人：每个人手里只有一截交代。真正代价是多走路、误饭点、押金到账延迟、代领责任与赶船的安排。

追踪设计（尚非事实登记）：

- O_BOX_ARROW，observation：拟用原字“箱盖右后角画着一支黄漆箭头，箭头朝向提手。”首次写入后以实际正文为准，正式登记时冻结statement/type/author_truth；后续只能另记解释、更新知情，不逆改观察。
- T_DELIVER，thread：核实委托后，把旧箱在关门前交到沈长年手中。第1章实际说出约定后才登记；跨卷兑现前回读首次原句，分别写谁亲见、谁获告、谁尚未知。
- P_BOX，object：合作点旧钢工具箱。首章按真实保管动作登记holder/location/condition；跨卷用previous_holder和完整custody跟随动作，不把下一借用人等同当前保管人。
- 父亲旧事：intentional-open候选，若只有一句提及不伪造完整作者真相。

创作方向来自本轮验收prompt；上述具体借用安排、金额、外观原字、配角和收束动作均为测试授权内的代理选择，不是人类作者逐字指定。当前进程权限及停点只看workflow和交接。
