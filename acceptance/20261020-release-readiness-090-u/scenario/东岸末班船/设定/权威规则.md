# 权威规则

以下为本隔离虚构场景的长期约束；角色卡和大纲属于创作计划，已发生事实以正文与正式追踪为准。

- 东岸、西岸是同一条河的两处渡口。候船室在东岸公共侧；售票口、检票口和下坡栈桥依次相连。未持票者可以进候船室，不能自行穿过检票口登船。普通乘客不能因送工具进入船舱维修区。
- 末班客渡二十点五十分离开东岸，二十点四十五分停止检票，约八分钟到西岸。东岸候船室二十一点十分关门。第二天开始检修停航，不能临时许诺加开一班。上述均为虚构站内安排。
- 旧工具箱属于东岸修理合作点，由老陶保管借用册。借出和归还是两件动作，下一位借用人可以委托家人领取，但须核实委托并留下交接。外观熟悉不等于有权拿走。
- 押金每次借用二百元。上一笔退还原交款人，下一笔另确认，不让代领人默认接收上一人的退款。不得把船票、借箱押金与修理报酬混作同一笔钱。
- 旧钢箱约四十厘米长，装工具后约九公斤，带提手和箱扣。有人看见箱体，不表示看过箱内；挪动与交接要有动作和保管人。箱盖有偏口，使用方法须在人物实际得知后才能熟练掌握。
- 父亲沈长年在西岸，脚踝未好，能短距离慢走，不能让他忽然横跨两岸出现。修理工周岸在东岸参加停航检修，不能因为沈禾到达西岸就自动知道交箱结果。
