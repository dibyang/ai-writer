# 《夜班退件》全书大纲

两章当晚连续叙事，收件差错闭合，善后责任保留。不预置章节正文。

## 第一章《八点以后》

20:32，梁穗接到许芸的电话：该收到骨灰盒的箱子里是旧收音机。小站的灰筐已有周姐20:00收回的三件退件。梁穗知道自己把原计划的投递顺序颠倒，为隐瞒第二次改线，向周姐报修理铺20:15，令两人排除回站的那批。她去修理铺，门已锁、退件格已空；电话不通。交付照片明示19:48，她仍先问如何开门。周姐追问实际顺序。章末停在承认之前。读者已经有足够信息推测盒子可能在站里。

## 第二章《退件人》

承接修理铺门前，梁穗发出未裁切的照片，说清自己先去了修理铺。周姐转查20:00退件，梁穗返站核对外箱，许芸带收音机来站，核对蓝布和木盒旧封条。二人交接不以愤怒全消为条件。梁穗亲笔写明“改投递顺序、未核地址、事后报错时间”，并登记次日归还收音机与后续联系。周姐继续留灯，许芸给她腾一只干净杯子；夜班延后结束。谜底、选择、代价和有限善意都在本章落地。

## 线索兑现

- 第一章灰筐三件、20:00回收 → 第二章回查定位。
- 计划20:15与照片19:48 → 假时间为何误导搜寻，不改变照片事实。
- 上层先取、临时改线 → 两箱交换的操作原因。
- 上次漏单的羞耻与“照单送”承诺 → 当场纠正、差错单亲笔留痕。
- 许芸明早回乡 → 当晚需找回，但不虚构整点危机。
