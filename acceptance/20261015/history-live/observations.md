# 历史散文实际使用记录

执行方式：当前 Codex 主会话实际写作、实读，逐步通过 run.mjs 调用同一项目CLI。NN-command.json只记录真实CLI命令、退出码和输出，不伪装独立codex exec进程或模型事件。原始请求在request.md，来源核读见history-source及网页工具记录。

1. 初始化、设定、两章细纲、事实卡、逐章context、写前record-template均可用；完整快照由模板保留，正文发生后才登记。
2. 第一章第一次check把史源说明的https://链接误判为Windows路径，警告位于第一章23行。根因是路径正则在协议末尾匹配到s:/。已修根工具正则，补“HTTPS不误报、实际正反斜杠盘符仍提示”回归；同稿再次check无发现。保留原警告命令日志，不删真实史源链接。
3. 知情实读修复术语切词歧义、还要取得出来的语序、沈括/毕昇代词指向，以及准备工夫可能误读为每次重新刻字。均在各章首次record前完成。
4. 事实卡明确单一史源及推断边界，没有为填verified使用合成测试卡；未编造毕昇私人对白、心理、现场或工艺普及结论。
5. 本轮没有发现必须再修改最终正文的问题，没有为验证而制造文学改动；回退重登已由剧本真实流程及工具回归覆盖。
