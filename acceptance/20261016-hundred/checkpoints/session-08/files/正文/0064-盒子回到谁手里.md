# 第六十四章 盒子回到谁手里

第三十八日退房时，沈禾把浴室门后的毛巾摸过一遍，边角还凉。她没塞进衣服中间，另装在薄袋里。前台阿姨仍坐同一处，今日没有面碗，正拿针挑衣扣里的线，见她提两袋下来，问房卡放哪儿了。

卡在电脑袋外层。沈拉开以后才发现收据挡在上头，先将它取出，卡递回，没让对方替自己翻。阿姨说衣架还在屋里就行，沈答在，拿过退房凭条，走出院子才回头看一眼。那床红被面今天没晾，窗台上一只空盆迎着太阳。

八点半，她将衣袋挂在现场小桌外侧，照当天设备状态准备，九点开录。陆岑已把昨日占椅的箱子叫人收回，自己在走廊吃最后两口早点。沈见她手里拿着菜谱，没有问昨夜做了饼没有，旅馆连锅都没有，书先随她走。

上午有个词念了两遍仍绕，主讲人自己改成一句短的，梁秋在视频里听完，答意思还在，新的可以留。沈将两种都记下，继续听后头，不为让今日早收就抹掉那一遍绕口的。十一点五十多，上午停机，十二点到一点仍照原来吃饭。

周砚十一点多发来消息，说今天班能按时收，二十点五十左右到车站，若有变化再告。沈午饭时才看，答自己车仍十八点四十，开了再报。她将手机放回，想起上回自己在城里等一句能不能接，今天终于不用一整天将他的下班也揣在口袋里。

陆见她笑，问是不是车还有座。她说票没动，有人今晚能接。陆朝她的两只袋看，说有人接好，别下车以后还站着找一辆已经收工的车，便没继续问那人是谁。

午后梁秋亲自到了，外套搭在臂上，先同陆核场地。陆拿手机给他看，刚收到场地方退的二百四十，前头第三十三日付三百六那条仍在。她没有让这两行自动相抵便完，将二百四十另转给梁，他点开确认已收。

“这样剩的一百二就是这次取消的。”梁说。

陆应一声，将原折票连取消确认打印页递给他。梁接过，夹进自己的项目票夹，旧椅借物单她仍另留，说那笔不认的还没结，后头再找他。沈站在桌边看见这次转收与递票，没给没在场的旧付款补一双眼睛。

原票离开夹板袋，里头露出一条旧汗印。陆拿纸巾擦了一下，擦不掉，索性把新买的菜谱放到另一层。她说回去先做一次饼，若成了给沈发照片，焦的也发，让她知道自己真开过锅。

沈说可以，没请她将照片当自己家的晚饭。录音房里有人叫，两人各回位置。下午这一房比昨日顺，走廊的架子装好了，仍有人来回，只是不再每隔一阵敲一下。沈听过当时声音再留一段底声，文件照日期和本房状态写，没将昨日的一段挪到今日假装屋里从来没变。

四点四十，最后一组结束。沈让人先别急关机，核两边文件，发现有一段自己标的重录号少写一位，翻回实际文件改清。机器没丢声，是她笔记省错了；陆看见她找，没先把正在桌边坐着的人都赶下楼。

五点十二，第三日文件与三日总记录交到陆手里同一只新工程盘。陆在另一台电脑试开当日各组和重录，按记录找36日程蔚所选第四遍，文件在，选择也还在，没有被第三天新文件顶掉。梁坐在她旁边，核三天各份齐，确认按约原录与记录已收，后面选段剪片另约。

五点十八，尾款一千三百五十到了。沈点开确认，连原定金，总共两千七。交通票合一百二十八，梁另笔返给她，她在票据那行记归还，不把这笔也添进工钱。顾那一小时八十是出发前真花过的，她记在准备开支，没因为今天收齐，便把它从本子上拿掉。

梁问后面若请她核听，最快哪天。沈说先把时长与要听的范围发来，自己明日午前不排，不能在走到车站时答一整段晚上。梁说好，让她先赶车。她把自己的委托暂备收好，盘退出，短线绕松，电脑装包；原带转录和旧客户文件都没为这次交盘打开。

陆陪她到电梯边，电梯里有人推箱，沈先让箱子出去，衣袋才没夹住。门将合时陆抬手说毛巾回去别闷着。沈低头看薄袋笑，答到家先晾，回手按住电脑包，没让它随着自己的挥手撞到门。

走到公交站前，沈在路边买一只菜包。摊主正装刚起锅的，热气将袋口顶起来，她请人先别扎紧，自己拿着等了一阵，外皮不烫手才提。旁边有人一次买六只，问摊主能不能再少五毛，摊主拿夹子的手停着，说今天最后一锅，只够照这个卖。

那人嘀咕着数零钱，沈没有替他补，也没催自己这一只先拿走。她的水杯就在包里，刚才买包以前还在想是不是就喝水撑到家；真闻见面香，才知道这一路并不只是在赶十八点四十。她从袋口咬了一点，馅里的菜汁还热，站到不挡人的一侧吃几口，余下留上车。

去车站的公交遇到一段慢车。她看了两次时间，终于将手机翻面，先把余下的菜包吃掉。旁边阿姨要下车，袋里一把青菜横过膝前，她将自己的袋子收直，给菜叶让一点地方，没因为自己赶车便让对方从电脑上跨过去。

进站还有空，她买一瓶水，坐下将两只袋的提带理顺。十八点四十车实际开出，她报给周，也给梁回已上车。周说自己七点多能收工，先回去换衣再来，沈回别带吃的，自己车前吃过了，又说只想到了能坐一阵。

窗外亮处慢慢散掉。她靠着椅背睡了一小段，醒来时，水瓶在杯架里，电脑包仍压着自己的腿。手机没有等她听的长段声音，只有周说到站外了。她回车快到，收起水，直到车停稳才起身。

二十点五十，下车的人散开，周砚站在出站口边，没有给她举牌。她朝他走，见他外套下还穿那件熟悉的工作衫，袖子放着，问是不是先回过家。他说回了，换双鞋又出来，手伸向她的衣袋，等她松开才提。

“录完了？”

“三天原文件交完，工钱也收齐。后头若叫我听，重新约。”

他点头，没问那三天每一笔怎样分。沈也没将陆的退款讲成自己终于挣到了哪一笔，只说最后一天坐车，比开机还累。周问她想走还是坐车，她说坐，自己那双脚不愿再绕院子，他便同她到路边等。

上车以后，他将衣袋放自己腿上，没拿电脑去压。沈看他手背，问鞋买了吗，周说没有，等她回来笑。她真的笑了，靠过去一点，肩膀碰到他的袖子，过了一会儿没有移开。

到沈家楼下，周提衣袋上去，她开门，屋里有几天关着的热气。她先开窗，将电脑与移动盘放干桌，短线另放。原来的长线停用袋和母亲原盘仍在抽屉分格，她只看袋字，没有取出试；纸袋各在干架，少原缺名袋的那个空位也还空着。

周站在厨房门边，问要不要烧水。沈说先坐，自己把毛巾拿出来。晾上以后，她从沥水架最外侧取那只借来的饭盒，盖子仍单立，都是干的。她对齐盒沿合好，走到桌边，递给周。

“这回真还了。没带它去坐车。”

周接住，打开一条缝看了看，又合上，放进自己带来的布袋。沈手里空出来，反而想不起刚才还要找什么，坐下才发现水杯已在桌边。他问她明日想几点出门，她说下午三点，看鞋之前自己先吃饭，不让他等一顿没做的午饭。

周答三点，眼下只约这一次。他坐着陪她喝半杯水，沈说城里那位讲师拍张照片要等，自己听一天别人说话，夜里竟忘了怎么听他。他没有马上替她说没事，过一会儿才答，累了能讲累，别把话接过去又不知道是什么。

她应了，没有再用手机示范自己现在多专心。九点半前周起身，提好有饭盒的袋。沈送到门口，他说毛巾别忘收，她让他明日穿松一点的袜子，省得鞋又怪到脚上。周笑着下楼，盒子跟他走了，沈关好门，自己去热水洗脸。
