# 第五十章 六十块里的一早上

第二十八日九点四十，沈禾把椅子让给刚进门的女人，自己坐到桌角。女人没坐，先从帆布包里拿出一件小雨衣，抖开看袖口，往外挪，才找着压在下面的票夹。

“孩子早上说少一只袖子，我以为穿反了。是卷到里头去了。”她将雨衣塞回去，笑了一下，“姚蕴。严姐说你也在。先说好，我十点得走，后面那个点有人等着领东西。”

严倩这才介绍，她负责这间小屋本月的临时开门款和零星修缮结算。严先前只在电话里提过这个名字，今天才将人带来。沈禾说自己只讲亲见的几段，姚已经蹲下，伸手去摸椅背下面松出的木刺，摸到以后又从包里找纸包住，没叫人先坐上去再想。

何映将另一张椅子拉给她。姚坐稳，严打开修缮夹，把顾遥开的八十收据放平。换件那一栏划着线，纸折处有一点灰，严用指甲刮，没刮干净便停了。

姚对过金额，取出手机，转给严。严没有只看通知，点进收款页，才说八十到了。姚让她把原据留下，严先拍过当次照片，再将原纸递过去。姚夹入自己的票夹，边上另一张小票露出孩子鞋子的号码，她将那张抽开，换到私人包层。

“这个八十是还给她，不是又付顾一次。”何映说。

姚点头，叫严在维修那行记已返。严写完，把手掌从夹子上移开，像终于能把这只夹子合得薄一点。顾的工钱早付了，今天回来的是她先垫出去的一笔。沈禾看见原据已经在姚手里，没伸手去拿来替她们再抄一份。

何映摊开前些日子的开放记录。姚看过两行，说后面这些少开的不能只填原因，得有真实时段。何指着二十一日，说十点二十以前自己在，后面接母亲去了，下午门调过但仍没开放；不能将整天抹成自己没来，也不能将后来严开门给顾修的那几分钟填成借阅。

她说得很快，纸角被手压得卷起来。严将那角拉平：“她原来的钱还在问，别拿今天这笔新开的盖过去。”

姚低头看了一会儿，将自己预先空着的一行划开。她说旧时段与旧报酬仍要逐段对，今天不能给何一句已经全清；也不会用新的三轮钱抵原来应付的。昨天的迟开照实留，不能因后头想请何继续来，就替她把九点写齐。

何映脸上紧了一下，终于将压纸的手收回来。她答昨天自己已经添了实际迟开，不让沈替九点二十九作现场证明。沈只说自己九点零六见门锁着，九点三十四回程才见门开，中间去顾店，不在门边。

姚听完没有再问沈那二十八分钟每一个去了哪里，直接将“本人记迟开”留在何的那一行。她翻到后页，说本月剩的临开款可先单列三轮，一轮六十，做完一轮结一轮；这三轮从原排时段里另列，不同一上午再双领。房子不是凭这点钱就从此每天都能开，先写真有人接的。

何映看着六十，先问上午两小时以外算不算。姚把笔拿回来，在九点前添十五分钟，十一点后又添十五分钟。

“八点四十五到十一点十五。这半小时也在六十里，不叫你凭空早到。借阅九点到十一点，外头就贴这两个钟头。”

“钱不变？”何问。

“总数不变。你觉得不合适，可以不接。不是把你答了的两小时偷偷拉长。”

何映没立即点头。她把自己的旧四折纸取出来，摊到公夹旁，旧蓝字与新勾都在一侧，没有拿那张私纸让姚留档。她沿着纸边的空处看，嘴里先报第二十九日，手指又点另一处，轻声算自己去印铺的路。

“二十九、三十一、三十三，上午这三回我能接。下午不写。我能把送样挪到午后，不是上午还接一个快点做完的。”她说，“可是三十三之后呢？”

姚摇头，说还没批，也还没排。她不能为了让纸上没有空，把后头的日子先填满。何映将第三十四日之后那一小块折回，没再写。

严问若哪一回何确实来不了，钱和门怎么处置。姚先看何：“严姐刚才同我说，陈那天是试一回。别先写让她接，我没有她往后的答应。”

“我也没再问她。”何说。

三个人谈的是停借怎样有人真去改门外告示。何若事先不能来，先电话找严，严接下了才由她改；严也去不了，何得在前一日把未确认开放写明，不得留着原时间等消息。真到早上临时出事，两人接通后决定谁去关告示，不能给沈留一句看见了帮忙。准备已经做过的照实际另说，不将没开的一轮当全做完，也不把叫来的那个人白跑归零。

姚的电话这时响了。那边问她是不是已经上车，她答十点，现在九点五十六，不叫对方先把要交的东西放到路边。挂断，她将三轮一百八十的上限写清，只写已确认的经费与日期，没有写已付。原来何的少开报酬那页另放，严的八十标已返，三个数没有揉成一行。

何映看过，问这张留哪里。姚将确认过的一张交何，自己留相应的结算联，说明每次结束由严核实接报，再从这笔临开款结给何，不让沈来作常驻点名的人。何接纸收进公共夹，压在一次试行纸之后，自己的四折纸折回袋。

十点，姚站起。她想起雨衣，从袋里抽出一角看看，终于将那只卷住的袖子完全抻出来。严说现在知道为什么孩子嫌，她答孩子早上气得直哭，自己还说人家磨蹭。说完将票夹抱稳，原八十收据没有从里面掉出来，赶去下一个点。

何映送到门边回来，没马上收桌。她望着那三个隔日的早上，说六十不多，写全半小时以后，倒比原来只写开门更像自己真的能去做的一件活。严叫她别光看三张纸，明天第一回要开，今天得先让门外的人知道。

何拿起笔，在新纸上写第二十九日九点到十一点，下午不借阅。原想把八点四十五也写进去，笔在上头停住，又另换一张。她说那个时候要放椅子、开窗，不能让人看见自己在就往里坐，一坐下又没有准备的十五分钟。沈禾替她按住空纸的一角，没替她填之后的日期。何写完，走到门外抽出前一天那张迟开说明，收进公夹，再将新纸送进透明封皮，两侧夹紧。

一阵风从巷口过，纸面鼓起，右边夹子滑了半寸。何将它移到更里面，轻拉下缘，确认不会掉。严在几步外读了一遍，说这一张只管明日，后日没写就不能回人照常。何答知道，回来将旧告示放在那次试行纸旁，没有撕成垫杯的纸。沈松开自己按了许久的手指，纸上没留下汗印。

“你到超市也照常收货，不替我留这一上午。”何说。

严答自己本来就没留，起身时才笑了一下。她带走修缮夹，原八十据已交姚，袋里留的是自己拍下的照片。沈禾在九点五十九已从桌旁起身，等她们讲完这两句便同严出巷，没有留下来把何的三轮排成自己的行程。

十点二十多，她走到孟丽的面食铺。柜台旁原来的收款牌还立着，新菜单已经压在干净透明板下，小碗与大碗两行分开。她没找一个何已全部做完的证明，先问小碗汤面能不能少一点盐。

孟丽从锅边抬头，认出她：“买米的？今天总算吃了。”

“小碗。”沈禾又说一遍，怕一笑便忘记要什么。

孟往锅里下，回头叫店里那位年长男人别替自己添半勺。男人说小碗吃不饱，孟答吃不饱人家会再问，不用刚端出去就替别人加成大的。男人不高兴地擦柜角，沈禾坐在靠门的桌边，听他擦布一下一下拍着板面，没有插嘴说谁对。

面上来，碗口确实比她记得的另一种窄。她挑开一口，汤不烫舌，先吃了几筷子才将桌上的小罐移近。孟问淡不淡，她说正好，自己要加一点醋，不是拿醋救咸。

孟笑着回锅边。有人来问外带盒，年长男人下意识说另算，没报数，孟从里面接上，声音盖过滚水。柜台那块空处仍没有印好的新排版，也没因此妨碍今天这碗面端出来。

沈禾吃到一半才发现，自己没有拿手机问何是不是谈完。桌上只有一只碗，包里没有原纸原带。她把面吃完，照小碗价付给孟，听见对方清楚应了一声收到，自己提空布袋走出门。明早的门还在明早，眼下这顿饭已经不用等谁先把一整个月说定。
