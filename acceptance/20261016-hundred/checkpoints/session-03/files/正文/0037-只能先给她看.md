# 第三十七章 只能先给她看

第十八日早上，沈禾将包里的文件袋拿出来。昨晚的雨把窗台打湿了，袋上却干，她先把三页纸平放到饭桌另一头，自己端着碗坐下。罗敬的旧改稿还在抽屉里，那两套邱稿各有袋口。她吃完才给何映打电话，问今天上午有没有一会儿能看纸。

何映正在开门，铁链在那头碰了两声，说十点来，十一点前得走，不是要关着屋看。沈禾说自己坐旁边，来人就先合上，三页只给她看。对方应了，又叫她路上带支笔，屋里有一支漏油，借还本上昨天已经沾过一回。

她挑了支按键的试过，没带电脑。走到河街，鞋后跟没有前两天那么疼，仍不能走快。巷口早点摊正收蒸笼，热水顺石缝流过来，她绕了一步，文件袋碰到自己膝盖。这个早上没有哪一件事要赶在一辆车开以前做成，她却仍一进门便想把纸掏出来。

何映半跪在报架边找书。昨天有人夹在报纸里还了，她照本子上的号翻了两轮才找到，拿起来时一张广告单掉到地上。沈禾替她捡了，没把广告和自己的稿一同放上桌，先问那支笔用得上吗。

“用得上。那支我都不敢竖着放了。”何映接过去，在废纸角点了点，“你带的东西要留几天？”

“今天先看。我在这里，看完拿走。罗叔只答应你一个人先看。”

何映手里的笔停住，随即把旁边的借阅本推远一点：“那你坐这边。我总觉得你都封好了，就是给我收着的。”

沈禾把袋面转给她看，字只写何映先看，没有写归还日期。她没说对方看漏了，给自己的本子加了一笔，才取出三页，将那页自己如何开始听旧声的文字也放在前面。

何映先读沈禾的。屋里有潮木头和洗过抹布的气味，窗外卖早点的人大声清点蒸笼，她读到一半，把椅子往亮处拖一点。沈禾本想指给她看下一段，手伸出去又拿回来。她原来预备了许多开头的解释，坐在旁边才发现，对方在读纸，自己不说话也没有什么塌掉。

读到罗敬的首说，何映轻轻念出两个字“船等”，随后将后面的几行看完，笔尖点在“我说多了”旁边。

“这句放最后，倒好记。”

“前面也得在。”

“我知道前面有。我是说以后真能讲，总得有个收尾。听的人回去能说一件事。”何映将纸往她这边转了转，“不然有人听完，只记着你们去开过一扇小门。”

沈禾看着那三行。自己确实也喜欢这句话，像把一个绷了很久的结松开；如果只在末尾留下，别人记住的恐怕是罗敬认错了，连他记准的两下都没有地方放。

“那也不能只靠他这句收尾。两短是对得上的，船等不是灯片能说明的。他后来把混进去的喊话分开，也没认是哪一回。”

何映用笔背按住下端，没有划。她又回去看最前面的原说，看工作稿写的用法片只管岸端暂停放行，没写船停在何处。读第二遍时，笔尖从那句改口上移开，落回最前面的两下。

门边忽然有人叫何映，是来续借的一位男人。她把三页朝沈禾一推，起身去柜边找本子。沈禾合好放回袋，没夹在报架里代占位置。男人只带了手机，书留家里，何映问哪一本，他说红皮的，翻出照片又是一册蓝皮。两人各自看了半天，才把登记日找出来。

他走后，何映回来先喝水。沈禾没有立即把稿重开，等她自己将杯子移开，才把三页摊回原来的顺序。何映问刚才那句能不能在罗叔看过后另想个办法，沈说可以，但这份现在连屋里朗读都还没答应，不能先拿句子去贴预告。

“先让我看明白了，也算一回。”何映说完笑了一下，“这话是安慰我自己。”

“你要是觉得我这页更啰唆，也可以说。”

“你那页是真啰唆。开头找文件、后面又说找文件。我读到第二回，还以为你已经出门又回家。”

沈禾低头找到那里，两处动作中间漏了自己在家吃饭的转折。她在自页上画一个小圈，不当场改罗敬看过的文字，准备回去把自己的时间写清。何映没继续挑字，拿起最后一页，一直读到下角，再和第二页对过页次。

十点三十七，陈玉荷独自进来，还的是孩子的一本书。她先把塑料封面的水擦掉，见沈禾收纸，问父亲那天看的那两页还在不在。

“在我家。今天没拿来，这是另一份，只给何姐先看的。”

陈玉荷说自己不是来讨同一份，又从包里抽出一张便笺。上头只写了两行，字挤得紧，写父亲前天下午看完纸，回去睡了一觉，晚上吃了半碗饭。她本想发给妹妹，放在手机里改了几次，最后抄到纸上，越看越觉得像给谁交差。

“我写他能出门，她就说挺好。我写他走得慢，她就叫我别急。怎么说都像我在嫌他。”

何映先把书翻开，发现里头夹着孩子的练字纸，递还给她：“这一张也别落这儿。回家又得找。”

陈玉荷接过，折便笺的手便空不开了。沈禾替她按住桌沿，没读那张练字纸，只问她便笺里有没有自己想说的事。她说有，又用拇指挡了最后半行，像忽然觉得带来让人看也是一件多余的事。

何映从柜里取一只信封，陈玉荷看了，先说不用帮她封，写成信更不知道怎样寄。何映说是装孩子的练字纸，别再从书里滑掉。她这才接过去，试着把纸折小，折到印着孩子名字那一边，又展开重折。沈禾将自己的文件袋往里移，桌上腾出的一块恰好够她放平，不必三种纸都捏在同一只手里。

“我想说我那天一路扶着他，回家腰都直不起来。可写在他吃半碗饭后头，就像怪他吃少了。”

沈禾想起自己当时给过一支笔，人家没有接。那时她只急着把邱稿收回来，似乎空纸一递，别人的需要便也有了去处。眼下陈玉荷仍坐在面前，张口时先看何映的钟，怕自己耽误两人的正事。

沈禾指了指便笺空着的背面，问：“要不要先不跟饭写一起？你先说你自己那天怎么回家的。”

“坐车。不然我还赶着接孩子。”

“那就从坐车写。也可以不写给我们看。”

陈玉荷抬头看她，像这句比怎么写更有用。她没有把纸交出去，在背面写下“那天到家，我先坐了五分钟”，写完停了一阵，自己把原来正面的两行折在里面。父亲吃多少饭还在，不必删掉，自己的五分钟也终于不是接在后头的一句抱怨。

她收起便笺，问大字的事有没有希望。父亲昨晚还问，下一次若仍得她替着念，就不去了。何映说屋里普通报纸也有大字版，可以先来坐，不等沈再办。陈玉荷摇头，说他想自己慢慢看完那两页，不是把所有大字都拿给他便行。

“我可以先排一份更大的，让邱阿姨看。她还没答应下一回，不能今天就给你带走。”沈禾说。

陈玉荷叹口气，终于笑了：“你别排成十张。我们家桌上没这么宽。”

沈禾拿本子量了一下纸宽，说会先放到小桌上试，别为字大叫人把脖子转得更累。没有约父亲哪天来，也没留下他家地址。陈玉荷自己说等还下一本书再问，拎包走时将练字纸放进了单独的一层。

何映把收回的书摆上架，才说前天下午那份校样送了，对方当时没看完，昨天又叫她重排一页，今午还得做。她从帆布袋翻出折四折的旧纸，蓝笔十七点十分那行横过折痕，正面的旧时段已经过了，她却没有扔，下面另记了今天要改的页。

沈禾看过就把眼睛移开，没有问挣多少。“我十一点前走。三页都看完了吗？”

“看完了。稿你收，我不替他挑那句好记的。”何映将页角对齐，“下次你只带自己的新页，也能坐一会儿。别每次都等东西全齐。”

沈禾收好三页。临走她想把笔拿回，见何映已经夹在借阅本上，便说先用，哪天路过再取。何映举了举笔，旧字条仍折回自己的袋里。沈禾走到门外，听见按键轻响一声，才想起自己今天本来怕没有话讲，竟一句旧录音也没有放。
