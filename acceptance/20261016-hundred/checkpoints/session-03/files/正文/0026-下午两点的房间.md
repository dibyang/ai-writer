# 第二十六章 下午两点的房间

第八天，沈禾煮的面粘在锅底。她先前怕扑出来，火关得太小，转身去听梁秋发来的补录，再回来挑，半锅已经结成一团。她倒进漏勺，挑了还能分开的吃，余下那点没有留给中午。

九点多，宋俭发来消息，说河街阅览间的何映想问旧站整理的事，能不能把她的号码给对方。沈禾问是借东西还是问一问。宋回说自己没有替她答应，请她直接谈。

她同意了。何映打来时，她正在听课程的一段低声，摘耳机慢了一拍，电话已经响过五声。

“下午两点来行吗？我现在做活。”

对方应得很快，说房间上午十一点关，下午两点才开，不必早来。她把地址发过去，后面补上自己的名字，姓何，映照的映。

十一点半，沈禾把补录接回工程，只作工作剪接，不改原收到的文件。窗外有人修雨棚，她改用耳机听完最后一遍，摘下时耳朵热得发胀。桌上的杯子还是昨晚两只，她只取自己那只倒水，另一只洗净放进柜里，没替明天留座。

下午两点，阅览间门前的铁链还没有收起。何映用膝盖顶住门，正从帆布袋里翻钥匙，袋里一盒印泥被带出来，险些落在台阶上。沈禾替她接住，她道了谢，开门后却先去看桌角。

“昨天走时明明扣好了。”

桌腿旁积着一小撮纸屑。她蹲下，把一块磨松的塑料脚垫按回去，抬头才正式看沈禾。三十五岁上下的女人，额前头发被风吹散，衬衣袖口沾着印泥。她没拿出沈禾预想的介绍信，先叫她把窗开一条缝。

屋里两张长桌，墙边报架，一排小椅子。何映将椅子从桌下拖出来，试着排成两行，还没摆完，一个提布袋的老人进来，站在报架旁，问今天是不是有别的事。

“先试位置，您照常坐。”

何映把椅子递回去。老人坐定，又将椅子往亮处挪，恰好挡住刚排的那行。沈禾原想帮她再往里挤，何映却推散了那一行，将几张椅子靠回墙边。

“下午有人接孩子前来坐会儿。我跟你谈活动，也得让他们有地方。”

她们只占长桌尽头。何映拿出一张背面有错字的打印纸，正面写“旧渡口的声音”，下面的日期空着。

“宋师傅说，你把旧录音听过，也查过几份纸。我想请你讲一回。这里以前办过读书的，来的人不多。”

“要放录音？”

“有声音总比我念纸好。再放几张旧东西的图，半小时，够不够？”

沈禾没有立即打开电脑。纸上的半小时很宽，能放下母亲重念两遍的话，还能放下她这几天走过的路；可邱阿兰在缝纫机旁叫她别只记母亲那一句，罗敬也只答应过代存。

“我能讲我自己做了什么。别人的话，还有录音怎么用，得另问。宋俭收东西，不等于替他们答应。”

何映在纸上写了一个小小的问号：“那你母亲的声音也不能放？”

沈禾先说那是母亲，何映等着，她却不能顺着这三个字把后面全接过去。录音里并不只母亲一个人；就连自己认得的那部分，也还没有定好在这里会怎样被截取、怎样讲。

“先别把放声音写上去。我给当事人看说明，再跟你说能用哪段。”

何映将笔搁下，轻轻向后一靠。沈禾看得出她失望，原先准备指给自己看的墙面也不指了。老人翻报纸，纸边擦着桌面，一下一下响。

“那还能讲什么？”何映问。

沈禾告诉她，有一段改候船的广播，已经和签记、调度纸及邱阿兰认过的回记对过，说明当年的通知怎样送到候船处。她只讲已经核过的那部分，没有报邻页人名，也没有提罗敬的旧约。余带有不知道来处的声音，不能拿来配成一个下午。

何映听完，拿起笔，将标题旁自己画的一只小喇叭划掉。

“我原来想得太省事了。你来讲一遍，我开门搬椅子，结束就算办成。”

她说自己只领这几个开放时段的报酬，上午收书，午间赶排版，下午再来；要办在晚上，就得找人替她看店。沈禾这才看见帆布袋里还露出另一摞纸，页边排着密密的表格，不是给她看的活动材料。

“没关系，我们慢一点。”沈禾说。

“慢可以。不能每次都等我下班以后慢。”

她怔住，何映却已经把笔递过来，说不是赶她，先在这半小时里挑最想让人带走的一件事。沈禾想了好一阵，写下“谁把一句话送到”。写完又划掉“谁”，改成“这句话怎样送到”。

何映看着被划的字，没有替她誊清：“保留这个。我问的时候，可能还会这么问。”

三点刚过，两个孩子背着书包进来，走到长桌旁看她们的纸。何映让他们去窗边，孩子说那边桌面歪，写字本会滑。沈禾这才明白方才那只脚垫并没有真正修好。她和何映把桌上的笔筒先移开，一人抬一头，换了墙边那张稳的桌子。报架前的老人不肯起身，她们绕了另一边，门口来回让了两次，才把桌挪过去。

做完，何映将活动纸收进夹板，没有再排那两行椅子。

沈禾提议去问宋俭，想知道如果只是用已经拍下的工作图作说明，他还要核什么。何映先请老人替自己照看十五分钟，走到门口又停下，改了口，说来回不止十五分钟。老人指指墙上钟，让她把要回来的时候说准。

她们约四点回。何映把不能外借的柜门锁上，给两个孩子留了铅笔，才同沈禾沿河街往里走。十五分钟到服务室，宋俭正在吃一只冷包子，桌上摆着没填完的单。

何映叫了声宋师傅，没先提开柜。他把包子吃完，擦手，才让她们坐。

“东西在这里，不会丢。”他说，“你们要办事，别又把人一拨拨领来，让我见一个开一回。”

“我们想先听你说能给多少时间。”沈禾说。

宋俭拉开抽屉，找出一张值班表，用手盖住别人的号码，指给她们看自己能在的半个上午。他没有许每周加开，也不让何映将今天坐过的两把椅子算成固定接待处。

里间门开着，沈禾隔门看见箱子仍在干板上，原袋的旧标签朝外。她没进去拿。何映往里看了一眼，只看见封着的箱，没有见牌。

“代存的还是代存。”宋俭说，“照片原来准你作工作记录，贴出去要另讲。先把要用的几张和说明放一块，我跟林秀核；别先印一墙，再问我行不行。”

沈禾说自己明白，心里却有一点烦。带回来、找人看、再拿来问，她刚刚才结束那样的一周。她低头把椅脚旁一小块包装纸踢开，鞋尖碰到桌腿，宋俭将未填完的单往里移了移，让她的膝盖有地方放。

她没把那点烦说给他听。柜子锁着，箱底垫着干板，自己不必再背着原带走，便也不能把有地方放当成别人多出来的时间。

何映说先不定公开日期。宋俭这才翻回单子，问她们是不是还要开箱。沈禾摇头，今天没有为了问活动搬出原物。

三点四十，她们离开，十五分钟回到阅览间。老人把报纸翻到最后一页，听何映道谢，只说那个小的借了两回橡皮，请她记着收。何映回到桌边，先找橡皮，没赶着将谈好的事写成结果。

沈禾帮孩子从桌缝捡出来，橡皮已经被抠掉一个角。何映说用还能用，别往缝里塞。孩子问她们是不是要放电影，她说暂时不放，仍可坐这里写字。

那张活动纸最后收进抽屉，日期继续空着。何映问她要几天，沈禾答明天先找一位当事人，不能保证一回便问完。

“你愿不愿先来一场没有观众的？”她问，“我把自己要说的念出来，让能来的人先听。不是叫他们给我点头盖章，是听见哪里被我讲错了。”

何映从抽屉将纸抽回半截，在背面写“先试读”。她问不来的怎么办，沈禾说另约，或者那部分先不用。

“那我先留桌的一头。”何映说，“整间屋子，现在不能全答应你。”

沈禾点头，离开时没有再要那张标题纸。她走到缝纫铺门边，听见邱阿兰的机子还在响，便没敲。她在街角翻开本子，给明早留了一段，准备先问罗敬方不方便；要带去的纸上，得先写清东西现在在哪儿，不能一进门便又向他要一件事。
