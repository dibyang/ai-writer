# 补帆人

文体：novel；新建长篇隔离方法实跑，非用户真实作品。

作者已给方向：修船学徒想保住师傅留下的船坞；偏温和现实日常，主要关系合作；不添加阴谋、神秘电话或超自然。

故事承诺：跟随一个手艺尚未成熟的人，理解他怎样通过维修、协作和承担日常责任争取留下船坞。保住的具体含义、产权或租约、资金规模、地域年代、师傅当前状况、最终结果均未定，不从“留下”推断师傅已经去世。

普通细节供本次模型推演：学徒暂名林遥，熟识的修船朋友暂名余青；先使用克制的第三人称近距离视角。名字与视角是可撤回的工作候选，并非作者新增核心选择。

篇幅：按 long 模式验证规划方法，尚不承诺总章数或百章供给。近期只保存三章方向；全书远期保留骨架。读者目标暂取愿意看手艺与合作关系逐步变化的人，不作商业或市场判断。
