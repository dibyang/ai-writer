# 28 走远一点的路（6/6页，0—10463）

目标：许独买合脚鞋/周真关门散步/沈为下周一早班安排家中早餐，女观察自己的裤里外损伤。选择：许不将黑鞋大码硬凑，试灰双脚走后买38、付100找62（50+10+1+1），原鞋自袋不拿盒；周16点才出门贴17回，不再等整点、16:58真回，河边拒立即跟去纱门；沈核老板早出买干货与粉袋另送非同车、约搬到干板/15:30早走，父自热深柄碗不过满。后果：新鞋仍会脚累/袜扭需捋，不是消费解决全事；错过看门人身份未知不追造；母衣又洗仍右肘凉留一夜，女只记周日又洗不造穿后结论。

关系/所知：母明确“你买自己的，我想粥”，女不默认多买一份；父讲自己问的是家里早餐，沈从答自己吃店饭的误解改听明；女问母裤衬垫法，母自旧法鼓不冒同款适用，沈只看照片说清不代老师给缝法。

物钱时：第21日周日换班女17后走，沈仍工作、下周日才全休；母灰鞋38/找62独立于26风扇16与未来E柜62；鞋票内格/旧鞋纸上待刷/米另提；坏旧灯仍未修。母工装晾右肘朝外、针盒待课袋/裤仍无拆；沈8册留床头里、白书签原页/干旧水印，没带店；父粥煮后放凉深碗冷藏/早隔水热关火再拿，咸菜可自开/布低架，不额外摆全套勺。伏笔：纱门照片只约次日18前来问、非前门预约，同两约区分；私散步有错失客户代价，仍不等于不负责任。无新确认硬问题。
