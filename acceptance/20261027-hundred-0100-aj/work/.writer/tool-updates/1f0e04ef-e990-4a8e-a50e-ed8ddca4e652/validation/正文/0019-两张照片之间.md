# 第十九章 两张照片之间

第六天早上七点半，沈禾在家里摊开电脑。母亲那只硬盘仍在抽屉，原样留着，她打开的是第一天拷出的工作副本，旁边另放昨晚的原带转录。

她先比两遍完整广播，字相同，“请”的长度却都对不上。往前退到试话筒的那一声，断口前的气音才接近起来。沙声里还有两下很轻的碰响，在旧文件里几乎听不见，放大看，起伏的位置也相近。

沈禾把两段交替放了三次，没有挪来后面的字给它接尾。旧文件的尽头仍断在那里。这让她更倾向于同一遍试读，却还不能替整盒带子写一个日期，更不知道是谁选出这不满半分钟，为什么放在那个目录。

她将比对位置记下，合电脑去修理店。到店先补了一日暂放费，接到明天早上。顾遥在门口给手推车轮上油，听她说箱子今天还不能搬，便指指台历让她自己添。

“不是怕你不付钱。明天真要搬，别一个人抱着走。”

“我先把接收的地方看好。”

她没有取顶架上的箱。八点四十离店，背着原带和钥匙，二十分钟后到了旧站。唐穗正往院里移一只空铁架，手机夹在肩头，沈禾替她扶住架腿，等电话讲完才松手。

“灯的拆费，我出。地方今天上午再问，没接收的，先不动。”

唐穗看了一眼灯：“那我不叫人白跑。十点以后要改，你自己跟师傅说。”

九点十分，周砚进门，将旧抄纸放到窗前。纸背的铜牌字样还标着沈禾述，正面的两栏下添过见续页。他没有再添新去向，先打开手机，让她看一张连着书脊拍的照片。

“昨天午间回去找的。前面那张缺角，夹在后面的纸向里折了，得让管册子的人展。原册没领出来。”

他说昨天等人开柜，午饭也一起放凉了。沈禾问怎么不先吃，他说那人还要赶另一处，自己吃完回来，册子又得锁。

“她也没吃。别等你去了，先说一句怎么现在才找着。”

沈禾将窗边那只大夹子挪开，给手机留出平地方。那是他第二天送来的，弹簧没有松，夹过的衬纸边沿却压出了一小道印。她抚平纸边，说不会那样问；这句话说完，又觉得自己原本确实有一点想问。周砚没看她的脸，等她坐好，才将屏幕转过来。

沈禾先看前页照片，再看这张。页头写“航务杂存续表”，书脊附近能见前页翻起的破边。下面两行是“航务散页一袋，移镇航运服务室”，另有“口信登记二册，随袋”。接收栏盖了一枚章，压住一部分小字。

“这地方还在？”

“房子在。袋子还齐不齐，得过去问。”

她本来只盯着航务，视线落在口信那一行，才回头看昨晚的记录。给候船室捎句话，听上去像让人传一声，不一定是广播给所有乘客听的内容。她原先想从泊位找一班船，如今得先找那个接话的地方。

周砚将两张工作照片发给她。她收到，放大检查页头和下缘，没有把盖章那片模糊处猜成名字。

“二〇一三是清点。”他说。

“我知道。不是传话那天。”

他收起手机，看了眼她的电脑包。沈禾问要不要听今早比过的那一小段，他抬腕看时间，先说今天不能坐完。她没把耳机递过去，改将昨晚记的试读、两遍广播和缺起首画给他看。

“等你有空，我从头给你听。不是只拿对得上的那声。”

周砚低头看那三个分开的小格，忽然说：“你原来总说，我听一遍你就明白。”

她想起来，有一回在学校排节目，他硬是没听出她调小的那一下，最后耳机被她拿走了。她笑了一声：“这回你可以听不明白。”

他也笑，将纸给她留在桌上片刻，自己去门口接电话。沈禾等他回来，把前天开箱的照片亮给他看。周砚这才在屏幕里看到那块牌，浅色布、原箱内的位置和右下两条线都在；她说是唐穗来看那次拍的，不是首日。

接着她给他看灯门原位照与检查页照，说清许成开门、罗后来改口、自己用原钥开现柜的先后。他只听她讲试锁，没见原钥，问了一句检查簿现在在哪儿，便没拿三处年份互配。

唐穗从院里回来，沈禾当面告诉她，续页照片写有镇航运服务室和口信登记，想今天去。唐穗从夹板内的联系页找到服务室号码，让她自己打。

接电话的人姓宋，名字叫宋俭。他听完清点年份与袋名，没有答材料一定都在，只约十点半来，十一点半他得带人验窗，晚了要另等。

沈禾记下地址，问清是河街往里的旧办公院，不是客运大厅。她将十点半写到本子上，唐穗在一旁收起联系页，没替她答应那边能接箱子或灯。

九点三十八，周砚收回自己的抄纸，要赶新渡口。她送他到门外，没有叫他一起去。他问今晚能不能留一顿饭的时间，沈禾没立即说能，翻开本子看了眼，才说七点以后，地点由他定。

“那我六点告诉你。别先站饭铺门口等。”

她点头，看他沿堤走远，回来替唐穗把空铁架推进院角。九点五十八，沈禾背包离站。她照着刚问到的地址往河街里走，手机里多了两张照片，箱子却仍在原来的架上。
