# 人物性格与情绪反应一致性审查

先读 `general-review.md` 的人物基线规则。审查人物塑造、情感情绪、同场多人反应、跨章人物弧线，或关键选择与既有性格看似冲突时，使用本模块；高压心理节点再结合 `psychology-readability.md`。目标是让读者认出“这是这个人会有的反应”，同时允许人物被经历改变。

## 从正文建立人物基线

只用已经写出的言语、选择、沉默、注意力和后果建立基线。先找人物在平常状态与受压状态各如何处理一件事，再看其欲望、顾虑、身份与能力、关系亲疏、惯用的自保方式。区分人物**公开说法**、**实际行动**和**叙述者推测**；设定表可帮助定位，不能替代正文证据。材料只有一段时，只判断段内是否可信，把跨章一致性记为证据不足，不补造过去。

性格是倾向，不是反应公式。“冷静”者可能先处理手边的伤口，稍后才发抖；“冲动”者面对某个人也可能迟疑。不要把一次失态写成性格崩坏，也不要用性格标签免除行为的因果解释。

## 同一事件，多个人的反应

挑选真正共同经历或得知的关键事件，先核对影响抉择或关系的人物**何时知道什么、误以为什么**。再逐人检查：这件事对他具体威胁或带来什么；他先注意谁或什么；想保住什么；对谁能说真话；最后做、说、忍住或拖延了什么。比对反应的**关注点、解释、时机、表达方式和代价**，不要只比“愤怒/悲伤/害怕”的标签；短暂在场但不改变事件的人物无需补内心戏。

同一情绪可以导向不同动作；同一动作也可能出于不同动机。两人都沉默时，一个可能在保护证人，另一个可能怕暴露自己。差异须由已写出的处境和关系支撑，不必为每人硬配一种情绪、口头禅或招牌肢体动作。群体在危险面前有相似反应也正常；问题是所有重要人物都自动说出最周全的分析、按同一节拍发怒或服从，只为推动情节。还要检查互动的下一拍：甲的迟疑、隐瞒或冒犯是否改变乙的判断，乙的回应是否反过来改变甲的选择；不要让多人只轮流陈述完整立场，彼此却不受影响。

## 跨章检查：稳定、变化与余波

对重要选择比对“先前相似处境 → 本次触发与新增压力 → 当前反应 → 此后行为”。核查人物知道的信息、积累的损失、关系变化、身体状态和可用选项是否已变；这些变化可以解释看似相反的反应。真正的成长、退缩或破例应在正文中有可追踪的诱因；若已有后续文本，再看它怎样影响关系、习惯或决定。变化可以迟到、反复，不要求线性成长，也不要求每章重复交代创伤或写出内心独白。

特别核对关系差异：人物对上级、陌生人、亲人、旧敌与被自己亏欠的人，不一定使用同一种语气或控制力。若对所有人都采用同样的善解、强硬、机智或牺牲方式，检查是否丢失了关系里的历史和利益。若本次突然改变态度，不急于判错，先查是否有足够的事件、时间与代价连接前后。

## 情绪落到行为与叙述

审查情绪时，问“事件在这个人眼里意味着什么”以及“这层意义怎样改变了注意力、说话、动作或选择”。可以有矛盾：想救人又怕担责、爱一个人又不信其判断、赢了却不敢庆祝。克制、走神、忙于手续、转移话题和迟来的反应，都可能比直说情绪更贴合人物。身体反应、回忆、误判与余波按场景取舍，不要把每个人写成同一套‘心跳—手抖—回忆—顿悟’流程。

检查对白和叙述视角是否替人物说了作者才知道的话：在当下压力里，他会用哪些词、避开哪个名字、先问哪件小事？不要把所有人润色成同一种漂亮、理性、结论完整的声音。也不要为了“真人感”强行加入哭泣、失控、脏话、笨拙或无谓的犹豫。

## 判断与反馈

- **硬问题：** 有清楚的前后正文证据证明关键选择、信任或情绪转向与已建立的人物逻辑冲突，而文本没有可支撑的触发或变化；或多名重要人物在关键事件中持续共用一套信息处理与说话方式，导致角色互换名字仍不影响场面。指出两处可定位证据及其对关系或情节的影响。
- **需优化：** 反应本身可能成立，但缺少人物如何理解事件、为何此时破例、或情绪怎样影响下一步的一处关键连接。优先建议补一个具体选择、迟疑、遗漏或关系后果，不泛泛要求“加心理描写”。
- **不判问题：** 仅因审稿人预设“这种性格一定会怎样”，或希望人物更激烈、更温柔、更讨喜；单次不典型反应已有压力和情境支撑。把材料不足与正文矛盾分开。

审稿时给出人物、事件、前后或同场的原文依据、具体不一致处和最小修正方向。跨章连读可用简短对照表定位变化，只报告影响重要决定、关系或人物可信度的点；不按出场人数或节拍数量扣分。没有高置信问题就明确说没有。用户只要求审查时，不直接改正文。
