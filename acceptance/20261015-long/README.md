| 阶段 | 实际结果 |
| --- | --- |
| novel-stage-a | 1164秒，40个完成的命令事件；实际写1–3章。错误层级的previous_holder被拒绝，同一写前模板修正后成功 |

| novel-stage-b-retry | 从根目录显式指定作品恢复，1169秒、43个命令事件，完成4–6章；收尾有TLS重连，自动恢复后完成 |

| final-recheck | 397秒、15个完成命令事件；19次随附工具调用全部成功，4个新导出一致，最终323文件基线0差异；不算新创作 |

初次进程的环境失败、两轮候选、旧工具、旧导出和重连日志都保留。发现问题与修复汇总见 [defects.md](defects.md)。Windows嵌套cwd启动问题仍属宿主限制；本轮验证成功的入口是根目录启动并显式指定作品，未关闭sandbox、重装环境或改全局配置。

最终只读复核期间，主会话曾新增并迁出一份旧报告归档；首次差异输出保留，不能写成全目录整个运行期间无变化。归档来源及原哈希证明见 [archive-note.md](final-recheck/archive-note.md)。正文、state、工具不因归档而改动，最终再按原始基线复算。

最终复算确认323个原文件的哈希、大小和mtime一致，包括13个正文与4份state；候选65项哈希（主目录13+四书52）一致。复核会话的报告辅助脚本有两次解析错误及一次被拒的机械替换，均保留输出并在本轮验收目录内修正，不与19次成功的产品工具调用混算。原始记录见 [最终复核结果](final-recheck/result.md)。

## 边界与交付状态

本轮没有覆盖完整百章/百万字持续创作、真人无提示阅读、市场数据、真实排演、历史影印校勘、Linux/其他Node版本或在线CI。旧作导入当前支持明确顺序的UTF-8分章文件；合订本需先保留原文并按真实章节拆分。卷纲来源采用保守的整文件保护，已消费卷纲调整需核实影响后回退；未来章纲可正常滚动细化，未提供卷内未来arc的细粒度免回退修订。

未移植平台爬虫、Cookie/浏览器管理、自动封面/发布、全局作者记忆或完整跨书灵感索引。项目仍为0.2.0本地候选，整体许可未改；未提交、推送或发布，未额外调用付费生成接口。
