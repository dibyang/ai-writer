# 第一章 五针白线

十一点十分，何素琴把最后一张时刻表卷起来，皮筋刚套上，十六号寄存柜的门弹开了。

里面还有一只木箱。

她弯腰把它搬上柜台。箱子不过四十厘米长，棕漆磨得发灰，腰上拴着一根灰布带。明早这里不再发车，别人连墙上的钉子都数过了，它倒安安稳稳留下来。

蓝布箱把让她想起家里的旧箱。小满上学那年，她也拿碎布包过把手，怕刮破孩子的手。后来箱子去了哪里？她正想，侧门吱呀一声，小满背着包进来了。

“不是说明早到？”

“路上耽搁了。”

“坐哪班？”

小满没答，先把包放在脚边，朝电饭锅看了一眼。何素琴想起饭早已凉了，开关按下去，又跳起来。

“这是不是咱家的？”她拍了拍木箱，“你以前装课本那个。”

小满凑近看，摇头：“不是。”

她答得快，何素琴有些不乐意。小时候什么都往这儿放，长大了，连自家的东西也不认。她把箱把翻过来，想找自己缝过的线头。

蓝布根部有五针斜白线，第三针跨着一块月牙形焦痕。

门边响了一下。郑来顺把工具袋搁在地上，扳手碰出了声。他原本来道别，眼睛却停在箱把上。

“先别给她拿走。”

何素琴的手还压着灰带：“你认得？”

郑师傅拿袖口擦了擦眼镜，没立刻戴回去。

小满往后让开半步：“我也没说要。”

何素琴这才听出自己方才那句问话，已经像是在替人做主。她松开灰带，掏出手机，把五针白线拍清楚。屏幕里第三针还在焦痕上，屋里三个人，谁也没再说这是自家的箱子。

# 第二章 先替我拿稳

小满指着照片，说自家的箱子右下角烫黑过，是她烘棉裤时碰了火炉。

“你拿鞋油涂，越涂越亮。”

何素琴想起来了。为这事，她骂过孩子半个上午。眼前这只箱子的角虽然掉漆，却没有那块黑。她把手机扣在柜台上，不再提装课本的事。

郑来顺戴好眼镜，隔着柜台看箱把。

“这种布把，我以前帮人修过。底下垫块皮，才不勒手。”

“那你说是谁的？”

“修过好些，哪敢就说。”他抬眼看了小满一下，“刚才我话也急了。不是说你要乱拿。”

小满嗯了一声，蹲下把背包拉链拢好。

柜台外就是值班桌，靠墙的位置空着。何素琴双臂托住木箱，绕出柜台。箱底蹭着袖子，她才觉出两只手被压得发酸。

“老郑，先替我看着。等查清了再交人。”

郑来顺点头，把双手伸到箱底。她等他说“接住了”，才抽出胳膊。郑师傅把箱子平放在值班桌靠墙的一端，灰布带原样拴着。他拉过椅子坐下，没有碰箱扣。

“我再找找以前的照片。站里照过那么些，兴许有。”

何素琴这回没催。她端来搪瓷碗，用壶里的热水烫了一遍。小满站着没动，裤脚湿了一截，鞋边也糊着泥。

“早说到，给你留点菜。”

“饭就行。”

电饭锅还是按不下去。何素琴索性往饭里添了热水，拿勺子慢慢划散。她想问店里是不是又扣工钱，话到嘴边，看见小满正把滴水的背包挪离桌腿。

她盛起半碗泡软的饭，连汤一起递过去。

“碗拿着，小心烫。”她说。

小满双手接过去，低头喝了一口。郑师傅在桌那头翻手机，屏幕一亮一暗，木箱还在他的胳膊旁边。

# 第三章 车棚里还有一辆

墙钟过了十一点半。郑来顺守着桌靠墙端的木箱，还没翻到照片。何素琴从抽屉取出登记簿，摊在自己跟前，指头沿日期往上找。

九天前那行字不是她写的：六十一号车转下，存十六号柜。领物人一栏空着。

她把“六十一”念了两遍。刚才总想着十六号，差点连该问哪辆车都弄反了。

“胡建民开的。”郑师傅说，“他还得回来交钥匙。”

何素琴把簿子摊着：“那我等他。”

小满喝完泡饭，把碗送到水池边，拧开水龙头。

“留着，我来洗。”

“冲一下又不费事。”

何素琴没再抢。她在领物人那格旁夹了一张空纸，没往里填自己的名字。没有人来认，也不能因为明天搬站，就算成已经交代完了。

小满擦干手，说车棚里还留着一袋东西。何素琴拿上侧门钥匙跟出去，想帮她提。车棚的灯只亮半边，空车架尽头停着一辆旧自行车，车篮塞着鼓鼓的布袋，泥水滴在水泥地上。

“你骑回来的？”

“借同事的，过几天还。”

何素琴伸手去解布袋。绳结打得紧，她越急越解不开。小满的鞋跟磨破了，露出一小块白袜子；她方才还在问坐哪班车。

“我不在那家店干了。”小满说。

何素琴抬起头。她想问是不是店里不要人了，女儿已经侧过身，仿佛在等这句话。她把问话咽下去，让开手。

小满两下解开绳结，把布袋递给她。

“工钱……”何素琴开了个头，又说，“回去再讲，外头冷。”

她提袋先往亮处走。屋里郑师傅还坐在箱子旁边，侧门的灯没关，照着母女回去的那一小段路。

# 第四章 钥匙还在他手里

何素琴把布袋放在椅子底下，掌心沾了水，正往衣襟上擦，侧门又响了。胡建民夹着一件棉袄进来，钥匙还在手里。

“家里催第三遍了。”他把钥匙往桌上一搁。

“等一下。九天前，你车上转下这只箱子？”

胡建民弯腰看了看，棉袄滑下来，他用胳膊肘夹住。

“是。我那天水箱漏了，让人换车。周大姐的女儿开车来接，她抱个布包，招呼我一声就走了。收车才看见后排底下还有它。”

“哪个周大姐？”

“原来站边补衣裳的。她坐那一排。可我没看见她把箱子放进去。”

何素琴把簿子转过来，指着日期。胡说箱子是他搬进来的，交给当班的人，自己赶着送车修理，没问到电话。

“那会儿想着，她总要回来找。”他说，手指在钥匙环上转了一圈，不催着走了。

何素琴抽出夹着的纸，写“胡建民说”，后面记了换车和补衣摊。她没把那个姓填进领物栏。

郑来顺看完日期，说：“我修过周家的，也修过别人的。先找照片。”

他起身托住木箱：“你接回去看着，我腾手找。手机里都是孙子的照片，翻得乱。”

何素琴把双手伸到箱底，托稳了才说：“好了。”郑来顺松手，她把整箱放回桌靠墙端，灰带没解，箱扣也没碰。

小满递来一条干毛巾。何素琴接过来，才看见女儿袖口也湿着，便把毛巾另一头让给她。两个人一人攥一端，胡建民挪开了椅子，给她们留出坐的地方。

墙钟还差一刻到十二点。何素琴把纸夹回簿子，问胡建民：“你能不能帮着找个电话？”

# 第五章 照片边上的人

胡建民到侧门边打电话，先问从前卖茶叶蛋的老刘还醒着没有。何素琴听他一连叫了两声哥，才把声音放低。

郑来顺终于停下手指，把手机横过来。

“就是这张。老刘前年发我的原片。”

照片里几个人挤在站门口，身后横幅印着“二〇一三年迎新”。何素琴那时候头发还没剪短，一手端着纸杯。最前头的板凳离镜头近，上面放着一只木箱，半边挡住了郑师傅的裤腿。

她先看见自己，笑了一下，才将今晚拍的箱把调出来。郑把原片放大到板凳那一角，两部手机并在一起。

旧照的蓝布根部也有五针斜白线，第三针跨着月牙形焦痕。她低头看桌上的箱把，又数了一遍，没少一针。

“这几针那时候就有了。”她说。

“补衣摊周桂枝那只，我修的。”郑师傅指了指照片边上系围裙的女人，“可她后来借没借给人，我可不知道。”

小满凑过来：“咱家的布还是你拿旧袖套剪的。”

何素琴记得，那只袖套她还留了半截。方才若把箱子抱走，回家再翻到自己的，才真不知道怎么开口。她没再摸灰带，将两张照片的日期记到夹纸上。

侧门边的声音高起来。老刘还存着周桂枝女儿的号码。胡建民挂断后重新拨，朝桌边说：“就说旧站有只箱子，别的我没讲。”

何素琴把笔帽拔开。铃声响了好几遍，她望了一眼小满，女儿把椅子往旁边挪了挪，让她坐稳。

“接通了先让她说，里面装的什么。”她对胡建民说。

# 第六章 再盛半碗

电话接通时，墙钟刚过十二点。胡建民走回桌边，开了免提。那边有人喊“妈”，过了一会，换了个沙哑的声音。

何素琴问箱里装着什么，又问箱把修过哪里，没有提照片。

“给外孙的拼花小被，红格朝外，里头裹个蓝枕套。把底下垫块皮，翘着一个角，老郑说剪短了怕脱。”

她把话记下，请对方报了姓名，是周桂枝。

“我让女儿在换车那头找了好几回。”周桂枝说，“那天催得急，我光顾着布包。被子洗晒过的，别给我拆散了。”

“能解开核一下么？”

“解吧，瞧完替我盖上。”

何素琴这才解灰带，拨开箱扣。小被红格朝外，她掀起折边，露出蓝枕套的一截；翻起箱把，垫皮果然翘着一角。郑师傅凑近看了看，没伸手。

周桂枝说夜里不便过来。何素琴约她上午九点带证件到旧站侧门核验签领。对方应了，又问一遍：“还在老地方？”

“还在，我替你收着。”

她将被角掖回，合盖拴好灰带，箱仍放桌靠墙端。夹纸写上“周桂枝，待到站核验签领”，原簿领物栏留空。胡建民这才穿好棉袄回家，郑去门边收工具袋。

小满把手机递到母亲跟前，是一笔工资到账记录。

“我自己辞的。等钱结清才走，借了车回来，不是人家不要我。”

何素琴看了看。那句“怎么不早说”已经到了舌尖，她把手机推回去：“那先住家里？”

“住几天。工作我自己找。”

“行。饭还要不要？”

小满把洗过的碗拿来：“再半碗。”

到十二点二十五分，壶里还剩些热水。何素琴倒进锅里，慢慢划散饭，给女儿盛了，也给自己盛了半碗。小满从椅下提起布袋，腾出位置，把母亲的凳子拉到跟前。
