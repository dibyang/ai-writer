# 作者声音

依据两章原文归纳的续写约束，不回改原文。

- 叙述贴着何素琴的手、眼和家常记忆走。具体物件承担情绪：时刻表、旧箱把、电饭锅、搪瓷碗；不在动作后再配一段主题讲解。
- 短对白与有起伏的叙述交错，容许停顿、没有回答的问题和改口。何素琴爱问、爱安排，也能以照料收回逼问；小满话少但能给具体记忆；老郑会迟疑和认错，不是随时给答案的人。
- 查证从可见细节起步。五针白线与月牙焦痕可以比对，不能据此一口认亲、定主或推定隐情。
- 保留体力与空间：四十厘米木箱需双臂托住，交接等对方接稳；靠墙的值班桌和柜台有明确相对位置。
- 原文资产：“她等他说‘接住了’，才抽出胳膊”；“碗拿着，小心烫。”日常照料与克制的不追问共同承接关系，不把每章写成推理报告。
- 新章推进一小步即可。不用刻意惊悚的异响、人物整齐说理或总结式金句催悬念。
