# 物理逻辑与操作可实现性审稿规则

Use this module when a fiction review involves key evidence, wounds, objects, body posture, concealment, staged reveals, crime-scene action, archaeology/forensic/procedural handling, or when the user mentions 物理逻辑、操作可实现性、物理可实现、清理顺序、线索出现顺序、伤痕方向、证据怎么来的、不合理.

## Core Principle

A clue may be surprising, but it must be physically and procedurally believable. Suspense timing cannot replace physical cause.

## Checkpoints

1. Reveal order: why this part appears first and that part later.
2. Obstruction: palm, mud, blood, folded paper, seal, angle, light, distance, permission, or procedure must explain partial visibility.
3. Body and object mechanics: posture, grip, direction, pressure, contact, tool marks, stain spread, and wound orientation must support the described discovery.
4. Operability: the character must be able to see, touch, move, hide, extract, clean, or seal the thing under current light, time, tools, rules, and physical position.
5. Professional sequence: record, photograph, locate, clean, extract, seal, and conclude in an order believable for the relevant profession or historical setting.
6. Clue fairness: a clue cannot appear, vanish, split, or become readable only because the chapter hook needs it.
7. Small-object action proportion: tiny or fragile evidence such as wet paper, paper scraps, medicine tags, broken needles, wood chips, seals, page fragments, or cloth corners must match the verbs used for holding, cupping, gripping, pinching, pressing, carrying, hiding, supporting, or covering it.
8. Object-state continuity: the same object must keep a consistent size, wet/dry state, fragility, carrier body part, and storage position across nearby paragraphs and chapters.

## Failure Modes

- Evidence appears according to suspense timing only.
- Body posture, hand position, wound direction, or blood/mud trace cannot support the stated reveal.
- A character sees too much in darkness, distance, crowding, dust, water, or restricted access.
- Forensic, archaeological, medical, military, or legal procedure behaves like a stage prop.
- A symbolic object lacks size, direction, layer, contact relationship, concealment reason, and discovery path.
- Small or fragile evidence uses the wrong action scale, e.g. a palm-sized wet paper is described as being held in someone's arms, a brittle page is casually clenched, or a needle-sized trace is seen clearly from too far away.
- The same object drifts between incompatible states, e.g. a wet wad becomes a readable sheet without handling steps, a sleeve-hidden scrap becomes an arm-held bundle, or an item that required cloth support is later pinched bare-handed.
- Cleaning or extraction reveals text or trace in an order that the object shape cannot support.

## Review Output Add-On

When this module is active, include concise judgments when relevant:

- Physical logic: pass / caution / fail.
- Operability: pass / caution / fail.
- Reveal order: pass / caution / fail.
- Small-object action: pass / caution / fail.
- Object-state continuity: pass / caution / fail.
- Highest-yield fix: the smallest concrete change that makes the object, wound, trace, or action physically believable.
