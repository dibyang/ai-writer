# 安全报告

[English](docs/en/SECURITY.md)

涉及任意文件读写、路径越界、授权或修订保护绕过、令牌泄露、敏感作品外传等问题，请勿在公开Issue中披露利用步骤、正文、令牌或攻击样例。

如果仓库启用了GitHub私密漏洞报告，可从仓库Security页的“Report a vulnerability”提交。是否可用以页面实际状态为准；本项目不假设该功能已经开启。

若没有私密入口，请只创建不含技术细节的公开占位Issue，说明“希望通过私密渠道报告安全问题”，等待维护者提供联系方式。普通功能问题走[反馈指南](docs/bug-reporting.md)。

请在私密渠道提供版本/内容ID、受影响入口、匿名复现、影响与必要日志。勿发送真实作品全文。本项目目前不承诺固定响应时限；更新支持范围以正式发布说明为准。
