# 问题反馈

[English](en/bug-reporting.md)

普通问题使用[GitHub问题表单](https://github.com/dibyang/ai-writer/issues/new/choose)。请先检索重复问题，并说明下载包版本与构建身份、操作系统、Node版本、Codex或CLI入口、预期结果、实际结果及最小匿名复现。记录首个错误码、退出码与调用顺序；多会话问题补充同时执行的操作及发生频率。

先在新建匿名目录复现，优先附最小测试。可在本地查看tool identify、status和doctor，但不要直接粘贴含私有路径、摘要、令牌或作品信息的完整输出。正文、作者规则、研究资料、完整state及修订所有权令牌应删除或脱敏。

升级问题请同时注明旧版与新版的版本、资源配置和内容ID；同版本号也可能是不同候选。保留失败日志及备份，不要手改状态或清除锁来制造成功。

安全问题请按[安全说明](../SECURITY.md)私下报告。贡献流程见[CONTRIBUTING.md](../CONTRIBUTING.md)。
