# ai-writer 0.8.0

首个正式版本的发布说明草稿。当前只完成本地发布准备；最终标签、正式发布状态和资产SHA以实际发布记录为准。

ai-writer是面向Codex的中文创作工具，支持小说、剧本、历史散文、散文与一般非虚构。本版包含七项技能、作品状态追踪、长篇分卷与增量账本、设定影响分析、跨会话保护修订、审查意见闭环、去AI味流程、本地工具更新及草稿导出。

## 安装与开始

下载`ai-writer-0.8.0.zip`和`SHA256SUMS.txt`，核对SHA-256后解压到新目录。在Codex中打开解压后的`ai-writer-0.8.0`目录；需要Node.js 20或更高版本，无须安装npm依赖。

```powershell
node bin/ai-writer.mjs doctor
```

然后说：“创建小说 works/雨夜来信，先规划两卷与近期前三章，本轮只试写第一章，写完暂停；完成审查、登记和检查。”详细流程见包内`docs/quickstart.md`和`docs/user-guide.md`。

## 已有作品与同号候选

先备份，使用包内当前工具的`tool identify`、`tool compare`和`tool update-plan`核对，再按手册显式更新。不要覆盖现有作品目录，也不要只替换CLI。作品正文、作者规则和本地定制不因本次发行而自动改写。

首发包版本为0.8.0，`package.json`中`aiWriter.resourceProfile`为`apache-2.0-v1`，包含65项受管资源。此前内部0.8.0候选没有该标识，0.8.1也是内部许可候选；不能仅凭版本号判断内容相同，应核对内容ID与差异计划。内部候选的历史证据保留原版本。本版不自动联网升级，不自动发布作品。
