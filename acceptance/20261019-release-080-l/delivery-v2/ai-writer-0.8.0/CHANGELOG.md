# 更新记录

## 0.8.0 — 首个正式版本（发布准备中）

- 在Codex中创建、恢复和审修中文小说、剧本、历史散文、散文与一般非虚构作品。
- 长篇支持分卷、滚动章纲、增量账本、结构化线索与知情记录、跨会话恢复、旧章保护修订及草稿导出。
- 集中记录创作阶段、授权范围、作者决策、设定版本及影响，支持跨章复核、登记减负、审查意见闭环和可恢复的本地工具更新。
- 提供按文体的去AI味流程及长篇推进、场景承接等按需方法；机械扫描不代替实读。
- 自有代码、规则、技能、文档及内置story-gate-studio采用Apache-2.0，第三方原文保留MIT许可。
- 增加独立资源配置标识、可校验的下载包、反馈入口和发行说明；同号内部候选按内容ID区分。

0.8.1曾用于内部许可候选，从未正式发行。按作者要求，首个正式版统一为0.8.0；不改写已封存的候选版本、构建身份及验证结果。具体历史验证范围见源码仓库的acceptance目录，正式包验证单独记录。
