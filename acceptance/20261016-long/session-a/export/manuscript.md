# 第一章 檐下的钥匙

雨落在旧泵房的铁皮檐上，陆衡把领取单挪了三次，纸角还是洇出一个灰点。林岚站在门廊里，盯着墙上那道褪色的水位线。汛前简报周五要交，她包里的维护记录却少了一份副页。上回有人把缺页写成漏检，澄清时简报已经发出去了。

陈师傅踩着湿拖鞋来，先把堵在门边的碎砖踢进沟里，才从裤袋掏出一枚铜钥匙。

“清工具箱翻出来的。你们既然查旧东西，就一并登记。”

林岚伸手接住。铜身只有小指长，柄上的油污干成了硬边。她把钥匙转向檐外，灰白天光照出柄边一个半月缺口，缺口里也积着黑垢。陆衡凑近看了一眼，在领取单上添了几个字。

“这是柜房的？”她问。

“说不准。箱里什么都有。”陈师傅把裤袋翻给她看，里面只剩一截棉线。

她想再问，陆衡已经递来笔：“先写接收，开哪儿以后再说。”

林岚有些烦。他总能把她往前赶的那一步截住。可她低头看到领取单，物品用途那一栏果然空着。她没填“柜房”，只写“用途待核”，签了名字。

陈师傅看见那几个字，肩背稍稍松下来。他说镇档案室还存着一个旧牛皮封套，是清理值班桌时送过去的，外面没题名；里面有什么，他没拆过。

“那天谁送的？”

“我。许澄收的。别让人家替我猜。”

陆衡按住被风掀起的单子，让他签名。陈师傅写得慢，写完用拇指擦了擦纸旁的雨水，没有碰字。

林岚把钥匙装进小透明袋，压紧袋口，收进帆布包的拉链内袋。泵房门上的铁锁就在手边，她没把袋子再取出来。下台阶时，她请陆衡给档案室打电话，自己回身扶住陈师傅，把那块翘起来的门垫推平了。

# 第二章 封套里面

镇档案室的接待间有一股湿木头味。许澄拉开抽屉，取出陈师傅送来的牛皮封套，检查了外面的折痕，在临时查阅本上写下林岚的名字。

“只在这儿看。要带走，等我回来登记。”她看了眼手机，“孩子午托今天不留饭。”

许澄把封套交给林岚，锁好走廊尽头的柜房，拎着饭盒下楼。陆衡已经去镇办取申请回执，不在这栋楼里。接待间只剩林岚，窗外的雨打着空调铁架，一阵密，一阵疏。

封套是手掌宽的，翻盖只折进去，没有胶封。林岚擦干桌面和手，托住底边，抽开翻盖。一张窄纸签滑到套口，她垫着封套把纸签移到桌上。

纸签上分两行写着：“七号柜”“副页待核”。

她把身子往前倾了倾，又看一遍。没有日期，没有签名。她原以为拆开就能见到那份薄纸，甚至想好了回去怎样催简报改字；眼前却只有一张让人继续找的纸签。

手机亮起来，是陆衡问回执要不要多取一份。她点开输入框，打了个“找”，又删掉，只回：“两份，谢谢。”待核这两个字使她不敢把“找到了”发出去。她决定等问清查阅办法再解释，仍觉得这一点迟延算不上隐瞒。

她没有给纸签拍照，也没有抄写，把它沿原来的方向放回封套，翻盖压好。桌上有许澄留的窄纸条和胶水；她用纸条跨封口粘住，在骑缝处签了名，外面没写内签文字。

包里的钥匙仍在拉链内袋。林岚把封套另放进包的大夹层，没有带出接待间。她坐回窗边，给许澄留出对面的椅子。那两行字她已经记住了，可她头一次盼着陆衡迟一点回来，好让自己先想好第一句话。

# 第三章 先留一栏

许澄回来时，饭盒上还挂着水。林岚把包口拉好，接过她递来的查阅申请。陆衡随后进门，把两张回执摊到电扇前吹，问封套看得怎样。

“我还没理清。先把手续办上。”她避开他的眼睛。

他没有再问，指了指申请上的柜号栏。林岚握笔停住。许澄说，眼下可以按泵房维护档案申请，柜号等目录核对后补；没批件不能进柜房，就算批了，潮湿的柜背也得先处理。

林岚写下档案名称，把那一栏留空。陆衡将回执夹在申请后，没看她包里的东西。

陈师傅在门口跺了跺拖鞋，送来一张旧值班姓名表。“家里找的。写得清的都在这儿。”

许澄擦了把椅子让他坐。他却扶着椅背，盯住姓名表下角的年份。林岚顺着他的目光问，那年清点时他是不是也在。他的手从椅背上缩了回去。

“十年前那回，我答应陪人清点，没去。”

“为什么？”

“私事。这个别问了。”他把椅子推回桌下，“名单你们用，别把没去也写成我知道东西丢在哪儿。”

林岚本来还想问是谁等他。那句问话已经到了嘴边，她看见他脚上的拖鞋，横带边裂着，雨水从裂口渗出来。他送这张表，特意又走了一趟。她把笔尖挪开，只在旁边记下“本人说未到场”，没添原因。

陈师傅不坐，也没收回表，独自下了楼。

许澄收好申请，给林岚开了临借条。林岚托着封套让她检查骑缝签名，始终没拆封；许澄只记外观和封口，准她带回，明天随补件一同归还。陆衡替两人移开桌下的废纸篓，让林岚能把包放稳。

“批件明天再催。”他说。

她点头，把封套放回大夹层。空着的柜号栏还在她眼前；这回的空白是她自己留下的，等他问起，她得亲自解释。

# 第四章 交给你

他们还没走出接待间，许澄就折回来叫人。走廊窗框漏了水，底下摞着一排空资料盒，最下面那只已湿出深边。柜房门仍锁着，她拿毛巾塞住窗缝，请两人帮忙把空盒搬到接待间的高架上。

林岚弯腰试了一下。盒子不重，一摞却挡着视线，包带从肩头往下滑。她直起身，把包抱到桌上，从大夹层取出牛皮封套。

“这个先交给你。封好了，别拆。”

陆衡没立刻伸手：“你还没告诉我里面是什么。”

“我知道。明早我跟你说，今天先替我保管。”说完，她才发现这要求有些不公平，自己捂着话，却要他接下责任。

他看了她一会儿，找出包里的硬纸夹，打开，平放在桌上。林岚把封套递给陆衡。他接过后只看了外面的骑缝签名，没有揭纸条，将封套夹进硬纸夹，再收进双肩包里层，拉上拉链。

许澄拿临借条过来，补写由陆衡代管、次日同还。两人在交接处签了名，时间是下午两点二十分。

“钥匙呢？”他问。

“还在我内袋。”林岚隔着帆布按了按那只小透明袋，没有取出钥匙。

陆衡把包移到干桌角，伸手托住最上面的空盒。两人一前一后搬，林岚踩上矮凳，把盒子推到高架深处。最下面的湿盒留下晾开，没有混进干盒里。许澄仰头指地方，直到最后一摞摆稳才把毛巾重新拧干。

林岚下来时，陆衡正背好双肩包。她张了张嘴，只说了句谢谢。

“明早别又说没理清。”他替她扶住摇晃的凳子。

她答应了。走出楼门，她习惯地摸向包的大夹层，指尖碰到空布，才把手放下。柜房没有开，副页也还没找到；她却已经不能再把全部事情都当成自己一个人的了。
