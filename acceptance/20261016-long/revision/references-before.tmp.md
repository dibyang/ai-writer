# 雨线档案

文体：现代虚构小说；十二章、三卷；本阶段只完成第一卷四章，每章正文450–700汉字。

背景为虚构小镇清溪，汛前一周。林岚参与旧泵房维护档案核验，希望找齐维护记录副页，让失去上下文的记录能够被准确引用。她害怕乡镇简报又把尚未核清的缺页写成失职结论，也急于赶在汛前完成工作；本书不以抓获罪犯为必需终点。

第三人称有限视角跟随林岚。主要阻力来自材料残缺、手续、柜房受潮与人物不愿说出的私事。读者能看到她的选择与迟疑，不能借叙述进入陆衡等人未披露的内心。

悬疑靠普通物件、信息差与可复核行动推进，克制、不写超自然。涉及的档案程序为本书虚构机构的内部约定，不冒充现实法定程序。没有死亡案、宏大阴谋或真实人物指控的预设。


===== 设定\文风.md =====
# 作者声音

以雨声、纸张、手上动作组织现场，情绪从等待、误会和代价里出来。叙述清楚但不逐条讲解协议；物证编号只留在创作材料，不进正文。

林岚问具体问题，有时急于替含混的话找解释；陆衡先问物件和手续，话短，却会出力照顾人的难处；陈师傅绕开私人问题时可显得不耐烦，不能只做谜语人；许澄守柜房也守自己的下班时间和经手责任。允许口气不同，避免人人都说完整的证据分析句。

每章有一处能看见的选择或变化，不用假惊吓制造收尾。保留自然叙述和短暂缓冲；避免连续用雨、水、阴影比喻秘密。章节长度按正文汉字计，标题和标点不计。


===== 设定\权威规则.md =====
# 权威规则

计划与已发生事实分层：全书大纲、卷契约是作者计划；正文与changes记录实际发生。author_truth只写已确认客观事实，不把未来计划或未定原因写成事实。

1. O_KEY只固定铜钥匙柄有实际可见的半月缺口；P_KEY追踪唯一这枚实物。外形不能证明能开哪把锁，不试配、不复制；匹配须到V3实测。
2. 第2章才首次打开牛皮封套。全书材料只称“纸签所示柜号”，不预置具体编号或纸签全文。纸签内容只在该章及以后的相关材料出现。O_LABEL固定所见文字，P_ENVELOPE追踪封套、内签与封口。
3. 陆衡不在开封现场；实际获告知或展示前不知道柜号与纸签完整内容，最早第5章告知。封套可交其保管，保管不等于知情；人物所知分别登记，不因同场或搭档关系自动共享。
4. T_COPY为维护记录副页核验主线，due_unit=6是回查提醒，不是兑现日。前8章不能核验；V2仅取得档案手续、干燥作业与开柜条件，V3第9–11章实际开柜与副页比对，第12章兑现主线。
5. 每次物件换手登记previous_holder、保管人、实际位置、封口/物件状态和本章动作证据；默认唯一原物，禁止暗中复制。未试、未核、未告知都须保持。
6. 陈师傅一次旧约未赴的私人原因保留边界：失约可以确认为他的陈述，原因作者未定、人物未获说明。不能将其等同档案损失或罪责，也不为清账强行解决。


===== 设定\角色卡.md =====
# 人物与知情初始边界

本卡为创作基线，不随每章更写。实际位置、物件和所知以登记为准；不含未来纸签具体文字。

林岚：镇里临时档案核验员，想把维护记录的副页找齐。曾见简报在材料不全时先下结论，担心重演；容易把迟疑当遮掩。底线是不把猜测写成结论；压力下会先少说，事后承担解释责任。

陆衡：同组搭档，经手手续和物件保全。怕没有交接记录时责任全落在经手人身上；先确认“谁拿着、放哪儿”，愿意帮忙但不默认享有查看私人材料的权利。初始不知道封套内纸签内容。

陈师傅：旧泵房退休维修工，掌握部分旧事，愿意处理能做的事，不愿交代一段私人失约。对具体机械与旧物说得清，对自己失约的原因保留。原因尚未由作者确认，不预置有罪或牺牲真相。

许澄：档案员，负责柜房；要按时接孩子，也怕受潮材料在自己手上受损。说话具体，帮忙需留下可交代的经手记录。初始不知封套内签；管理柜房不等于已经核验副页。


===== 大纲\全书大纲.md =====
# 全书结构

以下为计划，尚未写出的事不是人物记忆或追踪事实。远期仅保留里程碑，不预写正文。

## V1 雨到檐下（第1–4章）
林岚和陆衡在旧泵房领取铜钥匙，记录缺口而不试锁。林岚独自打开旧牛皮封套，看见纸签所示柜号与待核提示。随后争取查阅手续，问到陈师傅的一次失约但不问出私人原因。汛前临时搬动工作迫使林岚把封好的封套明确交给陆衡，愿意借助搭档但暂不披露内签。阶段兑现为建立查核路径与可信保管，不找出副页。

## V2 进入名单（第5–8章）
第5章林岚才向陆衡实际告知/展示纸签内容，修复暂缓分享造成的关系缝隙。第6章T_COPY到期回查：申请进入核验流程，缺开柜条件，继续挂账。第7–8章取得批件、在场人员安排与柜房干燥作业条件；完成这些准备仍不能核验副页。细节待写完近期章节后再滚动展开。

## V3 柜门以内（第9–12章）
第9–11章在手续与现场条件齐备后进入柜房，真实验证缺口钥匙是否匹配，实际开柜与副页比对。钥匙匹配结果不预定为已知，不能靠外形推断。第12章让副页与原维护记录的关系有可核对结论，并让林岚承担更正简报的实际工作，兑现找齐并核清副页的主线。陈师傅失约的私人原因可保留，不归入主线证明。
