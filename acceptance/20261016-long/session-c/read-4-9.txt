# 第四章 交给你

他们还没走出接待间，许澄就折回来叫人。走廊窗框漏了水，底下摞着一排空资料盒，最下面那只已湿出深边。柜房门仍锁着，她拿毛巾塞住窗缝，请两人帮忙把空盒搬到接待间的高架上。

林岚弯腰试了一下。盒子不重，一摞却挡着视线，包带从肩头往下滑。她直起身，把包抱到桌上，从大夹层取出牛皮封套。

“这个先交给你。封好了，别拆。”

陆衡没立刻伸手：“你还没告诉我里面是什么。”

“我知道。明早我跟你说，今天先替我保管。”说完，她才发现这要求有些不公平，自己捂着话，却要他接下责任。

他看了她一会儿，找出包里的硬纸夹，打开，平放在桌上。林岚把封套递给陆衡。他接过后只看了外面的骑缝签名，没有揭纸条，将封套夹进硬纸夹，再收进双肩包里层，拉上拉链。

许澄拿临借条过来，补写由陆衡代管、次日同还。两人在交接处签了名，时间是下午两点二十分。

“钥匙呢？”他问。

“还在我内袋。”林岚隔着帆布按了按那只小透明袋，没有取出钥匙。

陆衡把包移到干桌角，伸手托住最上面的空盒。两人一前一后搬，林岚踩上矮凳，把盒子推到高架深处。最下面的湿盒留下晾开，没有混进干盒里。许澄仰头指地方，直到最后一摞摆稳才把毛巾重新拧干。

林岚下来时，陆衡正背好双肩包。她张了张嘴，只说了句谢谢。

“明早别又说没理清。”他替她扶住摇晃的凳子。

她答应了。走出楼门，她习惯地摸向包的大夹层，指尖碰到空布，才把手放下。柜房没有开，副页也还没找到；她却已经不能再把全部事情都当成自己一个人的了。

# 第五章 先把话说完

次晨，林岚到接待间时，昨天晾开的湿盒还放在窗边。陆衡已经坐下，双肩包立在脚边。他没取封套，先把另一把椅子拉出来。

她没有坐。“昨天我看见的，只有一张纸签。两行字，‘九号柜’，‘副页待核’。没有日期，也没有签名。里面没有副页。”

陆衡抬头看她。她把包带从肩上卸下，接着说：“你问的时候，我怕说成找到了，想等手续明白了再说。后来越拖越不好开口。让你拿着，却不告诉你，是我不对。”

楼下有人收伞，伞骨在门框上磕了两声。陆衡等她说完，才问：“九号，是纸签写的？”

“是。我亲眼看的。”

“那先查目录。申请不能一直空着，也别直接填副页就在里面。”他把椅子又往前送了一点，“坐吧。今天一起问。”

许澄拎着钥匙进来，先去摸窗缝里的毛巾。林岚等她换好毛巾，将刚才那两行字和没有落款的情形又说了一遍。许澄翻出昨天的申请，没急着添柜号，说目录要从旧册里找，上午先接一批退件。

陆衡拉开双肩包里层，取出硬纸夹。他打开夹子，把签封的牛皮封套递给许澄。许澄接住，核对骑缝签名，在临借条上写明归还，递给两人签字。她没有揭纸条，将封套平放进接待间桌下的干燥抽屉，锁好。

林岚看着自己的名字挨在陆衡名字旁边。这一次，他知道自己签收过什么了，虽还没有亲眼看见那张纸签。

“钥匙也交回来？”许澄问。

“那是陈师傅另交的，还在我包内袋，没试过。”林岚说。

许澄点头，在补件便条上只列了目录和柜号依据。林岚把便条接过来，终于坐到陆衡留出的椅子上，和他分着看那张还没补完的申请。

===== 正文/0006-收件以后.md SHA256 913c0d95f2caf6031f98bb89ad31a7a41854d63ebdfb3d9aee249c16c62cb799 =====
# 第六章 收件以后

下午两点，退件车走了，许澄从接待间书架底层抽出一本蓝皮目录。林岚替她挪开晾盒，三个人才有地方把册子摊平。九号柜那一行写着旧泵房维护档案，后面只列年份，没有逐页的名字。

林岚的指尖停在那行字下。上午说出口的柜号终于有了对应，她很想马上给简报那边报个好消息。陆衡却问许澄：“这个能看出副页在不在吗？”

“看不出。旧目录只到整册。”许澄把夹在书里的补件单递过去，“柜号可以补。纸签上的话，写清是谁看的。”

林岚在依据栏分开写了两项：目录所列柜号，自己开封所见的两行字。她把“副页存于”划去，改成“申请核查副页是否存于”，在改处签名。陆衡把回执对上，许澄收件，装进送审的文件袋，拨电话请镇办值班员来取。

“批下来今天能看吗？”林岚问。

许澄把目录合上：“批件还没回。维修班明早先看窗框，再排柜背除潮。柜门不能现在拉，潮纸一带就破。我和你们得另排个共同在场的时间。”

她看了眼墙钟，又补一句：“别排放学那阵，我得走。你们等我也白等。”

林岚将原先圈着的“今日核副页”划成一条横线，在旁边写下还缺的三件事。手机接着响，是简报经办问能否把“缺页”改成“已补齐”。她举起手机，又放低。

“不能这样改。只补交了查阅材料，还没拿到副页。”她逐字发出去，接着请对方暂留“待核”，落下自己的名字。

发完，她盯着那个名字看了片刻。陆衡递来回执，她没有折起塞包，摊在本子未结的一页上。许澄桌下的抽屉仍锁着，铜钥匙也仍在林岚包内袋里。这一天，他们多了一张收件凭据，没有多出一张副页。

# 第七章 名单上的早晨

第三天一早，林岚把回执递进镇办窗口，换回一张盖章的查阅批件。她站在窗口边读完：准查九号柜旧泵房维护档案，由许澄陪同，发现受潮粘连须停止翻动。她先看自己的名字，再看陆衡的，怕少一个字还得重跑。

陆衡腾出走廊长凳，让她把批件放进文件夹。他拨通许澄的电话，开了免提。那边先传来搬凳子的声音，许澄说维修班刚看过窗框，下午送除湿机，得留一夜，第二天早上复查。

“那明天下午四点？”林岚问完，才想起昨天的墙钟。

“我四点走，早上能来。”许澄说，“八点半维修班到，你们九点。要是还潮，就再等。”

林岚在本子上改了时间，陆衡报了一遍两人的名字。许澄答应把名单留给维修班，又请他们下午带两个干净托盘过去，自己手边的都拿去垫湿盒了。

挂掉电话，林岚取出原来的钥匙领取单，又拉开帆布包内袋。她拿出装铜钥匙的小透明袋，没开袋口，递给陆衡。

“明早你清点物件，这个交你保管。还没试过，别拿去配。”

陆衡接过透明袋，沿压口看了一圈，把它收进双肩包的小拉链袋。林岚在领取单空白处写下转交时间和代管，两人签字。那点带黑垢的缺口隔着袋子晃了一下，随后被拉链遮住。

她忽然想起陈师傅那天翻空的裤袋，很想打电话问他一句，这钥匙究竟在哪堆工具里。可他早已说了说不准。她把手机收起，先去后勤室借托盘。

托盘比想象的大，两只叠着，她得用两手抱。陆衡替她把文件夹塞稳在包里。下楼时她没有再摸内袋，转而问他批件上停止翻动的那句话要不要抄到作业单。他说要，她便在楼梯转角停下，把托盘搁在干燥的窗台上，取出本子。陆衡托住本子底边，她借着窗光把那句话记全了。

===== 正文/0008-门前的空托盘.md SHA256 1bedc669d89cca42c2a33be8e1972cf8e663c4f4f6d98cebbce67c4a9d6164a2 =====
# 第八章 门前的空托盘

下午，林岚把两只空托盘送到接待间，挽起袖子擦查阅桌。昨天的湿盒已挪开，桌边还留着一圈印子。她换了块干布，连桌脚旁的空桶也移到走廊，给以后搬册子留路。

许澄用自己的房门钥匙开了柜房，让维修工推除湿机进去。林岚和陆衡留在门外。屋里一排档案柜都关着，许澄只让工人沿墙检查，没碰柜门。工人补过窗框漏点，接好排水管，试了插座和机器，才在作业单上记下开机时间。

“今晚值班的人来看排水，明早我再测。”工人说着，把软管往墙根收了收，免得绊脚。

许澄核对了值班人的电话，关好房门。她赶着去接孩子，走到楼梯口又回来，把钥匙圈从桌上拿起。林岚把装好的水杯递给她，没再追问明天究竟能看到什么。

第二天九点前，两人按约回来。维修工已经在复查墙背和湿度记录，许澄将作业单摊在接待间。林岚等他填完读数，看他在“可开始查阅作业”一栏签名，才把自己的批件推过去。

许澄逐个对了三人的名字，点了点批件上的停翻条款：“这里只管房里能干活。柜内纸怎么样，打开看见才能说；粘住了就停。”

陆衡报了钥匙：“透明袋还压着口，在我包的小拉链袋。”林岚应了一声。许澄也确认封套仍在她锁着的干燥抽屉，没人再拆。

林岚在本子的未结页下添上今日日期，没有划掉副页那一项。她原本怕这张纸上的空白拖过周五，此刻却先把笔帽扣好，检查托盘内有没有残水。陆衡替她让开门前的位置，许澄拿起作业单等她。

她抱起上面那只托盘，走到门前。柜门仍关着，铜钥匙没有出袋。托盘中央空空的，她把两只手重新托稳，等许澄把作业单夹好。

# 第九章 锁舌退回去

许澄夹好作业单，用房门钥匙开门，先绕过墙根的排水管。林岚抱着空盘跟进去。柜门上的九字漆掉了一角，她将它与批件对过，才给陆衡让出锁前的位置。

陆衡从包的小拉链袋取出透明袋，把领取单压在干燥的小台上。他沿袋口分开压条，捏住铜钥匙柄。半月缺口里的黑垢还在，林岚低头看看单上第一天添的字，没有伸手擦。

“就是这枚。”她说，随即把笔停住，等他试。

钥匙插到底，陆衡轻轻向右转。起初有一点涩，他停了一下，扶住柜门再转，锁里响了一声。左手一拉，门离开柜框，露出已退回的锁舌。林岚这才在用途栏旁补上“现场开启九号柜”，写下时间。那个缺口让她认回旧物，真正推开门的这一下，才给了她能填写的结果。

许澄没让她立即伸手。柜里几册纸的下沿泛黄，她先看边缘，再托住靠外一册的封底，轻抬封面；页边分开，没有湿黏拉扯的声音。

“先拿你们查的年份。里面别乱翻。”

林岚从包里取出原维护记录，隔着文件夹对年份和册名。许澄接过她的空盘，将对应的维护册托入盘中，自己端往接待间。另一个盘仍空着。林岚跟在旁边，手悬在盘沿下，没有碰纸。

陆衡关上柜门，用原钥匙重新锁好，轻拉确认后拔出，装回原袋压紧，仍收进包的小拉链袋。他在出柜登记旁签字，才跟过来。

许澄把册子平放到查阅桌上。林岚将自己的文件夹摆在旁边，手机却留在包里。她还没有可以报给简报的页数；先前空着的托盘，如今有了重量，她得把这份重量一页页看清。
