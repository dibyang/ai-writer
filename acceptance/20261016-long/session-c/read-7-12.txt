# 第七章 名单上的早晨

第三天一早，林岚把回执递进镇办窗口，换回一张盖章的查阅批件。她站在窗口边读完：准查九号柜旧泵房维护档案，由许澄陪同，发现受潮粘连须停止翻动。她先看自己的名字，再看陆衡的，怕少一个字还得重跑。

陆衡腾出走廊长凳，让她把批件放进文件夹。他拨通许澄的电话，开了免提。那边先传来搬凳子的声音，许澄说维修班刚看过窗框，下午送除湿机，得留一夜，第二天早上复查。

“那明天下午四点？”林岚问完，才想起昨天的墙钟。

“我四点走，早上能来。”许澄说，“八点半维修班到，你们九点。要是还潮，就再等。”

林岚在本子上改了时间，陆衡报了一遍两人的名字。许澄答应把名单留给维修班，又请他们下午带两个干净托盘过去，自己手边的都拿去垫湿盒了。

挂掉电话，林岚取出原来的钥匙领取单，又拉开帆布包内袋。她拿出装铜钥匙的小透明袋，没开袋口，递给陆衡。

“明早你清点物件，这个交你保管。还没试过，别拿去配。”

陆衡接过透明袋，沿压口看了一圈，把它收进双肩包的小拉链袋。林岚在领取单空白处写下转交时间和代管，两人签字。那点带黑垢的缺口隔着袋子晃了一下，随后被拉链遮住。

她忽然想起陈师傅那天翻空的裤袋，很想打电话问他一句，这钥匙究竟在哪堆工具里。可他早已说了说不准。她把手机收起，先去后勤室借托盘。

托盘比想象的大，两只叠着，她得用两手抱。陆衡替她把文件夹塞稳在包里。下楼时她没有再摸内袋，转而问他批件上停止翻动的那句话要不要抄到作业单。他说要，她便在楼梯转角停下，把托盘搁在干燥的窗台上，取出本子。陆衡托住本子底边，她借着窗光把那句话记全了。

===== 正文/0008-门前的空托盘.md SHA256 1bedc669d89cca42c2a33be8e1972cf8e663c4f4f6d98cebbce67c4a9d6164a2 =====
# 第八章 门前的空托盘

下午，林岚把两只空托盘送到接待间，挽起袖子擦查阅桌。昨天的湿盒已挪开，桌边还留着一圈印子。她换了块干布，连桌脚旁的空桶也移到走廊，给以后搬册子留路。

许澄用自己的房门钥匙开了柜房，让维修工推除湿机进去。林岚和陆衡留在门外。屋里一排档案柜都关着，许澄只让工人沿墙检查，没碰柜门。工人补过窗框漏点，接好排水管，试了插座和机器，才在作业单上记下开机时间。

“今晚值班的人来看排水，明早我再测。”工人说着，把软管往墙根收了收，免得绊脚。

许澄核对了值班人的电话，关好房门。她赶着去接孩子，走到楼梯口又回来，把钥匙圈从桌上拿起。林岚把装好的水杯递给她，没再追问明天究竟能看到什么。

第二天九点前，两人按约回来。维修工已经在复查墙背和湿度记录，许澄将作业单摊在接待间。林岚等他填完读数，看他在“可开始查阅作业”一栏签名，才把自己的批件推过去。

许澄逐个对了三人的名字，点了点批件上的停翻条款：“这里只管房里能干活。柜内纸怎么样，打开看见才能说；粘住了就停。”

陆衡报了钥匙：“透明袋还压着口，在我包的小拉链袋。”林岚应了一声。许澄也确认封套仍在她锁着的干燥抽屉，没人再拆。

林岚在本子的未结页下添上今日日期，没有划掉副页那一项。她原本怕这张纸上的空白拖过周五，此刻却先把笔帽扣好，检查托盘内有没有残水。陆衡替她让开门前的位置，许澄拿起作业单等她。

她抱起上面那只托盘，走到门前。柜门仍关着，铜钥匙没有出袋。托盘中央空空的，她把两只手重新托稳，等许澄把作业单夹好。

===== 正文/0009-锁舌退回去.md SHA256 661021804fc06e86da0461b9f3e6b32ab289d7c0d78fa180d2c9702594c35780 =====
# 第九章 锁舌退回去

许澄夹好作业单，用房门钥匙开门，先绕过墙根的排水管。林岚抱着空盘跟进去。柜门上的九字漆掉了一角，她将它与批件对过，才给陆衡让出锁前的位置。

陆衡从包的小拉链袋取出透明袋，把领取单压在干燥的小台上。他沿袋口分开压条，捏住铜钥匙柄。半月缺口里的黑垢还在，林岚低头看看单上第一天添的字，没有伸手擦。

“就是这枚。”她说，随即把笔停住，等他试。

钥匙插到底，陆衡轻轻向右转。起初有一点涩，他停了一下，扶住柜门再转，锁里响了一声。左手一拉，门离开柜框，露出已退回的锁舌。林岚这才在用途栏旁补上“现场开启九号柜”，写下时间。那个缺口让她认回旧物，真正推开门的这一下，才给了她能填写的结果。

许澄没让她立即伸手。柜里几册纸的下沿泛黄，她先看边缘，再托住靠外一册的封底，轻抬封面；页边分开，没有湿黏拉扯的声音。

“先拿你们查的年份。里面别乱翻。”

林岚从包里取出原维护记录，隔着文件夹对年份和册名。许澄接过她的空盘，将对应的维护册托入盘中，自己端往接待间。另一个盘仍空着。林岚跟在旁边，手悬在盘沿下，没有碰纸。

陆衡关上柜门，用原钥匙重新锁好，轻拉确认后拔出，装回原袋压紧，仍收进包的小拉链袋。他在出柜登记旁签字，才跟过来。

许澄把册子平放到查阅桌上。林岚将自己的文件夹摆在旁边，手机却留在包里。她还没有可以报给简报的页数；先前空着的托盘，如今有了重量，她得把这份重量一页页看清。

===== 正文/0010-薄夹袋.md SHA256 b68f03a3537d7c490cfadfe77582d462aa7c89571acd0b879c4690b889bdf5fc =====
# 第十章 薄夹袋

陆衡把另一个空盘从门边拿来，放在维护册右侧。许澄试着翻开前几页，每次先看纸边，能分开才往后翻。林岚将自带的原维护记录展开在左边，文件夹压住空白边，不让旧折痕重新翘起。

原记录右上角是十七号，日期六月三日，设备栏写二号泵。事项栏记着“停机待换垫圈”，末行还有几个小字：“复机情况见副页。”她以前总盯着少掉的那一张，此刻才把这一行逐字念给两人听。

许澄依着年份查到六月，将册中的十七号条目指给她看。那行末尾写“附后”。她继续往后翻，备件领用表后有个薄夹袋，袋口没有封胶，一角灰黄的纸露在外面。

林岚往前移了椅子。许澄抬手拦了一下：“让我托着，别抽破了。”

袋口两边能轻轻分开。许澄用干净硬纸衬住薄页，连衬纸平托出来，放进右侧的盘里。页首写着“维护记录副页”，下面也有十七号。林岚的手压在本子上，等盘放稳，才凑过去看日期。六月三日，一个字不差。

“还得看泵号和后面的事。”陆衡说。他在登记纸上写下册名、年份，又问许澄夹袋的位置，把“备件领用表后”添完整。

林岚把原记录朝右挪近些，两张纸之间仍留一道空隙。纸签叫她来九号柜，目录领她到这册子，如今桌上终于有了一张标着副页的纸；可那句“待核”，她还没走完。

许澄看了眼钟，把水杯移到背后的架上，重新坐下。林岚没有请她赶快翻完。她先在本子上写了“已找到，核对中”，将通知简报的那一栏继续空着。桌下的封套没有取出，骑缝封口也没有为这一次发现再揭开。

# 第十一章 逐栏念过去

林岚在一张新纸上划出两栏，左边写原记录，右边写副页。她怕自己急着认下那张纸，把最想见的字读得太快，便请陆衡从头再念一次。

“十七号。”

她把原记录右上角指给他看。许澄将衬纸略转一个角度，副页仍平躺在盘里，编号也正是十七。两张纸的年份相同，记录日期都是六月三日。林岚逐栏抄下，接着指到设备名：“二号泵。”陆衡俯身读副页设备栏，也念出二号泵，她才在这一行打了勾。

事项栏写得挤。林岚先念原件的“停机待换垫圈”，许澄再指着副页念：“六月四日换垫圈，试机半小时，无渗水。”

“这儿是四日。”林岚停笔。

陆衡把指头落在空白边：“处理日期。上面才是记录日期。”

她往上往下又看一遍，将两种日期分行写。原件那句“复机情况见副页”，终于接到了这行后续；如果只抄六月三日的停机，读的人便不会看见下一日的记载。

副页下端的落款褪成一团墨，许澄调整灯光，仍认不出名字，便把灯放回去。

“这个别替它补。”

林岚点头。她在结论处写：此副页与原记录编号、年份、记录日期、设备及事项对应，载有后续换件和试机记录。接着另添一行：本次核对确认纸面对应，不据此证明当年作业实际完成，也不能辨认经手人。

那句结论比“没有维护”长，也比“谁都没错”难写。她想起陈师傅推回桌下的椅子，把旧本子里“本人说未到场”原样留着，没有挪进核验单。

许澄核过发现位置，三个人在核验单上签名。林岚将这张新纸收进自己的文件夹，原记录仍压在桌上。陆衡问要不要替她送。她说：“一起去。我来解释为什么改。”

# 第十二章 名字落在这里

许澄把副页连衬纸平送回原夹袋，合上维护册，记好归还位置。陆衡取出袋里的铜钥匙开柜，她端盘将册子放回原格；他再锁好门，把钥匙装回原袋，压紧袋口。

回到接待间，陆衡把这只透明袋递给许澄。她接住，核对领取单上的缺口记录，两人在保管交接处签名。许澄将袋装钥匙放进干燥抽屉的一格，与仍签封的牛皮封套隔开放，锁上。林岚也将自己的原维护记录收回文件夹，再放进包。两只托盘又空了。

他们到镇办时，简报经办正把待发的样稿逐页摊开。林岚从夹中取出三人签过的核验单，递到他手里。他看过，指着样稿上的“缺页待核”：“现在能改已补齐了？”

“副页找到了，也逐项对上了。”她把核验单翻到结论处，“请把后续换件和试机的记载带上。只写停机，还是少了半截。”

经办挪出一块桌面，将单子放好，问原先担心的责任怎么写。

林岚拉近样稿：“这次只能核材料。谁当年做到了哪一步，我们还没法认定。”

她想起陈师傅那双漏水的拖鞋。他为什么失约，她仍不知道；这一页纸也没有替他作答。她没有将那句私事添进结论。

经办在电脑上删去“缺页待核”，改为副页已寻得并核对，对应记录载有后续维护情况；责任判断处留待另核。他打印一页让两人看，又在收件条上签下接收核验单的时间，原单留在案头文件夹内。

林岚将改后的句子从头读完，在核验人处署名，把笔递给陆衡。他签在旁边，问：“周五前再来看一遍？”

“来。”她说。

经办把签过的收件条递给林岚。走廊里有人催交另外一份材料，陆衡替她扶住包口，让她把收件条收稳。她终于不用先想一个听起来圆满的说法了。桌上改过的那一行有来处，她的名字也落在该承担的位置。
