# 第一章 檐下的钥匙

雨落在旧泵房的铁皮檐上，陆衡把领取单挪了三次，纸角还是洇出一个灰点。林岚站在门廊里，盯着墙上那道褪色的水位线。汛前简报周五要交，她包里的维护记录却少了一份副页。上回有人把缺页写成漏检，澄清时简报已经发出去了。

陈师傅踩着湿拖鞋来，先把堵在门边的碎砖踢进沟里，才从裤袋掏出一枚铜钥匙。

“清工具箱翻出来的。你们既然查旧东西，就一并登记。”

林岚伸手接住。铜身只有小指长，柄上的油污干成了硬边。她把钥匙转向檐外，灰白天光照出柄边一个半月缺口，缺口里也积着黑垢。陆衡凑近看了一眼，在领取单上添了几个字。

“这是柜房的？”她问。

“说不准。箱里什么都有。”陈师傅把裤袋翻给她看，里面只剩一截棉线。

她想再问，陆衡已经递来笔：“先写接收，开哪儿以后再说。”

林岚有些烦。他总能把她往前赶的那一步截住。可她低头看到领取单，物品用途那一栏果然空着。她没填“柜房”，只写“用途待核”，签了名字。

陈师傅看见那几个字，肩背稍稍松下来。他说镇档案室还存着一个旧牛皮封套，是清理值班桌时送过去的，外面没题名；里面有什么，他没拆过。

“那天谁送的？”

“我。许澄收的。别让人家替我猜。”

陆衡按住被风掀起的单子，让他签名。陈师傅写得慢，写完用拇指擦了擦纸旁的雨水，没有碰字。

林岚把钥匙装进小透明袋，压紧袋口，收进帆布包的拉链内袋。泵房门上的铁锁就在手边，她没把袋子再取出来。下台阶时，她请陆衡给档案室打电话，自己回身扶住陈师傅，把那块翘起来的门垫推平了。

# 第二章 封套里面

镇档案室的接待间有一股湿木头味。许澄拉开抽屉，取出陈师傅送来的牛皮封套，检查了外面的折痕，在临时查阅本上写下林岚的名字。

“只在这儿看。要带走，等我回来登记。”她看了眼手机，“孩子午托今天不留饭。”

许澄把封套交给林岚，锁好走廊尽头的柜房，拎着饭盒下楼。陆衡已经去镇办取申请回执，不在这栋楼里。接待间只剩林岚，窗外的雨打着空调铁架，一阵密，一阵疏。

封套是手掌宽的，翻盖只折进去，没有胶封。林岚擦干桌面和手，托住底边，抽开翻盖。一张窄纸签滑到套口，她垫着封套把纸签移到桌上。

纸签上分两行写着：“九号柜”“副页待核”。

她把身子往前倾了倾，又看一遍。没有日期，没有签名。她原以为拆开就能见到那份薄纸，甚至想好了回去怎样催简报改字；眼前却只有一张让人继续找的纸签。

手机亮起来，是陆衡问回执要不要多取一份。她点开输入框，打了个“找”，又删掉，只回：“两份，谢谢。”待核这两个字使她不敢把“找到了”发出去。她决定等问清查阅办法再解释，仍觉得这一点迟延算不上隐瞒。

她没有给纸签拍照，也没有抄写，把它沿原来的方向放回封套，翻盖压好。桌上有许澄留的窄纸条和胶水；她用纸条跨封口粘住，在骑缝处签了名，外面没写内签文字。

包里的钥匙仍在拉链内袋。林岚把封套另放进包的大夹层，没有带出接待间。她坐回窗边，给许澄留出对面的椅子。那两行字她已经记住了，可她头一次盼着陆衡迟一点回来，好让自己先想好第一句话。

# 第三章 先留一栏

许澄回来时，饭盒上还挂着水。林岚把包口拉好，接过她递来的查阅申请。陆衡随后进门，把两张回执摊到电扇前吹，问封套看得怎样。

“我还没理清。先把手续办上。”她避开他的眼睛。

他没有再问，指了指申请上的柜号栏。林岚握笔停住。许澄说，眼下可以按泵房维护档案申请，柜号等目录核对后补；没批件不能进柜房，就算批了，潮湿的柜背也得先处理。

林岚写下档案名称，把那一栏留空。陆衡将回执夹在申请后，没看她包里的东西。

陈师傅在门口跺了跺拖鞋，送来一张旧值班姓名表。“家里找的。写得清的都在这儿。”

许澄擦了把椅子让他坐。他却扶着椅背，盯住姓名表下角的年份。林岚顺着他的目光问，那年清点时他是不是也在。他的手从椅背上缩了回去。

“十年前那回，我答应陪人清点，没去。”

“为什么？”

“私事。这个别问了。”他把椅子推回桌下，“名单你们用，别把没去也写成我知道东西丢在哪儿。”

林岚本来还想问是谁等他。那句问话已经到了嘴边，她看见他脚上的拖鞋，横带边裂着，雨水从裂口渗出来。他送这张表，特意又走了一趟。她把笔尖挪开，只在旁边记下“本人说未到场”，没添原因。

陈师傅不坐，也没收回表，独自下了楼。

许澄收好申请，给林岚开了临借条。林岚托着封套让她检查骑缝签名，始终没拆封；许澄只记外观和封口，准她带回，明天随补件一同归还。陆衡替两人移开桌下的废纸篓，让林岚能把包放稳。

“批件明天再催。”他说。

她点头，把封套放回大夹层。空着的柜号栏还在她眼前；这回的空白是她自己留下的，等他问起，她得亲自解释。

# 第四章 交给你

他们还没走出接待间，许澄就折回来叫人。走廊窗框漏了水，底下摞着一排空资料盒，最下面那只已湿出深边。柜房门仍锁着，她拿毛巾塞住窗缝，请两人帮忙把空盒搬到接待间的高架上。

林岚弯腰试了一下。盒子不重，一摞却挡着视线，包带从肩头往下滑。她直起身，把包抱到桌上，从大夹层取出牛皮封套。

“这个先交给你。封好了，别拆。”

陆衡没立刻伸手：“你还没告诉我里面是什么。”

“我知道。明早我跟你说，今天先替我保管。”说完，她才发现这要求有些不公平，自己捂着话，却要他接下责任。

他看了她一会儿，找出包里的硬纸夹，打开，平放在桌上。林岚把封套递给陆衡。他接过后只看了外面的骑缝签名，没有揭纸条，将封套夹进硬纸夹，再收进双肩包里层，拉上拉链。

许澄拿临借条过来，补写由陆衡代管、次日同还。两人在交接处签了名，时间是下午两点二十分。

“钥匙呢？”他问。

“还在我内袋。”林岚隔着帆布按了按那只小透明袋，没有取出钥匙。

陆衡把包移到干桌角，伸手托住最上面的空盒。两人一前一后搬，林岚踩上矮凳，把盒子推到高架深处。最下面的湿盒留下晾开，没有混进干盒里。许澄仰头指地方，直到最后一摞摆稳才把毛巾重新拧干。

林岚下来时，陆衡正背好双肩包。她张了张嘴，只说了句谢谢。

“明早别又说没理清。”他替她扶住摇晃的凳子。

她答应了。走出楼门，她习惯地摸向包的大夹层，指尖碰到空布，才把手放下。柜房没有开，副页也还没找到；她却已经不能再把全部事情都当成自己一个人的了。

# 第五章 先把话说完

次晨，林岚到接待间时，昨天晾开的湿盒还放在窗边。陆衡已经坐下，双肩包立在脚边。他没取封套，先把另一把椅子拉出来。

她没有坐。“昨天我看见的，只有一张纸签。两行字，‘九号柜’，‘副页待核’。没有日期，也没有签名。里面没有副页。”

陆衡抬头看她。她把包带从肩上卸下，接着说：“你问的时候，我怕说成找到了，想等手续明白了再说。后来越拖越不好开口。让你拿着，却不告诉你，是我不对。”

楼下有人收伞，伞骨在门框上磕了两声。陆衡等她说完，才问：“九号，是纸签写的？”

“是。我亲眼看的。”

“那先查目录。申请不能一直空着，也别直接填副页就在里面。”他把椅子又往前送了一点，“坐吧。今天一起问。”

许澄拎着钥匙进来，先去摸窗缝里的毛巾。林岚等她换好毛巾，将刚才那两行字和没有落款的情形又说了一遍。许澄翻出昨天的申请，没急着添柜号，说目录要从旧册里找，上午先接一批退件。

陆衡拉开双肩包里层，取出硬纸夹。他打开夹子，把签封的牛皮封套递给许澄。许澄接住，核对骑缝签名，在临借条上写明归还，递给两人签字。她没有揭纸条，将封套平放进接待间桌下的干燥抽屉，锁好。

林岚看着自己的名字挨在陆衡名字旁边。这一次，他知道自己签收过什么了，虽还没有亲眼看见那张纸签。

“钥匙也交回来？”许澄问。

“那是陈师傅另交的，还在我包内袋，没试过。”林岚说。

许澄点头，在补件便条上只列了目录和柜号依据。林岚把便条接过来，终于坐到陆衡留出的椅子上，和他分着看那张还没补完的申请。

# 第六章 收件以后

下午两点，退件车走了，许澄从接待间书架底层抽出一本蓝皮目录。林岚替她挪开晾盒，三个人才有地方把册子摊平。九号柜那一行写着旧泵房维护档案，后面只列年份，没有逐页的名字。

林岚的指尖停在那行字下。上午说出口的柜号终于有了对应，她很想马上给简报那边报个好消息。陆衡却问许澄：“这个能看出副页在不在吗？”

“看不出。旧目录只到整册。”许澄把夹在书里的补件单递过去，“柜号可以补。纸签上的话，写清是谁看的。”

林岚在依据栏分开写了两项：目录所列柜号，自己开封所见的两行字。她把“副页存于”划去，改成“申请核查副页是否存于”，在改处签名。陆衡把回执对上，许澄收件，装进送审的文件袋，拨电话请镇办值班员来取。

“批下来今天能看吗？”林岚问。

许澄把目录合上：“批件还没回。维修班明早先看窗框，再排柜背除潮。柜门不能现在拉，潮纸一带就破。我和你们得另排个共同在场的时间。”

她看了眼墙钟，又补一句：“别排放学那阵，我得走。你们等我也白等。”

林岚将原先圈着的“今日核副页”划成一条横线，在旁边写下还缺的三件事。手机接着响，是简报经办问能否把“缺页”改成“已补齐”。她举起手机，又放低。

“不能这样改。只补交了查阅材料，还没拿到副页。”她逐字发出去，接着请对方暂留“待核”，落下自己的名字。

发完，她盯着那个名字看了片刻。陆衡递来回执，她没有折起塞包，摊在本子未结的一页上。许澄桌下的抽屉仍锁着，铜钥匙也仍在林岚包内袋里。这一天，他们多了一张收件凭据，没有多出一张副页。

# 第七章 名单上的早晨

第三天一早，林岚把回执递进镇办窗口，换回一张盖章的查阅批件。她站在窗口边读完：准查九号柜旧泵房维护档案，由许澄陪同，发现受潮粘连须停止翻动。她先看自己的名字，再看陆衡的，怕少一个字还得重跑。

陆衡腾出走廊长凳，让她把批件放进文件夹。他拨通许澄的电话，开了免提。那边先传来搬凳子的声音，许澄说维修班刚看过窗框，下午送除湿机，得留一夜，第二天早上复查。

“那明天下午四点？”林岚问完，才想起昨天的墙钟。

“我四点走，早上能来。”许澄说，“八点半维修班到，你们九点。要是还潮，就再等。”

林岚在本子上改了时间，陆衡报了一遍两人的名字。许澄答应把名单留给维修班，又请他们下午带两个干净托盘过去，自己手边的都拿去垫湿盒了。

挂掉电话，林岚取出原来的钥匙领取单，又拉开帆布包内袋。她拿出装铜钥匙的小透明袋，没开袋口，递给陆衡。

“明早你清点物件，这个交你保管。还没试过，别拿去配。”

陆衡接过透明袋，沿压口看了一圈，把它收进双肩包的小拉链袋。林岚在领取单空白处写下转交时间和代管，两人签字。那点带黑垢的缺口隔着袋子晃了一下，随后被拉链遮住。

她忽然想起陈师傅那天翻空的裤袋，很想打电话问他一句，这钥匙究竟在哪堆工具里。可他早已说了说不准。她把手机收起，先去后勤室借托盘。

托盘比想象的大，两只叠着，她得用两手抱。陆衡替她把文件夹塞稳在包里。下楼时她没有再摸内袋，转而问他批件上停止翻动的那句话要不要抄到作业单。他说要，她便在楼梯转角停下，把托盘搁在干燥的窗台上，取出本子。陆衡托住本子底边，她借着窗光把那句话记全了。

# 第八章 门前的空托盘

下午，林岚把两只空托盘送到接待间，挽起袖子擦查阅桌。昨天的湿盒已挪开，桌边还留着一圈印子。她换了块干布，连桌脚旁的空桶也移到走廊，给以后搬册子留路。

许澄用自己的房门钥匙开了柜房，让维修工推除湿机进去。林岚和陆衡留在门外。屋里一排档案柜都关着，许澄只让工人沿墙检查，没碰柜门。工人补过窗框漏点，接好排水管，试了插座和机器，才在作业单上记下开机时间。

“今晚值班的人来看排水，明早我再测。”工人说着，把软管往墙根收了收，免得绊脚。

许澄核对了值班人的电话，关好房门。她赶着去接孩子，走到楼梯口又回来，把钥匙圈从桌上拿起。林岚把装好的水杯递给她，没再追问明天究竟能看到什么。

第二天九点前，两人按约回来。维修工已经在复查墙背和湿度记录，许澄将作业单摊在接待间。林岚等他填完读数，看他在“可开始查阅作业”一栏签名，才把自己的批件推过去。

许澄逐个对了三人的名字，点了点批件上的停翻条款：“这里只管房里能干活。柜内纸怎么样，打开看见才能说；粘住了就停。”

陆衡报了钥匙：“透明袋还压着口，在我包的小拉链袋。”林岚应了一声。许澄也确认封套仍在她锁着的干燥抽屉，没人再拆。

林岚在本子的未结页下添上今日日期，没有划掉副页那一项。她原本怕这张纸上的空白拖过周五，此刻却先把笔帽扣好，检查托盘内有没有残水。陆衡替她让开门前的位置，许澄拿起作业单等她。

她抱起上面那只托盘，走到门前。柜门仍关着，铜钥匙没有出袋。托盘中央空空的，她把两只手重新托稳，等许澄把作业单夹好。

# 第九章 锁舌退回去

许澄夹好作业单，用房门钥匙开门，先绕过墙根的排水管。林岚抱着空盘跟进去。柜门上的九字漆掉了一角，她将它与批件对过，才给陆衡让出锁前的位置。

“就是这枚。”她说，随即把笔停住，等他试。

钥匙插到底，陆衡轻轻向右转。起初有一点涩，他停了一下，扶住柜门再转，锁里响了一声。左手一拉，门离开柜框，露出已退回的锁舌。林岚这才在用途栏旁补上“现场开启九号柜”，写下时间。那个缺口让她认回旧物，真正推开门的这一下，才给了她能填写的结果。

许澄没让她立即伸手。柜里几册纸的下沿泛黄，她先看边缘，再托住靠外一册的封底，轻抬封面；页边分开，没有湿黏拉扯的声音。

陆衡当着两人的面关上柜门，用原钥匙重新锁好，轻拉确认后拔出，装回原袋压紧，仍收进包的小拉链袋。他在出柜登记旁签字，三人才一起回接待间。

许澄把册子平放到查阅桌上。林岚将自己的文件夹摆在旁边，手机却留在包里。她还没有可以报给简报的页数；先前空着的托盘，如今有了重量，她得把这份重量一页页看清。

# 第十章 薄夹袋

陆衡把另一个空盘从门边拿来，放在维护册右侧。许澄试着翻开前几页，每次先看纸边，能分开才往后翻。林岚将自带的原维护记录展开在左边，文件夹压住空白边，不让旧折痕重新翘起。

原记录右上角是十七号，日期六月三日，设备栏写二号泵。事项栏记着“停机待换垫圈”，末行还有几个小字：“复机情况见副页。”她以前总盯着少掉的那一张，此刻才把这一行逐字念给两人听。

许澄依着年份查到六月，将册中的十七号条目指给她看。那行末尾写“附后”。她继续往后翻，备件领用表后有个薄夹袋，袋口没有封胶，一角灰黄的纸露在外面。

林岚往前移了椅子。许澄抬手拦了一下：“让我托着，别抽破了。”

袋口两边能轻轻分开。许澄用干净硬纸衬住薄页，连衬纸平托出来，放进右侧的盘里。页首写着“维护记录副页”，下面也有十七号。林岚的手压在本子上，等盘放稳，才凑过去看日期。六月三日，一个字不差。

“还得看泵号和后面的事。”陆衡说。他在登记纸上写下册名、年份，又问许澄夹袋的位置，把“备件领用表后”添完整。

林岚把原记录朝右挪近些，两张纸之间仍留一道空隙。纸签叫她来九号柜，目录领她到这册子，如今桌上终于有了一张标着副页的纸；可那句“待核”，她还没走完。

许澄看了眼钟，把水杯移到背后的架上，重新坐下。林岚没有请她赶快翻完。她先在本子上写了“已找到，核对中”，将通知简报的那一栏继续空着。桌下的封套没有取出，骑缝封口也没有为这一次发现再揭开。

# 第十一章 逐栏念过去

林岚在一张新纸上划出两栏，左边写原记录，右边写副页。她怕自己急着认下那张纸，把最想见的字读得太快，便请陆衡从头再念一次。

“十七号。”

她把原记录右上角指给他看。许澄将衬纸略转一个角度，副页仍平躺在盘里，编号也正是十七。两张纸的年份相同，记录日期都是六月三日。林岚逐栏抄下，接着指到设备名：“二号泵。”陆衡俯身读副页设备栏，也念出二号泵，她才在这一行打了勾。

事项栏写得挤。林岚先念原件的“停机待换垫圈”，许澄再指着副页念：“六月四日换垫圈，试机半小时，无渗水。”

“这儿是四日。”林岚停笔。

陆衡把指头落在空白边：“处理日期。上面才是记录日期。”

她往上往下又看一遍，将两种日期分行写。原件那句“复机情况见副页”，终于接到了这行后续；如果只抄六月三日的停机，读的人便不会看见下一日的记载。

副页下端的落款褪成一团墨，许澄调整灯光，仍认不出名字，便把灯放回去。

“这个别替它补。”

林岚点头。她在结论处写：此副页与原记录编号、年份、记录日期、设备及事项对应，载有后续换件和试机记录。接着另添一行：本次核对确认纸面对应，不据此证明当年作业实际完成，也不能辨认经手人。

那句结论比“没有维护”长，也比“谁都没错”难写。她想起陈师傅推回桌下的椅子，把旧本子里“本人说未到场”原样留着，没有挪进核验单。

许澄核过发现位置，三个人在核验单上签名。林岚将这张新纸收进自己的文件夹，原记录仍压在桌上。陆衡问要不要替她送。她说：“一起去。我来解释为什么改。”

# 第十二章 名字落在这里

许澄把副页连衬纸平送回原夹袋，合上维护册，记好归还位置。陆衡取出袋里的铜钥匙开柜，她端盘将册子放回原格；他再锁好门，把钥匙装回原袋，压紧袋口。

“副页找到了，也逐项对上了。”她把核验单翻到结论处，“请把后续换件和试机的记载带上。只写停机，还是少了半截。”

经办挪出一块桌面，将单子放好，问原先担心的责任怎么写。

林岚拉近样稿：“这次只能核材料。谁当年做到了哪一步，我们还没法认定。”

经办在电脑上删去“缺页待核”，改为副页已寻得并核对，对应记录载有后续维护情况；责任判断处留待另核。他打印一页让两人看，又在收件条上签下接收核验单的时间，原单留在案头文件夹内。

经办把签过的收件条递给林岚。走廊里有人催交另外一份材料，陆衡替她扶住包口，让她把收件条收稳。她终于不用先想一个听起来圆满的说法了。桌上改过的那一行有来处，她的名字也落在该承担的位置。
