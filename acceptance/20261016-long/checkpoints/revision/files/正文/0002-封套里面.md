# 第二章 封套里面

镇档案室的接待间有一股湿木头味。许澄拉开抽屉，取出陈师傅送来的牛皮封套，检查了外面的折痕，在临时查阅本上写下林岚的名字。

“只在这儿看。要带走，等我回来登记。”她看了眼手机，“孩子午托今天不留饭。”

许澄把封套交给林岚，锁好走廊尽头的柜房，拎着饭盒下楼。陆衡已经去镇办取申请回执，不在这栋楼里。接待间只剩林岚，窗外的雨打着空调铁架，一阵密，一阵疏。

封套是手掌宽的，翻盖只折进去，没有胶封。林岚擦干桌面和手，托住底边，抽开翻盖。一张窄纸签滑到套口，她垫着封套把纸签移到桌上。

纸签上分两行写着：“九号柜”“副页待核”。

她把身子往前倾了倾，又看一遍。没有日期，没有签名。她原以为拆开就能见到那份薄纸，甚至想好了回去怎样催简报改字；眼前却只有一张让人继续找的纸签。

手机亮起来，是陆衡问回执要不要多取一份。她点开输入框，打了个“找”，又删掉，只回：“两份，谢谢。”待核这两个字使她不敢把“找到了”发出去。她决定等问清查阅办法再解释，仍觉得这一点迟延算不上隐瞒。

她没有给纸签拍照，也没有抄写，把它沿原来的方向放回封套，翻盖压好。桌上有许澄留的窄纸条和胶水；她用纸条跨封口粘住，在骑缝处签了名，外面没写内签文字。

包里的钥匙仍在拉链内袋。林岚把封套另放进包的大夹层，没有带出接待间。她坐回窗边，给许澄留出对面的椅子。那两行字她已经记住了，可她头一次盼着陆衡迟一点回来，好让自己先想好第一句话。
