# 刀感与情绪杀伤力规则

## 文档目的

本文用于检查小说里的“刀子”是否真正扎到读者。它适用于悬疑、历史、仙侠、穿越、都市、言情、群像、职业文和任何需要读者心疼、愤怒、不甘或舍不得人物的作品。

刀感不是多死人、多哭、多惨，也不是把每个胜利都写成绝望。合格的刀感，是让读者先看见一个具体的人想活、想保住名字、清白、亲人、身份、职业、信任或一点体面，再看见世界、制度、关系、真相、选择或代价如何切掉他最想保住的东西。

一句话规则：

> 刀子必须先扎到一个具体的人，再扎到主题。

## 通用刀子类型

| 类型 | 核心痛点 | 合格写法 | 不合格写法 |
| --- | --- | --- | --- |
| 死者刀 | 人死了，但不肯被错误说完 | 死者留下选择、反击、证词、身体证据、保护对象或未完成愿望 | 只让死者死得漂亮、悲壮或成全主角成长 |
| 记录/制度刀 | 纸面、规矩、权力或系统先于真相伤人 | 记录改掉身份、死因、功劳、罪名、血缘、权限或归属，并立刻牵连活人 | 只反复说制度残酷、历史冷、系统吃人 |
| 关系刀 | 信任本身变成代价 | 角色信任会失去证据，不信会伤害活人；保护一个人会辜负另一个人 | 只靠“不能说”“误会”维持神秘或虐感 |
| 职业/身份刀 | 能力反咬身份 | 主角判断正确，但公开方式、权限、签名、身份、立场或伦理让自己失去位置 | 只让主角一直正确、一直被动受苦 |
| 选择刀 | 正确答案要求亲手付账 | 角色必须放弃救回某人、公开某名、洗清自己、圆满团聚或当场胜利 | 只靠命运自动闭合，人物没有选择痛 |
| 成长反噬刀 | 曾经最强的能力变成风险 | 法术、医术、推理、预知、重生经验、权谋手段或现代知识被敌人学走、误用或反咬 | 主角能力永远只带来优势，不产生代价 |

## 三步硬规则

每个高强度刀点必须经过三步。

### 一、刀前人味

读者先知道这个人想保住什么。

可以是：

- 名字、清白、身份、岗位、修为、道心、爵位、户籍、婚约、家族名声。
- 父母、孩子、弟妹、侍从、徒弟、同袍、恋人、证人、病人、百姓或旧友。
- 一份账册、证词、遗物、药方、剑、法器、报告、印章、钥匙、门票、契约、身份牌。
- 一个职业判断、一条活路、一点体面、一句没有说完的话。

禁止：

- 角色刚登场就死，只剩功能。
- 角色只有“可怜”“无辜”“聪明”“危险”“善良”“疯批”这类标签。
- 用大段悲惨身世替代当下具体欲望。
- 只让主角心疼，读者还不知道被伤害者自己想要什么。

### 二、刀落具体

刀子必须落在具体物、具体动作或具体选择上。

可用承载物：

- 被拿走的记录、被改掉的名字、被迫按下的手印、被烧掉的账、被封住的门、被摘下的令牌。
- 一页报告、一枚印章、一封信、一块牌、一把刀、一件衣服、一只手、一处伤、一段录音、一张照片、一条系统提示。
- 主角差点说出口又吞回去的话；同伴伸手拿走的那一页；亲人等不到的回信；恋人没有被叫出的名字。

不合格：

- 只写“她终于明白这很残酷”。
- 只写“制度吃人”“记录杀人”“天道无情”“命运闭环”。
- 只让人物说理，不让物件、身体、动作、权限和选择承担压力。
- 刀点完全靠旁白总结，现场没有人因此失去什么。

### 三、刀后余震

刀落之后必须改变下一场。

余震可以是：

- 主角下一次先检查伤处、袖口、手机、证件、权限、灵力、剑鞘、身份牌，而不是照常行动。
- 角色不敢按亮手机，不敢回家，不敢看流程通知，不敢叫某个名字，不敢再用某个能力。
- 同伴下次开口前停顿，避开某个称呼，或把一个旧习惯改掉。
- 证人、亲属、下属、敌人、同门、同事因此改变选择。
- 旧案结论、修行路径、职业权限、关系、证人链、身份安全或现代调查路径变坏。

不合格：

- 刀点结束后下一场完全正常推进。
- 角色只在当场痛，后续没有行为残留。
- 作者用一句主题总结替代人物代价。
- 每次痛都只服务主角感悟，受伤者没有赢回任何一点。

## 单章刀感检查卡

凡本章承担中高强度情绪冲击，开写、审稿或润色时必须填写：

```markdown
## 本章刀感检查

- 本章刀子扎向谁：
- 读者在刀落前已经知道他/她想保住什么：
- 刀落的具体物件、动作或选择：
- 被切掉的是什么：名字/清白/活路/证词/职业身份/信任/身体/未来/修为/亲情/爱情？
- 刀后余震会影响下一场什么：
- 受伤者是否赢回一点：名字、死因、证词、活路、选择、关系、尊严或某个谎言的破口？
- 这是否只是概念残酷，而不是人物受伤：
```

如果“刀子扎向谁”只能写“制度”“历史”“天道”“记录”“证据链”“系统”“命运”，本章刀感不合格。

如果读者在刀落前不知道这个人想保住什么，本章只能算剧情残酷，不能算刀人。

## 刀感强度分级

| 级别 | 用途 | 标准 |
| --- | --- | --- |
| 1级 | 不安 | 读者意识到某人处境变坏，但尚未造成实损 |
| 2级 | 可见代价 | 权限、证词、物证、信任、修为、名声或活路被切掉一部分 |
| 3级 | 不可逆局部损失 | 死因、名字、清白、证人链、职业判断、身份或关系被正式写坏 |
| 4级 | 以输换赢 | 人死、失名、失自由、失身份、失修为或失职业清白，但赢回关键真相或活路 |
| 5级 | 终局刀 | 答案本身要求主角保留牺牲，不能无损救回 |

使用限制：

- 1-2级可作为章内压力。
- 3级适合卷中爆点或卷末前反咬。
- 4级必须配套阶段性赢点，不能只让读者受苦。
- 5级只用于终卷或大阶段关键选择，不能提前滥用。

## 类型化应用示例

| 类型 | 常见刀前人味 | 常见刀落具体 | 常见刀后余震 |
| --- | --- | --- | --- |
| 悬疑/刑侦 | 死者想证明自己不是案卷里的那种人；证人想保住家人 | 报告、证词、监控、封签、签名、尸检结论被改写 | 主角不再相信太一致的记录，证人链变危险 |
| 历史/权谋 | 小人物想保户籍、名声、家人、清白或说话资格 | 官文、印信、族谱、婚书、供状、门籍改变命运 | 一句话让一家人能活，也让另一个人必须背名 |
| 仙侠/玄幻 | 修士想保道心、师门、灵根、同门或凡人 | 法器裂、命牌暗、誓约反噬、修为被废、功劳被夺 | 胜利改变修行路线，能力不能再无代价使用 |
| 穿越/重生 | 主角想保身份、现代知识边界、原主债务或未来改命 | 身份牌、旧记忆、系统任务、原主关系、蝴蝶效应反咬 | 主角知道正确答案，但说出会害人或暴露自己 |
| 言情/家庭 | 角色想保尊严、亲密关系、旧承诺或被爱的资格 | 一句没说出口的话、被退回的物件、错过的电话、公开选择 | 关系不是误会解除就复原，而要带着裂痕继续 |

## 防止过度刀人的规则

刀感不是压抑感堆叠。读者需要疼，也需要看见疼有意义。

必须遵守：

- 每4-6章至少给一次可见回报：小反派失牌、证人活下来、错误记录被打裂、现代案实质推进、关系理解加深、修行或权力格局出现新口子。
- 每个重要死者或受伤者必须赢一小局，不能只为主角成长而死或受苦。
- 同一卷内不能连续使用同一种牺牲方式：主动赴死、失名、封文、回避、待复核、废修为、断关系、替罪不能反复换皮。
- 刀后必须有喘息或整理，不一定轻松，但要让读者知道“痛换来了什么”。

禁止：

- 随机加死者。
- 为了刀而让人物突然愚蠢。
- 用大哭、崩溃、旁白煽情替代具体失去。
- 把所有胜利都写成虚无，导致读者麻木。

## 发布前刀感审查

发布前逐卷检查：

1. 本卷最疼的三处刀点分别是什么。
2. 每处刀点是否都有刀前人味、刀落具体、刀后余震。
3. 读者能否说清这个人失去了什么，而不是只说“主题很残酷”。
4. 刀点是否推动下一章行动，而不是停在章末漂亮句。
5. 每个重要死者或受伤者是否至少赢回一点。
6. 是否有足够阶段性赢点，避免全书只剩压迫。
7. 终章或卷末是否让答案变成现实代价，而不只是谜题解释。

一票否决：

- 刀点只能概括为“制度很残酷”“记录会害人”“天道无情”“命运闭环”。
- 被伤害者在刀落前没有欲望、锚点或具体关系。
- 刀点结束后没有任何行为余震、关系变化或现实后果。
- 终卷刀子只用于解释谜题，没有让主角、重要同伴或活人链承担不可逆选择。
