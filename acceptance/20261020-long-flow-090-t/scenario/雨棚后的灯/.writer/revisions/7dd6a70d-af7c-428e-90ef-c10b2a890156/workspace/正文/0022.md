# 第二十二章 差着一只

二十日中午，林照将剩的一点丝瓜汤倒进锅里，添水下面。水多了一些，面捞出来，碗里还剩半碗清汤。他坐着慢慢吃完，洗碗时听见隔墙有人叫孩子别将饭粒倒进水池，便把自己碗底那两根面也先拨进篓里。

手机的提醒还没响。他把窗边的杂志合好，夹纸露出一小角，留在桌上。昨日读到的那个人已经坐上船，下面的事要翻一页才知道。他没有翻，擦过手，拿钥匙出门。一点半到何店，何岚正从架底抽一捆面，背后的砖露出来，白了的角仍朝外。

“吃了？”她问。

“吃了。你呢？”

她朝后间指，碗已洗净，倒扣在桌边。林照去拿空筐，她说今天先别把筐都铺到地上，车还在里面。他走到后间，何岚跟来，两人把车面那张硬纸卷起，搁在饭桌空着的一头，再抬空车过槛。车落到棚下，他握住推把，何岚站到架外侧，让他往自己这边送一点。

“再来就顶我脚了。停这里。”

林照停下，车同架平行，前角避开侧门。何岚拿回硬纸铺好，放上两只空筐，先从上层取纸巾。纸巾很轻，两筐快满了，车板仍看得见一截。他想将旁边饼干整箱也叠上，她伸手拦了一下，说先看看下头的东西往哪儿去，别只顾上面越摞越高。

他们留下那截空车面，饼干放到另一排刚空出来的一层。何岚拆过的那箱只剩零散几包，她挑出两种摆在柜边，另外的合拢，交给林照。箱子比上回轻许多，他抱着往后间走，到槛边才想起车已经在外面，便将箱子转放车面。何岚看见，笑他脚比手记得牢。

“走过两回，就还想往里送。”他说。

“你要送也行，我下午取一包，又得往里走两回。”

她将价签拿过来，夹在各自筐边。前门有客人问糖，何岚去称，林照继续卸上头的纸。他两只胳膊捧着大包，原本得等何岚来接，这回退半步就能放在筐上。落稳再收手，胳膊没有像前日那样一直悬着。他把旁边一小包放到同一筐里，看见车把下压着一截捆面纸，弯身捡开，车仍留原处。

买糖的人又要一小袋盐，何岚从柜边取，找过钱，才回来拿下面的货。她蹲得急了，围裙带勾住横条，向后一扯没松，便叫林照先别接。带子解开，她把围裙摘下搭到柜后，重新弯腰，取出最外那两捆。

“今天别赶。陶到了重的再挪。”

林照望向底层的水箱，说自己能抱起来。她说知道他能抱，抱起来以后得等人腾位置，上次已经站着等过。他伸出去的手便转去接她递来的面。水箱留下，另几包散货放到柜内，何岚找得着的位置，林照没有再照空筐的宽窄往里塞。

日光斜进棚里，空了一半的铁条在墙上落下细影。架后那片水印仍在，车上的纸巾从一边盖住，何岚换个方向，站着便能取。林照退到棚柱外喝水，手上没闲多久，来买饼干的孩子叫他帮着拿上头那包，他回身伸手，拿到的却是自己刚放进去的整箱。

何岚从柜后探头，叫孩子到前门来选。孩子看着车，问架子是不是卖了，她说没卖，轮子要看看，随后把小包递过去。孩子蹲着拨了一下车前轮，她及时叫住，等人站开才收钱。林照放下整箱，发觉这车上卸了货，便也多了一处要照看的地方。

一点五十多，下面只剩水箱和两包重些的东西。何岚在前门给人称米，他将空出的上层用干布抹过，灰落进布里，露出原来掉漆的斑。他没有去擦底下被架脚压着的纸板，洗过布挂回去，站着等陶来。

街口有自行车铃响，何岚抬眼看钟，两点。陶师傅停在柱外，前筐换成一只扎着绳的纸盒，工具袋挂在另一侧。他把车支稳，先向店里说了一声来了，才解纸盒上的结。


纸盒没有先拆。陶师傅望见架底还压着水箱，便将工具袋和盒子搁到柜外干地，让林照站另一头。两人一起托箱底，何岚将门边那只空筐拉开，水箱才落到旁边的厚纸板上。林照松手时，指节让箱沿勒出一道浅红，甩了甩，陶师傅也在裤腿上擦掌心。

“这个一人能抱，两人拿不住倒要砸脚。”陶说。

何岚把剩的货取净，抬眼从空架后看一遍，让他们等自己送完一袋米。米袋扎好，客人提走，她另取一块厚纸板铺开。陶从袋里拿垫布，林照照上回托住架沿，跟着他慢慢侧放。铁条落到布上，砖已由何岚拿到旁边，折厚的旧纸板仍压在砖底，不会被风吹走。

陶师傅拆开盒子，取出一只轮，又从工具袋另格抽出纸样。林照看见纸边仍卷着，陶将它压在盒盖上，先对一只底板，再把东西放到架边。他取旧轮时换过两次握法，螺帽松了，放进浅盒，何岚移到棚边站，林照两手仍扶着空架。

新旧轮并在纸板上，圆边差不多齐。陶翻过底板，贴到原来那处，孔能从上面看通。他先穿过一颗螺丝，何岚蹲下一点，看着它从另一面露出头。林照扶架的手松了一线，想到只要这样再来一只，今日便真能把那块砖拿走。

“还没完。”陶师傅将第二只从盒中拿出。

那只轮边颜色相近，底板却比前一只长出去一截。林照起初以为是摆反了，陶自己也转了一个方向，拿起纸样重新贴。纸上的两个点露在板外，转回来，仍有一头错开。他把两只并着放，长出来的那一截正对着何岚。

何岚看看他，又看纸盒：“这不是一对？”

“他给放一盒了。我拿的时候，只看了上面这只。”

陶说完，低头将盒里垫的纸取出。里面没有第三只。他摸手机，向供货人拨过去，一手扶着盒盖站到棚柱旁。电话那头声音断断续续，林照听见他说两块板不一样，又让对方等自己发图。陶拍过两只，放下手机，回来再看架底。

“这一只用不上。得换。”

何岚没接话，将靠脚边的空袋提到车上。前门有人喊她，她进去拿酱油，留下林照扶着架。陶师傅把那颗试穿的螺丝退出来，放回浅盒。林照问是不是先装好的这一只，另一个等换来，他听见自己的话，已想到了何岚下一回少搬一点的可能。

陶抬头看看：“一只新一只旧，今天还是得垫。下回还是要空。你问她。”

林照没有向柜台那边喊。何岚找过零钱，拎起裙边跨过地上的纸板，回来听他说了。她先问好的一只是不是已经拧紧，陶说只比过孔、试穿一颗，便叫他先拿下来。

“我不留半只活在这儿。你去换齐，回来一回弄。可我今天还没答下一回。”

陶点一下头，取下新轮，放到纸盒盖上。林照的两只手都沾了灰，架子扶久了，掌心有点滑。他换过握处，何岚便挨到另一侧接住，让他腾出一只手擦。她没有怪他方才多那一句，只问陶是不是还有别的办法。

陶指着长出来的底板，说得另开孔，那又成了另一桩工，自己不想现成件拿错，反倒叫她改原架子。何岚说那就不弄，今天把旧的放回去，先卖货。他的手机响起，对面说了几句，他应着要自己明日去拿，没叫何岚再关一次门陪他跑。

两点二十多，盒中那一只长板仍干干净净，和旧轮上沾着灰的底板分在两边。林照看见何岚将车上的纸巾往里推了半掌，好给经过的人留路。她手上整理得快，嘴抿着，陶放下手机以后，也没有马上又说一句总能修好。

他蹲回来，拿旧件，先将方才卸下的螺帽一颗颗找齐。林照重新接稳架沿，何岚退开些，去前门接下一位客人。


旧轮装回，陶师傅将工具放低，叫林照跟着扶起。何岚回来摆砖，先试落的位置，架脚在砖面上停妥，才把那片压弯的纸板放回原处。林照松开手，站到另一头望，架子仍立在原来的地方，车上两筐纸巾却把棚柱后那点空处占着。

“货先别上。”陶说，“我看一下。”

他扶过架沿，蹲着再摸新动过的旧件，随后将垫布卷起。林照把浅盒递给他，里面已没剩螺帽；陶自己看一眼才收到袋中。他将两只新轮分别包好，都放回纸盒，纸样折回原折，收入工具袋另格。何岚没有伸手拿那只合孔的样件。

她到柜上取收据夹，抽出昨日那张便笺。林照看见上头的一百，旁边二十的字小些。陶师傅接过去，站在柜边读了一遍，抬眼朝她说：“这回二十，照说的算出门。那八十不收。”

何岚将便笺往回抽一点，又停住。

“我没装成，也看见你跑来了。二十照原话。可东西是你拿错一只，不是我今天又挑了别的。”

陶点头，说这趟换件自己去，不叫她出路钱。何岚问若换来，还是不是一百，他说装一对原来那种是一百，今天的二十已作了工，后面要做再算一回，不能把已经跑过的都抵进去。他话说得慢，说到末尾，手指在便笺边上搓一下，将纸抻平。

她看向林照，没等他替谁回话，又朝陶说：“我知道你有工。可我这两回搬下来又搬上去，也有我的工。换来以后你先看齐，别又让我卸一遍，光为了看一眼。”

“我先对。对完再找你。你到时候不想做，也行。”

何岚叫他在便笺上记这一回没装，那二十算清。陶从柜上借笔，写了几个字，将纸还给她。她收回夹里，没拿钱包出来。林照原来把手放到自己的裤袋旁，听她最后一句说完，手落回身侧，低头捡起陶收袋时落下的一片灰纸。

前门那位买酱油的又折回来，问有没有成箱的饼干，孙女下午要带到河西。何岚让他稍等，从车上搬下先前合拢的那箱，拆开数，差了两包。她去另一排找，同一种却只剩一包。他看着街口，说车快到了，散的就不要了。何岚拿着那一包站在门内，等他走远，才放回原处。

林照说方才先拿出来，说不定赶得上。她将箱盖合好：“少一包，就是少一包。你别替我找个能追上他的办法。”

他原想去门外叫住那人，脚没再抬。何岚把散包另放到柜上，捻掉箱沿一段胶带，说明天进货得记着这个，整箱留一箱，不能全拆。陶还站在旁边，手中的纸盒已经扎好，听她说完，才道要走了。

陶提起纸盒说得回铺，人家约了来取门扣。他在这里多留的这二十来分钟，外头那辆自行车已晒热了，握上车把，又松开手去扶车座。何岚走到棚边，说车明天自己还要用一阵，二十二号照旧给他送回。

“那天六点前，我在铺里收。到前头来个电话。”

林照说记着。陶看一眼车上两只筐，叫他们别站上去，自己有时踩一下够墙上的东西，何岚这边也别照着做。何岚说自己又没打算踩，伸手将最外那筐往内推，他便笑笑，将纸盒扎回前筐，工具袋放稳，骑走了。

林照站到车旁，想一口气把纸巾都送回去。何岚却先抽了两包，放到柜边，说客人刚才问过，要留下。两包拿开，筐上就露一块空口，他看见先前夹在边上的价签已经歪了，手伸过去，何岚说等会儿自己夹，叫他先把水箱挪回低处。

这次她站到另一头，林照等她托稳，一起把箱子从纸板上抬到架边。他们先将箱子落地，腾手理好底层的货，再送进去。何岚站直，腰背靠柜沿歇了一会儿，让林照先拆筐里的纸，不必等她。他取一包放上，再一包，空筐露出底，才推着车沿棚下平地慢慢移近半步。

不用从后间抱出来，确实省了路。到最下面的面，仍得蹲下，一捆捆放回何岚找得着的那层。她来帮着分粗细，林照拿错一捆，自己看见纸腰便改过来。她嘴角动一下，说这回倒认得，随后拿起笔把价签夹正。

三点刚过，车面卸空。两人把空车抬过槛，送回后间墙边，硬纸仍铺着。林照从水池到门边走出来，何岚端着杯子跟在后头，两人没有碰着推把。饭桌旁那只凳子能拉开，她坐下，先喝了半杯水，才叫他将地上的大纸板折起来。


林照把纸板的脏面折在里面，竖回空箱后。何岚坐着看他，忽然说自己上午想过，若轮换好，晚上就能将架子底下扫一遍。她朝那块砖看了一眼，杯子握在手中，没有立刻起身。

“明天再说。”林照道。

“不是明天的事。我就是今早想了。”

他嗯了一声，站到柜旁。何岚把杯底那点水喝完，问他晚上有没有菜，林照说没有，得去一趟。她叫他现在去，天还没斜，自己这里剩的几包慢慢摆。他先将扫帚提起，何岚说不用再扫，今日脚下都扫过两遍，他便放回去，去水池洗手。

出了店，林照向菜摊走。卖菜的人正把断的豆角挑进另一只筐，他看见没断的那一把嫩些，问了价，比前日贵。对方说刚来这一筐，自己也没便宜拿。他选了一小把，又买两只番茄，袋子提到手里才发觉买少了，回屋炒好，也就一盘。

他没回头添。午后扶架时握得用力，手掌用水冲过还留着红印，提袋便换到另一边。到家，先将豆角两头择掉，掰成短段，放在盆里。杂志还摊在桌上，他坐下读过下一页，那个人坐船去了另一处，又遇到旧时认识的邻居，前页没说的事，原来并没有多惊人。

林照将书夹好，起身切番茄。刀从圆皮上滑一下，没切下去，他换个落刀处，半只便稳稳伏在板上。番茄炒好盛在碟里，豆角也焖熟了，他关火，将锅盖上，去何店买酱油。家里的瓶底够一顿，往后又得想起才跑，今日手里没有替人捎的东西，正好买自己的。

何岚已将方才留在柜边的两包纸巾卖了，里面空着一小格。她拿酱油时，许舟从前门进来，袖口挽着，向柜台要一小袋洗衣粉。何岚问昨天的饼怎样，他先笑，说不是叫她别问么，母亲烤焦半片，最后还是自己吃掉。她说这回可没问好不好吃，许舟一时接不上，自己也笑起来。

林照接过酱油，往门边让。许舟付钱，才向棚下望：“轮装了？”

“没装。”何岚说，“带来两只，有一只对不上。他都拿回去了。”

许舟以为还是前日那种孔错，林照告诉他这一回一只合上了，另一只长出来，陶说拿货时只看上头一只。自己问过要不要先留好的，何岚不愿留下半桩，已经把旧件都装回去。原本说的一对连装好一百，今天没有装。他说完，许舟蹲着看看砖，没伸手去摇架子。

“那一百也没给？”许舟问。

“昨天先给过二十，原说不合就是跑这一趟。今天算掉了，八十没给。”何岚说，“前天看架那二十是另一次。你别听了两个二十，以为又给了四十。”

许舟低头算一下，说现在两趟共花了四十。何岚说是，车押六十还压在陶那儿，车送回才退，不算修架的钱。林照看见他终于将这几笔分开，何岚也没把便笺抽给他看，接着问他下午铺里忙不忙。

许舟说师傅去送东西，自己在门边坐了半下午，最怕来的人问一件自己认不出的零件，幸好两位都是按原单取东西。他想快一点把风扇递出去，提到半路，客人说还没试，自己又放下来开。讲到这里，他有些不好意思，说前天才叫人试过，换个人来，自己又忘了一回。

何岚说那就让人试，谁付钱谁拿回去用。许舟把洗衣粉装进家用袋，问换了那只以后还来不来，何岚说等陶拿齐、问清下一回的钱再说，自己今天不往外许。许舟点头，说若定了先告诉自己，能不能来，要看铺里哪天取货，别先数上这双手。

“你自己肯说就好。”何岚道。

许舟站在门边，又说师傅回来以后，自己已经讲了那位客人来取时险些没试的事。师傅问他是不是人已经走了才想起，他说人在，自己放下了才开。何岚问后来呢，他说师傅让他下回提到门外以前先把插头拿在手里，省得急起来光看取货单。

林照想夸他已经能看铺，许舟却指着袋里那包洗衣粉，说自己今天只给人取过两件，第三个人问的东西没敢卖，叫人等师傅。那人嫌等，自己走了。

“你没见过，留下人也是干等。”何岚说。

“我也知道。可他走的时候，我还是想叫回来。”

许舟说完笑了笑，低头把家用袋提稳。林照站在旁边，想起刚才自己望向街口那一步，没有将这句话接成一番教他的道理，只说今天陶带来的另一只，自己蹲着看也只看得出长了，真该怎样装，仍得让陶来。

他朝林照举举袋子，自己回家。林照将酱油收好，告诉何岚菜已经做好，得回去吃，她叫他快走，番茄搁久水都出来了。他走出门，又听见她叫一声，以为还缺什么，回头见她指的是他落在柜边的找零。

零钱收进口袋，林照这回没有再停。到了住处，锅盖揭开，果然积了一层小水珠。他把豆角热透，添好饭，将酱油瓶摆进自己那排瓶子里。窗外有人推过一辆车，声响沿墙过去，他盛出番茄，没有端着碗再去窗前看。
