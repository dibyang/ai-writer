# 第三章 渡口的空椅

第三天下午，雨停了。何岚把店门外的布帘卷到最上头，林照从窗边望进去，货架已经重新摆回雨棚下，前天腾出来的地方又装满了东西。

“出去走一趟？”他问。

“你先替我看五分钟，我把饭吃完。”

林照站到柜台后，替一个老人找了零钱，找得慢，老人也没催，指着外头问是不是要放老电影。他照实说还没定片子和时间，只在看地方。老人说那就好，别让人把孙子带来又散了，接过零钱走了。

何岚吃完最后一口，把碗放进水池，叫隔壁卖早点的嫂子帮着照看店面。林照这才有机会把候船亭的想法说完。

“那边比雨棚大。我想着，要是来的人多——”

“先去看。”她把店里的折凳往墙边收了收，“你别又在路上把日子答应了。”

从店里走到渡口，不到十分钟。水退后，台阶边留了一圈黏湿的泥。候船亭的长椅看着空，只有靠柱的一头坐着一位提菜篮的女人。女人把腿侧向外，给他们让了一个位置。

何岚没有坐，先摸了摸椅背。手上落下一层细灰，她用纸擦掉，站在林照原本打算挂幕布的那根柱子旁边，朝外看。

“你要挂这儿，人从哪边上船？”

林照沿着她的目光走了一遍。两根柱子之间最宽，却也正对台阶。布一挂，等船的人就得绕到侧面。侧面那条路上堆着空筐，只够人侧身走。

提菜篮的女人听了一会儿，问他们是不是来摆摊。何岚摇头，说只是想借个地方放电影。女人有些不好意思，往椅子里面挪了挪：“那我是不是得坐别处？”

“不用，我们还没借。”林照赶紧说。

她把菜篮放回脚边，仍用一只手扶着，像怕妨碍他们。林照也没有再站在她眼前比画。他走到亭外，看见另一头墙角摆着一把缺了半截椅背的竹椅，用一根绳拴在柱子上。

“那把不是没人用。”女人说，“晚班船有人坐。怕给搬走了，拴着。”

林照手伸到绳边，又收回来。他过去总是看见空位就想着添人，今天才发觉，一把暂时没有坐人的椅子也可能在等谁。何岚在旁边看台阶上的泥，没有替他把这个念头说出来。

一条船靠过来。女人拎起菜篮，走得很慢，前头一个年轻人回身接住她的篮子。林照退到柱后，直到他们都过去，才又回亭中看那一小片空地。

“站着看的人多一点，也能——”他刚开口，自己先摇了头。

何岚听见了，问他要让周伯站多久。林照想起周伯在柜台前不停换脚，说坐下再起身费劲，便在长椅边蹲下，试着从那个高度看原先选的位置。柱子正挡住一角。

“换边呢？”

“你可以再想。但亭子有人等船，不能当你的空院子。也别因为来的人多，就非找个能全装下的地方。”

林照站起身，裤腿蹭上了一点椅边的灰。他本来想说，只办一场，总会有人赶不上。话到了嘴边，又想到借雨棚那晚何岚说的“今天到今天”。她没有答应把店永远腾空，周伯也没有答应把柜子里的东西都借出来；只因为他回来一趟，别人的日子就得跟着挪，这个道理说不通。

“那先办一小场。八张凳子，留出门和过道。真坐满了就不再加。”

“八张，你也得一张张找。”何岚说。

“我去问。你这边只借一个晚上，具体哪天等布补好再说。”

她这才朝回去的路上走。走到台阶口，林照又问：“要不分三晚，每晚少些人？”

何岚停下，看了他好一会儿。

“你说三晚，我要是天天过去帮你，店谁守？不去，你一个人又说忙不过来。我只答应一晚，你别替我加。”

“好，一晚。”

他没有说“其实不用你来”。想要那块雨棚，就得有人认得开关、找得到凳子，也得有人看住进店买东西的人。这些事不是把何岚从安排里删掉就能消失。

回到店里，照看店面的嫂子将收来的钱交还何岚，笑着说自己少找了一毛，等客人下次来再补。何岚说记得人就行，去抽屉里拿账本。林照没有在柜台边摊开自己的安排，只把门外两只空筐挪到不会绊脚的地方。

他向隔壁借到两张凳子，又给周伯打了电话，约明天下午到店里，在亮处看那张节目单。周伯问他是不是已经选好片子了，他说没有，原件先留着，明天先看纸。

电话里静了一会儿。

“那把纸带好，别让我又跑空。”周伯说。

“我带着。您要不想来，我送过去也行。”

“我走一走。下午四点前后，别赶着我吃饭。”

林照把电话收好，去后间看了一眼。布的中间摸上去已经没有凉意，何岚仍让它挂着，免得卷起来又留下湿气。许舟今天有事没来，针线和那块试过的棉布都不在店里。

林照走到柜台边，把约在店里核字的时间告诉何岚。何岚把借来的两张凳子靠墙排好，手指点了点最外面那个位置：“周伯要来，这儿能伸腿。等人来了再搬，可来不及。”

林照搬开旁边一箱水，自己坐了一次，觉得还窄，又往里挪了半步。何岚没再教他。她回柜台卖东西，他坐在那把空凳上，直到前门进来一个人，才起身让出路。
