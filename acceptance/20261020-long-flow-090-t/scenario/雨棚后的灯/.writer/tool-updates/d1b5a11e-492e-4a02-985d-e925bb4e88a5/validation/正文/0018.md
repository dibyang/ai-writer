# 第十八章 各自收好

许舟捏开第一只夹子时，林照往上托了一点，布边离开绳子，没有一下落下来。许舟将木夹放到柜边木板空着的纸角上，回头问这头稳不稳。林照说稳，他才去松另一只，手先垫在布下，再将夹口张开。

绳上空了，两个人仍各托一边。许舟让林照稍等，先把没有展开的宽处接到自己臂上，再顺着原折往里拢。小弯折到上头，他没有用指头抹平，林照也只托着完整处，将垂在自己腕上的一角送回去。布放上垫纸的木板时，袋子被许舟先拿开，没有压在下面。

“这里没蹭着吧？”许舟问。

林照朝刚才靠墙的一边看看，边上没多一道黑印。许舟翻过补缝附近那一小截，线的颜色仍不齐，旧弯也在。他不拿两头扯，只将那截搭回去，把原来折进去的薄边护在里面。袋子张开，他先送进一边，等林照托着另一边放妥，才一点点将袋口往外提，没让布在口上挤成一团。

两只木夹并在纸角，许舟捡起一只，又将另一只拿在同一掌里。何岚还在前门，买面的女人正要找硬币，陈阿姨站在货架旁比两块肥皂的分量。他没有拿着夹子从她们中间伸过去，只将夹子搁进柜边的小盒，叫何岚等会儿看，自己还在这里。

林照将包纸空出来的边折回，留住垫袋的中间一块。纸上没有油点，往后还能垫别的。他想拿走，许舟说等何姐收了，自己再收纸，别让袋底先落到木板缝上。他便松开手，先将一张空凳移回柜边，沿着早晨摆的位置放稳。

陈阿姨挑定了小块肥皂，问何岚外头那层纸能不能不要，自己带的袋子装得下。何岚说包着拿回去吧，不另外算钱，手里还拿过钱，别直接往里摸。陈阿姨便没有再拆，付过钱，将肥皂另装进布袋的小口袋，同喝水的杯子隔开。

许舟看了手机，两点五十三。他抱起整袋，绕过空凳，从留着的通道进到店门边，朝何岚说：“布还你。我今天拿的这一袋，两只夹子也在盒里，一只没少。”

她先给女邻居找足零钱，等人提面走了，才空出双手。许舟将袋子往前送，她两手接住底下，他等她说稳了，才松开。

“我接着了。”何岚说。

周伯坐在棚边看见，笑说这回没等到三点。许舟笑了一下，没把已经递出的袋子又搂回来。他指了指小盒，何岚看过两只夹子，说数对，自己知道。他这才退开门边，让陈阿姨能抱着布袋出来。

何岚没有把布留在柜台下。她抱着袋子往后间去，许舟跟到门边，问要不要开柜。她说不用，柜门朝这边，自己能腾手，便先把袋放到后间干净的凳面，开足柜门，再将整袋平托进去。袋子放在柜中原来收布的那层，旁边的被单被她往里推了少许，袋底平着，口上的绳头收在里侧。

林照拿着从木板上收起的包纸，走到后间门口，看见她将袋口转好。许舟没有替她挪被单，只等柜门合上，才说今日没有拆线，也没烫，挂过一截，没落地。何岚说自己看见了，下一回要用还得来问，今天先收这回。

“我也没问下一回。”许舟说。

“那最好。回去做你的。”

他转身出来，抬头看看绳子，又摸摸裤袋里的钥匙，确定不是将家里的钥匙也随布塞进去。两只手空下来，走到门口时，他忽然回身，把刚才挪去墙边的凳子提回林照面前，说这张也是店里的，别跟着往隔壁送。林照点头，将它和先前那一张并好。

许舟向周伯和陈阿姨道别，说要回铺了，不等送人上车。陈阿姨叫他好好走，吃的东西自己买，不用顺路带。何岚已经回到柜台，他出了前门，沿街向修理铺走去，没有再带走那袋布。


林照将包纸折好收进包外袋，再将两张店凳送回柜边，何岚看见，叫他一张往里半掌，免得取下面的货总碰着。他照着放好，又将隔壁的两张分两回送过去。擦窗的人已将窗扇关了一半，见凳子回来，摸摸上面干不干，说自己还得站上去擦最顶上一条，今天倒没耽误。

“两张都在这里了。”林照说。

对方看过数，叫他搁墙内侧。他放下，没将人家的凳子同自己那张小的混在一起，也没因为借过一回就替下次留话。

回来时，许舟的消息到了：已回铺，两点五十八，锅收进柜了，师傅叫他先去洗手。林照看过，向还坐着的周伯和站在前门的陈阿姨说许已经报到，何岚在柜台后也听见了。他没说自己跟去看了，只回许一句收到了，手机便装回袋中。

周伯这才站起，扶着凳背等膝盖直过来。林照将自己那张小凳拿在一手，另一手提起稳凳。棚下六张的位置空了，地上剩下一小截不知何时掉下的纸腰，他把凳子先放稳，捡起纸，丢进何岚指的篓，再去看原来垫袋的木板。包纸已经收在自己包外袋，木板上没剩夹子或布角，绳子仍留原处。

何岚从侧门走出来，抱起早晨挪进去的一只空筐，走过那条路，将筐放回靠墙处。她看了看钟，还没到三点。

“就这样，收齐了。板子别再替我挪，我晚上还要用。”

林照说好，提起两张凳退到棚外。周伯走在他身旁，没去接那张稳凳。陈阿姨已经将肥皂和杯子都放妥，手上只拎自己的袋子，问街口这会儿车好不好叫。何岚说先在前门外等，别站侧门风里，等车停了再过去，自己这里还看得见。

陈阿姨拿自己的手机叫车，字看得慢，问林照选的是不是眼前这个门口。他将凳子并放到不挡人的一侧，俯身看屏幕，只替她对了店名，没有拿过手机替她一路按下去。她按好，司机说几分钟到，便先站在棚外的阴处，问何岚那块小肥皂泡水后会不会一下就软。

何岚说用完把盒里的水倒掉，哪块泡着都得软。陈阿姨笑，说这倒怪不着肥皂，自己那只盒底就老积水。女人买面时忙着找的硬币方才滚到柜脚，何岚蹲下捡，没再陪着站出来。陈阿姨朝里摆手，叫她做自己的事，自己认得车，不用三个人都替她盯。

周伯说自己先慢慢回去。林照问要不要一道等她上车，老人看向街东，说她这儿有你，自己就不多占一处；凳子仍请他送进门，晚些敲门就是，自己走到楼下也会歇一下。他没有因为想表现腿脚利索，就扛起那把凳。钥匙在掌中转正，他向陈阿姨道别，沿来路走了。

陈阿姨望着他的背影，说今日没上那段楼梯，倒还轻松。林照没有应下以后都在这里，只说何岚今天借的这一回已收好，往后真想坐，还得看各人的事。她说自己知道，哪能今天买了一块肥皂，就天天在人店里坐着。

车到了，她先对车牌，再向何岚叫了声走了。何岚从柜后应她，没放下正在称的东西。林照陪陈阿姨走到车边，替她扶住门，等袋子放到腿上，才将门慢慢带好。她说自己到家来一声，叫他不必为这几分钟的事跟到河西；他应下，没有预先向周伯说人已到家。

车开出去，林照回到放凳的地方，一手各提一张。自己的包里是自己的清稿，周伯那份没有随人来，也用不着从何岚店里往回找。何岚从门内叫他看看木板，他回头，见她已将一只装好货的小筐放上去。原来给布空出的那一块，又有了她要用的东西。


林照应了一声，提凳向东走。到了周伯住的楼口，老人还没上楼，正扶着栏杆，把鞋里卷起的袜边往下理。见他两手都有东西，周伯说自己没摔，也没丢钥匙，不用腾手，等这点皱褶抻平就好。

林照将两张凳放下，等了一会儿，周伯才重新站直。老人看见自己那把稳凳腿上有一道旧浅印，问是不是今早拿出去时磕的。林照不敢一口说不是，低头看过，凳脚下面已经磨圆，浅印里也有灰，自己没见它什么时候留下。他说这回抱来抱去没听见碰响，可旧印原来在哪儿，自己没逐处记。

周伯弯身看了一眼，笑他认真，叫他提着，凳子不是第一天用。林照便把小凳换到左手，稳凳提在右边，凳脚朝自己身后，不横在老人要走的那一级。两人一前一后上楼，到了转角，他先把凳子落在平处，周伯站着歇，手仍扶着栏杆。

“她上车了？”老人问。

“上了。她自己叫的，付钱也自己付，到家会来一声。现在我还没收到。”

周伯说知道了，没叫他当着自己打去追问。林照看见窗边那块潮印已经干了，栏杆旁也没有积水，便等老人愿意再走，自己才提起凳子。没有车在楼下按喇叭，柜台那边也不在等他回去，他不用一手提着凳，一手再向谁许一个赶得上的时候。

门由周伯自己打开。林照先将稳凳送进门，照他指的地方放回桌旁，四只脚都落稳，再提起自己的小凳退到门外。周伯看过，说这把还在这里，下回吃饭腿就有地方放。他没让林照把松脚那把顺便拿去修，自己把门再推开些，请他进来喝水。

林照将小凳放在门内一侧，进去洗了手，接周伯递来的杯子。老人坐回稳凳，抬脚试了试，问何岚是不是已经将布收了。他说许亲自交到她手上，自己和许在后间门边看着她收进原来那层柜，夹子也收回；许两点五十八自报回铺，没有误那半小时。

“那就行。人家还得做一天的事。”

桌边抽屉关着，上头没有他今天在棚下念的那张纸。周伯说自己的清稿还留原处，柜中节目单和片套也没往外拿，今天只借出去这把凳。他伸手拍拍凳沿，叫林照别又觉得空着手回去没做成什么。

林照低头看看杯中的水，说自己包里还有一张。周伯说那是你抄的，你带走，别同我的这张来回换。他笑着应了，将杯底最后一点喝完，冲净以后放在水池旁。老人家里留下的原信、原片和节目单，不因为棚下十来分钟便多出一份齐全来历；从粮店送过碗、看过一封信，各有说得出的一截，那些接不上的年月和转手，仍旧接不上。

周伯从里间端来一只小盘，问他晚上要不要留着吃。林照看见盘里是才拣好的豆子，想到自己住处还有上午洗过的菜，便说今天回去做，不留了。老人没劝，盘子放到自己一侧，叫他拿好那把小凳，别送了别人的又落下自己的。

下楼时，他的手轻了许多。小凳一手就能提，包纸折在包外袋，里面的清稿仍是原来的字。他经过何店门外，见侧门那条路已有人提着米袋走过，没有再问要不要明天也摆六张。何岚隔着柜台看见他，朝小凳指一下，他举了举，告诉她自己的拿回去，才想起家里只剩一把青菜，便将凳子放在脚边，等前头称米的人付完钱，买了两个鸡蛋。

何岚拿纸袋装好，叫他自己托着底。一个蛋壳上有点灰，他伸手想擦，她叫他回家再洗，眼下别隔着袋子来回搓。他把找回的零钱装妥，先将蛋袋送进包里空着的一格，再提小凳，转身时没让凳脚扫到门边的米袋。何岚已经接过下一只秤盘，问后头的人要多少，他便带着自己买的东西走了。

回住处，他把小凳放回桌边，取出薄袋，将清稿放回纸夹前层。后层的私人信摘抄、电话页和旧改稿各在原处，没有同今天念的纸混在一起。他先没去添一句结尾，将纸夹收进干处，才拿菜盆去水池。

陈阿姨的消息在洗菜以前到了，说已到家，肥皂那层纸拆好，盒里的水也倒了。林照擦干手，回她知道了。手机放回桌面，今晚没有等着他替谁念的一张新纸。他把洗好的菜下锅，先给自己盛了一碗饭。
