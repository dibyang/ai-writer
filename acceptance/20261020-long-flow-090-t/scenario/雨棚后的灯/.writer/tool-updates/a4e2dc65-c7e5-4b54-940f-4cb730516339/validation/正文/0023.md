# 第二十三章 明天要卖的

二十一日上午，林照穿到街东的旧鞋，右脚底下有一截线松了。走快时鞋底擦着地，轻轻响一下，他本来已经到何店门前，又转身往补鞋摊去。那日听讲述的男人正在给皮鞋上油，见他来，将刷子放到纸上，先让他脱下右脚那只。

林照穿着袜子站，男人从凳底踢出一块干板，让他踩着，免得袜子沾灰。鞋拿在手里一翻，裂的那一点比穿着时看得清。男人说能缝，叫他坐下等，眼前这双先擦完。林照坐在旁边，看他把鞋面那点油刷匀，另一只并到一处，才来拿自己的鞋。

“你还穿多久？”男人问。

“能穿就还穿。不是今天这一路。”

对方嗯了一声，线从旧孔旁过去，没有沿松开的那一截拉紧了就算。林照看着他的手，想起棚下那天他说补牢比看不出补过难，眼下自己只盼鞋底别再响，没有请他讲旧时的鞋子怎样做。缝好穿回去，林照站起来走两步，鞋底贴住，袜尖却卷着，便重新脱下来理平。

十二块，男人报了数，他付过，手指在鞋边摸一下，露在外面的线短而硬。回到何店，已经近十一点，送货的人蹲在柜前算钱。何岚对着单子，将其中两行划开，叫他别照整箱的数收。

“半箱也得拆。我给别人都是一箱。”那人说。

“你上回说能搭着拿。今天饼干整箱，纸巾拆半箱，别给我全放下再讲。”

门边留着一箱没拆的饼干，箱口朝上，新胶带仍完整。林照望过去，何岚看见，说昨天少了一包就没卖成，今日这一箱留下给要整箱的，另外散卖的还有。对方将单子拿近，算半箱纸巾贵出的那点，何岚听完，没马上说不要，而是朝棚里看了一眼。

“贵这一点就贵。你再给我一整箱，我晚上又得抱进去。”

林照走到门旁，将留着的饼干箱往内移。何岚叫他不要送后间，柜边底下有空，放进去不用弯得太低。新纸巾从外箱分出来，散包放进原筐，腾出的外箱由送货人带走。林照帮托着一头，等何岚数清，才松手。他们今天没有将平板车抬出来，后间墙边那块低板上仍是昨日铺的硬纸。

半箱比按整箱分摊多两块，何岚拿笔记在单边，叫送货人也写清。对方说下回肯拿整箱，这两块就没有，她没接这句话，只核过今天留下的数，把货钱付了。林照听见两块，原觉得不算什么，望向刚才露出来的柜脚，才知道她花的这点钱，买到的是自己不用再把一箱从里头抱出来。

有个女人提着两只布袋来要面，站在门口问能不能进去。何岚让她进，自己从柜后绕出来，拿同样一捆让她比。女人选了细的，又将布袋放地上重扎底绳，两个人都站在柜前，林照抱着半包纸巾从旁边让过，没有叫谁先起身挪脚。何岚看了他一眼，等人走了，才将最外那只空筐收进去。

送货人说有个铺子换下两只新些的架子，比何岚这只顺眼，轮子也齐，问她要不要，自己能给留话。林照听着，问价，男人说三百多，细数还得问原主。何岚正在收单，抬头看他，又望向柜边放箱的那一格。

“多宽？”她问。

男人两手比过，林照看不出比这里的多多少。何岚问旧的收不收，对方笑，说自己送纸送饼干，不拉废铁，真要了得另外找人搬。她核过合好的单子，说先不留，自己没答买。男人把单递回，抱起拆空的外箱出门，脚边让过那块砖，没再劝她。

“多两百多，换个新的，也许省事。”林照道。

何岚看着他：“你算的哪两百多？”

“同装轮的一百比。”

“那你把旧的搬去哪儿？”

他朝墙边望，那里竖着空箱和扫帚，上头是晚上要拉的窗钩。前些天自己也望过同一个角，何岚已比给他看，这会儿又先想到那里。她没接着问，只将新留下的半箱纸巾送到他手边，叫他帮把外侧两包转向前。

两包转好，价签露出来，何岚将新单夹进收据夹。里面昨日陶写的那张便笺还在，她翻到那一页，手指压住纸边，没有抽出来给林照重看。他站在柜外，忽然有些不想说话。自己穿鞋花十二，鞋穿在自己脚上，怎样缝听人说过便能定；这只架子在她店里，每一次货从哪儿拿，都得由她站着做。

何岚从柜后出来，蹲下取一袋面，不用先推车，也没绕进后间。她起身，把面递给刚来的客人，报过钱，又问对方家里那盒肥皂用完没有。林照向外让了让，鞋底落平，他这回站稳，没有急着再添一个更省事的办法。


近午时，林照离开何店，往面摊走。许舟端着空饭盒从修理铺出来，正要去买饭，看见他，问那双鞋底下怎么一走一响。林照低头听，才知道是鞋跟沾了一粒小石子，方才没觉出来，靠墙把它从纹路里挑掉，响声便没了。

许舟笑他修过鞋还得自己看，林照说补的是前面，这回在后头，换一处便又要弯一次腰。两人到摊前，许舟要少一点饭，另添一份菜。卖饭的人盛多，他说自己真吃不了，又将盒子往回推，叫对方收一点，没端走才抱怨。

林照要了一碗面，两人在摊边挤着坐。许舟的筷子夹不开，外边一层纸粘紧，他从袋口慢慢撕，终于抽出一双，递一根给林照问要不要。林照举起自己那双，他才笑着将两根并回去。

“早上没吃？”林照问。

“吃了。师傅今天叫我把那边旧东西分开，我翻了半上午，饿得快。”

许舟说原来柜里堆着的盒子，看着空，其实下面还有几包螺丝，自己想省地方，将两只套到一起，上头那包便找不到。师傅让他分回来，他一只只倒在纸上，才摸到纸袋。他说得有点烦，夹菜时却先把一根硬梗放在盒盖，没有将整段话变成师傅故意挑毛病。

林照问后来找齐没有。许舟说找到了，盒子外面也写了名字，下午自己得把取机那排分清，别又将等零件的放到已经做好的旁边。他吃过一口饭，抬眼看看铺门，外头没有人等，便将盒盖放平，慢慢吃完最后那几口。

林照的面还剩半碗，许舟先起身，问他去不去坐一会儿。林照说等吃完过去，他便拿饭盒回铺，出门前还向卖饭人买了一只茶叶蛋，装在小袋，说下午留着，免得师傅四点去买东西，自己又饿着看门。

等林照进去，许舟已洗过饭盒，正把一只风扇罩往原来位置装。机身放在低桌上，插头摊在另一边，没有插电。林照站到门边，许舟叫他帮扶一下底座，自己要把边上最后那一处扣进去。罩子落到外圈，几处贴着，一边却鼓起少许。

师傅从后头出来，手沿边摸了一圈，叫许舟先取下来，看那只扣到底靠里还是靠外。许舟看了一眼，说自己刚才想着转正上面的字，没管这一头，便拆下重放。他没有让林照帮着按住鼓起处硬扣，另一手先理好边，扣子才轻轻落进去。

师傅重新看过，将插头拿起来试。扇叶转时，许舟蹲着听，林照在旁边站着，风先吹到他脚背，转过头才到额前。师傅关掉，拔下插头，说放到待取那一排，许舟自己绕到桌后，提稳机身，没等林照替他送过去。

“这个我做得来，一急还是装歪。”许舟回来洗手时说。

“我看着也以为扣上了。”

“你站门口，我自己在前头，都只看上面的字。”

师傅在柜后说，罩子放回去也算一件活，不是只干完里头才算修。许舟应着，将风扇转回朝外的方向，忽然又低头看过刚才那一处。林照想说这回肯定齐，许舟先笑着朝他摆手，说别急，自己再看。他看过，才将手抽开，问师傅这一台是不是今日取。师傅说三点，有事先交代，不用一直望着门。

他笑了一下，拿布擦桌，顺便把刚才那包拆开的扣件收好。林照不再问那只架的孔，站到不挡人的地方。许舟将今天已经做好的两件分开，取机纸夹在各自的把手上，有一张被风扇吹落过，下面压着清楚的折痕，他拿起来抻平，重新夹牢。

林照问下午能不能歇一会儿，许舟说要看谁来取，自己吃过饭了，不必为歇又跑到街外。他取出小袋里的茶叶蛋，先放进自己的饭盒，免得同柜上沾灰的东西搁一处，盒盖扣住，才回头问何岚想不想继续修。

“她还没跟我说定。早上先订货，纸巾少拿了一半，饼干留一整箱。”

许舟听了，说昨天就算从铺里请出半个小时，也帮不上那只拿错的轮。林照说是，又告诉他何岚后来坐下，讲自己早上想过晚上扫架底。许舟手中的布停了一会儿，低头将桌边最后那圈灰擦去，说那一点自己也想早些看见。

门外有客进来，两人便散开。许舟去对取机纸，林照从前门出去，自己回住处洗下午要穿的短衫。水盆放到窗边，他把领口搓开，灰水慢慢浑了，脑子里仍是何岚拿面时不用再绕那半圈的背影。


短衫晾好，林照睡了一个短觉。醒来时，窗上那道亮已经移到椅背，他伸手去摸，布还湿着，便换回上午那件。桌上有半杯水，他喝过，去何店买米，带的是自己洗净的小袋，袋底内侧已经晾干。

何岚称到一半，电话响了。她先将秤盘放稳，接过来听，说是陶师傅，问自己能不能去铺里。林照没开口代她答，拿着袋子在柜边等。她隔着电话说下午不能又关门跑，问陶换齐了没有，又静静听过一阵。

“你要经过，四点半带过来给我看看。不拆架，就看拿来的两只。”

说妥，她把电话放回柜上，称好米，抖去袋口沾的一点糠，才向林照说陶自己讲上午去换过，原来那只长板退了，换回相同的，已经用纸样逐只对过。方才想叫她到铺里，她答傍晚带来，若只两件，提过来也不费力。

“我还以为你今天不愿见他。”林照说。

“东西拿错，我不高兴。该问的钱还是得问。我又不能拿不高兴推着架子走。”

她笑了一下，将米钱找给他。林照说自己先把米送回去，四点半能来，何岚说你要来看就来，别又等着来替自己付。他低头扎袋，结绕了两圈，拉紧才道知道，她望着那结，又叫他别扎死，回去得解开倒米。

回屋，林照果然解了半天。米倒进自己的罐，袋底落下一点碎米，他捻出来，用水冲净，放在晚饭那一小碗里。手从水里抬起，腕上还留着昨日扶架磨红的一小片，已经不疼。他将罐盖好，拿起手机，看见二十二号还车那条提醒还排在明日。

四点半以前，他重新到了何店。棚下只有原架与另一排货，车仍留后间，没人为了看两只件先卸货。何岚在柜边放下一片干纸，又把秤盘朝里移，前门那一半柜面留着卖东西。陶师傅骑车来，从前筐取纸盒，这次盒口没扎死，手托底，走进门先让她看。

两只轮分别包着，陶一只只取出，底板朝上，放到纸上。他从外衣内袋拿出原纸样，贴到这只，再贴另一只。何岚站在柜内，林照站在旁边，两块底板外边齐着，孔对着纸上的记号，林照不用像昨日那样看着长出来的那一截。

“这个是换回来的？”何岚指右边那只。

陶说是，自己拿旧纸去，先看了包里的两只，问清才拿走。他说话时把旧纸样放到盒盖，露出折边处沾的一点新灰。林照没有跟去换件，只能看见眼前这两块一样的底板，听见陶说路上来回用了一个多小时。

“昨天我少看一眼，今天该我自己跑。”陶将两件翻回轮边朝上，“你不要的话，我也收得回去。不是跑过就得逼你要。”

何岚伸手转过一只，轮子在掌边动，另一只仍留在纸上。她问这次是否要改架上的孔，陶说眼前这对按纸样能对，真装还得在旧座上试，架子不另开孔；要是他拿的件又不对，这一趟自己扛，不再收一回试工。她将轮放稳，问了最后装好连件的钱，陶报一百。

林照听见数，没再像前次一样先在心里替她凑。他朝棚下一望，纸巾没有又往高处垒，底下的砖却还得留。何岚把两只都推回陶面前，说自己愿意做，但不是明天下午，明天车得还，进的货也要收整齐。她问二十三号能不能来。

陶摸出手机，翻过自己的消息，说二十三号早得用平板车送一批东西，中午回不回得早不好答。何岚没有接一句那就晚些随便来，问三点行不行，自己那阵客少，林也用不着从上午坐等到下午。


陶师傅低头算了一会儿，回了那边一条消息，才说三点可以，上午先送的那批约在十点，过午能回铺，留着这趟。何岚让他若有变早点说，自己两点半才卸，不从早晨就空一地。他把时刻记进手机，向林照问那一会儿能不能来。

“两点半我到。”林照说。

何岚点头，没有再将许舟也算进来。陶先提起纸盒，又放回柜上，问这回要不要还是先给二十。她摇头，说东西是这一对，连装好一百；自己今日先不付，装好再给。前头看架和试工花掉的两个二十，昨天已经说清，不拿来抵，可也不能又装到一半，说还有一笔原来没讲的。

陶将纸样收回内袋，说是这一百，带件来，卸净以后试着装；若自己拿的件仍不合，收回去，不再加出工，若发现架上另有问题，先停下来同她说，不能擅自开孔。何岚听明白，才伸手将干纸往盒子底下抻平，好让他包东西。

林照问等车还掉以后，两点半卸下的货放哪儿。何岚指向后间墙边，说车占的地方能放两只自家的筐，饭桌还空着，轻的先分进去，重水箱留到陶来，三个人一起拿。陶说自己三点到，别为了等他先把水箱放到柜前挡路。他说着，向架底看看，何岚已给另一排留好常卖的货，便不再要求她两边都腾空。

柜前来了一位买面的老人，何岚向陶说稍等，给老人拿面，粗细问过，才去称糖。老人指着柜上两只轮，问小车坏了没有，何岚说车没坏，是自己的货架，二十三号才装。老人说那天来买米能不能进，她答能，下午三点以后棚下要动一只，早些来更方便。

林照听着，原想将约的事记到纸上提醒她，见她已经用自己的笔写在空价单背面，便只在手机添下二十三号两点半。日期排在还车的后一日，车还在原来的二十二号，一条也没有挪。

老人走了，陶把两只轮各自包回纸里，放进盒子，纸样仍在自己内袋。他问盒子先留这边还是自己带走，何岚朝柜面看了看，秤盘被让进去，自己刚才称糖还得斜着手，便叫他带回，装时再拿。

“这儿放一天，来个人都要问一回。我还得看着，不如你自己管。”

陶笑着将纸盒托起，柜面那半边便空了。何岚把干纸折起收进柜底，原来的秤盘重新放到手边。他没有给林照留工具，让两人别提前拆自己不认得的东西，话说完也知道林照还没碰过，摆摆手，自己走了。

林照同何岚站在门边，看陶骑车往铺的方向去。何岚将自己的小记页从单子后抽出来，在一百旁边写上“装好”，原来两个二十没有划掉。她问林照是不是觉得自己多花四十很不值，他说一开始有点，今日也想过换新架，可真问到价，自己连旧的往哪儿放都没算。

“这四十都花了，想拿回来，当然想。”她把页折好，“可不能为了不肯认它花掉，再去买个放不下的。这个还能用，我出这一百试着修；真不行，就先照旧垫着。不是你欠我一只新架。”

林照应了一声，没急着把话说成她的架一定修得好。他把钥匙从裤袋里拿出，手里却仍想找点要替她带的东西。何岚见他朝后间望，说自己的货自己留着，明天那辆车送回，后天用筐也能卸，不必因为还车便又借另一辆。

“明天五点，我照旧来。”他说。

她说会先空好，钱押了几天，拿回来正好放回自己的钱包。林照问要不要自己先打去说，她叫他明日要出门再打，人刚走，不必这会儿又追一通。柜前又有人进来，她转身便去接，没有让林照留下再等一轮。

回去的路上，他经过修理铺，许舟正弯腰将门边两件待取物往内挪，师傅在柜后写字。林照没有进门喊人出来，只站在门外说何姐定了二十三号三点装，自己两点半帮卸，问许那天是不是有空。许停下手，听清日期，说下午有一台要等客来，能不能走现在说不准，明日再问师傅。

“那先不算你。”林照说。

许舟点头，叫他自己先吃晚饭。林照往回走，钥匙在手里轻轻响，到了住处，将它搁回桌角。早晨修过的鞋从脚上脱下，袜尖这回没有卷。他先洗米下锅，再将窗前短衫收进屋，衣服只肩头还凉一点，明早再穿也来得及。
