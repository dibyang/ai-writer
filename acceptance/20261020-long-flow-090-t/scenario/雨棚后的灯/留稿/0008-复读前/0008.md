# 第八章 先把话带到

第八天上午，林照出门前给周伯打了电话，说十点半照旧。周伯正在拧毛巾，让他来时不必带吃的，自己已经吃过了。

经过街口的小修理铺，林照看见许舟坐在门边，膝前放着一台拆掉网罩的旧风扇。他没有开机，用一块干布擦网罩上的灰。门内的师傅正弯腰找东西，叫他把一只装螺丝的小盒放高些，别让经过的人碰翻。

许舟抬头认出林照，将布塞到网罩底下，站起来。

“你今天又去岚姐那儿？”

“先去周伯家。你在这儿帮忙？”

“这几天都来。下午师傅要出门，叫我看着店。”他说完，又朝门内看了一眼，“有东西坏了只能先收，真修还得等他。”

林照没有靠到桌边，把手搭在门外的栏杆上，问他这会儿说几句话妨不妨事。许舟将小盒盖严，放到高处，才走出来。

“周伯昨天跟我说，河西有位陈阿姨，以前跟放映的人打过交道。他愿意带我去见见。今天先打电话问人家愿不愿意。”

“原片能拿出来了？”

“没有。原片和节目单都留他家。是周伯自己想去看旧识，顺便带我认识。”

许舟手指上还有黑灰，他拿拇指搓了一下，问那自己去不去。林照说还没约成，想先问他明天下午有没有事，不能把人都叫齐了，再让陈阿姨不好推。

“明天下午也得在这儿。”许舟说。

门里的师傅找到那卷带子，叫他把靠门的电线收进去。许舟应了一声，回去将线束抱到桌下。他出来得比刚才慢，站在门槛里面，不再把手往林照肩上搭。

“我可以跟师傅说，晚一点来。”

“你已经答应几点？”

“一点半。”

“那就一点半来。我们那边还没问，别为这个改你已经说好的。”

许舟看着桌上的风扇，低声说，自己上次补布也是一开始说会，后来拆了好久才缝平。林照等他说完，问今天这台要不要他独自修。许舟摇头，说只擦干净、装回网罩，师傅回来自己看。

“我这几天先学着收东西。谁拿来的，留下什么，都得当面问。昨天一个人把线也带走了，我以为是连着的，等师傅找，才知道没留。”

他说着拿起那只小盒，给林照看里面分开的几颗螺丝。林照没有伸手，也没有拿补布的事来夸他，只问若明天真约好，出门那一小段能不能帮忙，回程归自己，不等许舟下工。

“送到哪儿？”

“先把周伯从楼上接下来。车若能开到楼口，就到楼口。不能，再一起走到路边。你该回铺里就回来。”

许舟没有马上应，脚尖在门槛上蹭了两下。

“你们都过去，我倒像就剩个搬东西的。”

林照原想说下次一起，话到嘴边，停住了。他问许舟是不是想听周伯讲旧事。许舟点头，又说想听也不能叫师傅把那半天重新找人顶上，昨天收来的东西，自己还没有交清楚。

“回来了，要是能讲，我讲给你听。”林照说，“她不让往外说的，就等以后再问。不是你送了周伯，就得回来换一份故事。”

许舟抬眼看看他，嘴角动了一下，终于说自己也不是那个意思。他把门槛上的布拾起来，挂回钉子上，说到时候有些话没听见就没听见，别替他编成也在场。

许舟想了一会儿，说中午吃过饭能去，但最晚一点二十得离开。修理铺离周伯家不远，走回来还要几分钟，不能把一点半当作从那边出发的时候。

“我先留这一小会儿。你打完电话再告诉我，没约好，我就不去楼下等。”

林照说好，没有把他算作去河西的第三个人。许舟回身将网罩拿到桌上，翻过来看一处歪掉的边。门内师傅说待会儿教他弄，叫他先别用手硬掰。他便把东西放下，拿起布，擦另一面。

林照看过时间，朝他抬了抬手。许舟低头擦着，嘴里仍说打完电话来一声，别叫他猜。他应下，沿街往周伯家走。

周伯已经把通讯簿摆在饭桌上，眼镜压在旁边。林照进门先说明自己遇见许舟，只讲了周伯提出引见的事，许舟明天下午有工作，最多帮着送到车边，不跟去河西。

“也好。跑一趟回来，他那边半天就没了。”周伯让他坐，自己戴好眼镜，“咱们先问，陈阿姨还没听说呢。”

林照将手机放到他手边。本子仍归周伯翻，号码也由周伯照着念。他按完一遍，先给周伯看，见他点头，才将电话拨出去。


铃声响了一阵。周伯将手机贴近耳边，另一只手仍按在本子上，像怕接通后忘了自己找哪一行。林照坐在对面，只能听见一点散出来的声音。

“是我。”周伯说完，等了等，又报自己的姓。

那边说了一句什么，他笑了，告诉对方腿还那样，出门慢点就行。林照没往前凑，将通讯簿滑下来的纸条扶回去，免得周伯一只手夹不住。

周伯先问近来家里忙不忙，过了一会儿，才说自己认识一个回来的年轻人，想带去坐坐。说到那场小放映，他停下来，问林照昨天是不是说今天不再放。林照点头，轻声答已经收好，周伯便照着说，只是放过自己拍的几段，旧东西还都在家。

他没有先报后天下午，话到嘴边，改成明天下午，自己也笑了一下，向那边解释日子说顺口了。

“你问问她，愿不愿意先跟我说两句。”林照等他停下，才开口。

周伯听见了，转给对方。那头又答了一阵，他将手机递过来，告诉林照，陈阿姨问他到底想听什么。

林照接稳，先报自己的名字。听筒里的声音比周伯说话亮些，尾音有点急，叫他不用把“阿姨”喊那么多遍，周伯已经说过他是谁。

“我想听您以前怎么认识放映的人。记得一两件就行，不是请您替我认家里那部片子。”

陈阿姨没有立刻应。林照听见水声，对方似乎将手机挪开，隔了一会儿才回来。

“你们那个片子，我没看过。你要问人，我兴许还能想起。你带着周伯过来，先坐一会儿吧。”

“明天下午方便吗？”

“几点？”

“您什么时候不忙，我们照着来。”

“那也得有个时候。我上午出去，回来还要做饭。两点吧，太早我没收拾完。”

林照将手机换到另一只手，用空手在周伯面前比了个二。周伯看懂了，点了点头。他又问两个人去行不行，陈阿姨说两个人长凳够坐，不要到了门口再带着一队人。

“就周伯和我。许舟帮他下楼，不一起过来。”

陈阿姨不知道许舟是谁，问了一声。林照便说是街上的年轻人，上午遇见才问的，帮送到车边就回去做事。她说那就好，不用为见一面叫人请假。

问到路，她报了榆树巷六号，进巷以后别跟着巷口的大门牌直走，先看右边那家补鞋的，再往里拐。林照写到手机旁的一张空纸上，复述了一遍，念成左边，她当即纠正。

“右边。你从桥过来，右手边。左边那家关了。”

他将“左”划去，另写一个“右”。周伯把眼镜往上推，指着他写的六号，问那边是不是还放着一只旧水缸。陈阿姨在电话里听见，笑着说早搬走了，叫他别又找缸，找门牌就行。

周伯伸手要回电话，林照先告诉她，这里都记下了，明天若有变化，会提前打电话，不叫她一直守门等。陈阿姨让他真改了就说，不要让周伯在路上淋着才想起来。

电话回到周伯手里，他又问她走路还好不好，听完应了几声，末了才说“那明天见”。挂断以后，他没有马上起身，把那张记路的纸拉到自己面前，一字一字看完。

“水缸没了，我上回真是照着那个找的。”

“所以明天到巷口，还得慢点认。”林照说。

他把两点、两个人、右边补鞋处和六号分开写好，念给周伯听。周伯只在六号下面画了一道短线，说别把楼下停的车也当成记号，车一开走，又什么都不认得了。

林照笑着收了笔。两个人商量从家里出门的时间，周伯不想走到车站再等，决定去时叫车，到了河西路口，先问能不能往巷里送。林照没有许诺车一定开得进去，说若只能停巷口，就留一点步行的时间。

“明天下午一点十分，我来接您下楼。一点一刻左右上车。去早了，在附近等一会儿。”

“别空着肚子来接。”周伯说。

“吃过再来。”

周伯从零钱包里数出一部分车钱，推到林照面前。林照先问他是不是连回程也算上，周伯说先放着，回来多退少补，不用现在把每一程讲完。他接过钱，另放在裤袋里，告诉周伯，明天回来同他算清楚。


离开周伯家以前，林照将记路的纸照着折口折小，收进自己本子。他这次带了本子，里面那张旧便笺仍夹在原处，没有同新记的地址贴到一起。周伯把通讯簿收回抽屉，柜门没有再开，临到门口，又嘱咐他别忘了给许舟回话。

修理铺门前的风扇已经装好网罩，插头放在台面，线没有接到墙上。许舟正帮师傅把另一件东西移到里面，等手空了，才出来问电话打通没有。

“陈阿姨答应了，明天下午两点，榆树巷六号。她和周伯在电话里说的，我也接了电话。”林照将记路纸翻开，“只去我跟周伯。你不在电话边，我现在把约定带回来。”

许舟看见被划掉的那个左字，问是不是很难找。林照说是自己听岔了，电话里已经改成右边，明天还要在巷口看门牌，不照周伯记得的水缸找。

“你要一点半就回这儿，我一点十分在他楼下等。”林照说，“你要过来，帮着下楼就行，一点二十以前走。”

“一点二十离开，赶得上。”

许舟抬头看了眼门里的钟，像是把那十来分钟在心里走了一趟。他说周伯楼梯转角有车，自己可以先去看看有没有人用，碰上主人就问一声，不能碰见再等。

“你别为这个提前半上午。”林照说。

“我知道。中午吃完过去。要是车到得晚，你们慢慢等，我先走。”

“我在，不让你在那儿陪等。”

许舟这回才笑。他进铺里，向师傅说了明天午饭后出去一小会儿，一点半以前回来。师傅没有抬头，只让他把桌上新收到的那包东西记清楚，说下午来取的人不一定还认得原来的袋子。

许舟应下，拿出小纸片，问站在柜边的人姓什么。林照等他写完，才同他道别，没有在门口将陈阿姨可能知道的往事猜给他听。许舟也只问了接周伯下楼的时间，没有说自己已经认识了电话里那个人。

林照到何岚店里买水，何岚先问他明天还来不来吃饭时坐那十分钟。他说中午得去接周伯，不能答应。她点头，手上扎袋子的动作没有停，让他自己拿两瓶，别拿最底下那排刚放进去的。

许舟恰好提着一只待修的电水壶从外头经过，听见说话，进来买一卷胶带。他将壶放在脚边，先擦了手，才接何岚找的钱，顺口问那块幕布收得好不好。

“还在后间柜里，没拿出来。”何岚说，“你问这个，明天还要用？”

“不用。我们明天也不放。”林照说，“周伯跟我去见一位朋友。”

何岚将两瓶水放到柜台边：“那就带好自己的水，别到别人家先找杯子。那一袋布我还收着，要用的时候再说。”

许舟把胶带装进口袋，提起水壶，先回铺去了。林照付过钱，也没趁这会儿替何岚约别的帮手。她只知道两个人要出门见朋友，河西的门牌和电话里的旧事，都不需要她隔着生意一件件记。

午后，林照回到住处，将一瓶水放进布包，另一瓶留在桌上。他找出一把自己的折伞，撑开看过，没有破口，晾了一会儿才收拢。包不大，本子放进去，水瓶便将一侧撑满；他把笔夹回本子封面，不再往里塞投影机的线。

周伯给的车钱从裤袋取出来，放进一只小信封，信封上只写一个“车”字。他没把它混进买水剩的零钱。还有一张空纸，被他夹到记路纸后面，明天若真有人愿意说，再问能不能记。

手机上“待电话确认”那几个字，他删掉了，改成“明天下午两点，周伯和我”。给许舟的一点十分到一点二十，也另记在下面。

他把包放到椅上，拿起桌上那瓶水喝了一口。事情终于有了一个实在的去处，但明天到了门口，先开口的仍该是周伯。
