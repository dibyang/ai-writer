# 第十四章 先问一句

第十四日上午十点过后，林照给陈阿姨打电话。桌上放着前天抄清的短稿，他没有将昨天下午的信文凭记忆添到下面。电话接起，那头先问是不是林照，听见他应，便说正等着这一声，又怕他赶在十点整守着。

“没守。我刚洗完衣服。”

“我也刚把窗台擦了。你先听我说，昨天有一句，我回来想了半天。”

林照将笔拿起来。陈阿姨说，自己提到从前在粮店前柜拿信，说有人叫她顺路捎过去，那句话说得太顺。信是自己带给周伯的，这件事还记得，可是谁叫的、那时究竟有没有人当面交代，她现在分不清，不能因为后来送到了，就替前面添一个托话的人。

“你记成我顺路带过一封信就好。谁放柜上，我还是不知道。”

林照将这句话记下，念回去。她听完说对，别将那个不记得的人写成父亲，也别换成邵师傅。他问封面四个字呢，她说自己昨天对着原字认了，今天没什么新话，信里面怎么写也没变，变的是自己讲拿信之前那一小截。

“里面你昨天是头一回看？”

“是。这个不用再改。我送信那天没拆，后来也没听他念。”

林照应了。他看着手边那张粮店后屋的短稿，没有将两回送东西并成一次。他将新记的一页移到旁边，告诉她自己接下来想做的事：请街上几个相熟的人坐坐，听这一小段，不贴出她的住址，也不把纸发给人带走。地方和日子还没定，先问她愿不愿意。

陈阿姨没有马上答。电话里传来抽椅子的声音，她像是坐下了，问他准备讲后屋那一回，还是连昨天的信也一块儿讲。

“先讲您已经听过的后屋那段。周伯送碗那句，还得他自己应。”

“信先别放进去。我刚改一句，你这边要讲出去，又得追着别人改。”

“那后屋这一段呢？”

“我在旁边的时候，你可以念。哪句念岔，我还能叫住你。别说是替邵师傅交代什么，他后来去了哪儿，我不知道。”

林照没有把这句话写成她已经答应某日到场，只在短稿旁边记下本人在场可纠正。他说还要找地方、问她那天方便不方便，她说到时候再说，自己愿意讲这几句，也不能叫她随时出门。

说到这里，陈阿姨停下来，叫他等等。她的水放在另一头，刚才坐下时忘了拿，起身去端，又将一只凳子碰得响。林照听见，问有没有磕到，她说没有，脚上穿的是旧拖鞋，总往凳腿下面钻。

“昨天那条楼梯，下的时候比上来还慢。”她说，“我到家才觉得腿酸，坐着看东西倒没觉出来。”

林照说下回不必一坐就是半下午，念这点话，用不了昨天那么久。她说别替自己算死，有时人坐在一起，讲完了还想问问各家过得怎样，总不能一句正文念完就端杯送客。他笑着应，说自己还惦记她昨天同周伯争哪一回送碗，她在那头说没争，要真争，早把碗找出来了。

电话里的话松下来，林照将刚刚写下的几行挪远，腾出搁手的地方。这些闲话没往纸上走。

她问会不会有人拿手机对着自己，林照说自己不会开着拍，若有人想拍，要先问她，不能将今天一句可以念顶成同意留影。她说那就这样，眼下只讲人坐着听的事，稿子别散出去。

“有人问昨天理成什么样，我怎么说？”

“说看了东西，没看电影。新想起的我还要想，别将刚才这点又讲成一长段。何岚那边，你就照这个说。”

她提起何岚守店不容易，叫林照别把人请出来了，又让人家柜台没人照看。他说会当面问，不替她空出一下午。电话将挂时，陈阿姨又问他昨天带回的纸卷是不是没派上用场，他笑着说铺过信了，干干净净带回来，还能用。她说能用就留着，别因为碰过旧东西就当宝贝收起来，自己买菜回来垫一垫，也照样是纸。

林照放下笔，等她挂断。洗过的衣服还在盆里，他先到窗边拧了一件，再想起手机没有移开，水快滴到桌脚。他将盆放稳，把桌旁那张短稿收进纸夹，新记的送信一页夹在后面。随后给周伯打去电话，约好吃过饭再上楼。

上午剩下那点时间，他将衣服逐件晾好，没有让一通电话替自己把饭也吃了。纸夹放在门边，里面多了一句能念和一句先别念的话，都还得带到人跟前去。



午后到周家，林照先将陈阿姨刚才的话说给周伯。老人正在水池边洗一只小锅，听到她不再认有人当面托话，便说自己也记不得那封信究竟哪天收到，不能从送到倒着补回去。

锅底有一处黏住，林照想接，周伯让他先坐，水泡一会儿自己就松了。林照将纸夹搁在外侧干处，等老人回来，才取出那张旧短稿，指送碗一句给他看。

“我想找几个邻居听。陈阿姨说她在旁边时能念，不能把稿发走。您这一句呢？”

周伯戴眼镜看过，说送碗可以讲，自己若到场，就自己说。倘若临时来不了，林照也只能说周伯曾这样补述，别将他写成那天在后屋的人。他问邻居究竟几个、在哪儿坐，林照说尚未定，今天先问材料，不能问过一句就把棚下的位子也算好了。

“你总算先问这个了。”周伯说。

林照笑了一下，将纸收回原来的位置，又拿出一张空白纸。他问旧信能否只抄那两句留给自己，下回同周伯说起来，免得又随口添出一个字。周伯望向柜子，说抄字可以，先在这里抄，抄完给自己看，原信不拿走。

“不是抄来给人散的。那盒片，你也别顺着说已经有地方能给复制。”

“片先不动。我也没有能放它的机器。”

“我知道你没有。往后真找到谁，还是得先来问，不是说找着人就能拿。”

林照答应。这一回周伯只开柜下层右侧，取出昨天下午那只信封。纸套仍平放在左边，他没有伸手碰。信封摆到桌上，周伯从里面抽出内页，按原来的两道折慢慢打开，放在自己手边，朝林照那边转了个方向。

林照照着原字写：“碗劳你带回粮店。上回托收的那盒片，先在你处放着。”

写完，他看原信，再看自己的纸，将句号和中间那一顿也对过。纸的下方另留一行，注明信下只署邵，未写年月；这一行是自己的说明，不接进引号里。他没有将抄的纸贴到原信上对，等墨迹干，才推给周伯。

周伯看得慢，念到“托收”，抬头问他这回少没少那个你。林照说没添，笑着让他再看。老人将两张纸放开一点，各念一回，确认字相同，才将原信折回信封。

“你这一张，先只在自己那儿放着。要拿给人看，另外问我。”

“今天跟何岚说，有信提过托收一盒片、没写年月，这样能说吗？不把字递给她。”

周伯想了想，说这点可以，别说那封信就证明盒里是什么，更别说自己已答应把片送出去。林照将这点口头范围记在新纸背面，没有去写何岚已经听见。

原信由周伯放回柜下层右侧，纸套仍在左侧，柜门合好。他又将给周伯的原清稿从桌边抽屉里取出，看了一眼送碗句，仍放回独立文件袋，合上抽屉。两处旧纸各回各处，林照拿走的只有自己的清稿和新抄两句。

林照收纸时，原来抄短稿用的硬纸底从纸夹里滑出一角。周伯让他留着垫，免得刚写的纸挤在包里蹭花。他将硬纸翻过来，背面还粘着旧胶带，便把干净的那一面朝着新纸，合回去，手掌轻轻压了一下。

老人看着他收，问在外头做事时是不是也这样，一张薄纸外头还得套好几层。林照说有时更省事，手机里发出去就算交了，后来谁转给谁，自己也不知道。周伯将眼镜摘下来，说自己不会这些，先前还觉得他拿着纸来去不够快，如今倒觉得慢有慢的好，起码这一张放错了，还能当面拿回来。

“也可能放包里忘了。”林照说。

“所以你得知道自己带走哪张。我不替你翻包。”

小锅泡了一阵，周伯回水池边一刮，锅底那块便松了。他拿给林照看，说有些事等会儿倒省力。林照问要不要一起冲，他只叫把开水瓶挪远，免得自己甩水时溅上。林照挪完，去洗手，顺便将锅外沿抹干，交还老人。

出门以前，他把新抄纸装进自己的纸夹后层，前面仍是获准当面念的旧短稿。两张不是一份能到处用的故事。周伯送到门口，告诉他真定下日子，再来问，不用今天回去就将屋子全搬空等人。



何岚在店里给人拆一捆挂面。细绳勒进面捆的纸腰，她找了一下剪刀没找着，先将面放回去，叫客人等，不能硬扯得满柜台都是断面。林照到门口，见剪刀就挂在秤旁，取下来递给她。

“刚才还看见的。”她接过来，剪开，先把客人要的那一份称好，才问他抱着纸夹做什么。

“来跟你说昨天那边的事。你忙，我等一会儿。”

等客人走，她没有腾出后间，只把柜台旁的小凳往外挪。他坐在凳上，让出前门进来的路，才告诉她：昨天陈阿姨和许舟都去了，周伯自己开了纸套和里面的盒子，只看见卷着的片，没有放。盒子收回周家柜下层左边，另外看了一封信，原信收在右边。

何岚先问周伯累不累。林照说收完坐了一阵，自己送陈到车边再回来，老人还留着水，晚上自己热饭。许舟三点四十走，后来报回铺了。她听完点头，没将许舟能去一趟当作以后都能随叫随到。

“信上写出片从哪儿来了？”

“只提托收过一盒片，没写年月。周伯准我口头说这点。是不是现在这盒、前头后头怎么走，还没接上。”

“那你说清楚是没接上。别叫听的人以为终于能看旧电影了。”

林照说不会，今天来问的是另一件事。陈阿姨愿意在本人能当场纠正的时候，讲已经听过的后屋小段；周伯也应了送碗一句。自己想请几个相熟的坐坐，还没定地方，不能把上次借过她的棚当成这次也借了。

何岚将剪刀挂回秤旁，手却没有离开柜台。她说要坐着听，自己也想，可店开在这里，不能一到下午就替别人腾地方、等散场再收拾。前几天送货的人来时正碰上找零钱，自己一急，差点把两个人的钱弄到一处；若还要隔着后门听谁说到哪句，更没法做买卖。

“我能帮你留句话，能告诉熟客你有这个想法。要我连着几天关门陪着，办不到。一次也得先说清时候。”

林照没把她最后那句接成肯借。他说会另找能坐的地方，真还想借棚，得带着人数和时段再来问。何岚说这就行，今天自己只听见他们看过东西，没有答应哪天开门等人。

前门又有人来要米，袋子刚一提就漏。何岚拿空盆接住，林照扶着盆沿，等她换袋，没有去动柜台上的纸夹。那人抱怨袋子不结实，她说这只装过两回硬东西，边角早磨薄了，换新的便好，别把米再从破口里掏。

忙完，林照问那袋幕布还在不在柜里。何岚说在，昨日也没人拿，真要用，得先说带到哪里、多久回来。林照说还没问许舟的时间，不替他接。何岚朝纸夹看看，又问这次是不是准备把它当布景，没片子也往上挂。

“还在想。纸夹里的不是给人散的，信那两句也只许我自己留，没说能贴。”

“那就别因为有块布，硬给它找一部电影。”

她说完自己也笑，转身去拿新的米袋。林照将空盆送回她指的柜下，站起时把小凳放回原处。纸夹依旧合着，何岚没看里面的两页，听见的只有他当面带到的那些话。

林照原要告辞，何岚指指他手边的纸袋，问是不是来买东西的，怎么坐了这一阵，袋子还是空的。他这才记起自己还想买盐，包里特地带了只装零碎的小袋，听她说话竟忘在一边。

她让他自己去拿，架上有两种，他看清分量，拣了一包平日用的。付钱时，前门有人问面捆扎好了没有，何岚应了一声，先将手里的零钱数给他，再去取面，没有叫他顺手替自己把价钱都报了。林照将盐装进小袋，把袋口折住，纸夹换到另一只胳膊下。他在这店里听了半天别人的安排，自己回去仍有一顿饭得做。

何岚把空盆往柜下送了一点，叫他出门别踢着门后的纸篓。林照应下，低头让过，又听见她在身后问新客要细面还是宽面。

他出门走了几步，才看见自己手里还攥着替何岚拾起的那截细绳。他回到门边，问还要不要，何岚朝纸篓一指。他将绳丢进去，收好纸夹，等门口骑车的人过去，才重新走到街边。
