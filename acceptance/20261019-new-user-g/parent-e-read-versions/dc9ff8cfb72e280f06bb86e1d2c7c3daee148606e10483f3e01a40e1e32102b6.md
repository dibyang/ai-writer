# 权威规则

## 世界与能力

当代虚构小镇青汀镇，交通、通信与生活条件遵循常识。书店、河桥及学校均为虚构，不借真实机构背书。无超自然能力，书中夹页与旧账本只能提供其真实记载的信息。

## 时间、劳动与经营

主线覆盖一个夏末至入秋的时段。修缮、查找书主和整理账目需要实际工时；同一人物不能同时处理相距甚远的事务。经营支出、库存变现与预收款分开，寄存书与自有库存分开；一次活动的收入不能自动证明长期盈利。

## 物件与信息

寄存书的所有权、保管人、受损情况与归还记录分别核对。发现夹页不等于获得传播私人内容的同意；不能未经书主同意出售寄存书。原物搬动和交接须有实际行动，拍照、口述与亲见分别处理。

林乔只知道自己所见、所读及别人确实告诉她的内容。旧账中的缺项不能直接证明某人失信；新的解释不得逆改已呈现的日期、字迹或书本状况。

## 因果与人物底线

困难通过协商、投入劳动和承担损失解决。社区志愿劳动不能无限供给，捐助不能强迫受助者公开隐私。许芸不以牺牲女儿的生活换取书店存续，林乔不把母亲视为等待拯救的对象，周岚有提出明确条件与拒绝不合理要求的权利。
