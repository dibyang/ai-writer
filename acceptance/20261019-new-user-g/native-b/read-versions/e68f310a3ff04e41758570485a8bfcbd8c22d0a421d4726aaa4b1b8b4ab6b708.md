# 第六章 留给回来的人

海堤代办所的柜台上多了一盆绿萝。林柯先把信袋放在脚边，从小本子里取出折好的纸，向盆后探头。昨天答应留回话的女人正在给包裹缠胶带，牙咬着带头，腾不出嘴。

他等她粘好，才把纸展开。

“钟试过了。这是抄件，原的在阅览室。”

女人擦了擦手，读到九点十四分那里，抬头问：“到底好了没有？”

“走过十五分钟，没见停，就是慢。师傅还没调准。”

“那我照纸说，别让我记你这几句。”

她找来一只白封套，让林柯在外面写“十七号钟铺回话”，没有写收件人。纸放进去以后，她将封套插到柜台里的留言夹，朝他点了点头。

“留到月底。来问的自己看，我可不知道谁寄的。”

“您肯留就行。月底还没人来，我再问一次。”

林柯在本子上记下位置和这句话，原先夹纸的那一页空了。他没有往投递簿上添签收，也没有把柜台的人写成寄信的人。下午这一路还有七站，海风把车筐上的纸角掀起来，他用手压住，骑到下一个门牌。

四点二十分，林柯交完信袋，回旧阅览室时只见半扇门开着。屋里已经没读者，老人坐过的桌子倒扣在墙边，四条腿扎在一起。陶芷站在桌子空出来的位置，正揉自己被胶带勒红的指头。

“海堤接住了，柜台里面的留言夹，留到月底。”他告诉她，“纸还在，不等于人看了。那边也没想起是谁。”

陶芷嗯了一声，从桌上透明垫下抽出原记录。她把纸夹进灰布皮旧簿的末页，合影仍在原来的前页，合上后一起放进帆布袋。

“上午那位一直读到中午。”她指指倒扣的桌子，“搬的人来了，我让他们先搬后面的架子。他走时还问，换了地方这张桌子摆哪儿。”

“你答应了？”

“我哪知道新屋哪扇窗户好。让他周一跟我去挑。”

她把一把钥匙从清点单底下拿出来，试过门锁，又塞回自己的小袋。墙上的钟还在摆。林柯看它已不和手机对时，也没想着再去拨，早晨那张纸写的是什么，就还是什么。

“今天不搬钟？”

“车装书了。周一早上再来，钟还暂放这里，钥匙我拿。”陶芷把写好的暂存说明系到钟下方的墙钩，纸没有碰到钟摆，“新地方的钩子也得先看。”

林柯把推车从门后拉出来，想起上午借车的事：“这辆还给谁？”

“隔壁杂货店。你推过去，我就少跑一趟。”

“这个能做。”

他答得快。陶芷看了他一眼：“周一呢？”

林柯刚握住车把，又松开一只手，看看手机里的值班表：“那天早班，不能答应。要不我问——”

“不用。你把车送到就行。”她伸手帮他抬过门槛，没让他把后面的话接完。

钟师傅这时从街口走来，衬衣口袋里插着一张价目表，说铺里有个人换电池，非问旧电池还能不能用。他进屋拿毛巾，先瞥了一眼倒扣的桌子。

“纸呢？”

陶芷拍了拍袋里的旧簿：“原的收这里，之后有人问就翻。林柯那份已经交海堤了。”

林柯把留言夹的位置、月底的期限又当面说给他听。钟师傅问那边有没有认出谁，他摇头。

“牌是还回来了，名字没跟回来。”师傅说。

“您不是说只凭一个姓，记不起？”

“记不起就慢慢想。我没说让你替我想。”

他把陶芷从桌底拿出的毛巾搭在胳膊上，进门看了墙钩，又退出来。陶芷提到周一运钟，他说早上来搭把手，新墙能不能挂得看过再说。旧材料钱仍等找齐账，不和这一趟算在一起。

林柯这回没替两人接话。门里还留着一只未运走的钟，师傅铺里还有没找全的账，海堤那页纸也可能等不到人来。这些事都有了能再问的地方，他却不必每一处都守着。

他把车还到杂货店，店主接过去，按着轮子说没有蹭坏就好。出来时，陶芷正锁阅览室的门，钟师傅站在一旁，毛巾垂在腕上。她将钥匙收进小袋，冲林柯摆了摆手。

五点差十七分。林柯给房东发了“现在过去”，收起手机，往自己还没走过的那条巷子骑去。
