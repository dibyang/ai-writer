# 第一章 没有回址

林柯在十七号门前停了两回。第一回门上挂着“配钥匙”，第二回才看见下面还有一行小字：修钟表。两块牌被海风吹得碰来碰去，谁也不肯让谁露全脸。

他把车挪离鱼摊的水沟，从信袋里抽出那封白信。雾港路十七号，钟守义收。字写得大，最后那个“收”却缩在角上，像临时想起来补的。信封背面没有寄件地址，正面邮戳倒清楚：海堤代办所，九月十二日。

“钟守义在吗？”

柜台后的人戴着一只放大镜，正把小螺丝往一张白纸上拨。他没抬头，先问：“换电池还是取表？”

“送信。”

“那就是我。放干地方。”

林柯把信递进他伸来的手里。钟师傅接住，翻看背面，又朝门外望了一眼。

“哪个给我的？”

“就这些字。我从站里拿到的时候已经封好了。”

林柯把投递簿压在柜角，记下这一路最后几封信送到的门牌。上周他把十八弄认成了十八号，绕回去补送，组长没有骂，只让他把两处地址各念一遍。他现在一见模糊门牌就想停下来确认，可今天再停，午饭又得赶着咽。

一个来取手表的女人挤到他旁边，问昨天说好的电池换了没有。钟师傅把信压在茶杯底下，摸出手表，收了钱，又被追问旧电池能用多久。

“旧的要是还能用，你何必来找我。”

女人笑着走了。钟师傅将钱抹平塞进抽屉，才从杯底抽出信。杯子在封角印了半圈水迹，他啧了一声，用袖口擦了擦。

林柯已经把投递簿收回袋里。门口太阳白晃晃的，鱼摊的人把遮阳篷往外推，他的车得再挪一次。他正要告辞，信封里忽然掉出个小东西，在玻璃柜面上弹了一下。

钟师傅用拆信刀划开的封口还捏在手里。那是一枚椭圆黄铜牌，比一元硬币长一点，正中刻着“二十七”。牌孔边有个小缺口。

“你的？”林柯问。

“我铺里的。早不用这号了。”

钟师傅抽出一页蓝线信纸，看了好一会儿。他把纸转过来，推到林柯眼前。

“你看这写的是不是阅览室？”

林柯俯下身。信上只有几行：

“请把二十七号牌带到旧阅览室。要是钟还在，先别上弦。周六闭馆前，我想知道它还能不能走满一刻钟。”

下面没有署名，也没有再写一个字。

“是阅览室。后街那个？”

“这条街还有第二个？”钟师傅把信拿回去，“他们搬东西，倒想起我来了。”

“要还什么钟？”

钟师傅指了指柜台后面的窄门。林柯只看见半幅布帘和堆起来的纸箱，钟藏在哪儿，他看不见。

“搁了好些年。送来的人不来取，换了管理员，问我拿没拿过公家的东西。你说这话好听？”

他嘴上说着，手却把刚才那块白纸移开，另取一只浅铁盒，将铜牌放进去，免得掉进螺丝堆里。

林柯看了一眼手机。十二点零六分，站里的饭还有二十分钟。他该说信已送到，旁的事找管理员。可钟师傅又问他下午过不过后街。

“过。送报。”

“替我问一声。叫她来认实物，别隔着一条街叫我还钟。我收修理钱，不收扣东西的名声。”

“那你把信给我？”

钟师傅把信封往身边一拢：“你传句话就行。原件给出去，回头人家又说我没收过。牌也先留我这儿。”

这倒省了林柯拿着私人信纸去解释。他把手机上的时间按灭，问管理员姓什么。钟师傅想了想，说陶，年轻的，头发总拿一根铅笔绾着。

林柯在路线纸背面记了一个“陶”。他的字没有信上好看，最后一笔还被车钥匙顶歪了。

“我只管传话。她来不来，我不能替她答应。”

“我也没请你抬钟。”

钟师傅将信纸折回白信封，把信封和装着铜牌的铁盒一同收进柜台右侧抽屉。林柯听见抽屉关紧，才从鱼摊的篷沿底下弯腰出去。

他把车推上路，想起那张信纸。寄信的人连名字都不留，却算准了周六闭馆。后街贴出的搬迁告示，他昨天才留意到，下面的日期被一辆童车挡着，没有看全。

午饭少吃两口还能补。答应别人的事，下午若装作忘了，明天这条路还是得从十七号门前过。
