# 作者声音（代理试写方案）

用清楚、略带海边生活质感的叙述，物件细节服务于人要办的事。允许轻微幽默，不给每段加谜语式收尾。视角贴近林柯，不越入其他人的未表达心理。

林柯先问地点、截止时间、谁签字；年轻，怕被评价不牢靠，偶尔抢着兜底又会算时间。口气简短，着急时会漏半句，不能变成全能鉴定人。

钟师傅说话有修理人的价目意识，先分清谁拿来的、修到哪步、谁付钱。硬话会被自己的动作戳破，例如嘴上不肯搭工，仍把旧布铺好。不能句句都是“钟表哲理”。

陶芷关心空间、读者与实在的工作责任，问证据也会讨价还价；不做程序讲解员。她在办事时常夹一件生活小事，给人留面子但不替人签不清楚的账。

三个声音由代理在授权内设计；未经真人声音验收。
