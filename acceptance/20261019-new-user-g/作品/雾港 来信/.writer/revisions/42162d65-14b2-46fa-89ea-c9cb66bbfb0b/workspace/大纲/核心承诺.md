# 核心承诺与稳定ID（计划）

读者承诺：搞清信究竟请钟师傅办什么、二十七号牌与挂钟能否对应；逐步看清三人愿为这件小事付出什么。寄件人的人情原因可以留一部分未说完。

- O_LETTER：白色普通信封与单页蓝线信纸，视为一组原件；收件人钟守义，邮戳海堤代办所九月十二日，无回址。起初归投递员，完成投递后归钟守义。
- O_TAG27：信中附的椭圆黄铜修理牌，刻二十七，孔边有小缺口。不是产权证明。
- OBS_TAG_NOTCH：牌孔边小缺口，第一章观察。后续不得改成另一位置或凭此鉴定寄件人。
- O_CLOCK：旧阅览室木壳挂钟，初存钟铺；右下有掉漆，表盘背后留铅笔修理号。第三章只试摆与核对，不移交阅览室。
- T_SENDER：信由谁寄、为何现在寄；第一卷最多查到可回访的地点，不排他锁人。
- T_TEST15：三人约定搬迁清点前，在阅览室实测挂钟十五分钟并把结果留给寄件人。第一卷种下，第二卷可兑现一次实测和反馈，不等于钟永久准确或所有旧事结案。

这些是代理的规划ID，只有在正文实际出现后才以真实引文写ledger。计划截止单元T_TEST15=5，T_SENDER=6（允许intentional-open且说明边界）。
