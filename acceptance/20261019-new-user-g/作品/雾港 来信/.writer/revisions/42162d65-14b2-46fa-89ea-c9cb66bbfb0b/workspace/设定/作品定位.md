# 作品定位

《雾港来信》：原创当代日常悬疑，普通读者，无超自然、谋杀或终局阴谋。两卷各三章用于小规模方法验证，不代表百章承载能力已验收。

投递员林柯想按时清掉一封无人署回址的信，免得试用期再添一笔差错；修表师钟守义想保住一笔旧修理的名声，也不愿白搭工；图书管理员陶芷要在旧阅览室搬迁前做好财产清点，争取保留周六的社区开放时段。三人因“钟能不能交、谁有权收”发生具体分歧。

读者跟随林柯的近距离第三人称，先追查普通寄递与修理痕迹，再理解一个人为何拖延认领。悬念来自未说完的旧事和不同利益，不靠藏掉已被视角人物看见的字。生活后果包括迟到、工钱、清点表和可开放的时间。

本文件具体设定由代理在本轮授权内创作，是当前试写方案，非真人作者逐项采纳。当前阶段仅试写1–3章，4–6章不得动笔。
