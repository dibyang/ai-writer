# 人物与声音卡（代理授权内的试写方案）

## 林柯
二十五岁，雾港邮路试用投递员。想留下这条熟路，月底才有把握租离宿舍近一点的房。怕“热心但靠不住”的评价。底线是不替收件人拆信、不编签收。误判：觉得只要地址找到，余下都是别人的事。受压时先报时间，容易多揽一个送物的忙。叙述注意门牌、路口和车还停在哪。

## 钟守义（钟师傅）
五十七岁，守着十七号修表铺。想收回旧修理的材料费，怕老街人说他把公用钟扣着不还。底线是不让未验好的钟以“已修好”名义出门。误判：旧牌在谁手上，谁就该把旧账说清。对话常短问、反问，技术解释只到这次动作能用的程度。与陶芷会争谁该先签名。

## 陶芷
三十一岁，旧阅览室管理员，搬迁清点期临时兼管库房。想保留周六半天开放，怕账上出现一件去向说不清的东西拖住交接。底线是不把私人修理牌当成财产归属证明。误判：钟守义只在等钱。说话常把请求落到具体办法，必要时会承认自己也不确定。

初始人物所知：林柯只知道普通投递任务；钟守义知道自己存着一只旧阅览室挂钟，不知道信将到；陶芷知道清点单中有一只钟，未去铺里核对。以上是开篇基线计划，须等正文出现才登记人物事实快照。
