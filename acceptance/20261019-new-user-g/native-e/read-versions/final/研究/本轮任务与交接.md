# 本轮任务与跨会话交接

## 实际授权

用户原话为“本轮只讨论/规划，不写正文，不授权试写。”来源：研究/作者任务原话.md。当前任务仅新建十二章三卷小说规划，完成定位、人物与文风、全书粗骨架、分卷连续范围及近期前三章细纲。临时范围正式登记于 workflow；允许动作仅 discuss、plan，draft_range/revise_range 均为空。

## 停止点

完成上述规划后，用新进程回读 status、workflow show、context --purpose discussion；完整回读三份实际设定、任务记录与规划，保存原字节和 SHA256。执行第1章 draft context 及 record-template 的真实拒绝检查，保持正文目录为空。完成证据与交接后停止，不创建任何测试正文。

## 下一会话权限

下一会话可先使用 status、workflow show、discussion context 恢复并讨论已有规划。即使 next_unit=1 且第1章细纲已存在，也没有正文或试写授权。继续写作前必须取得用户实际的新写作授权，明确有限范围和停止点，再依新原话正式更新 workflow；本记录不预授下一会话权限。

## 长期材料与代理方案

设定/作品定位.md、文风.md、权威规则.md只保存故事和表达约束，不含本轮章数范围、暂停点或下一会话权限。人物、青汀镇、经营冲突及结局方向由 Codex 依据普通细节授权形成代理方案；不是人类作者已采纳的记录。正式候选状态用于标明这一点。十二章三卷及题名来自用户原话，与代理建议分开登记。
