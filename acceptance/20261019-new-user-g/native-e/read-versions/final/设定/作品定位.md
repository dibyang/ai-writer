# 纸桥书店

文体：小说

## 读者与故事承诺

面向喜欢当代小城生活、代际关系和普通人相互扶持的中文读者。故事发生在虚构的青汀镇，中心场所是一间兼卖新书、收售旧书并提供少量寄存服务的纸桥书店。

林乔离开城市工作回到家乡，想替准备退休的母亲许芸处理书店结业。她在清理寄存书时发现，一批书的主人仍盼着归还，账面上的存货也不能随意出售。她需要弄清一间常年勉强维持的店究竟对谁有用，并面对自己的收入、母亲的体力和承诺的成本。

核心问题：一间书店能否成为值得保留的公共生活空间，同时让经营者拥有可持续的生活？价值通过退书、记账、协商和有代价的选择体现。

## 视角与冲突

以林乔为中心的第三人称限知视角，允许日常幽默与克制的感伤。读者跟随她的实际调查和协商认识镇民；母亲与其他人物的隐情通过行动、物件和当面谈话呈现。

冲突来自店租期限、有限资金、寄存责任与不同人的生活需求。房东也有自己的维修与收支压力；母女的关心可以与意见冲突并存。书店的存续不能依赖突然巨额馈赠、名人引流或一场活动奇迹翻盘。

## 关系与终局方向

母女关系从替对方作决定走向共同承担、各自保留选择。林乔学习区分被需要与无限承诺；许芸学习放下凡事亲自兜底。社区参与需要清楚的职责与退出方式。

终局追求规模更小、账目透明且责任明确的书店合作方式；经营风险与劳动成本仍然存在。书店可以改变形态，不能让任何人的自我牺牲被写成理所当然。
