# 作者声音

## 叙述姿态

贴近林乔的第三人称限知叙述，温和、具体，容许人物觉得难堪、想占一点便宜或临时改变主意。叙述不替角色宣布书店的伟大，不用整齐的道理替代争执后的实际处理。

## 节奏与细节

重要段落围绕可见的事务展开：翻出寄存单、核对书脊、挪开漏水处的书架、商量营业时间。细节应改变人物判断或行动；书页气味、雨声与桥的意象少量使用，避免反复抒情。句子长短随动作和思考变化，保留必要的停顿与过渡。

## 人物口气

林乔习惯把问题分成可处理的步骤，受挫时容易说得过硬；许芸先顾及对方的面子，谈到女儿生计时反而直接。维修工陈朔多用物件和工时说话，教师唐薇会主动问活动由谁收尾，房东周岚说清期限与条件。对白允许答非所问、玩笑和欲言又止，同一场谈话中每个人应有所求。

## 情绪与表达资产

感情落在劳动被看见、承诺被调整和物件被妥善归还的时刻。允许平静的章节结尾，以一个新决定或关系变化带出后续。保留生活幽默、人物各自的比喻与自然复句，不统一压成短句，不批量添加身体反应或章末格言。
