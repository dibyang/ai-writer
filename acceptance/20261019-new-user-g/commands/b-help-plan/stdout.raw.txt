ai-writer 0.7.4 / plan
保存下一章、场或篇的细纲。

node 'D:\work\other\ai-writer\bin\ai-writer.mjs' plan --project 作品目录 --input 细纲.json

输入示例（UTF-8 JSON）：
{
  "unit": 1,
  "title": "来信",
  "goal": "确认寄件人",
  "change": "发现寄件时间不符",
  "beats": [
    "核对邮戳"
  ],
  "cast": [],
  "setting_refs": [],
  "research_refs": []
}

在作品目录运行时可省略 --project；其他位置须明确提供作品目录。
