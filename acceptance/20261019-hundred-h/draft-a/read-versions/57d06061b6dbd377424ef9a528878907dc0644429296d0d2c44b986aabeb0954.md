# 第一百零八章 先陪你走这一趟

第六十六日十二点二十，沈禾到家，换鞋时手机响起来。何映没打电话，先回了两行字，说今天先不看，菜单那边又要改汤名，自己盯着十八和二十四，连买东西都怕看串。

沈扶着门框，把还没脱下的鞋蹬掉。那句可以晚点看已经打出，何的下一条又来了：下午想去买双鞋，你愿不愿陪一趟？我两点出门，三点得回。

她将刚打的字删掉，手机放到柜上。何不想看纸，却有时间买鞋，她知道这两件事不该接成一句，心里仍先这么接过。脚后跟在旧鞋里闷了一上午，脱出来凉快，她低头将鞋并到墙边，过了一阵，才拿起手机。

“去哪家？”她问。

何发来街名，说先去路口那间，若没有就不赶第二家。沈看了日历，下午没有接下的活，上午没写完的报价例子也还没另排时间。她答两点门口见，三点自己也回。

发完，她有些后悔答得这样快。坐到床边时，屋里那份稿像正等着她看，手不用伸得很远就能拿到。沈仰面躺下，原想歇十分钟，眼睛闭着，脑子却将昨天纸上的句子又走一回。周说不看时的样子也跟着来，她翻个身，将脸转向窗外，没能睡着。

一点四十多，她起身洗脸，水从下巴滴到领口。镜里的人没有看起来那么失落，只是头发睡乱一边。沈重新梳好，小包里放手机和钥匙，走到门边又回头，取了几张纸巾。窄夹留在架上。

两点差三分，何已经站在鞋铺外。她穿的那双布鞋右侧开了一小截胶，正将脚往台阶边藏，见沈过来，才把鞋尖转出来。

“我还以为是袜子顶着。”何说，“摸了半天，把自己袜缝都拽歪了。”

沈蹲一下，看见开口在鞋底边，不在脚尖。她想说能粘，何已经摇头，说这双先留着，今天想试一双自己不用老惦记的，别让她进门又给说回去。

“我还没说。”沈抬头。

“你刚蹲下去，我就知道大概要说了。”

沈笑着站起来，膝盖弯过一下，裤腿粘在腿上。何先替她拉了拉包带，带子夹住领口，沈自己没发现。两人进店，门上的铃响得很急，柜后女人正在吃半只馒头，用袋子包好放下，过来问穿多大。

何报了尺码，先指柜上灰的那双。沈却看中旁边浅色细带的，拿起来在她脚边比，说这双配今天的裤子好看。何也觉得好看，伸手去翻价签，一百六十九，看完将鞋放回去，仍请店员拿灰的。

“那双也给你试试？试不花钱。”店员说。

何犹豫一下，答两双都拿。沈退到小凳旁，自己脚尖收进来，给店员过。凳面只够一个人，何坐下解鞋带时没地方放袋，沈伸手接过，袋里手机又在震。何听见，先将脚套进去，脚跟卡在后头，一时够不到袋口。

沈递回去，何抬起半穿鞋的那只脚，坐姿歪着接电话。对面的话沈听不清，只听何说汤名要改可以，下面材料那行也要一起看，别等改完上头，才发觉叫的不是同一碗。说着想拿笔，袋底翻到一把钥匙，笔却夹在另一边。

“我回去再改。三点以后。”她终于说，“你现在先把要的全发来。”

电话停了，鞋后帮已经被压扁。何低头一看，啊一声，将脚退出来，店员递鞋拔，她接过道谢，自己把后头扶正。沈原想问新菜单是不是已经好了，听到刚才几句，没再问这个，改问灰的那双要不要先松鞋带。

何点头，两人一人抽开一边。鞋带原本穿得紧，沈解开最上头两个孔，何脚终于进去，站起来先踩了两下。镜子靠在柜边，她侧着看，裤脚太长，堆在鞋面上，便提起一点。

“是不是像去跑操？”何问。

“跑操还不一定发这么软的。”沈说。

何走到门口，右脚轻，左脚拇指却顶着。她回来只说左边有一点，店员答新鞋都紧，让多走几步。何又走，越走越短，走到第三个柜前停下，低头将脚往后蹭。

沈想起刚才自己说软，说得像已经穿过。她把店员摆回来的另一双拿近，没再替灰的讲好话。何坐下，先脱左脚的鞋，袜尖湿了一小片；她将袜头褪开，拇指上有一道压出的红印。

店员找大半号，柜里没有，得去后间。她站在门前说稍等，将几只散鞋并回架上才进去。店里一时只剩风扇响，何朝沈挤一下眼：“这回真是我自己来找罪受。那只馒头怕要被我耽误成晚饭。”

“人家没说你。”

“所以我得自己先说。”

门铃又响，一个男人进来，手里捏着断掉的拖鞋，说早上看见门口挂二十元两双，现在能不能拿。店员从后面探身，说两双是前头蓝色那款。男人将手里的灰鞋翻给她看，自己要同这样的，说家里另一只还好，凑上便成一双。店员从架底取一包给他，鞋面很像，底纹却不一样，男人蹲在门口对，越对越近。

何的左脚没穿鞋，想把凳让出来，站到一半又坐回去，单脚跳一下，自己先喊不行。沈挪开旁边一个空盒，给那人腾出放鞋的地方，他连说不用，最后还是将灰鞋搁在盒上。店员把他要的大码挑出，回身找何的鞋，先拿来一只，又转回去，说还有一只在里头，别真穿成两只左脚。她拿着那一只又进了后间。

沈看着柜边已经摆开的几双，原来觉得买鞋一个钟头太宽，眼下只等一个大半号，二十分钟便过去了。何将袜子拉正，说今天出门前还想顺便买条裤子。沈问那现在呢，她朝脚下指指，说先能两只脚一起走出去再说。

沈笑。何将浅色那双穿上，系带要绕过脚背，她一边系，一边让沈看别的颜色。浅鞋配她的裤子确实好看，沈忍不住说就这个，何站到镜前也看了好一会儿，转身走路，带子却磨到脚侧。

“你站着别动，拍一张倒挺好。”沈说完才察觉自己像还在劝。

何已经举起脚：“那你替我把店也搬走，我以后就站这个角。”

她们笑得有点大，后间店员问是不是有事，何忙说没有，鞋还没选好。沈靠到柜侧，肩头碰落一只样鞋，连忙接，接住了鞋跟，鞋尖又敲到小腿。何的笑更停不下，她索性拿鞋在掌里托着，等店员回来再放。

样鞋旁夹着一小张鞋带包装纸，一并贴在沈掌心。她将纸剥下来，正要找地方放，何叫她看脚侧磨出的印，沈俯身去看，纸便被捏到另一只手里。何摸着那条红痕，说刚穿进去时还觉得自己脚显小，没想到真是挤小的。沈答那你别选了，等下脚先记恨我；何说已经记上，浅的可是你最先拿。

大半号的灰鞋拿来，何重新试。她这回没有先去看镜，站着活动脚趾，又走到门外台阶前，来回两趟。沈跟到门口，看她脚落下来，鞋跟没掉，问前头还挤不挤。何说不挤了，低头看裤脚，仍有点舍不得刚才那双浅的。

店员报灰鞋七十九，浅色可以便宜十元。何站在两双中间，问沈要是哪双都能穿，她会挑哪个。沈答浅的，何说我也是，伸手拿起浅鞋，最后又将它放回原处。

“灰的吧。我真穿这双走回去。”

她取手机付七十九，店员看过收款，拿鞋盒。何问能不能只用小袋装旧鞋，盒子今天不带，自己换着走。店员找了一只厚袋，先让她看底有没有破，才将旧鞋装进去。何拿袋时，手指在开胶那一边碰了碰，没把旧鞋扔在店里。

出店还不到两点五十。何踩在街面上，比在店里走得快，走过几块砖又慢下来，说新底有点高，腿还当自己穿旧的。沈说看不出来，何便故意抬一抬脚，像跨过一条看不见的水沟，两人又笑。

走到街角，何停下，低头看完客户发来的几行字，脸上的笑慢慢散了些。她没有给沈看，只说对方终于将要改的放一起，自己回去得先对一遍。沈说那就这里分开，何却把手机收好，问要不要再往前走到阴处，太阳正从这条街头照过来。

她们沿屋檐走了半条街。何的新鞋底偶尔响一声，沈听着，原来那点没被看稿的不高兴又冒出来。她想何今天大概很快就忘记这回事，自己却能将手机上短短的回复记很久。

“我中午看见你说不看，挺扫兴的。”沈说。

何转头看她，脚步没有停：“那你刚才怎么不说？”

“刚才你在挑鞋。我现在也没想好说了要你怎么办。”

何走了几步，说自己今天确实不想看，刚才那半天却真想有人陪。她原以为沈下午也忙，消息打出又想撤，怕问完还得跟一句你有事就算了，越说越像自己非得给人留一句标准答复。

沈听到这里笑了一下：“我本来想回，今天不行，明天可以。”

“你明天真有空？”

“还没看。就是想先回得不那么难看。”

何低头看看手里旧鞋袋，答那幸好还没约。她没有答明天看稿，也没为中午的回复补一串解释。沈走在旁边，既没有觉得自己全不在意了，也没有要将何这一个小时退回去的意思。

到了分路处，何举一下袋子，说这双再开口，自己先让它闭嘴。沈提醒别把鞋放到新菜单上，何说那倒不用提醒，放上去自己才是真给客户加了一道菜。三点前，她拐进巷里，沈朝另一头走，到了转角才发觉自己手里还捏着店里落下的半截鞋带包装纸。

她折小，找到垃圾桶放进去，回家时肩后出了一层汗。屋里没有外头凉快，窗推开，纸巾从桌边被吹下去一张。沈弯腰拾起，忽然很想将刚才那双浅鞋画下来，画一半大概就认不出是鞋。

她先去换上衣，脱到头顶时领口卡住发夹，手举着够了两次，才将夹子取下来。镜里一条领印歪着，包带压过的地方有点红。那一小时不是在家等一条回复，脚底走得发热，回来也得洗衣服。沈将衣服泡进盆里，看见今早袖口沾水那一圈已经干了，下午的汗又添上去，忍不住叹一口气。

她找支笔，在废纸背面画了两道带子，越画越像两条挂着的面。沈笑着停笔，把它留在桌边，没有发给何叫她回来评。

窄夹取下来，新页从前层抽出，她坐着从石沿那一句读到袖口。想被谢的那几字还让她不大舒服，七百二十后面仍是没接。她没有将今天买鞋放进去，让这张纸突然有一个轻松的收尾。读完，原页按原样放回，后层折着的划头稿也没动。

沈给何回了一句：那页今天先留我这里，你不用找空补看。发完，她没有再开另一个人的名字。桌上的怪鞋还在，上午那份工作说明也还在，她翻日历，将报价例子排到第六十七日上午九点半到十点半，别的空处没有接着填满。

窗外一声车铃响过，她去厨房倒水，想起晚上还得吃饭。午前那碗面里有个蛋，下午自己什么也没买，家里能拿什么做，得开柜看看。沈把杯子放回桌面，绕过摊着的废纸，先去淘今晚自己的米。
