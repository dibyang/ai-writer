# 第一百零七章 九点到十一点

第六十六日八点五十七，沈禾把早饭碗放进水槽，桌上的电脑还没开。她看了一眼日历，昨天留的两小时底下空着，没有人催，也没有谁会在十一点来收。

她反倒先去找手机。周砚的对话停在昨晚那个好字，往下没有新话。她将屏幕按暗，搁到窗边，走回来时差点又把它带上。最后只拿了水杯。

九点，电脑亮起来。她新开一份说明，第一行打了修音，后面接课程、访谈，又删掉访谈。自己做过的事不少，真要让一个没见过她的人拿着这几行来问，仍不知道该从哪里问起。

她先写可以让声音更清楚。看了一会儿，自己笑出一声。这样写，买一副耳机也像能找她报销。

说明往下列，很快占满屏幕：收到什么、要交什么、哪一版、什么时候要。她熟悉这些问题，敲起来不用停，心里渐渐有了做完许多事的轻快。写到修改次数，她忽然将手从键盘上拿开。眼前有一整页话，却没有一句能回答，别人把一段声音送来，她这回究竟交回去什么。

沈将上面几行移到后面，留下两个空白处。一个写听过以后给意见，一个写实际处理声音。字很笨，她没急着换。

楼下有人拉开卷门，铁片一路响上去，末尾卡了两下。她等声音停了，拿自己的手机录一小段试声。念的是眼前白纸上随手写的几句，讲桌上水杯、窗帘和今早那碗粥，念到粥时自己咳了一声，后半句被门外一辆车盖住。

她本来想重录，手已经点到停止，想了想，只另录了清楚的一遍。两段都标了今天自录，放进新建的试声夹。没有从从前的工程里挑一段现成问题来替自己省事。

第一遍听，她知道自己说的是什么，车声底下那几个字竟也像清楚的。摘下耳机再戴上，她将纸翻过去，光听，听到后半句时还是顺着记忆补。沈把进度往前拖，拖多了，连自己的咳声又听一次，有点烦。

她没有再来第四遍。在纸上记下那处位置，写车声盖住后半句，单凭这一遍不能保证还原。写完再看第一行，修清楚三个字太轻松，轻松得不像要由她来做。

那份清楚的试声，她也听过。开头一声嗒，是自己将手机放回桌面时碰到杯底；后面念得太近，有一个字突然鼓起来。沈重新把手机立稳，杯子移走，站着念。才站好，又觉得声音像在给一屋人介绍东西，连桌上水杯都被自己说得很郑重。

她停了录音，朝空屋说你先坐，自己先笑，笑完才慢慢坐下。这一遍没按纸上的次序，看到什么说什么，念到窗帘，风正将布角推过来，擦过椅背。她伸手抓住，后半句离远了，声音跟着变轻。

沈听完，原来想把这一遍算废的，手停在删除旁，改将它留作另一段：人在动的时候，声音会变。可她不准备为了写一份工作说明，把自己的屋子录成一套课程。手机从桌沿取下，后面的试声到这里停。

沈试着压低那段车声。人声跟着薄下去，原本能听见的尾音也碎了。她退回去，将前后两小段交替放，按下暂停时，耳罩里还残着细细的嘶声。要是真有人坐在对面，她不愿让对方误以为自己再多听一阵就能答应。

她在处理那一栏换了句话：先看一小段原文件，能做到哪一步，再谈整份。听辨意见另起一栏，写明给的是问题位置和听到的情况，不是已经改好的片子。

九点四十，手机在窗边震了一下。沈立刻转头，椅脚也跟着挪响。拿起来，是一条门店消息。她看清后仍在屏幕前站了片刻，才关掉。回桌时，刚才那段试声已经播到末尾，自己漏听了后面十几秒。

她将播放停住，没有把漏掉的算听完，重新从记下的位置往后听。这回车过去以后，她那句声音还在，只是自己念到一半笑了。试声里的人比坐在电脑前的人轻快，沈听得有点不好意思，把那一下笑也留着。

耳机戴久，耳后压出热意。她调松一点，低头找自己刚才记的位置，纸却被手肘推到了电脑底下。抽出来时，末行有一道淡铅痕，像划掉了，又没有真正划掉。沈换笔将要留的那句重写到下面，抬头一看，才过去七分钟。听一小段声音时，七分钟很长；看着空白说明时，它又短得不够交代一个词。

十点零五，她把说明缩到一屏，给自己出了一道题：有个人只想知道一段话为什么忽大忽小，今天傍晚要答复，应该先发什么来。

她合上原文，只看缩过的这份。文件长度、版本都写了，唯独没写能不能先只发手机翻录。她知道该要原文件，可纸上没有。于是又添一句，若眼下只有翻录，先说清；听它能谈的范围和原文件不同。

添完，她往下一看，刚刚空出来的地方又被填满。每个问题都能再长出两句，今天若非得把所有可能写全，十一点以后还有十一点。

沈往椅背一靠，腰下空了一截，酸意这才明显。她站起来，去厨房把早饭碗洗掉，水开得太急，冲到腕上，袖口湿了一圈。今天这件也没能一直干净。她将袖子卷高，没有因为这个念头去拿昨天的窄纸夹。

回来，她删掉两段同一个意思的话，把不能先说齐的放进末尾：具体要看文件。不是一句包办，也不是让人先填满一张表才许开口。她将示例文件和一条自己写的听辨意见并排摆好，忽然发现意见里只写第十七秒，没写是哪一遍。

两段文件名字只差后头几个字。她点错一次，第二段清楚的声音一出来，就知道自己找错了。沈没有笑，这种错送到别人手里，解释起来得花比改名更多的时间。她将意见补全，关掉两个窗口，只从说明里的名字重新找。

这次找到了。那辆车在同一处响起，她往后听完，意见里没有替原声补出的字，另一段清楚试声也没有被塞进去顶掉。她写的几行终于能带自己走到一个确定的地方。

她把处理过的那一小段也另存出来，再次打开，先听到一阵空白。方才只选中前头几秒，导出的竟不是自己以为的整段。沈看着文件名，烦得将手掌贴在桌上，没立刻再按一次。名字写得再全，里面空着也白搭。

她关掉那个窗口，回工程选好范围，重新导出到另一个清楚名字下，再从头播放。咳声、人声、车声都按原来的次序来，处理后的缺点也还在。她将第一份错误输出移出待用的位置，留着记这次错在哪里，没有用第二份的名字把它盖掉。等这件小事做完，刚才站起来时松快的一点腰又酸回来。

十点三十六，沈把说明转到手机上看。电脑里刚好的一屏，到了手机上，最关键的交付内容被推到下面。她先看见的还是一大段问对方要什么，像人还没进门，自己便已经把手伸出去了。

她又坐下，将交什么挪到前面。小屏上的字不够整齐，两行长、一行短，却不用一口气滑到底才知道她在做什么。水杯空了，她喝到最后一口才发觉水已经凉。

还有报价例子没写。沈开了个空白，刚敲出一行，十一点的提醒便响起来。她抬手把声音关掉，手指还留在键盘边。再写十分钟大概就能凑出样子，午饭晚一点也不要紧。可那十分钟若真能写清，刚才半小时就不该还停在这里。

她将空白页单独留作待做，没有往完成的说明里添一个随口估的价。文件保存，重开一次，先前补的名字和交付内容都在。今天上午做成的是这一份，还没有发给任何客户，试声也只由她自己听。

电脑合上以后，屋里安静得很快。沈看着桌面，忽然觉得没有谁会知道自己刚才忙过。她想把那一屏发给周，打了半句，又想到他正在上班。自己不是一定要今天请他看工作，可手指已经替自己挑了最熟的那个对话框。

她退出来，没有换成一句更轻的忙不忙。架上窄夹露出一角，昨晚没给看成的纸仍在那里。她原想等两小时过去，自己就会对它淡一些，现在才知道，上午的说明做好了，并没替那一页找着去处。

她站到架前，又走回来。给人看工作的那几行，自己能问对方是不是找得到文件；给人看那一页，她想问的却大得多。写得好不好，像不像自己，看完是不是还愿意坐在这里。她不可能把这些全缩成一个不麻烦别人的问题。

沈拿起杯子，杯底压着今早随手写的试声纸。纸上那碗粥已经吃过，窗帘仍会擦到椅背，她录的两回也都有不好听的地方。她将纸挪到电脑旁，没另抄一张，再去换鞋。午饭得真吃，不能等那个问题自己变小。

十一点二十，沈锁门下楼，没带电脑，也没带纸。街口面店里有人端着碗找座，老板叫她先往里走，她绕过门边一只装空瓶的筐，坐到靠墙的小桌。桌脚轻轻晃，她将椅子往侧边挪，不想吃碗面还先修一张桌。

“青菜面，放蛋吗？”老板问。

她说放，又问共多少，听见十二元，先付了。老板朝灶边喊一声，没给她留一段说自己做了两小时工作的空当。

面端来时，蛋卧在底下，沈先挑了半天，才从青菜下面找到。旁边那人比她早坐，碗还是空的，见她先吃上，问老板是不是忘了自己的。老板隔着热汽答你要的宽面，正煮着。那人说自己没催，下一句又问还多久。沈低头吸面，笑意差点呛进鼻子。

面店的风扇朝灶台吹，转过来才有一点风到她背上。她将头发从领口拨出来，原来想快点吃完回去，挑起一大筷又放回去一半。昨晚坐着不想走，今早坐着又老想站起来，两条腿并没比她更知道一天该怎样用。老板来收隔桌空碗，见她碗边还堆着面，说不够可以再加，她忙摇头，觉得自己这副吃相已经很像准备续碗。

她也总觉得自己只是问一句。昨晚那页推到桌中央，右角离周的碗还有一截，她却已经在等看完以后的话。面汤烫，沈将筷子搁住，喝一口另倒的温水，没有顺着想他究竟会评什么。

手机被她放在桌内侧，屏幕上粘了一点指印。她擦净，翻到何映的名字。何见过旧半面，可没见过这次新写的；昨天她带着几版样纸回去，今天是否仍忙，沈确实不知道。

她打了很长一段，读完删到只剩一句：我又写了一页自己的事，想请你一个人看，今天有没有一段合适的时间？

发出去，她将手机放回原处。问得直，等起来也并没有轻松。宽面终于送到隔桌，那人用筷子一挑，说太多了，老板答刚才就说这个碗大。两人拌一句嘴，各自笑起来。沈把自己的蛋翻上来，咬开，里面的黄刚凝住，她决定先把这一碗吃热。

十二点前出店，何还没有回复。沈没发照片，也没补不急。路上经过一家鞋铺，门口挂着的鞋带被风吹成两排乱线，她停下避过一辆送货车，再从台阶外侧走过去。下午还空着，她先回家，想将那张说明里没做完的报价例子留到另一个清楚的时段。
