# 第一百一十章 坐下以后还想说话

第六十八日九点二十多，沈禾到葛筠铺前，先闻到锅里的米香。她今天没吃早饭，走最后一段时已经有点后悔，眼睛往柜里找，想要咸的，嘴里却先问了甜糕热不热。

陶敏从锅边说刚好，葛问要几块，她这才改口说一碗粥，配咸糕，甜的待会儿再看。葛将笔往台上一放，笑她今日带了两个人的嘴来，一个说一个改。沈答肚子只一个，别真给自己装两份。

她付了八元，坐到普通桌边，将挡早风的薄外衫脱下搭到自己椅背。原凹处的靠背木椅上压着一盘待折的纸袋，葛经过，拿起来抱到柜后，想搁在自己的早饭旁，放不下，便先把饭碗端走。碗上倒扣的小碟一滑，她用腕子夹住，纸袋边还是散出几只。

沈站起一点，葛叫她吃，自己将落的拢回盘里，碗放到后头矮架。那里的盒仍照前些天陶试过的顺序摆着，她取出日用一只，没再踮脚到上层找，盘终于能搁到手边。

“我坐着也能折，老图那把椅近。”葛说。她摸过椅面，干布擦掉一条纸灰，自己又将布挂回去。

粥端来，沈吹着吃第一口，烫得上唇发麻。她不必听文件，也没有一条消息等她判字，偏偏脑子里还闪过昨天那句两百四十买到什么。沈把手机从桌面收进包，咸糕的边咬下去有一点焦脆，这回先知道八元买到了什么。

九点四十多，素姐提着一只旧布套进门。葛朝柜上两只盒看，她先摇头，说今天不取饭，本想去换眼镜上的小配件，那家十点半才开，自己又把时刻记早了。

“我能在这儿赖一会儿吗？”她问。

葛朝木椅指，答能，空着。素姐却站在价目旁，眼睛找一圈，说早饭吃了，再吃半块糕，回去饭便又剩给自己。葛正伸手取碟，听见这句，把手收回来，说那就坐，别替自己的糕硬找一顿。

素姐坐下，布套落在腿上，肩膀终于低一点。她抬脚想将鞋跟往椅子底下收，试一下又伸回来，笑说坐太整齐，腿反倒没地方。葛告诉她背靠实些，椅后就是墙，不用替自己省那一点。

“我不是怕占。”素姐说，“刚才出门前穿反一只袜子，坐下老想它。”

沈抬头看她鞋口，两边都是黑的，看不出。素姐也低头，半天自己笑，反不反只有她脚知道，眼睛还非要跟着操心。她没在店里脱鞋，把裤脚拉平，重新靠好。

葛把纸袋抽一只出来，边折边问眼镜怎么坏了。素姐说没坏，要换贴鼻梁那两小块，戴久总往下落，昨天端汤，腾不出手来推，差点用肩去够眼镜。

陶从后头出来，正听见肩那句，举着空盘试着歪一下头，眼镜没戴，自己先歪得像牙疼。素姐笑得往后靠，布套里一只小盒碰到椅沿，她按住，说自己要真长成这样，母亲得先问是不是汤又放咸。

“你妈嘴还灵。”葛答，折过袋口，伸手去拿下一只。

素姐说就是太灵，自己一早煮的那锅，母亲说淡，楼上那家又说味重，索性都盛好送去，各自在碗里补。自己那碗就在灶边站着喝了，喝到见底，也没想起找把椅子。

葛说下回先坐下吃，素姐嗯一声，却没有接着说汤。她望望门外，说今天本来可以等店开再出门，自己仍提早下来，家里一闲，眼睛便总往那只电话去。

“他们没打来？”葛问。

“也没约要打。就是外孙上回说我头发短了像他班上谁，我想起来，自己倒……”

葛这时正叫陶把锅边的空盘先收，后半句没听全，只回短了好洗，夏天省事。素姐停下，手在布套上抹过两下，朝沈笑一笑，说是，好洗。

沈含着一口粥，听见那声是比先前小。她原想接问像哪个同学，葛却先把折歪的袋子抽出来，停在手里。两条折痕交错，压哪条都合不上，她终于把纸摊平。

“你刚说到哪儿？”葛问。

“说我不像外婆。”

“谁说的？”

素姐看着她，嘴角抬起又落下：“你看，你根本没听。我说了半天，倒像给你折袋子配个响。”

葛捏着那张纸，没有立刻笑。沈垂眼看自己碗里剩下的粥，方才确实想接话，可素姐望过来时，她又有一点不愿。这顿早饭若从这里接成长聊，自己走的时候也许还得找一个听来不冷淡的理由。

陶将锅火调小，指了指柜后：“你坐两口饭的工夫吧。这会儿我顾得过来，后头新那盘你还得自己弄。”

葛朝后面看一眼，将手里那只歪袋放到盘外，没塞回折好的。她端回自己的碗，饭上小碟已经凉，原来想放到沈这张小桌，素姐却已抬头等她，她便转到木椅斜对面的小桌旁坐下。素姐把腿收了一点，她将自己的椅子拉侧，给两人的脚各留一处。

“我坐一会儿。等下还得做午前那盘。”葛说，“刚才那句你再讲给我听，别从眼镜重来。”

素姐看她一眼，笑了：“眼镜也算听进去了。”

她说外孙在屏幕里看见自己剪短发，说像班主任，第二句却跟着说班主任最凶。自己本来笑着，后来关了电话，总想是不是平时催得太多，孩子只记住她问吃了没有、作业做完没有。

葛拿筷子拨冷饭，答小孩那句未必想得这么远，素姐马上说自己也知道，知道了照样想。葛将要说的下一句咽回去，夹一点菜，咬完才问，那你剪之前，是不是自己想剪。

“是。我头顶一热，汗全顺着后脖子走。”

“那剪完凉快没有？”

“凉快。”素姐摸后头，“后悔的是剪完，理发的拿小镜给我照。我看见后脑勺那一块，第一次觉得自己头还挺扁。”

葛笑得饭差点掉，端稳才说早知道就不问。素姐也笑，抬手想让沈看，沈摇头说自己坐这头看不全，素姐答看不全最好，还能留一半像好看的。

两人说起年轻时烫发。葛说自己烫过一回，头三天不敢洗，出锅的热气全往头上钻，觉得自己连头发都端得小心。素姐问后来呢，她说后来洗完，只剩耳边那一小卷，家里人问钱是不是按卷给的。

陶在柜后笑，叫她别说，自己听着都想把工资按袋给，今天那只歪的先得扣。葛朝她扬一下筷，嘴里还吃着饭，没有赶她来替自己说哪一回最难看。

素姐说自己倒想过给孩子寄张长头发的旧照片，找了一晚，从一叠里挑出三张，放到手机上再看，背景那张花沙发比人还抢眼。她问过女儿怎么裁，女儿先回是不是又想叫孩子看，叫她留自己喜欢的就好。

“我就不高兴了。”素姐道，“我还没说要给谁，她先替我知道。”

葛问那后来给没有。她将布套口抻平，承认没给，后来自己又觉得花沙发真好看，现在家里那只灰的，擦得再净也像等人来开会。

“那你这回是替头发难过，还是替沙发？”葛问。

“都不耽误。你这话说得，像我今天只能带一件下来。”

葛笑，拿筷子指自己的饭，说那她也要算上这碗，昨晚特意留的锅边，今早热过，本来该脆的地方已经软。素姐看了一眼，问还吃不吃，葛把碗往自己这边挪，说吃，软了也是自己爱吃的，不给她端回去喂第三家。

沈把粥喝完，咸糕剩的那点先留在碟里。她原以为有人说自己头扁，是要等一句并没有，素姐却已经同葛争哪一家的烫发水味道更冲，谁也不准备拿她的头作结论。沈坐着听了一阵，笑的时候只管笑，不必每句都接住。

十点零八，一个穿衬衫的女人进来问留的点心。葛放下饭碗，起身拿那两只原盒，问她是不是要分别拎，女人说一只带公司，一只送楼上，口味得先认清。葛把每只打开给她看过，取袋时才发现手边折好的不够，方才那盘还停在自己放下的地方。

她没有叫素姐帮折，自己抽两只，袋底压开，一只边斜，盒角送不进。陶手里端热盘，停在柜后等，葛叫先放原位，自己把这一只重折，待两盒各装稳，才接下一盘。

女人等得看过两回手机，临走问以后能否自己先装好。葛答知道了，这两份今日是自己慢，没将话推给在椅上坐的人。收好钱，她转回去，自己的碗还剩一半，筷子横在上头。

她先收那只没能套住盒子的歪袋，拇指沿原折痕抹，抹过才发现底口也偏。葛把它打开，放到一边收干纸屑，另抽新纸，做了几只够眼前用的，余下整盘移到柜内。陶去拿日用盒，袖口擦到纸边，葛看见，自己又将盘往里推，给她伸手留出空处。

沈望着盘原来放过的空处，才发觉葛的饭还没吃完，碗沿那点油已经凝住。那十几分钟里她坐着吃过几口，站起以后，桌上的活没有跟着停在同一个位置。葛拿回自己的筷子，把碗沿沾的饭拨进去，仍没有端去热，先抬头答门口问路的人。

素姐叫她继续吃，葛却看钟，说先得拌午前那盆，吃完再动就赶不及。她把碗端到后头，让开热盘的位置。素姐问自己是不是把她耽误了，葛停一下，说那十几分钟确实用在这里，活也还得做。

“你不坐也没事，我还能坐到那家开门。”素姐说，“你拌你的，说话总能说。”

葛已经在洗手，水停后，她擦过才答：“能说两句。可你若接着讲，我未必都听得见。我这手一忙，耳朵也老跟着去。”

素姐没有马上应。沈看见她将布套口折了一道，原来敞着的小盒被包进去。她偏头问沈急不急着回去，沈望一眼空碗，答自己吃完想回家了，今天没预备坐一上午。

这句说完，沈有点舍不得方才那阵热闹，好像自己一走，屋里便少了一样很容易给的东西。她把碗端到收碗处，没有将包放回原椅。素姐也没拉住她，只说那你走你的，又问葛这把还能坐不能。

“能。坐到你想走。”葛说，“我就在后头干活。”

素姐将布套放稳，真的往椅背一靠。葛转身去拌料，陶问糖用哪一罐，葛先答右边，回头看，自己两只罐放反了，赶紧叫停。素姐听见，忍不住说右边也得看人站哪边，葛隔着柜笑，答今天她们谁都别听自己只说一个方向。

沈原本已走到门边，想起咸糕那一角还在碟里，折回去两口吃掉。葛问甜的还要不要，她摇头，说今天一个肚子已经够了。素姐笑她两个人的嘴终于商量好，沈拿纸擦手，将纸送进桶里，才说再见。

十点二十多，她出了铺。素姐仍坐着，眼镜铺还没到说好的时刻。沈没替她约下一早，也没请葛将今天写到门上。她沿街买了家里快用完的盐，拎着折回这条街时，已经快十一点。

她到铺门口取刚才忘在椅边的薄外衫，木椅空着，素姐的布套也不见了。葛从盆边抬头，说她刚过十点半就走，自己没陪她去眼镜铺。沈将外衫搭在臂上，没把这句听成眼镜已经修好。

陶把围裙解开，找自己的小夹时摸到围裙袋，掏出一只发圈，才说难怪方才怎么都觉得头发散。十一点，她拿包出门，指给葛看哪盘刚上，别同旁边凉的弄反。葛应一声，自己洗手去拿布，先试盘边，觉得还热，换成两手各垫一层，稳稳端到台前。

沈侧身让她过，顺手握住快扫到盘边的门，等盘落稳便松开。葛问中午还来不来，她说今天回家煮。说完，原凹处那把椅子就在她身旁，她却先把外衫穿好，扣错一粒，解开重新扣，带着自己的那袋盐回去了。
