# 第一百一十一章 先吃这一碗

第六十九日一点零六，沈禾到葛筠铺里买咸糕。她在家煮过一锅面，水开了才发觉面罐见底，捞出来只有小半碗，吃完还饿。走进门，她先伸两根手指，葛却问两份还是两块，问得她自己也笑起来。

“两块。我真吃不下一份又一份。”

葛从盘里给她夹，边上那块切得厚，沈指了它。葛说这个沉，另一个薄的给你搭着，秤过说六元。沈付了钱，本想拎走，低头看见袋里冒着热气，肚子又叫一下，便问能不能坐着吃。

“我还当你来催我吃饭。”葛朝小桌扬下巴，“水自己倒，别拿后头那壶，刚烧的。”

沈先把袋放到普通桌上，倒半杯温水。葛自己的饭碗搁在柜后，盖着小碟，碟边伸出一小截葱。她端起，掀开看看，又盖回去，转身去拿擦台的布。沈已坐下，咬到厚糕里的芋头，太热，嘴闭不住，一时没能说话。

“慢点，又没人来取你这份。”葛说。话才落，门口真有人问自己的好了没有。

来的是个穿深蓝上衣的女人，带一只硬提袋，说上午留的两盒，拿去同妹妹吃，今天不要再给纸袋。葛应着，从柜内取出合好的盒，指给她认哪盒甜、哪盒咸。女人打开提袋，底下躺着一把伞，盒子放不平，自己先把伞取出来。

她想将伞夹在腋下，伞柄又勾住袋带。葛没把盒递过去等她三只手，先放回干处。女人解了两回，终于把带子抽开，笑说就怕下雨才带，一下午没有云，倒先淋了自己一身汗。

葛也笑，等她把袋底撑平才放进去。第二盒下去，提手短，女人指头伸不到一起，葛想起再拿一只大袋，对方却将第一盒转了个方向，两盒并在底下，提手便能合。她付钱，自己试提一下，走时伞仍夹在腋下，没有留给店里。

葛送她到门边，回头看那两只原来占着的盒位，伸手把一只空盘往里推。日用盒就在柜内，她取一只便能拿到，不再搬凳。纸袋也在手边，只是上头一只袋口合得太紧，她用指腹捻开，试过能张口，又放回去。

“昨天等人家站到跟前，我才找袋。”她说，“今天倒先备着，人家又不用。”

沈将嘴里那口咽下，答下一个或许用。说完觉得自己像急着替她找补，便低头把袋折开，露出还没吃的半块。葛没说白折，拿布擦干刚才放盒的地方，手在边沿停一停，忽然问沈觉不觉得她头发太长。

沈抬眼。葛将夹子一抽，头发落到耳边，原来夹着的地方翘出一弯。她朝那弯抹两下，越抹越显，自己先烦了，重新夹起来。

“昨天说烫头，我说完一直想。”她道，“今早照镜，觉得也未必非得烫。先把这后头剪短一点。”

沈原想说现在也好看，话到嘴边，葛却已转身，用两只手比给她看领口上那一截。布围裙的带子压过头发，几根贴在颈上，她将带子解开，问的是剪到这里还绑不绑得住。

“我没替人剪过。”沈说，“我自己的，有时候也先剪掉才知道。”

“那你跟我差不多。”

她将围裙挂到柜侧，饭碗终于端到桌上。小碟拿开，里头是饭拌着昨晚的菜，菜汁沿碗边渗到下面。葛拨开上头一口，停住，拿回厨房。沈听见锅盖碰响，以为她又做下一盘，过一阵，先闻到一点油香。

“我热饭。”葛隔着柜说，“别看我半天没回来，以为又去揉什么。”

锅铲刮过两下，忽然一声轻响，葛说糟了。沈站起，到柜外才看见她把饭下早了，锅底还有水，油溅到灶边。葛将火调小，退半步，等那阵响过，才用铲把结住的饭团压开。

沈问要不要递个盘，葛指旁边干净的。她拿过去，停在柜外递，没挤到两盆东西之间。盘接到葛手里，沈便回来坐着，自己那杯水已经不热。她将剩下的糕翻个面，里头一股芋头气散出来，才发现刚才下意识站起来时，咬着的半口也跟着在嘴里等。

葛炒饭出来，多了一个蛋。蛋只碎在一边，另一边的饭团还没全开，她自己看着说火太急，拿勺先压最硬的那块。沈问昨天那碗后来吃完没有，她说只吃了几口，晚上要倒时还舍不得，端在手里，想自己早上留它是为了什么。

“那锅边我还挑了最好的一块。”葛低头尝饭，“专门留的，最后专门倒。”

沈没劝她今天多吃，只将自己空出的桌面让近一点。葛的碗放稳，勺碰到碗边，头几口吃得很快。外头卷门拉动一阵，她朝门口望，手里的勺却没放下，听见是隔壁，才又低头。

沈的两块糕够了大半，剩一点，她本想装起来带走。葛说那一口放到下午，硬了还得找水，沈想想，又坐回来吃掉。她们隔桌各吃自己的，没有另开一壶茶，风扇慢慢转过来，吹到葛碗里的蛋，饭香比刚出锅时淡，却还热着。

一点半多，葛把碗往前推，终于空了。她拿水涮过勺，仍坐了一会儿，脚从鞋后跟里退出来一点，没叫沈瞧，只问河街口那家理发的下午开不开。沈答自己经过见过门开，不知道今天，葛便拿手机找号码。

她翻错一个名字，打出去才听见那头问订几份。葛忙说不是不是，自己手快，挂了电话，拿屏幕给沈看，两个名字头一个字相同，后头一个是理发，一个竟是送米。沈笑得杯子没敢端，叫她真过去，别让人顺手给头上扛一袋。

号码重找到了。葛先问现在能剪不能，听一阵，朝沈伸出两根手指，又收回，自己说两点到，只洗剪，不烫。那头似乎又问，她答不要先给自己算上烫头，去了看。电话停后，她摸一下后颈，手上沾一小粒饭，低头看见，脸先红了。

“还当剪完能清爽一点。现在这样，去了人家先叫我洗手。”

她去水槽洗手，顺便将碗洗了，回头又看柜里。沈问是不是还得做一盘。葛说原来想做，下午若还有人要，现有的也许不够；说着已把盆从下面抽出，盆口到手边，又放回去。

“那一盘动起来，就不止洗个头的工夫。”她拿布擦盆边，“今天先不添了。”

沈听出那句里还有舍不得。葛没拿今天卖过的来抵，望着柜里剩下的几块，说少做未必就少卖，也可能真少一份，自己现在不知道。她拿纸写下午两点至三点暂歇，写完盯着那个三字，问洗剪一个钟头够不够。

“你还得走回来。”沈说。

葛把笔拿起，又放下，说刚才电话里问过，前头只有一个人，自己早点去。她不肯将后头一下午都写空，也不想叫别人守着，于是在下面补剪发外出。几个字比上面的时间小，贴上门后远看，倒先看见外出两个字。

她出去看了一眼，手里仍捏着胶带，站到太阳里眯眼。沈在屋内喝完水，忽然觉得她站在自己门外，有一点像不认识这间铺。葛抬手把纸贴高些，回来将胶带压在抽屉角，问沈往哪头走。

沈原来想回家，再开一遍工作说明。上午已看过，后来起来煮面，没接什么新活；眼下回去，大约先会将那个二百四十盯上一阵。她没有告诉葛自己究竟想将它改成什么数，只说今天下午还没定。

“那陪我走到街口？”葛问，“不必等剪完。我怕自己走到门边，又想起一盆东西。”

沈答可以。葛这才去收柜上晾的两只盘，盘底有水，她一只只擦过，没将湿的套到干的上。沈收好自己吃糕的袋，见里面留一点碎屑，用手指拢起来吃了。她想这条路走过那么多回，今日倒要等一个人在自家门里出来。

一点五十，葛把围裙挂好，取一件薄衫穿上，纽扣还没系，先摸手机。沈已经走到门外，听见里头又响一声，回头看，葛只是将饭碗重新摆正，没拿那只盆。她出来时，手里除了小包还握着店钥匙，钥匙齿从指缝露着。

“我头发还没剪，你倒先替我守在门口了。”她说。

“你再不出来，我就先往阴处站。”

葛笑着把门拉好，试过锁，隔着玻璃又望一眼柜台。原凹处的木椅在里面，没替她将这一小时的生意留住，也没替谁许下一早的空位。她把钥匙放进自己包里，转身到沈旁边，先问那家门前是不是有一段台阶。

沈说有两级，自己记得。两人走到街角，她才看见葛左脚那只鞋的后带扭着，提醒一声。葛停下来，扶着墙把它翻正，说原来不是自己忽然长了块骨头。沈忍不住笑，等她站好，两个人再往前走，谁也没有折回去把那顿已经吃完的饭重热一遍。
