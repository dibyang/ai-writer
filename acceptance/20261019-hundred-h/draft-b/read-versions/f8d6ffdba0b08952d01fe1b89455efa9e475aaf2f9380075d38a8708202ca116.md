# 第一百零九章 两百四十买到什么

第六十七日九点半，沈禾将昨天画得像面的鞋挪开，打开报价例子的空白页。早饭吃过了，水也在手边，她却先在纸上写了一个二百四十，再给它围上框。

框画完，倒像这笔钱已经有地方收。她把边上留给名字的一格擦掉，写自用示例。用的仍是前天那段车声盖住后半句的试声，自己念的粥，不劳哪位客户再给她一份东西。

一小时，二百四十，交带位置的听辨意见。沈将这一行打好，又在后面添可修改一次。看起来齐全得很快，她甚至想将字放大些，像这样便能把前天没有做完的事补上。

她按说明从头走了一次。听到车过来，声音仍薄了一截，处理过的那份也没使那几个字回来。沈将两份轮着放，自己早知道下头是什么话，耳朵便老想替它添。她索性停在车声过后，把听不清的地方留空，只写听到的情况。

意见很短，短得放在二百四十旁边有点寒酸。她给每处添原因，添到第三行，才发觉自己正在解释为什么不能再多给。鼠标停住，她将那两句挪到旁边，重新写若手里有原文件，先取原文件再看。眼前这段本就是自录原件，她又将若字圈出来，换成这个例子没有另一份更完整的原声。

九点五十八，纸上已有几道箭头。沈把它们顺到一处，拿手机只看说明，不开电脑里的工程。报价能看见，交付的意见却得另找，点开以后，只露出第一行，下面还压着文件名字。她往上划过头，那二百四十又回来了。

她小声说：“钱倒很容易找到。”

窗外无人答她。沈笑一下，将意见的开头放到价钱下面，留一小段真能读到的例子。她仍想写一小时处理完，手打到完字，想起自己单是把名字和意见摆到一起，已经用了半个多钟头，便退回去，只留一小时核听与整理意见。

十点半提醒响时，她正将最后一行缩短。沈存好，起身把晾干的衣服取进来。袖子穿过衣架时翻了面，她拉两下才顺，原来以为做个报价只缺一个数，如今数写下了，还剩许多自己看着顺眼、别人未必接得上的地方。

午饭后，她给顾遥发消息，说自己做了一份工作说明，想请他拿手机找一找，花十分钟，只看收到什么，不问这价该收多少。顾过了一阵才回，两点左右来，今天不借监听位，他台上还有东西。

沈答好，把说明和那一小段自录另存到手机。新本人页没取，窄夹仍在架上。她出门前换掉领口磨脖子的那件衫，换完才发现两件都朝同一边歪，只好重新理肩缝。

两点零三，修理店门开着。顾坐在台后，正给一只电扇装外罩，脚边螺丝盒的盖没合，沈走近便先停住。他抬头叫她从另一侧过，说那颗螺丝掉下去，到现在还没找着，别替自己踢到更远。

她低头找，见一粒亮的，指给他。顾伸手夹起来，是昨天剪下的线头。沈说那它还挺会装，顾答真螺丝从来没这样显眼，叫她先坐，自己装好这半圈。

外罩一边扣住，另一边却翘着。顾想让她扶一下，手伸到半途，先将电源插头拿到台面，才指给她按哪里。沈只压住边，他从下头对，扣子没进，倒将她指甲夹痛一点。她啊一声，立刻松手，顾说别硬压，又取下来转了个方向。

“我还以为是自己没力。”她说。

“力大就给我多修一项。”

重新对好，那一下轻得她几乎没觉出来。顾让她放手，外圈稳着，自己把电扇移到一旁。沈看他将台面腾出一点，原想说用不着这么麻烦，话还没出，又觉得这十分钟若一直站在零件旁，自己大概要连想问什么都忘了。她坐下，把包抱在腿上，接受他真正腾出的这一小块。

沈把手机放到旁边没有零件的窄台上，没有将电脑拿出来。顾洗过手，擦干，接过她的手机，第一眼便问：“两百四十买到什么？”

她想指下面，他把手机转开一点：“你别指。我试试。”

顾先点那份意见，看见车声盖住后半句，抬头问声音在哪儿。沈说在上一个页面，话出口便闭住。他退回去，找到文件，听过一遍，店外正有摩托经过，里外车声碰到一处，他将音量按高。

“还是没听着。”

“里头就是没听清。”沈说。

“我说你前头说碗什么。”

“粥。”

“听成轴了。还想你早上已经开工。”

沈笑出声，顾却没跟着往下听，先将手机放回台上，说这个地方放声音不大合适。她从包里取出自己带的一副耳塞，线绕在一起，解开用了片刻，顾等着，拿布将扇罩边一小块灰擦掉。

戴上以后，他从头听，这回听见粥，也听见后面实在被盖住。顾按她写的位置重放一次，摘下一边问：“你这里说能改一次，是再给我一份声音？”

“改意见。比如位置记错，或你看不明白。”

“那我说没听清，你是不是还得改？”

沈张嘴，没立刻接。她原来很熟修改一次这几个字，可落到眼前，他同她说的竟不是同一样东西。顾把耳塞取下，绕得松松的，没有还给她，自己又翻那几行字。

“我找得到你说的地方。”他道，“可找到以后呢？我花了钱，把这一句再听一遍，还是不知道拿它干什么。”

沈的脸热起来。她觉得他把自己的活说得太轻，尤其那句再听一遍，像她坐着两个钟头只替人按了播放。她拿回手机，把意见拉到下头，想让他看自己不是只记一个秒数。

顾瞧见她动作，先说：“我没说你不该收。我修这个，也有人说不过拧两颗。”

他朝扇罩抬了抬下巴，台上还有没合的边。沈将手慢下来。她刚才真准备从试声开始讲，讲自己怎么听、怎么试，又怎么退回去，一讲，十分钟便只够她替自己作证。

“你想拿它做什么？”她问。

“我要发出去，当然想知道能不能发。要留自己听，我不一定在乎那半句。”

“可我不知道你发给谁。”

“你这上面也没问我。”

这句话叫她比刚才更难受。她明明写了，手指已经按到那一行，想将手机朝他转。顾却在纸边找一枚垫圈，翻过布角，东西粘在下面，他低头取出来，没看她伸过去的屏幕。

沈举着等了一阵，才将手机放低。自己确实可以把那行找出来，像在争一件有没有做过的事；可方才让他独自找的人也是自己。他若得等她指过去，今天跑来便只剩听一句你写了。

“放得太后了。”她说。

顾应一声，拿手里的垫圈比过轴端，又搁回小碟。他没有赶着替她把不自在也改好。沈将那行圈出来，心里仍觉得自己不至于差到要从头写起，便在圈外又记，前面交付那几行留。

沈低头看。她问了文件和版本，问了何时要，对方到底要拿去做什么，竟藏在一大段后头，写得像有空才答。顾也没继续挑，只说自己若真来问，大概先把录音发来，问救不救得活，不会先想到分清听意见还是改声音。

门口来了个戴帽子的男人，手里抱着电饭锅内胆，问顾是不是能配盖。顾转头看了一眼，说盖不是照内胆口径就能配，锅身在哪里。男人说锅沉，自己只带最要紧的这一只。

顾笑不出来，拿布在台边铺开，让他先放，说得问型号。男人把内胆往地上一搁，掏手机翻家里的照片，翻到一张饭桌合影，锅只在最角上露出半边。沈侧过身，给他空出站的地方。

“这张我也看不出。”顾说，“你回去看底下那张贴纸，拍清，再来问。今天别先买一个回去硬扣。”

那人说白跑了，手伸向内胆，又放下，问先放这儿下午来取行不行。顾望望自己脚边，答今天不收，拿回去才好同锅身放一起，别配到最后连哪只锅都忘了。

沈坐在旁边听，原来要补的那句能给修改建议，忽然也不大敢写。听辨意见能让人看见问题，不一定能让他手里的材料变成可用，更不一定有一条照着做就能好的路。她若为了让二百四十看着值，许下那条路，回头仍得自己做。

男人抱走内胆，门帘掀起一阵风。顾回来问刚才到哪儿，沈说到自己没问人要拿它做什么。他看一眼钟，已经两点十六，便把耳塞递给她，说今天先到这儿，扇子三点前有人来拿，自己还得通电试过。

“你别为了说得好卖，改成我讲的那样。”他又说，“我就是会那样问。你得另答。”

沈收线，心里还想听他补一句这样已经比原来好了。他却开始合罩，卡扣错开一处，重新按回去，顾忙着看边，没抬头。她将手机放进包，只说谢谢，让他先干。

走出门，街上热得鞋面都发烫。沈在屋檐下站住，把刚才几句记到自己的纸上，写顾想要能发，写到一半停下，将想要改成举例说若要发。她并没有收到他的一段待修录音。

回家，她先将耳塞线重新松开，刚才随手绕紧，线圈压住耳塞孔。她捋过一遍，摆到桌边，才开电脑。改意见一次换成可就这份意见问一轮，另外在前面加用途。还想加不能保证的地方，一连打出三条，她看着烦，自己也像准备跟人吵架。

沈全选那三条，没删，先挪到草稿。她将听辨例子改成对着声音能看的几行：哪一段、听到了什么、这次仍缺什么；若对方要公开用，自己先问用途和现有原件，再答能否处理。不能在这份自录中恢复的那半句，就留在缺的那里。

二百四十仍是自用的一小时例价，下面写这是听辨意见的例子，实际文件和要做的事看过再议。她没有把顾刚才那句我不一定在乎，改写成有人已觉得值得买。

接着她只留一份原试声和相应意见给人先看，前天处理过的声音另放到后头，有名字也写明缺点。自己点开，先听，再看意见，找得回去；只是往返两个页面仍有点笨。沈将对应名字挪到每段开头，宁肯多占两行。

她原来想将那一下咳也剪掉。耳机里听见自己咳，总像给人看的桌上留着没擦的水印。鼠标选住以后，沈又听前后，粥那句跟着少了开头，整段顿成不自然的两截。她退回去，不再为这份说明另外造一遍毫无毛病的自己。那声咳留着，意见只说它在什么位置，是否要动得另看用途。晚一点她重新用手机打开，先翻到的终于是给人的那几行，价在旁边，也没有藏。

快四点，桌边那张鞋画被水杯压了一角。她拿开杯，发觉自己方才又把说明写到饭桌中央，起身去将午饭碗收净。这一版没有发给新客户，顾也没有替她定价。若真有人看过便走，今天补的这些未必留得住人。

她想到这儿，还是有点慌，想将价换低些，好让人先来。手却没往那个数落，倒将顾没看见的最后几行读了一次。再改低，交什么仍得回答；今天先把这个答得不像一口空话。

傍晚她下楼买两只番茄，挑了许久，回家切开，一只里头仍青。沈尝一点，酸得眯眼，想起昨晚画的鞋，连带着笑出来。她把那一半切薄些同蛋下锅，没有急着拿手机问谁有办法。

吃过饭，说明关在电脑里，窄夹还在原架。她本来想再做个更像样的封面，坐下却先打了个哈欠。明天早上不想再端着冷饭找文件，她翻到日历空处，只记去葛铺吃早饭，电脑留家。写完，沈去厨房给锅添水，酸番茄粘住的那一圈，得趁现在泡上。
