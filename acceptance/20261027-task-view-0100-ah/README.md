## 失败与纠正记录

早期定向测试纠正了测试使用的阶段名、恢复参数及授权凭据，未绕过产品保护。完整回归首次通过后，实际 CLI 演练继续发现了脚本假设问题，保留了所有轮次：

1. 完全相同的已登记输入是幂等成功，原脚本错误地期待拒绝；最终样本分别验证幂等成功和修改旧输入后的拒绝。
2. 重试脚本复用 operation_id，产品正确拒绝；后续使用独立标签和操作 ID。
3. 回放模板入口需要原修订令牌；据此补充产品视图的明确参数提示和手册说明。
4. 脚本误把登记结果当作登记输入读取；纠正文件来源。
5. 正文必须先改，再生成绑定正文哈希的回放模板；最终脚本遵循这一顺序，并提交完整的合成复核报告。
