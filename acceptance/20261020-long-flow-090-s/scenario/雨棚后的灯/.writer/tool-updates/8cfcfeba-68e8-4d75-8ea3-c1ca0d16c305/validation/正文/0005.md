# 第五章 帘上那一针

第五天下午，许舟比约的时间早来了一刻钟。林照到店时，他已经站在柜台边，装幕布的布袋放在两脚之间，何岚没有动，先等林照过来。

“有一截，看起来还是皱。”许舟说。

他先把那一截指出来，才解开袋口。林照托住折好的中间，何岚从另一头接过去，两人把布展开在后间桌上。补过的线颜色不大一样，许舟缝得慢，有几针明显绕开了快散的旧线，留下一块不齐整的小弯。

“我拆过一回。再拆，边上又多针眼。”

何岚用指腹顺着旧边摸了一遍，叫他把布提起来。林照和许舟站到桌子两侧，缓缓抬高，何岚后退半步，看那块小弯垂下去是什么样。

“挂起来不就这样？你不说，我还得找。”

许舟没有马上笑。他把靠自己这边往外移了一点，让那道缝迎着光，又给她看了一次。何岚这回也没说看不见，只点头：“看见了。留着，别再扯。”

两人把布放低，何岚接住靠近桌边的折角。许舟松开手，先往旁边退，给她站稳的地方。

“幕布交还给你了。”他说，“里面没有留针，我装之前数过。”

何岚把布收到自己怀里，抱到干净的凳面上。“我收着。今晚还不挂，明天你们来，再一起动。”

林照将空布袋叠好，放在她旁边。许舟带来的针线盒仍留在他自己的小袋里，何岚从抽屉取的夹子也留在抽屉，没有混进去。三个人终于能在后间那张桌边坐一会儿，林照便把自己的本子拿了出来。

“昨天那三个格子，还没讲给你们听。”

他翻到便笺那一页，讲周伯在原纸前认出的“校门”“雨棚”“渡口”，也讲那是曾经打算去的地方，并不是三场都办成的勾记。何岚靠过来看了一眼便笺，许舟将凳子挪近，指着林照划掉的那个小勾问为什么划。

“我当时记岔了，以为是做完再打勾。周伯说不是，就划了。”

“所以这个是你画的？”

“嗯。旧纸没动。你们昨天没在，这些是我现在转给你们听的。”

何岚把本子推回去，说她认得渡口以前有个雨棚，但周伯说的第二处到底是哪一个，她没有听过，不能替他定。林照记住了，没有把两个棚并成一处。许舟问以后还去不去校门看，林照说等这次做完，再问周伯愿不愿意带路。

他没有把老人说起失约时的神情也讲出来。眼前两个人只需要知道这张纸不是一份已经完成的清单；其余的话，可以留到周伯自己愿意说的时候。

何岚回柜台卖东西，许舟抱起空出来的凳子问明天能不能再搬四把来。他刚给家里打过电话，家里答应借四把折凳。加上隔壁已借的两张、店里一张，再向周伯借一把稳的，就够原先说的八个位置。

林照应下去问周伯，自己回住处取了出差时带的小投影机。机器从箱子里拿出来时，袋底还压着一张外地住店的单子。他把单子抽走，将机器抱到店里，先问何岚哪一块柜面晚上能放，才解开收好的线。

“旧片还没借。”许舟提醒他。

“先用我们自己的，试一晚。不拿周伯没答应的东西来凑。”

林照提议拍一点眼前的事。许舟拿手机，先问何岚能不能拍她收货，她说别叫她对着镜头说话，干活倒随他拍。许舟就站到不会挡过道的墙边，拍她把价签朝外转，再拍自己和林照试着展开幕布。拍到自己的歪针脚时，他停了片刻，终于没将镜头移走。

傍晚，林照把刚拍的几段接着放出来，只给他们三个人试看。画面不长，先是何岚半个肩膀，再是从门口抬过的一箱水；屏幕上有人叫“等一下”，许舟在旁边跟着笑，说那时自己没看见门槛。

林照将机器关掉，与何岚商量明晚收好货以后，只放这一小段，八把凳子坐满就不再加，不让她另停三天的生意。何岚答应了一晚，叫他们七点半把架子搬进来，别占着门口等她收。

许舟将手机收回口袋，提走自己的针线袋。幕布仍由何岚收在干净凳面上，空布袋盖着边角。林照去周伯家问那把凳子以前，先把还放在柜台上的杯子端回后间，让何岚有地方装下一位客人的糖。
