# 阅读行数口径

FastCtx编号及早期模型报告按文本以换行切分后的字段计数，含文件末尾换行生成的最后一个空字段。例如10—15返回编号范围累计1015。`verify-native-read.mjs`的`total_lines`去掉这个无内容EOF空字段，因此同六章计1009；每个完整文件差1，不是漏读。

该校验保留每个真实read调用的first/last/lines和matching_current_lines。10—15的原生D日志已证明所有当前正文行逐字匹配；额外的末尾空字段仍在原始工具返回中可见。行数不作为文学质量或语义理解证明，版本以SHA及真实读取窗口为准，不覆盖旧报告的原统计口径。
