# 第八十九章 这回不留下一次

第五十五日午后，沈禾刚擦完灶边，邱阿兰打来电话。她说想把纸的事再讲一句，若沈两点半能来，自己那会儿刚好在铺；不是叫她带一大袋来比字。沈答能，将抹布拧净，挂到厨房门内，没有先去干架翻哪一版。

两点半，机板前坐着一个穿灰围裙的年轻女人，左手攥住围裙口袋，右手往外掏零钱。两枚硬币从掌边滑下去，一枚落在脚旁，另一枚滚到门槛里。沈蹲下替她捡起脚边的，门槛那枚由她自己用鞋尖慢慢拨回，没让人一直钻到桌下找。

“又掉。今天替老板数零钱，数得好好的，我一站起来，他说少五毛。”女人将钱放进自己衣服内袋，“走到门口，从鞋里倒出来了。”

邱把围裙翻过来，袋底裂了一小段，旁边有两针颜色很深，扯得布皱。女人先认是自己缝的，没缝到一周，手插进去拿钥匙又给勾开。她问能不能直接将袋口缝小，自己少放东西。

“里头破着，口再小也往下掉。”邱说，“你先把里面真掏完。”

女人摸了几回，又摸出一只扁掉的发圈，最后才从折角里找出那把小钥匙。她看着笑，说难怪方才口袋不肯翻，自己还当邱拉错边。邱将围裙取下，让她坐到墙边，拿一块颜色近的布垫在破处下面，没有从正面盖一只大方块。

“八元，补这儿，旧的两针拆了重走。你愿意我就做。”

女人答愿意，说明晚还要穿，邱说这会儿就能收。问名字，她说冯小满，在街口便利店上夜班，今日洗过另一条，晾到现在还湿，自己没法等它忽然干。说完又笑，问是不是说名字就行，不用把店什么时候关也报一遍。

“对。你坐着等这几针。”邱也笑。

沈将捡到那枚钱放到小满手里。小满道谢，见她一直站着，往自己凳旁挪，却险些将脚边装湿伞套的袋踢倒，手忙脚乱去扶。沈说不用挤，自己站这一会儿，来得正好让腿动动。她便不再硬让，低头将硬币全收进有拉链的衣袋。

机针走过补布，邱停下来，让小满把手伸进去试。她这次只伸两根指头，邱叫照自己平时拿钥匙的样子，真勾住哪里才知道。小满笑着说自己怕再扯坏，还是把手放全，指尖沿袋底走了一圈，里面没有刚才那根长线。

她当场付八元，套回围裙，先往里放钥匙，又取出，改收自己衣袋。邱看她这一来一回，问是不是不信自己缝的，她答信，今天先让它歇半日，自己也想歇。两个人笑过，邱将剪下的线头扫到桶里，小满拿好自己的包，往街口走了。

等灰围裙从门外转过去，邱才擦净手，坐到刚空下的凳上。沈原以为她要起身开下柜，便往旁让，邱却只将柜门前一只取衣袋挂高，没有摸里面的透明盒。

她把右边套袖脱下来，松紧口朝外翻，里面补过的那块布露出一角。沈以前摸过，知道不是将自己的衣袖卷进去，今天再看，外面浅色那层已经沾了新的线油。邱取另一只干的套上，左边却不换，说那只早上才洗净，别两边一齐丢水里，等晚上又找不到能用的。

沈伸手接脱下的那只，想顺手拿到后头，邱叫先搁盆边，里面没有放水，不能把它同客户刚试过的衣服压在一起。她照放，回来时凳子终于真正空出一面，便坐下，膝上的本子仍合着。

邱搓了搓手腕，套袖刚勒过的一圈有浅印。沈问紧不紧，她说新洗那只紧一点，戴一阵就松，不叫沈又去线匣替她找带。铺里机子停着，街口卖水果的人喊了两声，她端水喝完，才转过来看沈。

“你那几份，往后不要再排我的了。”她说。

沈没有立刻打开本子。前几次听先不用，她总还在心里给以后留着一个日期，今天那句话没带先字。她问是自己的送话说明，不论后来用过的两张、大字四张，还是电脑里准备再印的。

“对。不是又改哪行。就不接着给人看、给人念了。”邱说，“别等我这两袋衣服赶完，再来问是不是忙好了。”

沈望向机板，刚才那块补布还剩一个小角，没有被缝进围裙。她忽然有点想说将来未必还办，也不必今天把以后全断掉。这句话听着很省事，仿佛不办，便能让自己暂时不用承认舍不得。

她把话咽回去，手放到本子封面：“我原来想，屋子以后开了，也许还能有一回。我没有答别人，但我自己一直这么想。”

“那你今天知道我不想了。”

邱说得平，没有拿手里的活替这句话挡住。沈点头，心里那一下空没有立刻过去。她记得最初把字排大，送来这里，邱扶着第二张问掉开怎么办；自己那时急着把纸做成能用的东西，如今纸确实做过、用过，对方却可以不用找出新的错。

“柜里的原两张还留你这里？”她问。

“留。拿回来不是叫你毁了。第二张原来没名字，也别替我补。”邱朝柜前看一眼，“我说的是往后不讲，不是那天我没去送。”

沈答不会去改那件已经有纸、有她亲认回记的事，也不会将不讲写成她收回当年的话。自己保存的工作记录和后面给人看的稿分开；旧稿留作来路，不能拿一张留着便说还有机会用。

“也别只把名字拿掉，接着讲我跑那一趟。”邱忽然补一句，“你们一听就知道是谁，没名字也没用。”

这句话让沈已经落到本子上的笔停了一下。她原先还想，若只留送到门口的过程，变成无名的一段是不是能省去以后再问；邱没有等她做出新一版，先把这条路也说了。她将本子转正，写下不再用这几份工作说明，也不拆掉名字换成匿名接用。

邱看的是这行新记，没有重读任何旧页。她问小何那里怎么办，沈说自己明早找她，清楚说这次同先前暂停有什么不同，不给她一张纸去猜。邱答告诉她就行，不叫何为了听一句不讲又走来这里，自己也不需要对每个人再坐一次。

“做到了再给我一声。别现在就答都讲过了。”

沈应下。她看墙上钟，两点五十多，自己没有等到一份可继续用的新稿，邱也没为叫她来这二十来分钟道歉。门外有人问能不能补拉链，邱站起来去看，沈将自己的本子收好，挪开门边位置。

那人提来的包拉链齿掉了两颗，邱拿指腹试了一下，先问要不要保原来的头。沈没在旁替他选，朝邱告辞。走到街角，她才觉得方才那声好答得有点轻，像原先每次听见一句限制都先答下，后头再慢慢找可用的缝。

她没发消息向何概括成邱最近忙。回家开门，先把包放远，洗净手，将干架那三袋按原来的样子一袋一袋取到桌上。旧使用两页仍两张，大字四页仍四张，标过的试样上那些挤过的小字也在；原缺名两张不在家，不能为找齐一摞，又开打印机补一份。

她没有在原文上涂字，每个袋外另夹一条新纸，写第五十五日邱本人撤回后续展示朗读，不改原纸、不匿名接用。旧停用字留着，新说明没有盖掉它。试样本来不能当成实用稿，也加同一限制，不让带着改痕便成了另一种可拿去讲的资料。

三袋各合回原位，罗那三页没有开。沈坐到电脑前，将本机旧说明稿各版找到，在同一个旧稿夹旁另存一份本日退出说明，指到这些文件名。文件内容不改成没发生过，当前也没有另做一份去掉邱名的新稿。她看着屏幕，想起移动盘里还有以前自存的备份，手往线袋去了一下，又收回。

今天下午已快四点，她不想只贴一个说明就把盘上几份也算完。那一项另记未查，明早同告何放在一起；母亲原硬盘不动，那里面的原工作副本也不该为一份后来的朗读许可改名删句。

桌面空下来以后，沈将未喝的水端回厨房。午饭那只碗底还有一点油，她添洗涤液，抹两回才去净。窗外机车经过，镜片一样的亮光从水面滑过去。她把碗放稳，没有给邱回都好了，手机留在桌上，那句做到了再给一声，要等真做完剩下的再说。
