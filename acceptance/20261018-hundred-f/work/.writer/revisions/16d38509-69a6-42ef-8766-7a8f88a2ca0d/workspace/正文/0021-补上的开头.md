# 第二十一章 补上的开头

沈禾在河街吃过午饭，沿街走二十一分钟回到顾遥店里时，还不到一点。顾遥正在给电饭锅的主人回电话，她便坐在门边，没把电脑摆上柜台。汤里胡椒放多了，嘴里一直热，她慢慢喝完自己带的水，才发现这几天很少有这样等着的时候。

顾遥放下电话，问她下午还去不去旧站。

“先去河街见一个人，四点以后。晚上再回站对单。”

“那你别一听见什么，又把机器丢给我。”

她答应，去隔间看了原箱。新封口没有起，旧标签仍压在袋侧。她把顶架边沿那只快掉下来的空纸盒往里推好，出来等到两点，才将背包放上自己的凳子。

顾遥留的半小时已经写在台历上。他拔开旁边烧水壶的插头，给电脑和接口空出位置。沈禾先用店里的试机带核走带和转录，听过电脑里收到的那段，又清洁磁头与带路，等干燥。原带取出时，顾遥移来台灯，两人照过壳口和可见带面，没有散带或新碎屑。

“还是这台，没换。”他说。

她点头。兼容不等于这回便不会出问题，耳机仍要有人守。顾遥坐到能看见卷轴的那侧，沈禾把起初记的停点放在手边，装带，在机内倒回这一面的起首，停稳再播放。电脑另开一份转录，没有往昨天的文件里接。

钟声过来时，她先看了一眼顾遥。他看着机器，没有说话。那声“麻烦”后面的沙响还在，“给”仍像隔着一层东西，不能因为已听见后半句，就把前面的空处也顺口念出来。她把原先留下的问号照旧留着。

声音跨过第一次停下的位置，男声接出了昨天那句捎话。她让它再走一段，连试话筒的“请”一并录下，才按停。三分多钟里没有新摩擦声。取带后看过带面，原带回到原盒和硬袋，纸仍隔在外袋。她在补录旁记下与昨天转录重叠的范围。

“这下头尾都有了。”顾遥说。

“都有转录了。听不清的，还是听不清。”

顾遥摘下耳机，揉揉被压住的耳廓：“你再说一遍，我也不会给你补字。”

她笑了，先保存文件。接着，她把今天重叠的一段和昨天开头轮流放出来。男声停顿、近处两下碰响，以及试读的气音依次经过，没有少掉一截。她没有抹掉其中一份，也没有拼成一份冒充从未停过的录音，只在播放次序里注明重叠处。

顾遥去柜下找绕线带，她叫住他：“还有第一天带来的那段，能听两分钟吗？算在这半小时里。”

他看钟，重新坐下。

“这是我从家里母亲硬盘拷的，原盘还在抽屉。目录叫未送达。我以前一直把这名字往一句话上套。”

这回来，顾遥才把那不到半分钟听全。她先放旧副本，再放原带中试了又停的那个“请”，最后放两遍完整广播。第一遍尾音慢些，第二遍利落，起头也不同；试读前后的轻响和气音，却与旧副本能挨得很近。她在屏幕上将两段起头对齐，放过断口，再退回去交替听，没有拿完整句子的后面填上去。

“像同一个口子截的。”顾遥说。

“我也这样想。可这只够说这一小段。谁截的，为什么单放，还是不知道。”

他望着那个目录名：“你妈存东西，也全按字面？”

沈禾原想说母亲一向细心，忽然想起家里一个写着毛线的盒子，打开却是发票。母亲有自己的收拾办法，她只是很晚才来翻。

“不知道。她没跟我交代过。”

说完，她没有再去改目录名。顾遥把绕线带递给她，让她先收接口，自己起身接客户送来的电扇。沈禾合电脑以前，将补录和昨天两份原始转录另备一份到自己的移动盘，核过能打开。那个被截断的旧副本仍单放着，没有添字。

移动盘里还留着她自己做过的活。有一只文件夹叫不要用，里面的几声雨，后来却用在了别处。她将光标从那一排名字上移开，忽然不大愿意让顾遥看见，仿佛自己也有过这样的随手一放，就没资格再来问母亲。

顾遥正让客户把电扇底下的胶布揭开，对方怕揭坏，他便说留着原样也行，修前先讲。沈禾听见这句，重新打开笔记，在目录名旁添下“命名人及用意不明”。写完她又觉得太硬，像要将自己从中摘出去，便在下面另记了一句：最初是我以为它没送到。顾遥回头问她借过的转接头收了没有，她从桌沿拿起，放回他能找着的抽屉。

两点二十八，她把台面清出来。顾遥给电扇通电，听了两秒便说电容要查；那是另一件正在等他做的事。沈禾抱着电脑站开，等他报完价才付清今天工时。

离四点还有一阵，她没去缝纫铺门前守着。在店外的阴影里，她将口信册照片关掉，换成一页空白笔记。等对方自己说到哪儿，再问自己缺的哪儿。纸上的日期很容易先走进别人的记忆，她已经不想再拿一条看起来通顺的路，省掉真正要走的那段。

顾遥隔着门帘叫她，问明早箱子用不用车。

“现在还答不上。今晚给你准话。”

“七点前。七点我收车。”

她在本子上记下，没说一定搬走。三点三十五，沈禾背包离店，沿河街走了二十一分钟。门边的蓝围裙还挂着，里面传来缝纫机断续的响声。她从门前走过，在街口买了一瓶水，等手机过了四点，才折回去敲门框。
