# 权威规则

1. 权威顺序：本次作者授权和冻结原稿优先；已登记追踪须有正文证据。大纲、卷契约、未来设想均为计划，不是已发生事件。.writer/state.json 只由 CLI 维护。
2. 本阶段原稿有权使用；顺序固定为 fixtures/original/0001.md、0002.md。不得改动输入或冻结副本，不润色正文，不写第三章。
3. 信息边界：第一章读者看到蓝袋照片及左下角五针白线，得知许棠昨晚缝过；饭盒及“棠”字来自许棠的叙述，尚未在现场开盒核验。周叔能听到她说的话，不等于掌握她未说出口的饭盒信息。
4. 许棠报称最后见袋是“六点四十，三路末班车”，下车接电话、手里只拿伞。不得擅自补确切日期、失物入库时间或登记内容。
5. 周叔找到一条登记并伸手拿钥匙；第一章没有开柜、展示袋子、完成核验、交接或领回。蓝袋及饭盒的当前持有人、所在位置、状态均待核。
6. 父亲说过等她下班再吃，后来又说不用等；缘由、身体情况与当前位置未知。不得把猜测写入作者真相。
7. 物证稳定：已见补痕和已说标记不因后续解释逆改。重要物件确有交接才更新 custody，不能凭“拿钥匙”认定已找到物件。
8. 先实读第二章再做反向章纲及登记，导入完成后才恢复正常续写。本阶段断点保留在第二章，未读内容不填摘要、人物变化或线索结论。
9. 每三章需要实际滚动连读并登记覆盖；本阶段仅一章已读，不虚构两章或三章审查记录。机械 check 与登记、导出均不等于作者定稿。
