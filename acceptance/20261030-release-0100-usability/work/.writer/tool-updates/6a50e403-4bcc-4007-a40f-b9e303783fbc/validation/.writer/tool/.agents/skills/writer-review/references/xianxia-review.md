# 仙侠与修仙小说审稿规则


Apply `psychology-readability.md` whenever cultivation, breakthrough, heart demon, oath, tribulation, betrayal, sect pressure, power loss, or dao-heart choice carries the scene. Realm changes must be psychologically and bodily legible, not only named.
Apply `general-review.md` first. Apply this file for 仙侠、修仙、玄幻仙门、宗门斗争、境界升级、灵力体系、飞升、妖魔神仙、法宝丹药、秘境试炼等作品。If the plot is also clue/case-driven, also apply `suspense-review.md`.

## Core Standard

仙侠小说不能只靠设定、境界名和爽点堆叠。读者必须持续关心：主角为什么修、修到哪里、付出什么、和谁的命运相撞。

## Hard Checks

Block or downgrade if:

- 修行体系只有名词，没有规则、限制、代价和可预测性。
- 境界升级只靠机缘硬送，缺少选择、代价、训练、悟性或牺牲。
- 法宝、丹药、血脉、系统、秘境只在需要时突然解决问题。
- 宗门/家族/仙朝权力只像游戏副本，不像会压迫人的社会结构。
- 主角一路碾压，没有失败、误判、道心裂缝或关系代价。
- 反派只负责嫉妒、作恶、送经验，没有利益逻辑或修行逻辑。

## Cultivation System Review

Check:

1. 境界差距是否有清楚后果：寿命、感知、身体、资源、话语权、战力、禁忌。
2. 修炼资源是否稀缺，谁掌握资源，为什么会争。
3. 功法、灵根、血脉、剑意、丹道、符阵等是否有边界。
4. 突破是否改变身体、心理、关系或危险，而不只是数值提高。
5. 道心、因果、誓约、心魔、天劫等是否真正约束人物选择。

## Xianxia Character Rule

主角必须有“道”：不一定高尚，但要有持续驱动她修行的核心问题。

Review:

- 她修仙是为活命、复仇、自由、救人、权力、求真、摆脱命格，还是别的？
- 她的道会不会让她失去某些东西？
- 她的强大是否改变别人对她的恐惧、依赖、利用或背叛？
- 配角是否各有自己的道、债、欲望和隐瞒。

## Power Scene Rule

斗法、突破、试炼、秘境不能只写招式名。

A strong power scene should include:

- objective: why this fight/trial/breakthrough must happen now;
- rule: what technique or realm rule matters;
- cost: spirit power, injury, lifespan, relationship, oath, exposure, debt;
- reversal: one expectation fails;
- consequence: victory changes future risk.

## Ordinary Reader Rule

仙侠名词可以华丽，但关键危险必须通俗：会死、会废、会被夺舍、会欠因果、会被逐出宗门、会暴露身份、会失去资源、会连累师门。 Do not let beautiful terms replace stakes.
