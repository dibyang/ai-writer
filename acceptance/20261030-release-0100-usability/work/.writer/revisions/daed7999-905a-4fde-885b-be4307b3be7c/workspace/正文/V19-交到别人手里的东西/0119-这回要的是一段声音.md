# 第一百一十九章 这回要的是一段声音

第七十三日早上，沈禾把昨晚晾的两块布收下来，一块已经干透，另一块折着的地方还凉。她将那块重新展开，搭回杆上，才去吃锅里的粥。桌上两张椅子仍隔得开，自己一个人坐，手肘倒不用再往电脑旁缩。

九点十二，顾遥来消息，问她今天有没有空剪一段声音。

沈将勺搁在碗沿，先点进对话。昨天发过的三份还在上头，顾新来的这一句就在下面，她险些顺着答修后那版已经有了。随后又读一遍，是他有一段，不是要她再拿粥来试。

“你要剪成什么？”她问。

顾回得慢。她吃掉几口，手机才又亮，说自己录了收音机怎么用，想跟机器一起寄回去，录得乱。他还发来一张相片，收音机横在旧布上，前面两个圆钮，上面一个小开关，提手竖着。

“我说这里这里，后来想，人家光听声，哪知道我指哪。”

沈问有没有同时拍画面。顾说没有，本来想按着讲，开口以后忘了手机只在录声音。她看着那张照片笑，粥沿结起薄薄一层，勺再伸进去，得先将它推开。

她没有先报二百四十，问他原录多长，几点要。顾答两分多，明天中午前给他就行，机器还没装箱。若得重录，今天上午可以，他十点多能腾出一会儿，下午说不准。

“十点二十，我先来听。要改的话，我得问你哪一步怎么做。”沈答。

“行。声音里那个别往里拧，我自己也说错了。你别替我剪成真的。”

沈将这一句读了两遍，回他到时一起看。她喝完粥，去洗碗，水打到勺背，溅湿胸前一小块。昨天洗得那样净的桌子，今早照样有碗印；她拿布擦过，将电脑推到中间，给今天的文件另建一处。

顾还没发原录。空夹里只有一个今天的日期，她看了一阵，没有先放那份自用说明进去。九点五十，她装好电脑和耳机，带本子出门。宽鞋里仍穿薄袜，小趾不再一落地就磨，她到街口才发现走得比前两天快，便放慢些，免得在顾约的时间以前跑去等。

十点二十，店门开着，顾正蹲在一只纸箱边，拿膝头抵住箱沿。他叫她先别跨，自己将地上的塑料带捡起来，卷成一团，塞进箱角。沈从窄处进来，包放在空凳上，顾却抬头说那凳待会儿要用，脚边那把能坐。

她将包换过去。收音机还在相片那块布上，提手已经放下，旁边有只空杯，杯底黏着一圈茶。顾想给她倒水，提起杯看一眼，又搁回去，说等一下，先别喝这只。

“你先把声音给我。”沈说，“我水带了。”

顾坐到台后，从手机里找出原录，发到她的对话。沈存好，屏幕上两分四十三秒。她问里面是否都是他自己讲，顾答是，就早上关着店门录的；机器要寄回外地，收机的人没来过店，自己才想省掉以后电话里隔空找钮的工夫。

她接耳机，从头放。顾的第一句很近，第二句忽然远了，像人往台后退，实际动作她没见，只听见他接着说，先把这个拨过去。随后有一声轻响，短短的广播冒出来，他却边听边讲，把后面半句盖住。

沈没有立即停。录音中顾咳了一声，又从刚才那句重来，这回说的是上面，不是这个。再往下，往里拧刚说完，他便改口，别，往外才对。最后一句很清楚，听完关掉，手机却又录着他在找停止，足足留下一阵擦碰。

两分四十三秒走到头，她将一边耳机摘下。顾指指机器，说是不是中间那声广播太响。沈点头，又问：“往里往外，是站在哪头说？”

顾两指搭上右边的钮，转了一下：“就这样。”

她没有伸手接，先把本子合了一半：“我要是不看你手，你刚才这一下，我还是不知道往哪。”

顾停住，自己也笑：“我一拿着它，就全会了。”

他将机器转到正对她。两个钮在前，上面的开关沿机壳横着走，旁边的小字磨掉一角。顾按着自己说过的做一遍，沈问哪处开、哪处调台、哪处只改大小，听清以后才在本子上分行写。

店外有人叫他。顾应了，手从机器上拿开，没叫沈接着替他试。来人拎着一根黑线，说只要换个头，顾看过两端，问另一端接什么。那人将线一甩，远端撞在柜沿，沈把自己的水瓶移近，给他空出一点地方。

问了几句，那人说还得回去看看，线暂且卷走。顾回来，先伸手取杯，发现茶圈仍在，皱着脸笑，说自己刚才是要去洗这个。沈等他从后面回来，没有让录音在空台上继续放。

水杯终于放定，顾喝一口，指着她本子问，要不要照这个念。沈让他先看看写的是否对，自己只听懂了这些，并不知道收机的人平常怎样用。

他低头读，笔拿到一半，先划掉往外两字，改成朝右，再把机身向她这边推正。那一下没有通电，桌面上只响了一声塑料脚擦过布的轻响。


顾将本子读到末尾，问沈能不能替自己念，反正已经写得顺了。

“你说的时候，我能问。换成我念，哪句弄错了，我还不一定听得出来。”她答。

“你嗓子比我这个好听。”

“你先别替我加一样活。”

顾笑起来，将杯推开，说行，自己念。他重新拉起提手，把手机斜靠在后头，沈叫他先录两句。头一句还近，他一低头看本子，后一句就闷了。沈请他把手机平放到靠嘴的这一侧，又在桌上垫块折布，免得指节一敲，整个台面都跟着响。

“你那手就搁着，不用一直扶它。”她说。

顾松开，第一句才完，手机又朝下歪。他看沈，沈也看他，两人忍不住一起笑。布太厚，原来为了稳，反把底下垫成了一个坡。她展开一层，重新放平，让他试着碰一下桌沿，这次没有倒。

试声放回耳机，近远差不多了。门外的响动仍有，顾说关门又热，沈答不用全关，只先让自己听他在这里讲，不必等一条街都安静。顾将门掩到留一人能进，回来说这要被人看见，还当自己今天不干了。

沈取出笔，看着本子上那几行，忽然觉得该先把钱讲了。她已经陪他重走一遍，若再录完带回去，临走才开口，那时自己多半会先说也没花多久。

“我得录、剪，给你一段声音，不是上回那份听辨意见。”她说，“你今天能把这几步讲全，我下午给初剪。你听完把说错、漏讲的地方凑一回给我，我再换一版，明天中午前交。总共一百六。”

顾没有马上答，先看了眼收音机：“一百六。”

沈应一声。顾说这台本来也没收多少修理费，自己早上还以为把头尾剪一剪，十来分钟。她望着本子，没有拿起笔往下算得更少。

“要是只去头尾，我可以另给你报。里头‘这里’那些还在，你得自己同他再讲。”

顾伸手搓了搓下巴，目光还在那台机器上。沈让他想，电脑没有从包里拿出，耳机也先放到腿上。她心里那一下着急却实在，刚才还肯重录的人，听见价以后，可能就觉得这一趟不必有她。

“我这个录好，以后换一台还能用不？”顾问。

“钮的位置变了就不能照这个发。”

“那我得多寄几台一样的才合算。”

他说得像同机器抱怨，沈想笑，又没笑出来。顾将提手提起，试着往旁边箱子里落，箱口小一点，得斜着才放得下。他没有硬塞，拿出来，放回布上，朝后间看了看。

“这人先前打了两回电话，讲来讲去还在摸那个大钮。我也想少讲几回。”他道，“做吧。你给我写一句总共多少、什么时候拿，我转你一半。”

沈打开手机，将方才答的几件事写在同一条，补上本次一段、用今天本人重录的声音。顾看过，说自己今天下午四点半前找时间听，若店里耽误，先告诉她，不能叫她一直等。她答好，又问改的那一回，若自己剪坏了哪处，当然得自己改，不算他另提要求。顾说这个不用争，先把他那句往里拧换了再说。

八十元到了，沈点开收款，确认是顾这次转来的。她在本子新行写预付八十，余八十，没有把上午约的十点二十写成开工到交付的一小时。

顾拿起手机要开始，沈却说先不用一口气念到底。每一步说完留一点，手也可以真跟着做，若发现本子不对，就停下来改。他问停过以后能不能接，她答能，有句话连着气好听，就整句重说，不必为省那几个字把自己念急。

这一回，他先让收音机正面朝自己，再指出上方的开关。沈坐在侧旁，没碰机器，耳朵听他讲左边的圆钮。他指的是自己的左边，机身也始终朝着他，她这边斜看，倒像另一头。沈在纸角画个小框，记面对正面，不替他改成自己坐着看到的方向。

顾念到调台，习惯性又说看这里，话停住，自己先往后退了一句。他按本子换成右边的圆钮，边转边听，广播从细细的沙声里冒出一点。沈抬手示意这一遍先停，等机器关好，问他这一句能不能不让广播压着讲。

“那怎么叫人知道找到台了？”

“你真找到以后停着，让他先听那个声。下一句再讲。我回去听，看留多长。”

顾答好。再来一遍，电台里正说一串很快的话，他手指仍搭着钮，停了片刻才松。录完关机，他自己也说，刚才好像不用边拧边喊给它听。

到十一点十二，几步才录齐。顾将新录发过来，自己戴一边耳机陪沈听完，发现末尾把开关位置说成了下边，又拿回手机补录整句。沈将两份分别存好，先前两分四十三秒那份也留下，名字标清，没让手机自动编号替她决定哪一份在前。

顾起身开门，门外热气进来。他原本还想让她在这里剪，一看那把待用的凳已被自己压上纸箱，便说回去吧，下午在手机上找。他换了只大些的箱子，还得将箱底垫厚，里面空得会晃。

沈收好东西，看他拿一团旧纸试塞，纸太薄，一压就塌。他朝她摊手，说声音得等你，箱子也没省下我。她笑着答那就各做各的，到了门边才问，今天新录的能不能按说好的给他剪后发回。

“不就是请你做这个。”顾道，“别把我那句一百六也剪进去。”

沈笑着挥一下手机，答没录那句，推开门走出去。背后顾又在同纸箱较劲，胶带拉出长长一声，到了门外才断。


回到家，沈先将电脑放到桌上，包搁在椅边，没有立刻插耳机。路上热，后背一层汗贴着，她换了件干衫，去厨房开冰箱。昨晚那一点米饭在小盒里，够炒一碗，不够再替谁添。

她打了一个蛋，锅里的油刚热就倒下去，蛋铺得太快，边缘一下卷起。沈用铲推开，米饭跟着下，原本结在一起的一团，压了两下还不散。她将火收一点，慢慢拨，让热气从中间起来。昨晚做鱼时一直怕别人等，今天没人坐在桌边，她仍差点拿着那一团就往碗里盛。

饭炒热透，碎蛋裹在粒间，碗端到桌上，她先尝一口，盐淡，又回厨房取辣酱。椅子拉开，脚碰到包带，险些将电脑包拖下来。她俯身提好，挂回椅背，忽然想起顾那把明明说待会儿要用、转头便压上箱子的凳，笑得嘴里那口饭都得慢些咽。

十二点十分吃完，她将小盒也洗净晾着。窗外有推车的声，离这里远，低低一阵。沈看手机，顾没有新消息。她在本子上添本日新录，八十已收那一行就在下头，数字小，却不再是她围好等人走进来的框。

电脑接好，她先把上午收到的三份声音各开一次。最早那份两分四十三，后来完整重录三分十九，最后补的一句十三秒。她从头核过完整重录，顾说左边时，自己在本子画的机身还正对他；说右边时，他的手曾从上面落下来。她记得那只手，没有把记得的动作当声音里也有画面。

新录的开头顾清过嗓，问开始没有，沈在旁边答还没有。他却已经往下念了第一句。两个人的声音夹在一处，她听着笑起来，先在工程里留个记号，没有马上下刀。机器名称他说过两遍，头一遍咬得清，后一遍像赶着把前头漏掉的补齐；哪一遍接下去顺，得放到后一句一起听。

她照现场那几行写出一个短次序，末尾十三秒只补关机的位置，前头没有因此变成另一份整录。写到开关，顾在店里那阵轻响又从耳机出来，她把音量稍收，听见他说拨过去之后，有一小段空。那是他等电台出来，肩膀向前，自己也跟着屏住呼吸的地方。

沈没有将空全剪掉。她在桌前伸手，摸到的是鼠标，动作快；若手里真放着一台陌生机器，听一句便找一个地方，不会像她这样一点就到。她先留着，给它换成不同长度试了两回，长的有点拖，短的又像后一句抢着催人。两份暂存，她摘下耳机，去喝水，让耳朵离开那阵轻轻的沙声。

水杯握在手里，她才觉得上午拎包的肩有点沉。顾说只剪头尾十来分钟，自己听到时很想立刻讲清还有多少事。真带回来，一件件摆开，比在店里争那个十来分钟慢得多。她将椅背上的包取下来，电脑已经不在里头，空包仍占着她半边靠背。

重新坐好，沈打开下午的空格，把初剪写在四点以前，给自己留一点听整遍的时间。她没有在三点那格接着写还能做一单。旁边顾答四点半前听的消息她又看过，存到这一夹，今日几点能回，仍要等那边真的有空。

她原本想将自用说明的入口图拿来，改个名字便发。打开以后，图上仍是原声A、意见A，两份各是什么，讲的是上一次怎么找到车声。这次顾要收到的是一段能放的声音。沈关掉图，在新工程的输出栏里先写初剪收音机，把初剪两个字放到最前面，后面才跟七十三日。

屏幕弹出一个同名提醒，是她刚才试着导过的一小截。沈停下来，将那截移到本次试剪里，另给完整输出留位置。她没删掉它，也没有让只有开头十几秒的一份混进待发栏。

一点多，楼下有人叫卖，尾音拖得很长。沈关了一半窗，将耳机戴稳，重新回到顾第一句。台上的机器没有跟她回来，本子在左，声音在右，她得把这一个下午坐在这里做完。
