# 第一百二十章 把这一句放在前头

一点过后，沈禾从顾遥新录的开头往下剪。先去问开始没有的两句，再接他重念的机名，声音一放，却像有人推着他进门，前一个字刚出来，后一句已经碰上了。

她往回放一点空。顾吸气时有很轻的一声鼻音，平时面对面听并不觉出，单留在这里，倒像他又要清嗓。沈没有把那一口全掐净，只从旁边取回一点，第一句终于能自己站住。

录到中间，顾一时找不着词，用指甲敲过桌面。那两下紧挨着话尾，沈戴着耳机听，响得比他在店里敲时大。她单独压一点，再放回整句，桌声轻了，尾字也瘪下去。她退回原样，另找下刀的位置，最后只减了没碰着人声的那一小截。

那张记着步骤的纸在左手边，左边圆钮管大小，右边圆钮找台，上方开关负责开和关。顾在新录里已经说清正面朝自己，随后却又添了一句现在看我手。沈将它圈出来，回到下一遍，找到不带这句的一段，连着前后听过，才换上去。

她原本以为先把话挑齐便快了。挑齐以后，顾在两个段落之间忽然换了坐姿，声音也跟着高一点。沈调到接近，不追着每一个字拉平；讲开关时那点用力，是他怕人又找错，留下倒比全揉成一个轻重好。

两点多，窗边的水杯见底。沈起身续水，手从杯耳里抽出，指头竟还保持捏鼠标的弯。她伸开，在门边站了一阵，等楼下叫卖声走远，再回来听收音机响起的那段。

广播冒出来以后，顾在等，嘴里没说话。沈上午留下的那份长停顿还在，听着像声文件断了，短的又急。她将人声和广播之间那一下起伏接顺，只留够辨出找着台的片刻。那一点节目话音不必听全，听的人须知道现在放响的是手里的收音机，接下来还有顾要讲的话。

末尾十三秒补句近得多。顾大概对着手机直接说，嘴唇碰出来的气在耳机里有些重，不能照前一段的大小直接贴。沈挪到同一句前头，比较开关两个字，调整以后再从关机那步听。他说的是把上方开关拨回去，声音停了；店门外一声车喇叭留在后面，她剪掉，留一点尾巴，没有连着最后一个去字一刀断。

两分零六秒。她看了一眼长度，摘耳机，用自己的手机从头听，没伸手去翻那张纸。顾仍有一点口音，说圆钮的钮字像短了一截，但前头左右能认，句子也没有因此变成别的。沈不替他另换一个更像播音的人。

三点零七，她发出初剪，只接一句，请你对着这台机器走一遍，漏了或说错的凑一起告诉我。文件名最前面是初剪，后面才是收音机和日子。她又点开刚发出去的这一份，确认不是先前留在试剪里的十几秒，才把手机放下。

等顾回话，沈没再坐着听那两分多。灶边干布有一块还没收，早上展开的湿处如今也干了。她取下来折好，另一块搁在旁边，想了想，没把它们卷成一团塞回去。昨晚换过湿布才端出的那盘鱼，使她今天一看那两块便还记得哪块先用。

手机响时，她正在擦水槽边的水。顾说刚有空，现在听。她回好，没接着问第一句怎样。四点半以前他愿意找时段，如今确实找了，余下的几分钟没有必要先被自己说满。

三点二十三，一条短语音进来。顾那边先有收音机很响的一声，随即低下去。他说自己按初剪从开关开始做，开机时才想起音量方才拧高过，差点连后一句都听不见。

“那个先拧小，得放开前头。我早上顺手就做了，嘴里没讲。”

沈戴回耳机，原录和初剪各听一次。左边圆钮那段在后头，说的已是开机以后怎样调到合适；她若将整段硬拖前去，顾口中的开了以后便会留在那里。她把鼠标放开，问能不能补一整句，从开机以前讲。

顾先回一个好，过片刻又说等一下，门口来人。沈将这处记到纸上，没有在工程里先拼一个字等他。左边那段仍留原位，屏幕上新空出来的一行，等着上午两个人都没说出的那句话。
