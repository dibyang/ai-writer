# Final Arc Live-Cost Fixture

This fixture is an anonymized commercial-safe example derived from a real project trial pattern, not from private story content.

It preserves only reusable structure:

- evidence that can clear one person may endanger living helpers;
- a responsibility position can protect names while preserving future review;
- a final verdict must change the protagonist's professional access or next action.

It must not contain private names, case names, proprietary clues, endings, or source-project artifacts.

node scripts/story-gate.js chapter-batch-metrics examples/final-arc-live-cost/chapter-01.md examples/final-arc-live-cost/chapter-02.md examples/final-arc-live-cost/chapter-03.md
