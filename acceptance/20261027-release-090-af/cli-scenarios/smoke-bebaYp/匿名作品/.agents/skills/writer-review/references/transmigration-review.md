# 穿越、重生与身份错位小说审稿规则


Apply `psychology-readability.md` for first awakening, identity replacement, original-owner pressure, past-life memory shock, system coercion, timeline change, exposure risk, or any scene where the protagonist must convert confusion into survival action.
Apply `general-review.md` first. Apply `psychology-readability.md` for first-entry or identity shock scenes. Apply `dual-world-review.md` when two timelines/worlds both matter.

Use this file for 穿越、重生、魂穿、身穿、书穿、年代穿越、古今穿越、系统、任务者、回到过去、替身身份、重开人生等作品。

## Core Standard

穿越不是金手指本身，而是身份、知识、时代和选择的错位。读者要看见主角如何在不属于她的位置里活下来，并为使用现代/前世知识付出代价。

## Entry and Identity Checks

Check:

1. 主角什么时候意识到错位？是否有身体、环境、语言、衣物、身份、关系的具体落差。
2. 她占据的是谁的位置？原主的债、亲友、仇敌、身份风险是否存在。
3. 她能不能自由承认自己不是原来的人？若不能，为什么。
4. 她的现代知识/前世记忆有什么边界：记不全、用不上、会暴露、会反噬、会被制度限制。
5. 她第一阶段目标是否清楚：活下来、避免暴露、保住身份、找回去、救人、改命、复仇。

## Knowledge Cost Rule

Modern or future knowledge must not become万能钥匙.

Downgrade if:

- 主角一说现代方法，古人/旧时代人物立刻无条件接受。
- 知识不需要材料、技术、制度、资本、人手或时间就能落地。
- 主角凭预知绕开所有痛苦，没有蝴蝶效应。
- 她改变历史/剧情后，世界不反击。

Good use of knowledge creates new problems:身份暴露、利益争夺、伦理困境、技术断层、政治风险、亲密关系不信任、原剧情失效。

## Original Owner / Past Self Rule

If there is an original body owner, past-life self, book plot, or previous timeline, review whether it has moral and emotional weight.

Ask:

- 原主是不是工具人？
- 原主留下的关系和债务是否会追上主角？
- 主角是否尊重或利用原主身份？
- 重生者是否只是复仇机器，还是会重新理解旧关系？

## System / Mission Rule

If there is a system or mission, it must have rules and limits.

Check:

- reward and punishment are clear;
- system cannot solve every crisis conveniently;
- tasks force meaningful choices, not only checklist labor;
- system information can be wrong, partial, delayed, costly, or morally biased;
- protagonist eventually forms agency beyond the system.

## Genre Combination

- 穿越悬疑: also apply `suspense-review.md`; clues cannot be solved only by future knowledge.
- 穿越历史: also apply `historical-review.md`; modern values must collide with period constraints.
- 双时空互证: also apply `dual-world-review.md`; both worlds must change each other.
