# 追踪闭环实现补充

设计中的“稳定语义哈希”在实现中仅指规范化对象键顺序后，对登记摘要和章末事实快照的JSON值计算哈希，保留数组顺序；它不是自然语言语义判断。公开手册使用“追踪哈希/真实登记变化”，不宣称脚本能理解日期或判意见已解决。

实现不接受用户自填追踪哈希。publication额外返回已校验事务的state前后归档引用，tracking模式从这些实际状态与journal恢复目标单元完成后的事实快照；同时核采用时旧单位依赖和当前实际追踪。默认正文模式保持原条件；新模式仍须后续当前有效实读报告verify。

合成前置回归在旧实现2项失败；核心修后2项通过。正式模块共19项通过，含5项新增保护验证；最后将技术手册的JSON字段片段明确为带引号的合法写法，最终全回归须针对这一冻结版本，不能只沿用模块测试代替最终交付。
