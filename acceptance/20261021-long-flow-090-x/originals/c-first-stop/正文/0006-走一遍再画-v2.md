# 第六章 走一遍再画

停航第一天的下午四点，许蓉提着饭盒回到候船室。门前的椅子已经挪开，早晨贴好的那张清单还在库房门旁，检修的人用木条拦住靠河的一段，穿着沾灰的鞋从另一边进出。

老何坐在窗后，眼镜架到额头上，正读一张折小的纸。许蓉认出是他们印的绕行图，纸上多了几道圆珠笔的横线，右边那段已经压出深槽。他见她进来，将纸转过半圈，指给她看药店旁边的箭头。

“上午两个人问我，是不是上这几级台阶就到桥了。”

“上去能到。”

“一个推车的。走到跟前又回来了，问有没有不用抬的路。”

许蓉将饭盒放进柜里，站到窗边看图。纸上的路从药店旁一折，直直连到桥头，小小一块台阶符号挤在店名下面。她知道前面还有一道坡，画图的时候却只想着把桥标清，让人别再到河边等船。

“他后来走哪边？”

“我指了粮油店那头，他说去看看。没见他再回来。”

许蓉把纸拿近，想起前夜戴毛线帽的老人。那张图上原来漏写了“明早”，他以为说的还是当晚，折回来问的也是药店。她后来另取干图添过时间，又让沈禾自己圈过车站，那半个圈还记得，入口这一小段却没再问。

门口的检票同事抱着一摞旧票夹进来，问放哪个柜。许蓉接过去，搁在窗内干的那格，翻出压在最底下的钥匙，让他先别走。她想和老何去药店前后各走一下，回来再把图添清楚，问他能不能看一小会儿窗口。

他先看表，没立刻应。

“最迟五点。我得去接孩子，学校那边不让一直等在门口。”

“我四十前回来，走不到的留着。”

“你们别走到桥那头去了。”

她应着，将这班要用的值班钥匙交到他手里。他把自己的茶杯搬进窗内，坐到老何让出的椅上，又将票夹往里推了推，让人从外面看得见桌面。许蓉指指窗台的图盒，说有人急着问就照老何刚才讲的，不清楚的先让人等一会儿，别跟着跑出去。

老何将眼镜从额上拿下来，用衣角擦过，放回鼻梁。他本来已经将外套背在椅后，见许蓉去取雨伞，才又穿好，说外头早不下了，带着反而得多拿件东西。

许蓉看看门前干下来的地，便把伞放回去，只取一支铅笔和两张旧图。刚走到门口，她又回来，把饭盒旁的小勺收进盒盖边，免得等会儿开柜掉到地上。

老何在台阶下等她，两只手插在外套口袋里，没催。她将一张图递过去，自己留一张，说从他们平常指给人的起点走，不从近巷子穿。

“你是怕我走熟了不认字？”

“我怕咱俩都走熟了。”

他笑了一下，掏出一只手接图。两个人沿着药店那条街走，经过卖水果的门面，台阶下刚冲过水，许蓉往里侧让了一步。她隔着街看药店的招牌，一片新换的白底红字，下面几个小字远看不清，原图上却连那几个字都想印进去。

她低头在图边点了一下，没急着写，脚步慢下来，等老何和自己并排走。


药店旁的台阶夹在两堵墙之间，下头看着不高，走到半中腰，才见上面还有一折。许蓉先上了几级，鞋底沾到窄缝里的湿泥，便扶住右边的铁栏杆，把图折到只露出这个路口。

老何在下面望着她，问是不是还往上。

“你等一下，我看看上头接哪儿。”

她上到最后一级，路在眼前展开，右手一排栏杆沿河伸出去，往左是通向公路桥头的堤路。她走到能望见桥身的地方，没有继续过桥，回身向下看。老何还在台阶脚边，手里的纸已经卷起来，药店门帘遮住了他一只肩。

从上头喊“往这边”容易，站在下面却看不见那条横着的路。她把图翻过来，在空白处画了两个小直角，写上台阶，笔尖被纸下的掌纹顶得发涩，最后一笔没画直。

她沿原路下来，手仍扶着栏杆。到最后两级，她把鞋底在粗砖上擦过，指指图上那条粗线。

“画到这儿就一下接桥了。怪不得以为上来就看得见。”

老何看了眼铁栏杆，伸手试了试那层湿气，没跟她再爬一回。“推个米车到这儿，还得先把袋子搬下来。”

“我下回不能光说药店旁边。”

她把台阶两字圈住，不去涂原来那条线，跟老何继续往前走。药店门里有人往外搬一摞纸箱，最上面那只向前滑，许蓉本能地抬手扶住。搬箱的人急着腾门口，让他们往边上站，说后面还有两摞，送货车等着拿空箱。

两个人退到墙边，等那摞箱子过去。许蓉看药店台阶的入口被纸箱短暂挡住，直到送货的人将最外边一只拖开，才又露出来。她将图展开一些，把药店店名下边留出空，没再添那一串小字。

粮油店还在前头。门侧的缓坡比石阶远出一段，起初混在几家门面的水泥地里，走近才看得清它慢慢向河堤升上去。老何没从店门口穿，领着她沿外边走，过排水沟时指了一下铁篦子，让她留意鞋跟。

许蓉低头跨过。篦子两边有一点高低，旁边立着一辆装了空米袋的小拉车，店里的人将车往外拖，两个轮子先后压过沟边，车把往上颠了一下。那人没停，将车拉到平处，弯腰把歪了的袋子扶正，又拖回去。

老何向她抬抬下巴。“这边不用搬上去，过沟还是得慢点。”

许蓉沿坡往上走。坡面宽，没谁让她侧身，可一步步往上，腿上仍要使劲。快到堤路，她将外套拉链拉开一点，原先塞在袋里的那张图又让风吹出来，她一把按回，掌心贴着纸角，出了点汗。

到了上头，药店那片屋顶在后面露出一角，前头的栏杆和刚才看见的是同一排。她绕过路旁的矮石墩，站到公路桥头，从这里望得见对岸的车站牌，字却认不全。

“今天别过去了。”老何说，“那边站里发车的表，我带的通知还在窗后。”

许蓉看表，离四点半还有一点。她原想再往前走两步，听他这么说，便停住，将手里的图平放在栏杆上，只按住东岸这一截。

“咱们刚走的这两处先画开。站那边照通知，不添我猜的数。”

老何用笔盖压住被风卷起的纸边，让她画。她先点出粮油店，再顺着刚才上来的坡画一条弯线，接到桥头。原来从药店直折的那道箭头还在，两道线挤到一起，她索性把纸转过来，在背面另画，桥头只留一个清楚的落点。


回去时，两人沿缓坡下去。许蓉将纸折到能装进口袋的大小，没有沿原折痕，纸角支出来一点，她用手压了压，仍留在那里。风从桥身那边吹下来，拢在外套里的热气散去，她这才想起柜里那只饭盒，晚上若又只顾给人指路，女儿炒的菜就白热过一回。

老何走在她外侧，经过粮油店门前，他忽然放慢，低头扯了扯右脚袜口。许蓉停下问是不是磨着，他说新袜子松，一走就往鞋里缩，站着扯过两回，最后扶着墙把鞋跟提开，将袜子往上拉平。

“近路走成远路了。”他笑着说。

“你早上没觉得？”

“早上坐着多。等走完了才找着。”

他将裤脚放下来，鞋后跟在地上磕了一下，继续往前。许蓉没抢到前面去，隔半步和他走，手指摸到口袋里的纸角，也没有再把它按平。纸上那条线比脚下这段路省事得多，原先只画一折，走起来却有好几处要停一停。

她的手机响起来，是女儿的语音，问楼下快递店是不是五点半关门，她今晚回来怕赶不上，若母亲顺路能不能先领。许蓉停在一处屋檐下听完，按住语音键，说自己还得先回码头，赶着替同事换回来，今天不绕那边了。

女儿过一会儿回字，说那她从近路下班，自己去，问母亲的饭带没带。许蓉回了“带了”，将手机放回包里。她没有替女儿算那条近路该省几分钟，只记得等回去把饭盒拿出来，别一直压在柜里。

“家里叫你带东西？”老何问。

“叫我拿个包裹。我得先把人家的半个钟头还上。”

老何点头，脚步快了一点，没再提往米糕店拐。方才上坡前他还说，早晨吃的糕软，回家时若店里有可以带两块。许蓉想着先把图改出一张，让他看完再走，便说买糕不急，明天也还开。

他们回到候船室，钟离四点四十还差一点。检票同事正给一名来送检修单的人找笔，窗台上那只图盒推到旁边，茶杯底下垫了一张废票纸。见他们回来，他没马上起身，等对方把单子写完才接过笔，将纸放进老何指出的夹层。

“走到哪儿了？”

“东岸两个口，到桥头就回了。”许蓉说，“没过桥。”

他伸出手，许蓉将折过的图递过去。新画的那面还没写多少字，他翻看一会儿，问这条弯线从哪家店进去。老何指给他看粮油店，许蓉在排水沟的位置点了一下，说这一处要画大些，别缩成一个墨点。

“别让我看见弯线就往药店里钻。”他笑着把纸还回去，“我可没跟你们走。”

许蓉找来一张白纸，先把桥头的位置点在上方。她原想接着画药店，听见老何拿起杯子问水壶在哪儿，才起身给两人的杯里都添一点热水。检票同事端着自己那杯喝，鞋尖已经朝着门外；她看看钟，让他再歇五分钟，说画完这两条入口就换回来，不耽误他走。

老何在一边揉右脚踝，没有接着站。她将凳子朝他推过去，让他坐着看纸，铅笔搁在白纸上，自己绕到窗外看一眼，从人站着问路的地方望进去，桌上那两个小点很快就混在一起了。


许蓉从外面绕回来，将药店和粮油店的字隔开，分别放在纸的两边。石阶那条线短，旁边写“需上台阶”；粮油店门侧那条拐得远些，她用较粗的一笔连到桥头，写“推车从缓坡上，沟边慢行”。字写到最后，空白不够，她把纸横过来，不再往字缝里塞。

老何坐着看她画，伸手将桥头那一笔往上比了一点，说路不是从店后头直穿，两段之间还有一截沿街走的地方。她将那截留出来，让粮油店门口不至于贴着桥。笔落下去，她手边能看见纸上多出的一小块空，走的时候，那一段却实实在在花了几分钟。

她把纸递给检票同事。他没去猜线，从药店的字开始读，读到“需上台阶”时，用指尖挡住另一边，再顺着粮油店那道线看过去。

“推车的就是往前，过店侧那道坡？”

老何说对，又将自己鞋底往地上蹭一下，提醒许蓉把沟边留着，别只图线条好看。许蓉笑着说留着呢，指给他看“慢行”两个字。他这才把手缩回杯子旁，低头吹了吹热水。

窗外有人敲玻璃，来问检修人员能不能借两把椅子。许蓉起身，将白纸压在桌上，让检票同事先走，自己出去应。她从侧门搬了两把给对方，问清放在河边哪一头，约好收工时摆回门里。回来时，同事已经端起自己的杯子，值班钥匙搁到她手掌上。

“我走了，孩子先放学了会跑出来找我。”

“去吧，我在。”

他到门口又回头拿自己的笔，笔被他夹在票夹封面上，方才一直没找着。许蓉替他从底下抽出来，他接过，笑着揣好，才快步走下台阶。她站在门里望了一会儿，见人出了路口，回来将自己那把椅子拉到窗前。

老何把窗台盒里原来的图摊开，挑出三张干净的，问她是重新画，还是在原来的上头添。她拿刚画的白纸比着，说车站和发车通知不用重抄，入口这点用大字补在背面，正面添个“翻看入口”。

他先补一张。许蓉将白纸放在两人中间，拿另一支笔写第二张，不去赶他的速度。写药店那两个字，她停了一下，将笔放下，伸手捏了捏右腕。早上搬椅子那一阵没觉得，这会儿小指侧有点酸，她换个握法，慢慢写完。

第三张由老何添。他写完把三张并到一起，让墨迹晾一晾，自己又到门边看了次天。太阳压得低，药店方向的招牌反着光，许蓉拿起一张补过的图，站到窗外，把“翻看入口”朝着自己，翻过去，背面大字落在手指上边，没有再被折边挡住。

她进来，看见正面昨晚添过的“明早”，拿笔轻划一道，改写“停航期间”。老何将另外两张也这样改好，一起放进茶叶盒。旧图余下的一沓，她取了个旧信封装好，在封面写“入口未补，先别发”，放进窗内抽屉。信封口折住，没有扔掉。

“昨晚拿走的，还有外头的。”老何说。

“碰到拿来的，就看看他手里哪张。别光说图上都有。”

许蓉想起沈禾拍过一张，老人也带走一份；人没站在面前，叫名字也叫不回来。她将那张白纸夹进值班簿，露出“入口”两个字，老何明早翻本子，先看见它。他把夹的位置看清，又指指窗台的三张，说这里可以先给，自己不拿回家去了。


老何收好自己的外套，正要告辞，玻璃门开了一半。一个女人扶着门进来，另一只手拖着带轮子的布袋，保温桶搁在袋口，粗带绕在桶把上。她先将轮子抬过门槛，才问他们去桥头是不是只能走药店旁的台阶。

“我看见停航的字了。”她向告示抬抬下巴，“饭都热两回了，再绕来绕去，到那边人又说我送凉的。”

许蓉本来已经拉开柜门，饭盒刚取出来，听见声音，手停在盒盖上。老何站在离窗近的一侧，从茶叶盒里抽出一张补过的图，先问她过桥之后认不认得路。

“认得。就上桥这边我不常来，怕拖着一桶汤还得爬。”

他将图翻到背面，指着两边的字，说药店旁边是石阶，带这个往前走，到粮油店门侧找缓坡，过排水沟别拖得快。他没有将纸举得很高，胳膊撑在小窗边，让女人能把布袋留在脚边，腾出一只手看。

女人先跟着他指的地方看，读到粮油店，又从正面找到店名，手指换了两回，才点头。她问是不是越过药店还得往前，老何说对，自己和许蓉刚走过，东岸两处到桥头这一段，沿街走就能接上。

“那这张我带着？”

“给你的。”

她将纸折到只有入口那面露在外头，夹进外套口袋，没往布袋里塞。保温桶歪了一点，她扶正，带子跟着绷紧。许蓉从窗后探过身，看桶盖扣得牢，才将门替她撑住。

“门槛高，慢点抬。”

女人将轮子一前一后提过去，落到外头平地，回头道了声谢，沿着药店的方向走。许蓉只送到门口，看她绕开台阶下那片积水，便回来关上门。老何往她手里的饭盒看，笑着让她赶紧吃，自己去街上转转，也好回家了。

她向他道谢。他说一双袜子拖了半条街，让她别嫌他走得慢，提起放在墙边的包，出去时顺手将靠近通道的一把椅子挪正。许蓉看着椅脚放稳，没再叫住他问别的事。

窗台盒里还剩两张补过的图。她将其中一张稍稍立高，让“翻看入口”那几个字露在外头，旧信封留在抽屉里，白纸仍夹值班簿。她记着，下次谁带图来，就先看他拿的是哪张。

饭盒打开，茄子压在米饭旁，酱汁浸湿了一小片。她把盒盖翻过来，垫住边沿，拣出压在底下的小勺，才发觉女儿给她放了两支，一支短的，一支长柄的，大概收桌时顺手都装了进去。

她拍下饭盒一角，发给女儿，问家里是不是又找不着勺。女儿回一个哭笑的表情，让她明天记得带回来，别让小勺也在码头住一星期。许蓉回了“吃着呢”，将手机立在杯旁，夹起已经不烫口的茄子。

女儿又发来一句，说短柄的早上还要用，家里那支大汤匙盛酸奶不方便。许蓉看看两支勺，原想把一支留在抽屉里，省得下回又忘带，手伸过去，碰到票夹，便收回了。抽屉里连充电线都不肯老实待着，添一支勺，哪天还得在一堆纸底下找。

她将短柄那支擦净，先收进空的小布袋，长柄的留着吃饭。手机还立在那里，她回女儿说短的保证带回去，长的用完也一起洗。女儿说她下班晚，不必赶着刷，盒子放水池边，明早自己起来会洗。

许蓉隔着屏幕笑了一下，想说她明早也要上班，打出几个字又删掉，只回了一个“好”。她将洗碗的事留在那里，低头继续吃，没去猜女儿究竟会不会比自己起得早。

有人从门外经过，停住看告示。她透过玻璃望了一眼，那人读完，转身往检修围栏那头去了，是来找工友的。她将刚夹起的菜吃下，没有端着饭盒去门口追。

天光慢慢从窗台退到地上。灯一开，玻璃照出她拿勺的手，外头的人反倒看不清里面。她把桌上的新图往小窗前挪了挪，问路的人走近，能直接看见纸。饭吃到一半，她的手机又亮，是女儿回字说包裹已经取到了。

许蓉用手背按住盒边，将最后那一点酱汁拌进饭里。门外偶尔响一声检修工具相碰的声音，屋里的钟走过一格，又一格。她吃完才盖好饭盒，两支小勺一同收进去，搁在挎包旁，留在明天出门会先看见的位置。
