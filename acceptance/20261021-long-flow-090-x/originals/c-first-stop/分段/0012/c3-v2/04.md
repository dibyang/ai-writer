老何沿缓坡回来，经过粮油店门口时，那辆自行车已经挪走。店里的人坐在米袋上记东西，抬头问送到没有。他说送到桥头，人往桥上去了，没跟到对面。对方应一声，脚边的空袋叠到一起，门侧那段路仍敞着。

回候船室，许蓉正在给坐阴处的年轻人找一张写电话号码的废纸。对方手机能用，就是要照着号码打，空着手不好记。老何进门先喝口水，水在杯里搁了一阵，温度刚好，不必再对着杯口吹。

“人走上去了？”许蓉问。

“到桥头了。我看他推上桥，过了前两根灯杆才回。沟前重绑一回，不绑还得掉。”

她将笔放下，问是不是图上那处沟。他指给她看，说就在粮油侧，坡上能走，门侧有辆车，店里人挪开便过去了。许蓉听着，把那张母图翻出来，让他在沟边的空白处添“到沟前先停稳”。他拿笔写，写到稳字，发现字挤了，便把字往下一行落，没覆盖原来的慢行。

“你写，我来读一遍。”她说。

他把纸推过来。她从药店读到粮油店，再读停稳和慢行两行，指着新添的那句，问是不是所有车都得绑。他摇头，说那人的上包会滑，别写人人都要拆。她点头，母图便只留停稳，绑绳的事没加成给所有人的规矩。

窗台还剩的那张补图，老何照母图添了同一句。许蓉站到窗外看，他把纸放到小窗前，让她从拿着车柄的高度再读一回。她说能看清，回来把母图夹回值班簿，旧未补图的信封仍放抽屉，一张也没有拆出来混上。

年轻人拨完电话，过来还椅子。椅子沿地砖拖了一小段，老何让他抬起来别磨脚。他有点不好意思，和老何一人一边搬回墙边，放下还按了一回，说这把稳。许蓉将旁边垫纸的那把推开一点，给它们留出各自的地方。

六点半到了。许蓉把当班页翻好，指给老何看哪位检修的人还在河边。充电插头已经拔了，小窗外那张号码纸也让年轻人带走，她把桌边剩的废纸拢齐，先放到他能顺手取的位置。

“母图那一页今天添了字。”她说。

“我写的，我记得。”

她笑一下，将值班钥匙从腰边的小扣取下，交到他掌心。老何接过，挂到窗后，自己坐到窗前，把簿翻向当班那面。她洗好自己的杯子，塞入挎包，临走又回头摸一遍椅背，外套和纸巾都拿了。

门外有人来问明天还发不发船。许蓉站在门旁，老何已经开口，叫他看今天仍挂着的停航告示，说新通知到了会贴，眼下要过河仍走桥。他把窗台那张图拿给对方看，没有先向许蓉望。

许蓉便从问话的人身后绕过，出门下台阶。河边有金属碰响，她没将那一声听成开船，朝药店方向走。经过粮油店所在的路口时，她往前看了一眼，远处门面挡着坡脚，老何说过的那段路在外头，她没有为了亲自再看一回转过去。

她取出手机，给女儿发“下来了”，女儿很快回字，叫她经过楼下看看有没有葱，没有就算了。许蓉回好，收起手机，走进卖菜摊旁余下的那一点光。摊上只剩几把带黄叶的，她挑了一小把，付过钱，纸包的葱根朝下提着，走回自己的那条巷。
