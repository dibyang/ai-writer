# 第六章 走一遍再画

停航第一天的下午四点，许蓉提着饭盒回到候船室。门前的椅子已经挪开，早晨贴好的那张清单还在库房门旁，检修的人用木条拦住靠河的一段，穿着沾灰的鞋从另一边进出。

老何坐在窗后，眼镜架到额头上，正读一张折小的纸。许蓉认出是他们印的绕行图，纸上多了几道圆珠笔的横线，右边那段已经压出深槽。他见她进来，将纸转过半圈，指给她看药店旁边的箭头。

“上午两个人问我，是不是上这几级台阶就到桥了。”

“上去能到。”

“一个推车的。走到跟前又回来了，问有没有不用抬的路。”

许蓉将饭盒放进柜里，站到窗边看图。纸上的路从药店旁一折，直直连到桥头，小小一块台阶符号挤在店名下面。她知道前面还有一道坡，画图的时候却只想着把桥标清，让人别再到河边等船。

“他后来走哪边？”

“我指了粮油店那头，他说去看看。没见他再回来。”

许蓉把纸拿近，想起前夜戴毛线帽的老人。他当时把“明早”两个字看漏了，折回来问的也是药店。她在图上添过时间，又让沈禾自己圈过车站，那半个圈还记得，入口这一小段却没再问。

门口的检票同事抱着一摞旧票夹进来，问放哪个柜。许蓉接过去，搁在窗内干的那格，翻出压在最底下的钥匙，让他先别走。她想和老何去药店前后各走一下，回来再把图添清楚，问他能不能看一小会儿窗口。

他先看表，没立刻应。

“最迟五点。我得去接孩子，学校那边不让一直等在门口。”

“我四十前回来，走不到的留着。”

“你们别走到桥那头去了。”

她应着，将这班要用的值班钥匙交到他手里。他把自己的茶杯搬进窗内，坐到老何让出的椅上，又将票夹往里推了推，让人从外面看得见桌面。许蓉指指窗台的图盒，说有人急着问就照老何刚才讲的，不清楚的先让人等一会儿，别跟着跑出去。

老何将眼镜从额上拿下来，用衣角擦过，放回鼻梁。他本来已经将外套背在椅后，见许蓉去取雨伞，才又穿好，说外头早不下了，带着反而得多拿件东西。

许蓉看看门前干下来的地，便把伞放回去，只取一支铅笔和两张旧图。刚走到门口，她又回来，把饭盒旁的小勺收进盒盖边，免得等会儿开柜掉到地上。

老何在台阶下等她，两只手插在外套口袋里，没催。她将一张图递过去，自己留一张，说从他们平常指给人的起点走，不从近巷子穿。

“你是怕我走熟了不认字？”

“我怕咱俩都走熟了。”

他笑了一下，掏出一只手接图。两个人沿着药店那条街走，经过卖水果的门面，台阶下刚冲过水，许蓉往里侧让了一步。她隔着街看药店的招牌，一片新换的白底红字，下面几个小字远看不清，原图上却连那几个字都想印进去。

她低头在图边点了一下，没急着写，脚步慢下来，等老何和自己并排走。
