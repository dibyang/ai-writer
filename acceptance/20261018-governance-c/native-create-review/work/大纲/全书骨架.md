# 全书骨架（计划，不是已发生事实）

第一卷《留一夜》1–3：旧木箱从渡口仓房进寄存处。周梅凭黄漆和旧记忆认领，林禾暂不交；旧借据证实箱子曾供周梅母亲放缝纫物，但归属尚需老邵到场说明。钥匙独立保管，雨夜移箱不是领箱。第3章低压合作结束，留下蓝布补角与一张未送出的纸样。

第二卷《交到手里》4–6：老邵承认当年把两家相近的箱子记混，蓝布补角由周梅实际辨认、试合纸样得到有限兑现；不是用外观排他定主。周梅先不运走受潮箱，选择共同晾修。第5章在清点钥匙与归还工具时练习交出控制；第6章约定使用与保管，完成这次交接，关系只修复到能一起吃一碗面。

未决：林禾是否留镇常住、寄存处长期费用怎样分担、纸样是否复制给更多人。只留未来讨论条目；第6章不能把这些写成已作决定，更不生成第7章。结构讨论可考虑第3和第5章的桌边核对是否需压缩，但先保留不同选择与后果，等实际文本后判断。
