# Proofreading and Language Quality

Apply this module when the user asks for typo, grammar, copyediting, proofreading, line-by-line review, or formal full-manuscript release review.

## Required Separation

Treat these as separate checks:

1. Mechanical scan for suspicious punctuation, duplicate strings, placeholders, encoding damage, and known forbidden patterns.
2. Human line-by-line reading for language meaning, sentence integrity, and contextual consistency.
3. Style and market-readability review.

Passing a script does not mean the manuscript has passed proofreading.

## Line-by-line Checklist

- Typos, incorrect characters, omitted words, and duplicated words.
- Broken collocations, wrong measure words, and verbs that do not fit the object size or state.
- Missing subjects, predicates, objects, or connectors; malformed sentence structure.
- Unclear pronouns, subject drift, and action ownership that changes without an on-page handoff.
- Chinese quotation hierarchy, paired punctuation, sentence-final punctuation, and dialogue attribution.
- Accidental duplicate sentences or near-duplicate adjacent expressions.
- Names, ages, dates, chapter numbers, evidence labels, counts, terminology, and object names that change unintentionally.
- Contextual statements that contradict already established body location, device state, observation status, or object lifecycle.

## Editing Boundary

- When editing is authorized, directly fix only unambiguous errors.
- Keep debatable rhythm, voice, and stylistic rewrites in a separate suggestion list.
- Preserve deliberate fragments, repetition, and character-specific speech when they are contextually functional.

## Formal Release Gate

For a full manuscript or formal release candidate:

- Record the exact chapter/file range read.
- Read every target chapter in order, even when mechanical scans are clean.
- Re-run mechanical checks after edits.
- Block final release if the dedicated line-by-line pass is incomplete or clear language defects remain.

## Output

Report the reviewed range, changed chapters or finding locations, representative before-to-after fixes, unresolved style-only suggestions, and the final proofreading verdict.
