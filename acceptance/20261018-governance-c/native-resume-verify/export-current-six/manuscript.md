# 第一章 木架空着一层

林禾把第三把伞挂上墙，门外又有人喊她。她母亲去县里复查，把便民处交给她两天，收钱的铁盒在哪儿说了三遍，偏没说旧渡口还会往这里送东西。

老邵推着小车停在门口，车上横着一只半米长的木箱。柳河渡船停了几年，仓房如今要腾出来堆防汛沙袋。他说，别的都有主，就剩这只，卖废木头又觉得亏。

“先放你这儿，等人来认。没人认，也别急着送人。”

林禾手里还拿着抹布。“放多久？”

老邵挠挠耳后：“先问一圈。我明天从县里回来，再过来。”

箱子不算重，两个人抬着两头，得侧过身才进得了门。林禾空出木架最下层，老邵却说挨地容易潮。她只好把上层的纸杯搬下来，又踩着矮凳把旧招牌往旁边挪。腾完那一格，背后已经出了汗。

放稳前，老邵托住箱头，让她看底下。黄漆掉得斑驳，箱底外侧钉着一块蓝布，补住了左边的缺角。林禾用手指压了压旁边的木板，没敢去扯布。

“这里原先就这样？”

“我见着时就有。谁补的，想不起来。”

箱盖扣着一把小铜挂锁。老邵从裤袋摸出钥匙，连同一本薄薄的旧借物簿放在柜台上。簿里夹着一张电费单，他忙抽回去，说自己眼下最容易把这两样弄混。

林禾笑了一声，找出母亲记寄存的本子，写了日期、木箱一只。写到送来人，她抬头问全名。老邵报得很响，仿佛她从小就认得他这件事，让这一问格外多余。

“我妈回来要问。”她解释。

“那就写，写清好。”

林禾把钥匙装进一只空布袋，放进自己柜台下的抽屉。旧借物簿另搁在抽屉右边，跟她的寄存本隔开。她没有开锁，老邵也没催，只叮嘱有人认领先叫他来一趟。

走前他向墙上看了看：“你妈那把黑伞呢？”

林禾指给他，他才放心推车。那把伞的弯柄曾经断过，周梅替母亲用布缠好；林禾十来岁时把它借去上学，丢过一回，回来却说是周梅没放稳。后来伞找到了，她也没有专门去说什么。

隔壁改衣摊的卷帘门哗啦一响。周梅拎着半袋青菜出来，先看那只空车，又看门里的箱子。

“仓房的？”

林禾点头。周梅在门槛外停了一会儿，手上的菜叶碰着裤腿。

“黄漆还在呢。”她说。

林禾正要问，巷口有人喊周梅去取缝纫机皮带。她应着声走了，青菜袋在腿边一晃一晃。林禾把抹布洗净，搭在水池边，回来又给本子添了半行：黄漆，左底角蓝布。

字写得太靠边了。她把本子往灯下挪，却没另换一页。母亲的茶杯还在桌角，杯底压着找零用的一块钱。她抽出钱，放回铁盒，顺手给杯子添了半杯热水。木架上少了一层空处，屋子看起来比早上小了一点。

# 第二章 先放一夜

周梅回来时，青菜已经送回家，手里换成一只饼干盒。她没坐林禾让出的凳子，把盒子垫在柜台边，揭开盖，里面是几张折小的纸。

“我妈留的。你看这一行。”

林禾把台灯转过来。纸上写着米缸、棉被，最下面是黄漆木箱，字旁有个小钩。没有年月，也没写箱子后来放在哪里。她认得徐兰的名字，母亲从前做裤子，总往周梅家送。

“我记得她放剪刀和布头。”周梅说，“后来渡口给大伙儿借地方，她就把箱子留那边，拿取方便。”

林禾看一眼木架，问箱上还有什么记号。

“黄漆呀，左边那块掉了。”

“底下呢？”

周梅往前走了两步，又站住：“好多年没看底了。我哪记得。”

这话让林禾松了口气，也让她更难开口。她本来盼着一个准准的记号，说出来，事情就能在晚饭前办完。现在周梅抚着饼干盒盖上的锈点，像在等她开抽屉。

“老邵说明天过来。要不，等他回来一块儿看？”

“你是怕我拿了不认账？”

“不是。钥匙也是他给的，我答应叫他。”

周梅把纸折起来，有一道旧折痕没对齐，她又打开重折。林禾下意识伸手帮忙，手伸到一半停住，拿起旁边的水杯。

“倒点水？”

“家里烧着呢。”

她没有抱走箱子，只把那张清单重新摊在灯下。林禾从本子上撕一张空纸，请她自己抄下那一行，原件带回去。周梅先问收多少寄存费，林禾说这不是她送来存的，得等母亲回来问，今天先不收。

“钱倒好说。”周梅低着头抄字，“别弄得我像来捡东西。”

林禾掸了掸本子边上并不存在的灰。“也可能是我想错了。你知道这箱，我不知道。”

周梅笔尖停住。门外卖豆腐的人骑过去，喇叭喊得破了音，两个人都等那声音过去，没接话。

末了周梅写下名字和住处，又把改衣摊的电话补在边上。她说家里的号码已经不用，打那个只能听见忙音。林禾跟着改了一遍，才发现自己一直记得的，还是她们家十年前的号。

临走，周梅问能不能明早早点。她有件校服得赶在中午前改好，不能整上午守在这儿。

“我八点开门。老邵要晚，我去隔壁喊你。”

周梅点头，把盒盖扣了两次才扣紧。她走后，林禾把抄纸夹进寄存本，没压在箱上。她想给母亲打电话，又看见手机里半小时前的一条消息：还在排队，别急。

她放下手机，去门口把招牌翻到晚间那一面。厨房是临时隔出来的，电饭锅跳了闸，饭还夹生。她添半杯水按回去，想到周梅那句“家里烧着呢”，忽然有些后悔，刚才没顺口问一句吃的什么。锅盖边慢慢冒出热气，她拿出两只碗，看了看，又把其中一只放回架子上。

# 第三章 垫高两块砖

林禾刚吃两口饭，雨就下来了。先是檐口滴水，随后巷子里白成一片。她去关侧窗，鞋底踩出一声响，低头才看见墙根渗进来的一线水。

木架的腿正挨着那面墙。她伸手够箱子，抬起一头，另一头便卡在架边，连纸杯也跟着倾斜。饭锅还亮着灯，她索性关掉电源，站在凳子上重新挪杯子。

“别站那么高。”

周梅从门口进来，肩上搭着塑料雨披，手里提两块砖。她家厨房门边也进水，出来看水往哪儿走，正瞧见便民处窗里的人影。

“这砖干净的，我垫花盆用。”

林禾下来接了一块，腾开柜台前的长凳。两人把砖摆平，又在上面铺了折叠的旧毛巾。抬箱前，林禾往柜台里面让了让，把抽屉推紧，给周梅留出转身的地方。

“你扶这头，我这头高一点。”周梅说。

箱底离开木架，两个人慢慢往后退。周梅的袖子蹭到黄漆，留下一小片粉。她低头吹掉，没腾手去拍。直到箱子落稳，林禾才发现自己一直屏着气，腰也弯得发酸。

周梅俯身看底角。“这蓝布倒结实。”

林禾蹲在旁边，掀起毛巾一角给她看，却没扯钉住的布。周梅说颜色像母亲以前做围裙剩的，随即又摇头：“镇上买布都去那一家，光看蓝色，算不了。”

雨点把门帘打得贴在玻璃上。林禾去拿干毛巾，顺手从抽屉右边取出老邵留下的借物簿。白天忙着收件，竟没翻过。周梅擦完袖口，接过她递来的那条，搭在膝上。

簿子前几页是救生衣和绳，往后字迹越来越疏。林禾翻到一张折角页，上面写着“徐兰，黄漆箱一个，存缝纫物”。周梅凑过来，把灯拨近些。

风从半掩的门缝里钻进来，吹得薄纸往回卷。周梅用一个空杯压住页角，杯底先在裤腿上擦过，确认没有水。林禾看着她掌边的细小针眼，想起刚才自己递毛巾时，递的还是那条最旧的。她没有换，只把放针线的小碟挪远，免得碰伤周梅的手。

“是我妈名字。”

“这儿没写借走还是借来。”林禾把那一页摊住。

周梅说老邵知道，等他明天来问。她拿起手机给他打过去，雨声太大，开了免提。老邵在电话里应了，说八点半到，别忙着撬，锁能用。至于那行字，他得戴上眼镜看。

两个人便不再翻。林禾收好簿子，把湿抹布拧进水桶，周梅扶着桶沿，免得她连桶一起提起来。门前积水退得慢，但已不再往墙里钻。

“你饭凉了。”周梅看一眼电饭锅。

林禾说热一下就行，问她吃过没有。

“菜洗了，还没炒。”

林禾这回拿了两只碗。她留了一半饭在锅里，让周梅回去端菜。周梅嫌雨披占地方，挂上门后的钩子，空着手从檐下跑回去。林禾把长凳往里推了些，给桌边多让出一双腿的位置。

# 第四章 盖子打开以后

八点半差两分，老邵夹着眼镜盒进门。周梅刚把校服送给来取的学生，指尖还沾着一段白线。林禾把借物簿摊在昨晚那页，三个人挤在台灯底下。

老邵戴上眼镜，看了一阵，说这是存进仓房的，不是渡口借出去的。那几年谁送来什么，他都写进这个本，图省事，没另起一本。

“昨天还说没主呢。”周梅说。

他把眼镜往上推，没接得那么快。“我把它跟公家的那只记混了。也是黄的，后来拿去装救生绳。这只，是你妈自己带来的。”

“我妈走后，你怎么没来叫一声？”

“我以为你早拿了。仓房换过两回锁，我也没天天去。”

林禾把水杯往他那边推。老邵没喝，手放在膝上。周梅望着簿上母亲的名字，说先开吧，看看还能不能用。

钥匙从布袋里取出来，在锁眼里转了一半就卡住。老邵叫她别硬拧，先把箱盖往下按。林禾照做，挂锁便弹开了。她把锁和钥匙并排放在自己手边，慢慢托起盖子。里面没有大家想过的整套剪刀，只有几片蓝布、一些纸样和一条卷紧的旧围裙带。

周梅先拿围裙带，贴着边摸过去，又放回。她请林禾帮着把箱子侧起一点，好看底角。外面那块蓝布有一条卷边，卷到角上，线针来回叠了三趟。

“她总怕这儿散。”周梅用指头比了比，“我嫌她缝得疙瘩大。”

她从箱里捡起一片余料，托在掌上靠近补角；两边参差的裁口隔着木板边缘，能看出相接的轮廓。林禾扶着箱子，等她看够才放平。昨天只是蓝颜色，今天周梅终于把那片布叫作母亲留下的料。

纸样干得发脆，最上面一张是小孩子的背心，肩口还用铅笔收过窄。周梅说那像是给她女儿改的，话到一半又停下：“也不一定，没写名字。”她没把纸展开压平，连着底下的硬纸板一起取出，搁在柜台干燥的地方。

林禾在旁边摆开两只空纸杯，挡住要往下滑的纸边。周梅伸手把其中一只移开，说那儿折着，别抵出洞来。她们换了个方向，让硬纸板的长边靠着墙，才松开手。老邵一直站着，直到周梅往旁边挪出位置，他才拉过凳子坐下。

箱底木条摸着有些潮，右边一根还松了。林禾问要不要找车，周梅说先别搬，关回去明天得生霉。她想在这里摊一晚，下午拿工具来，把松条拧好。

“占你地方了。”

“反正昨晚已经腾了。”

周梅笑了一下，去拿毛巾垫盖边。老邵终于端起那杯水，喝完，向她要回旧簿。林禾把簿子递给老邵，看着他夹在腋下带走。门槛还有昨夜的水印，老邵迈过去时说，自己回去也该把箱柜翻一遍，省得又把人的东西放忘了。

林禾把钥匙收回布袋，仍放抽屉。箱盖支着，空出一道窄窄的口，巷子里晒热的风慢慢吹进来。

# 第五章 抽屉留条缝

下午太阳照到门槛，箱底已经摸不出潮气。周梅拿来小锤和螺丝刀，发现松的是螺丝，便把小锤搁到一边。林禾替她扶住木条，螺丝转了几下，木条重新贴紧，没闹出想象中那么大的动静。

周梅拿手指试了试，说不用添新木头，旧的再用几年没问题。她把工具并排放好，去隔壁取个装纸样的纸套。林禾等着，眼睛落在柜台上的硬纸板，伸手把一角翘起的纸扶住。那张背心还是没摊平，她没有再试。

寄存本翻到昨天那页。林禾另拿一张纸，写木箱、纸样，又看了看小锤，连螺丝刀也添上。借物簿已经让老邵带走了，她只剩周梅留下的抄纸，夹页间那道折痕压得很深。

周梅回来，看见她写的东西，笑了一声：“锤子本来就是我的，也要领回去？”

林禾把笔停在纸上。她知道周梅没认真恼，可还是想解释，写一份总比说不明白好。昨天对着清单，她怕交错；今天东西都认得了，笔尖却还在往下找。

“你看看，怎么记？”她把纸转向周梅。

周梅没急着接笔，先把螺丝刀插回工具套，再拿起锤子。“就写拿走的。箱明天搬，今天不算。”

林禾把两件工具从纸上划掉，没另抄一张干净的。周梅从纸套里抽出一小片垫纸，塞在背心肩口的折痕下面。两个人把纸样连着硬纸板收入宽纸套，放回晾干的箱底，围裙带和余料分放在旁边。

林禾问那张没名字的要不要单放。周梅想了想，说先跟其他的在一起，别为了找名字又翻坏了。她说完看着箱里，手还搭在盖边，过了一会儿才轻轻放下。

挂锁摆在柜台上，钥匙还在林禾的布袋里。她取出来，和锁放在纸旁，等周梅清点。周梅数过，又问明天几点方便搬，改衣摊的门框窄，得先把脚踏板挪开。她们约了早上十点，各自先忙完手里的活。

“今晚钥匙还是搁你这儿，我明天连箱拿。”周梅说。

林禾把钥匙放回布袋里，收紧袋口，搁进自己柜台下的抽屉。

她手在抽屉把手上停了停，问锁要不要先扣上。周梅掀开箱盖，又摸了一下底板，说再透透气。挂锁于是仍放箱旁，谁也没把它扣回去。

临走前周梅拎起工具套和锤子，忽然问昨天那盘豆角咸不咸。林禾说有一点，话出口才抬头，怕她听着不舒服。

“我就说吧，锅边那把盐手重了。”周梅把空盘递过来，盘沿擦得很干净。

林禾去接，腾不出手关抽屉，便让它留着一条缝。等盘子放稳，她用膝盖轻轻抵上，听见门口周梅在叫卖豆腐的等等。巷子还晒着，没到该收摊的时候。

# 第六章 一碗面的位置

第三天十点，周梅把改衣摊里的脚踏板挪到墙边，来叫林禾。她没借车，两家只隔一道门，慢慢抬过去就行。林禾先把柜台前的凳子搬开，免得出门时再卡一下。

周梅掀开箱盖，看看纸套有没有压住余料。林禾把昨天那张有划痕的纸摊在台上，周梅顺着念了木箱、纸样，又添上围裙带和蓝布。念完，她自己签了名字，日期写错一笔，划掉重写，没要新纸。

“那张小背心，以后要不要再描一套？”林禾问。

“等能摊开再想吧。给谁都还不知道。”

她们把纸套放稳，合上箱盖。林禾从抽屉取出布袋，把钥匙倒在自己掌心，递给周梅。周梅接过钥匙，扣上铜锁，试着转了一下，又往上提提锁扣。

林禾等她试完，把空布袋叠好放回抽屉。两人各扶箱子一头，从门槛抬过去。周梅往前看路，林禾退着走，经过门柱时停一下，再换手。木箱落在改衣摊腾出的矮架上，箱底没有挨地，也没挡住脚踏板的位置。

周梅把钥匙串进自己的钥匙圈，挂到围裙口袋里的小钩上。她拉了拉，确定不容易掉，又把纸套那一侧转到靠墙。林禾站在门边，看她重新把脚踏板摆回缝纫机下，才发现箱子那半米地方是从她原来堆布的空处挤出来的。

“要收多少，你妈回来问好了告诉我。”

林禾说好，没替母亲免掉，也没当场报个数。周梅把找出来的碎布收进筐，留了条过人的缝。林禾伸手帮她提筐，正对着便民处的门，能看见墙上那把黑伞。

“你上回缠的伞柄又松了。”

“拿来，我有条厚布。”

林禾回去取了伞。弯柄上缠的布已经洗成灰色，靠末端露出一小截断口。她摸着那里，笑了一下，没有马上递过去。

“上学那回，伞其实是我忘在教室。我回来怪你没放好，后来找到了，也没说。”

周梅手上的碎布停了一会儿。“你还记这个？”

“记得。”

“我也没全忘。”周梅把筐接过去，“那天我找了半下午。”

林禾点头，没再说自己那时多小。周梅挑一条厚布，把旧的拆下，沿弯柄一圈圈缠紧，再用线固定两头。忙完，她让林禾把黑伞先拿回去，等林秀回来再说缠柄的钱。

巷口面摊开始下第一锅午面，热气越过低矮的灶棚。林禾问吃不吃，周梅说摊上没人，端回来吧。她们各要了一小碗，林禾多走一趟取筷子，回来见周梅把缝纫机上的布移开，铺了两张旧报纸。

吃到一半，周梅问她哪天回县里。林禾说还没定，要等母亲复查完。周梅说那明天若在，帮她看十分钟摊，她去买菜。

“在就来。”

林禾把碗往里挪，给门外伸进来的日头让了让。便民处的木架还空着，她吃完得回去把纸杯放好；周梅这里，那只箱子已经有了自己的位置。
