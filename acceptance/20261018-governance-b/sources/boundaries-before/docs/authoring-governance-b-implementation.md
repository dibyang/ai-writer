# 设定版本与跨会话修订：第二批实现约束

日期：2026-10-18。本文件补充八项设计中 B 批的实现决策；代码候选 0.5.0，最终验证状态见本轮记录，未发布。背景、目标和非目标沿用原设计 §§7–8：固定旧输入、显式处理影响、隔离完整修订、避免覆盖另一会话，复用分卷和增量链。

## 协议与权威

原设计拟在 schema 3 中扩展；核实 0.4.0 后发现其解析器接受 3 并忽略新字段，所以本批采用 **schema 4**。这是拒绝旧写客户端的必要兼容边界，不代表重做事实账本。治理字段、baseline/journal、旧 source_hashes 都保留；protection enable 仅显式升级，备份后一次替换 state，实际作品不自动迁移。

state 是唯一可变业务权威：source_versions、source_ranges、source_events/source_binding、source_operations、impact_pending、committed_revisions；每章增加 source_bindings、decision_bindings 和 tool_build_id。不可变来源为内容哈希命名 .source 文件，事件和提交清单为哈希绑定 JSON；当前索引须与事件一致。每次业务变化推进统一 revision；协作会话独立存放，不推进业务 revision。

## 接口与状态机

source：freeze（提案）→impact（只读）→baseline/future publish；historical 则 stage（持久阻断）→revision 区内 publish→重登→一次 commit。bind 只补充完全等价的旧消费证据；cancel 保留未发布提案和历史。默认三份设定、单元细纲、卷纲及研究走统一解析层，历史正文承接/配置仍原哈希校验。间接影响保守 unknown，不自动语义裁决。

revision：begin→open/editing→prepare→prepared→commit→committed。中断/冲突保留分支；resume 不重置基线；conflicted 须另开新基线，aborted 仅释放占用。parallel_candidate 显式允许并行候选，最终全局 CAS，不自动合并。transfer 核明确授权及会话哈希后换令牌，证据存协作目录。

## 提交时序与恢复

begin 短锁内固定业务状态、相关普通文件、实际消费依赖和工具运行模块，明确复制受管目录，前后核基线，正文独立复制。主作品相关写命令共用占用门禁；分支写命令验证令牌和当前工具构建。

prepare 验完整原尾段重登、前缀保留、事实/journal/hash、授权及一次最终尾段实读报告，保存完整文件差异与目标 state。分支 revision 仅审计；主 state 以 base_revision+1 发布。首版禁止删除、章节路径改变、新正文、配置/治理决策改写。

commit 锁内再核主基线与候选树，持久准备旧/新字节和事务计划，写新对象及普通文件，state 最后替换。每条普通读写发现未结束事务即拒绝；recover 对目标集合先全量核旧/新哈希，再逐文件重复比对，遇第三方字节保留三方并停止。同步与同盘 rename 用于本机发布；不宣称多文件天然原子、断电保证或共享盘保证。

遗留锁只接受明确恢复授权、匹配锁哈希、会话所有者令牌，且原进程不可仍存活；PID 消失本身不授权删除。事务终态幂等，不能借恢复撤销已提交作品；撤销另建逆向修订。分支与备份不自动清理。

## 幂等、异常与回滚

source 稳定 operation_id + 完整输入指纹，旧 revision/影响预览拒绝；不可变孤儿保留但不成为权威。begin 每次新 ID；commit 和同向终态 recover 可重复查询结果。准备后改稿、业务 CAS、文件/工具变更、错误令牌、未知字段、来源损坏分别拒绝并保留现场。

未完成事务可显式回滚到旧集；已成功提交只能新建逆向修订。旧 1/2/3 不自动升级，旧 0.4 实际解析器拒绝 4；新版 doctor 核旧副本协议不兼容。没有安全更新工具、数据库、常驻进程或新增依赖。

## 实施和验收

先统一协议和来源解析，再会话/事务，最后手册、技能与独立 Codex 实跑。每轮保留源码快照、输入、事件、失败与修后结果；冻结最终候选后完整 npm test、doctor、smoke。引擎未改不扩大引擎测试声明。

重点验收：future-only 旧章及报告保留；真实旧字节补绑；默认设定/细纲/卷纲/事实卡统一解析；历史 pending 与依赖复核；跨进程恢复；并行 A/B 只提交一方；主文件/候选/工具漂移拒绝；真实中断的补完、回滚及第三方冲突；作者移交不改业务基线；普通写旁路拒绝；旧版本兼容回归。

文学复核由模型实读版本化正文承担，接口合成报告不能算实读。实际作品只读核指纹；B 以外的章节功能表、意见级闭环和工具安全更新未实施。主要剩余风险是任意编辑器锁外竞态和用户手改协议文件，工具不能提供同用户的安全隔离或自动语义保证。
