# 第1–3章初稿完整连读

独立 Codex 实读，范围为本次登记的三章全文；不是真人盲读或市场验收。

铜片在第一章阿禾衣袋，第二章当场交周叔验记后回阿禾腰袋，第三章交周叔锁入旧柜借验匣。第二章两枚押钱和收条有原文；第三章仅暂存，未声称完成归档或退款。描样来自旧页，不冒充封套原拓，阿禾与周叔只知右下缺角相似；柳婆尚未获知。没有将卷纲的修印答案填进事实。

语言与连续性问题：第一章“不能让你的信再落到别人手里”中的“再”会无依据暗示这封信以前已经落入他人之手，后续应改成具体的冒领防范表述。第三章柜脚砖裂后“蹲下去扶正”不清楚扶何物，且容易让人理解为徒手动承重砖，应改成把脚边碎砖拨开。第二章“等那一行字上的墨失了亮光”在近距离观察内，可以保留。两次“问得太迟/怎么记得这么晚”分别指阿禾的延误与周叔迟来的回忆，不强行合并。

上述两处不直接改已登记主稿。先完成仍获授权的第4–6章，然后按补充测试授权从最早影响章1至末章6建立独立修订区；完整重登、核对人物所知和物证，再做尾段复读并提交。此报告不宣称问题已经修复。

第二卷须兑现：用可复验的原印及修补痕迹解释缺角，不凭柳婆一句话定案；第五章结清两枚退款；第六章给读信的日常情感留篇幅。暂无扩大阴谋或第七章正文需求。
