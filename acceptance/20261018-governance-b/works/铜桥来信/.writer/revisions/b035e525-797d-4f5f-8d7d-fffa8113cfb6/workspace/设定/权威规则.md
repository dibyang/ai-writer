# 权威规则 v2（第七章起）

这是独立验证小说的当前创作规则，来源为研究/测试授权原话.md。细纲和卷契约只表示计划，正文和带本章引文的增量追踪才表示已发生。

1. 主角阿禾；限制为她合理可知的近距离第三人称。铜片有折起的耳、一条浅划痕，信件封口有一枚右下缺角的方印；观察、推断与查明须分开。
2. 铜片每次交接须写出交出人、接收人、存放地点与状态；人物没在场或未获转述不能突然知道新结论。不可用新解释改掉旧观察。
3. 第一卷1–3章埋缺角印，第二卷4–6章查清：缺角是修补后的旧柜印痕，不能仅凭相似印记认定偷信。第5章完成解释和退钱，第6章处理信件与情感余波。
4. 第1–6章适用当前押钱制度：借验铜凭交两枚押钱，归还铜片并结清登记后退两枚。第2章缴两枚，第5章退两枚，不抵扣、不漏退。
5. 本v2经冻结、实读影响和版本发布后，仅从第七章起的新借验采用三枚押钱，归凭结清退三枚；以前按两枚收取的借验仍按原收条退两枚。第1–6章的缴二枚、退二枚及人物当时所知完整保留，严禁追溯改价。此规则发布不等于人物已经知道、已经发生新借验，也不授权撰写第七章。
6. 本轮只写六章，到第六章停止。第七章及更远内容仅可讨论；具体未来剧情未获模拟作者确认。
