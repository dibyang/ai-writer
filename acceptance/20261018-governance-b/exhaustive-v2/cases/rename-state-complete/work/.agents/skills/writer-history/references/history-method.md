# 史料与讲述

提炼自本地历史散文项目的史料与引证规范 v0.7、亲和讲述规则 v2.9。原书特定篇幅、双票数量、删字阈值和章末栏名不强制推广到所有项目。

## 证据层级

接近事件的史书、文书与出土材料是核心来源，但须识别成书时间、立场和传承偏差。后出文献用于互证补缺；现代研究用于解释争鸣；百科、数据库、媒体与检索摘要只提供线索。两书若节录共同史源，不能当成两条独立证据。

事实卡 JSON：

```json
{
  "status": "verified",
  "claims": [{
    "type": "direct",
    "statement": "这里写已经核对的事实陈述",
    "boundary": "该条材料能确认的范围、异文及不能推出的结论",
    "sources": [{
      "title": "实际读过的史料书名",
      "locator": "已经核对的卷次、篇名或版本页码",
      "excerpt": "核对过的短原文；不能拿搜索摘要代替",
      "checked_at": "核验日期"
    }],
    "source_dependency": "与其他史源的依赖关系或尚未核清的部分"
  }]
}
```

以上为格式说明，不能把这些文字当作核验过的材料。工作中先用 status=draft，核查原文后才更新 verified。程序只检查字段与声明，不判断内容真伪。

## 四层边界

| 类型 | 做法 |
| --- | --- |
| 直接史实 | 可追溯人物、时间、关系、行动、数字与结果 |
| 合理推断 | 从已确认条件推出常识后果，不新增个体未载经历、精确数或排他责任 |
| 场景复原 | 只补低风险非因果缝隙，显出不确定性，通过删除测试并统一披露 |
| 关键归因 | 动机、罪责、死因、战争责任等依证据强度表述，争议不压成唯一答案 |

私下对白不能凭复原补写。现代类比限定当前功能，不把古今权责画等号。人口、军队、粮储与购买力先核时代、地区、单位和统计口径，不能输出伪精确换算。

## 文气保护

先把具体人物与麻烦放到眼前，让可核行动推动解释。叙述者可以有体谅、惊讶和态度，不替人物编心声，也不拿受害者痛苦抖包袱。

自然表达检查做自然转述、搭配拆分、具体关系和朗读改口四项。转述不同不意味着原句错；除明确语言错误外，确认问题需要两项以上证据和可说明的阅读损害。有效拟人、对称、书面节奏和余味可保留。

每轮润色先列声音资产，再列阻断项。更短、更快不自动更好；保留自然过渡、呼吸和承担情绪的停留。作者明确换风格时建立新基线，旧风格不再享有文风优先权。

连续阅读检查是否反复解释同一制度、章节都像整理材料、人物换线后失去处境，以及声音是否随材料变化。模型自检、隔离代理与真人无提示阅读分别记录；不得伪造独立票或市场证据。
