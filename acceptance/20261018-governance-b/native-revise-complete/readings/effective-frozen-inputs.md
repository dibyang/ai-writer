# 《铜桥来信》定位

本轮独立测试原创小说，非真实历史。以阿禾有限视角写一座河镇的寄信旧事：她要替已故母亲领回迟到的信，先要查清一块铜片为什么被当作冒领凭据。读者跟随普通人的查问、核验与相互让步，不靠侦探式全知。

六章正文各600–900汉字，两卷各三章；第六章完成本次信件和缺角印的回收。后续只留生活空间，不扩张阴谋。桥名来自桥栏铜饰，人物和制度均虚构。

阿禾做补衣活，怕替母亲辩解时反而伤及旧友；驿柜值守人周叔看重交接有据，愿协助但不能放出原账；修锁匠柳婆惜物、护短，会承认自己的手艺痕迹。三人的意见不同，逐步以可查证据建立信任。

# 文风与声音

近距离第三人称，随阿禾感知。水、铜、纸和缝线形成生活质地；每章一两处具体感官即可，不堆叠象征。对白按利益和熟悉程度说话：阿禾问得直接，周叔讲手续但会替人省事，柳婆嘴硬而肯动手。

# 全书骨架（本轮六章试写方案）

第一卷《凭铜寻信》1–3：阿禾拿母亲留的铜片问信；第一章保留两枚旧报价；第二章次晨得知三枚，补足一枚交押，柜面保留铜片登记；第三章见旧封口缺角印，尚不能据此指认。卷末以可查的修印线索转向柳婆。
