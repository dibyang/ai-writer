ai-writer 0.5.0 — Codex 文件创作工具（Node.js >=20，无额外依赖）

init --path 新目录 --kind novel|screenplay|history|essay --title 作品名
  建立作品和随附工具，不覆盖已有目录。
plan --project 作品目录 --input 细纲.json
  保存下一章、场或篇的细纲。
context --project 作品目录 [--purpose discussion|draft|revision] [--unit 1] [--max-chars 40000]
  discussion 无需下一章细纲，只恢复当前任务/范围/决策；draft（默认）及 revision 需符合授权并有细纲。字符预算默认40000、最低1000，超出预算会报错，不静默截断。
record-template --project 作品目录 --unit 1 --draft 正文/0001-来信.md
  动笔前取得登记模板。短篇填写 snapshot，长篇填写 changes；保留真实来源哈希。
record --project 作品目录 --input 登记.json
  填写写前模板中的实际摘要与追踪，然后顺序登记正文。不要从手册抄写假哈希。
status --project 作品目录 [--view compact|full]
  查看进度、过期来源、未登记正文和建议下一步。
check --project 作品目录
  检查机械一致性与未登记正文；不裁定文学质量。
rewind --project 作品目录 --from 1 --expected-revision 当前修订号
  备份并作废指定单元及后续追踪，保留正文。先 status 获取当前修订号。
export --project 作品目录 --out 作品目录外的新目录
  导出已登记草稿，列出未纳入的正文；不覆盖旧导出。
long-enable --project 作品目录 --expected-revision 当前修订号
  备份迁移到长篇协议，再用 volume 建分卷计划。
volume --project 作品目录 --input 分卷.json
  保存连续覆盖的分卷与剧情单元计划。
outline --project 作品目录 [--unit 1]
  查看长篇当前卷与剧情单元契约。
recall --project 作品目录 --query 关键词 [--limit 20]
  查找线索与证据位置；完整账本ID匹配优先，空白分词为AND。默认20条，limit允许1—100；根据结果回读正文。
review --project 作品目录 --input 审查登记.json
  登记已实际阅读的报告及范围内全部正文哈希，不自动审稿。下列单章示例；多章须列齐实际阅读范围的全部路径。
import-index --project 作品目录 --input 源文件清单.json
  为空的长篇作品冻结自有旧稿。files 必须按章顺序；相对源路径按命令 cwd 解析。
import-status --project 作品目录
  查看导入进度、can_continue 与阻断路径。完成后转为正常续写。
import-next --project 作品目录
  取下一章冻结稿，实读、规划、登记后再取下一章。未登记时重复返回同一章。
import-relink --project 作品目录 --input 路径映射.json --expected-revision 当前修订号
  为同一冻结内容重定位原文件；内容哈希不同会拒绝。保留定位历史，不修改冻结清单与正文。
style-scan --project 作品目录 --draft 正文/0001-标题.md [--out 审查/语言线索-r1.json]
  只读扫描表达线索，供去 AI 味实读复核；不自动改稿、不打 AI 概率分。可检查未登记正文。
doctor [--project 作品目录]
  检查当前工具，或指定作品的随附技能、用户文档和工具文件。
governance preview|migrate --project 作品目录 [--input 迁移.json]
  preview 只读；migrate 显式备份迁移为 schema 3，保留事实。须提供 expected_revision、operation_id 和 author_evidence，不自动升级随附工具。旧工具会拒绝新状态。
workflow show|set --project 作品目录 [--input 阶段.json]
  show 只读；set 登记本轮阶段、任务和有限正文/修订范围。输入含 expected_revision、operation_id、author_evidence、workflow；普通作者用自然语言说明，由 Codex 按手册准备 JSON。
decision current|list|set --project 作品目录 [--unit 7] [--input 决策.json]
  当前作者计划与事实 ledger 分开。set 逐项列出 candidate/confirmed/withdrawn、采纳/排除/未决项；同主题同范围取代用新 ID + supersedes。不自动采纳整稿。
tool identify|compare [--project 作品目录] [--other 工具或作品目录]
  只读计算受管内容指纹；compare 指出同版本不同内容、缺失文件和定制差异。本批不提供更新或替换。省略 --project 时检查当前调用工具。
protection preview|enable --project 作品目录 [--input 启用.json]
  显式将 schema 3 备份升级为 schema 4，保留事实/原来源；旧 0.4 工具拒绝新状态。不更新随附工具。enable 输入 expected_revision、author_evidence。新作品默认已启用。
source list|freeze|impact|bind|publish|stage|cancel --project 作品目录 [--input 来源.json] [--unit 7]
  冻结设定/细纲/卷纲/事实卡，按章生效；impact 只读，publish 必须绑定实际预览、实读报告和作者授权。历史变更先 stage，进入持久阻断，再在独立修订区发布和重登。原 source_hashes 不改写。详见手册。
revision list|begin|resume|abort|transfer|prepare|commit|recover|unlock --project 主作品目录 [--input 修订.json]
  独立修订区覆盖实读、改稿和重登；begin 不推进业务修订号。候选写命令带 --revision-token 所有者令牌。prepare 要完整尾段重登及一次模型实读复核；commit 全局 CAS、多文件事务、state 最后替换。中断后普通读写暂停，显式 recover；第三方字节冲突保留三方。不自动抢锁；unlock 仅处理有明确授权与匹配哈希、且原进程已结束的遗留锁。
gate <story-gate-studio 参数...>
  调用主项目原有质量引擎；独立作品不含该引擎。
