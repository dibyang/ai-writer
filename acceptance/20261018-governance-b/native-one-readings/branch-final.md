# 第一章 铜片的耳

阿禾拆开母亲旧棉袄的里衬时，针尖碰出一声轻响。她以为是遗落的顶针，伸进两根指头，摸到一块薄铜片。铜片的耳向内折着，正面有一条斜斜的浅划痕，像谁试过刀，又舍不得真切下去。

铜片底下还压着纸条：“桥头问信。”只有四个字。母亲去世后，她收过欠账、补过屋漏，连灶边半罐盐都挪过两回，却直到这个秋天才拆这件棉袄。袖口磨亮了，她本想裁成一双鞋底。

她把纸条折回去，另外找块净布裹住铜片。天还没黑，桥头驿柜的木窗应当开着。她洗掉指上的靛蓝，走到门口，又回来把那件棉袄摊平，免得散棉落进灰里。

桥面留着午后雨水。周叔正把窗板往槽里插，看见她，留了半扇。

“补好的衣裳明天取。”他说。

“今天不是送衣裳。”阿禾摊开净布，“这东西，能领什么信？”

周叔没有立即拿。他先问从哪里得来，又问她母亲的名字。听见名字，他把已经挂上的门钩摘了，点亮柜里的小油灯。铜片在两人之间泛着暗黄，她忽然觉得自己问得太迟。

“旧柜的铜凭。”周叔说，“有些信迁柜时没交清，留凭的人来查。可这耳折过，得对旧簿，不能拿一片铜就开信箱。”

阿禾把纸条也给他看：“这是她的字。”

“我认得。”周叔声音低了些，“认得字，也得查东西。前些年有人捡了铜凭来冒领。你的信，我更不能随便交出去。”

他取来薄簿，只在窗台翻开能见光的一页，用手指往下找。阿禾想凑近，他便把簿子转给她看：母亲的名字后头添着一个小小的“候”字，旁边还有旧柜号。她摸了摸净布边，忍住没问那一个字究竟候了几年。

“明早来办借验，押钱两枚。铜凭要过手登记，对完归档，押钱退你。”

“现在不能查？”

周叔给她看窗外的水：“旧库在下坡，灯照不清台阶。信不会因多等一夜又走掉。”

阿禾重新包好铜片，放进贴身衣袋。她不是十分信最后那句话，但周叔肯让她看见那个名字，她就还能再来一趟。回家经过桥栏时，她没有像往常一样赶路，隔着衣料摸了一下铜片折起的耳，才想起晚饭的米还没淘。

# 第二章 两枚押钱

天刚放亮，阿禾就把钱绳上的结解开了。两枚钱抵得一顿荤菜，她在桌上摆了一会儿，还是拿净水洗去孔里的积垢。周叔说押钱会退，她信手续，也想让这两枚钱好认些。

驿柜前已经有人等着寄包。她站在末尾，听见一只公鸡隔着竹篓打鸣，篓上写的却是“药材”。周叔让寄包人重写，惹来几声抱怨。阿禾没笑，忽然明白昨夜那句认得字也得查东西，不只是说给她听的。

轮到她，她把两枚押钱逐枚放到窗台上。周叔数过，收入标着借验号的小木格，给她一张收条，写明“收押二枚，归凭退还”。她把收条读了两遍，折进袖里的布袋。

“要是信还没找到呢？”

“凭归柜，押钱就退。领信另记，不混在一起。”

阿禾这才取出铜片。周叔接过铜片，放在柜内的白布上。他没有去扳那只折耳，只拿竹签沿着浅痕比了一遍，在借验簿画下形状。阿禾看见他写“耳折，斜痕”，又补了母亲的姓名。

“昨日为何不直接收下？”她问。

“没开收条，你走了，我也说不清什么时候到我手里的。”

她想到自己给人补衣，常把熟客的衣裳挂在门后，说一声就算收了。真丢一件，怕是连颜色都得争半日。她便不再催，等那一行字上的墨失了亮光。

周叔把铜片交还阿禾，让她当面对照。折耳和浅痕都在。她用原来的净布包好，系进腰间的小布袋，收紧袋口。铜凭得带到下坡的旧柜，与柜里的验样对上；周叔带簿和钥匙，谁也不必把东西递给路上搭话的人。

他们出门时，寄鸡的人又追来问日子。周叔停在门槛上答，阿禾先走了两步，看见坡口的青苔，便站住等他。昨夜的雨把石阶洗得发白，沟里一股细水急着往河边去。

“你娘来查过一回。”周叔跟上来说，“后来柜子搬了，怕是没再碰上。”

阿禾本想问他怎么记得这么晚，话到嘴边又改了：“那回她自己来的？”

“自己。还替我把这钥匙绳缝紧了。”

他举起钥匙，绳头密密缠着一截褪色蓝线。阿禾看了片刻，把腰间布袋往前挪了挪。她跟着那串钥匙下坡，头一回觉得，今天找的或许不只是柜子里的一封信。

# 第三章 缺掉的一角

旧库的门比驿柜矮，周叔进门先侧了肩。阿禾跟在后头，闻见晒不透的木头味。墙下垫着两排砖，柜脚搁在砖上，外沿崩下的碎砖散在脚边。她蹲下去将碎砖拨到墙根，腾出落脚处，才把腰袋解开。

周叔照着簿上的旧柜号开锁，里面没有散信，只有几包扎好的纸。迁柜时另立了待核一包，凡印记不全、去向未清的，都放在那里。他把包袱放上长凳，解结前叫阿禾把铜片放在净布上，免得掉进砖缝。铜片仍放在她手边，周叔只看没有拿。

第三只封套上，阿禾认出了母亲的姓，名字却被一块水渍漫住。封口压着方印，右下角空了一块，露出纸本来的黄。她低头，又把封套转向窗光；空处的边缘不齐，周围红色却很深。

“有人揭过？”她问。

“看这一角，断不了。”

周叔翻出夹在旧页里的印样，让她隔开比着看。印样的右下也缺了一小块，大小相近。他在两张纸之间留着一掌宽，没让它们叠在一起。

“以前有人说是仿印，迁柜时就搁下了。我来接柜，接的也是这个包。”

阿禾看着水渍底下那一点残墨，想起母亲常嫌她洗菜舍不得换水。她几乎要说这就是自家的信，末了只是问：“谁见过这印？”

周叔想了一阵：“柳婆修过柜锁，也修过印匣。她还留着旧东西，能问问。”

他不肯让原套出库，拿一张薄纸盖在印样上，阿禾用炭条轻轻描出边线。她本想描齐那个缺口，笔到那里才停住：缺的就该空着。周叔在纸边写下取样日期，又注明出自旧页，并不是从封套上拓下来的。

“铜凭也带去？”

“不用给她看。先问印，省得几样搅在一起。”

阿禾把铜片交给周叔。周叔连净布收入旧柜上层的借验匣，写下暂存，扣锁后让她试拉了一下。她摸到锁鼻上的凉意，才将描样收进袖袋。铜片还没算归档，收条上的两枚押钱也仍在柜面等着结清。

出库时她回头，看见周叔把封套重新放回待核包。那一角空白没有告诉她是谁的错。她得沿坡走上去，问问柳婆，为什么连旧页上的印也缺在同一个地方。

# 第四章 柳婆的抽屉

柳婆的铺子只有半扇门开着，一条狗卧在门后，听见脚步也不挪。阿禾从它尾巴边跨过去，把描样放在没有铁屑的那块桌角。

“周叔让我来问，这个角为何缺着。”

柳婆还在锉钥匙，没抬头：“纸缺了，找糊纸的。”

“纸没缺，印没印上。旧页和信封上都有。”

锉声停了。柳婆拿起纸，先看周叔写的小字，再把描样转过来，问阿禾是不是亲眼见过封套。阿禾说了水渍和右下的空白，也说这只是描的旧页，封套没有带出柜。

“你倒晓得分清。”柳婆把钥匙压住纸角，“不过这几条炭线，认不出是哪一方印。”

她拉开最底下的抽屉。阿禾往后让了一步，抽屉才越过她膝前。里面没有金银，都是断簧、铜屑和用过的纸。柳婆一张张拨开，找出夹在账皮里的一小条，红印旁写着修补工钱。

“旧柜的印跌过，右下崩了。我补过铜，怕磨坏字口，没敢磨齐。”

纸条上排着三个方印，头两个都缺右下角，最后一个稍完整。柳婆拿指甲指给她看：“垫软些，压重些，这一角才肯吃色。那时叫他们换一方，嫌贵，照旧用了。”

阿禾想起第三只封套周围很深的红：“可那封信，别处印得重。”

“那也未必能压着低处。你带我看原印。”

阿禾没有马上应声。她本来只想拿一句话回去，如今却得让这位腿脚不好的老人下坡。柳婆看她望门口，取过墙边的竹杖：“你别替我疼。修成什么样，我自己去认。要不是这一方，也当我走了趟路。”

她把试印纸放进硬纸夹，搁在自己篮里，没让阿禾代拿。出门前又问：“信是谁的？”

“可能是我娘的。名上沾了水，还没认全。”

柳婆望了她一眼，收起桌上的锉：“那就走慢些，别在台阶上催我。”

阿禾扶住门，让她先出去。到坡口，她才将原来的描样另折好，仍收回袖袋。柳婆篮里是修印时留下的纸，她袖中是今早从旧页描来的线；两样都要带回去，却都不能替柜中的原印开口。

# 第五章 旧印归柜

柳婆进旧库时，周叔正在擦长凳。她没有接那块湿布，先叫他找原印。印匣封存在柜底，封条上有接柜日期；周叔记下开封，才将印匣捧到窗前。

方印右下接着一小块颜色略深的铜。柳婆把竹杖靠稳，取一根直竹签贴住印面，叫阿禾迎着光看。竹签下露出一线空隙，正在补角那里。她不再多说，让周叔蘸色，在硬板上的废纸压一回，又垫上折布压一回。

头一印缺右下，第二印那一角浅浅显了出来。柳婆取出旧试纸，周叔将它与旧页、封套分开放着。印内小字左边还有一道短缺口，四处都对得上。

“低了一点，硬纸碰不着。”阿禾说。

“是我没磨齐。”柳婆答。

周叔在旧簿上写下复验经过，没再写仿印。他又翻找迁柜的对照页，发现封套号是九，誊到待核栏却成了六。名字遇水，柜号又错，先前的疑处便一层压着一层，谁也没有重新核。

周叔从借验匣取出铜片，摊布让阿禾看过折耳浅痕，再翻背面的旧号。九字底下的短竖与根票画样相同；根票另记着母亲全名和寄件人的住址。阿禾念出南埠榆树巷，那里住着姨母，门前的榆树是外公种的。周叔逐项问她，并把答话记在领信栏。

“没有哪个印能替我免掉查簿。”他停下笔，“我接的时候也该多翻一页。”

阿禾没说不怪他。她用手背抹掉凳上的灰，给柳婆腾出坐处。过了一会儿才问：“如今能领了？”

周叔点头，把铜片连净布放回旧柜上层借验匣，登记归档并扣锁。阿禾在簿上签了名，铜片从此留柜，不再随她出门。柳婆也签了复验那一栏，将自己的旧试纸收回篮里。

周叔将原印封回印匣留在柜底，把待领封套收入随身布囊，锁好库门，才与她们回到坡上的驿柜。他核对收条，从原借验号木格取出两枚押钱，平放在阿禾掌心，写下“二枚已退”。她数过，正好两枚，穿回钱绳。交出去时洗亮的孔边，沾了一点木格里的细灰。

信另作签领。周叔双手把未拆的封套交给阿禾，她沿着没沾水的边拿住，没有立刻揭封。窗外有人催寄包，她退开半步，让出窗台。迟了这么久的信，终于可以由她自己决定，在哪里打开。

# 第六章 信纸背面

阿禾回家先烧了水。水壶坐上灶，她才解下钱绳，把退回的两枚钱放进米缸旁的小碟。来回走了一上午，手心还留着铜的气味，衣袋里却没有铜片了。她拍了一下空袋口，想起它已经留在锁着的旧柜里，便把手收回来。

信放在裁衣桌上，旁边就是那件拆了里衬的棉袄。她找来剪子，沿封套顶端剪开细细一条，避开水渍，也避开封口的红印。里面两张纸，没有银票，没有催债的数目，只有一张鞋面花样和姨母的信。

姨母说，托找的花样终于找到了，照阿禾如今的脚长，再放宽半指就好。又说母亲寄去的旧样留在她那里，等过河赶集时带回，不必另裁。写信的日子在两年前，正是阿禾长脚、旧鞋挤得脚趾发疼的那年。

她一直以为母亲那阵子只顾给人补衣，忘记了她想要一双新鞋。那时她赌气，把破鞋踢到门后，光着脚走了半日。母亲晚上替她挑出脚底的木刺，一句也没提鞋样已经托人去找。

信的末尾还有一行：“别总挑便宜的线，你小时候也爱穿红的。”

阿禾读到这里，去翻针线篮。篮底有一截旧红线，比她惯用的粗，打结处被人用指甲剔得很松。母亲也曾是会为了线色讨价还价的人，只是她记住的总是母亲低头数钱的样子。

壶盖跳了两下。她提水时洒出一点，烫得缩了手，忙去舀凉水。先前没吃午饭，如今肚里空得发响，她把早上的半块饼搁到灶边烘，拿碗压住信，免得穿堂风把纸吹落。

吃过饼，她把鞋样夹进母亲留下的旧样册，信另收入桌上木盒。木盒合上前，她又拿出来看背面。纸是空的，连姨母惯常舍不得浪费的边角也空着。她想写点什么，磨好墨，笔悬了许久，只落下“姨母”两个字。

母亲的死讯早已托人捎去，她不必再把那一日写一遍。她想告诉姨母的，是信找到了，鞋样也到了，自己这两年脚没再长，还能照着做。

最后她在信纸背面添了一句：“过桥来看我吧，我给你留饭。”她把信搁回盒中。墨未干，她便将木盒敞着，转身量棉袄还能裁下多大一片。窗下有光，够她把一条线从头理到尾。
