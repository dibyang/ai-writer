# 《铜桥来信》定位

本轮独立测试原创小说，非真实历史。以阿禾有限视角写一座河镇的寄信旧事：她要替已故母亲领回迟到的信，先要查清一块铜片为什么被当作冒领凭据。读者跟随普通人的查问、核验与相互让步，不靠侦探式全知。

六章正文各600–900汉字，两卷各三章；第六章完成本次信件和缺角印的回收。后续只留生活空间，不扩张阴谋。桥名来自桥栏铜饰，人物和制度均虚构。

阿禾做补衣活，怕替母亲辩解时反而伤及旧友；驿柜值守人周叔看重交接有据，愿协助但不能放出原账；修锁匠柳婆惜物、护短，会承认自己的手艺痕迹。三人的意见不同，逐步以可查证据建立信任。

# 文风与声音

近距离第三人称，随阿禾感知。水、铜、纸和缝线形成生活质地；每章一两处具体感官即可，不堆叠象征。对白按利益和熟悉程度说话：阿禾问得直接，周叔讲手续但会替人省事，柳婆嘴硬而肯动手。

不预知别人心意，不重复解释每个隐喻，不把所有情绪写成身体发抖。章节允许日常停顿；查清证据后给人物处理情绪的篇幅。标题不计入正文汉字数。

# 权威规则 v1

这是独立验证小说的当前创作规则，来源为研究/测试授权原话.md。细纲和卷契约只表示计划，正文和带本章引文的增量追踪才表示已发生。

1. 主角阿禾；限制为她合理可知的近距离第三人称。铜片有折起的耳、一条浅划痕，信件封口有一枚右下缺角的方印；观察、推断与查明须分开。
2. 铜片每次交接须写出交出人、接收人、存放地点与状态；人物没在场或未获转述不能突然知道新结论。不可用新解释改掉旧观察。
3. 第一卷1–3章埋缺角印，第二卷4–6章查清：缺角是修补后的旧柜印痕，不能仅凭相似印记认定偷信。第5章完成解释和退钱，第6章处理信件与情感余波。
4. 第1–6章适用当前押钱制度：借验铜凭交两枚押钱，归还铜片并结清登记后退两枚。第2章缴两枚，第5章退两枚，不抵扣、不漏退。
5. 第七章起的三枚新规则须另经冻结、实读影响和版本发布才生效；本v1未发布三枚制度。严禁把新数额追溯到前六章。
6. 本轮只写六章，到第六章停止。第七章及更远内容仅可讨论；具体未来剧情未获模拟作者确认。

# 全书骨架（本轮六章试写方案）

第一卷《凭铜寻信》1–3：阿禾拿母亲留的铜片问信；第二章交两枚押钱，柜面保留铜片登记；第三章见旧封口缺角印，尚不能据此指认。卷末以可查的修印线索转向柳婆。

第二卷《落印有声》4–6：柳婆辨旧手艺，回柜验印；第五章说明旧印右下曾补角，误扣的信找到，铜片归档并退两枚；第六章阿禾自己拆信，读到母亲托人捎回的寻常嘱咐，决定给仍在世的姨母回信。

以上均为计划，不是登记事实。终局承诺是信件交接和缺角印得到可核解释，普通人承认手续造成的耽搁；不预设幕后恶人。后续结构待讨论，本轮无第七章细纲。
