# 第二章 三枚押钱

天刚放亮，阿禾就把钱绳上的结解开了，照昨夜说的数出两枚钱。两枚钱抵得一顿荤菜，她在桌上摆了一会儿，还是拿净水洗去孔里的积垢。周叔说押钱会退，她信手续，也想让这两枚钱好认些。

驿柜前已经有人等着寄包。她站在末尾，听见一只公鸡隔着竹篓打鸣，篓上写的却是“药材”。周叔让寄包人重写，惹来几声抱怨。阿禾没笑，忽然明白昨夜那句认得字也得查东西，不只是说给她听的。

轮到她，窗边多了一张纸，写着“借验押钱三枚”。

“昨晚不是两枚？”阿禾没解钱袋。

“今早才换的。”周叔指了指落款的日子，“照新数收，归凭三枚全退。”

她把钱绳又解开，另取一枚，和洗净的两枚并排放到窗台上。新添的那枚孔里还带着黑垢，她拿指甲抠了抠，才推过去。周叔将三枚押钱逐枚数过，收入标着借验号的小木格，给她一张收条，写明“收押三枚，归凭退还”。她把收条读了两遍，折进袖里的布袋。

“要是信还没找到呢？”

“凭归柜，押钱就退。领信另记，不混在一起。”

阿禾这才取出铜片。周叔接过铜片，放在柜内的白布上。他没有去扳那只折耳，只拿竹签沿着浅痕比了一遍，在借验簿画下形状。阿禾看见他写“耳折，斜痕”，又补了母亲的姓名。

“昨日为何不直接收下？”她问。

“没开收条，你走了，我也说不清什么时候到我手里的。”

她想到自己给人补衣，常把熟客的衣裳挂在门后，说一声就算收了。真丢一件，怕是连颜色都得争半日。她便不再催，等那一行字上的墨失了亮光。

周叔把铜片交还阿禾，让她当面对照。折耳和浅痕都在。她用原来的净布包好，系进腰间的小布袋，收紧袋口。铜凭得带到下坡的旧柜，与柜里的验样对上；周叔带簿和钥匙，谁也不必把东西递给路上搭话的人。

他们出门时，寄鸡的人又追来问日子。周叔停在门槛上答，阿禾先走了两步，看见坡口的青苔，便站住等他。昨夜的雨把石阶洗得发白，沟里一股细水急着往河边去。

“你娘来查过一回。”周叔跟上来说，“后来柜子搬了，怕是没再碰上。”

阿禾本想问他怎么记得这么晚，话到嘴边又改了：“那回她自己来的？”

“自己。还替我把这钥匙绳缝紧了。”

他举起钥匙，绳头密密缠着一截褪色蓝线。阿禾看了片刻，把腰间布袋往前挪了挪。她跟着那串钥匙下坡，头一回觉得，今天找的或许不只是柜子里的一封信。
