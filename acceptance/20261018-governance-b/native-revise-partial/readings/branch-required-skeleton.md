# 全书骨架（本轮六章试写方案）

第一卷《凭铜寻信》1–3：阿禾拿母亲留的铜片问信；第一章保留两枚旧报价；第二章次晨得知三枚，补足一枚交押，柜面保留铜片登记；第三章见旧封口缺角印，尚不能据此指认。卷末以可查的修印线索转向柳婆。

第二卷《落印有声》4–6：柳婆辨旧手艺，回柜验印；第五章说明旧印右下曾补角，误扣的信找到，铜片归档并退三枚；第六章阿禾自己拆信，读到母亲托人捎回的寻常嘱咐，决定给仍在世的姨母回信。

以上均为计划，不是登记事实。终局承诺是信件交接和缺角印得到可核解释，普通人承认手续造成的耽搁；不预设幕后恶人。后续结构待讨论，本轮无第七章细纲。
