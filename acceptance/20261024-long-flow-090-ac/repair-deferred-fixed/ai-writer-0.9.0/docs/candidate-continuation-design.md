# 独立候选的限章续写采纳设计

状态：限章功能已实现，0.9.0 开发版。此批暂停扩大长篇实跑，只处理已有独立候选的第七章登记阻塞。固定制品及完整验收记录单独保存在 `acceptance/20261024-candidate-continuation-fix-y/`，未发布正式版本。

## 问题与边界

旧修订会话固定为修订第一至六章；增加正文授权不能扩大旧会话。活跃会话绑定旧构建，不能覆盖随附工具。原候选、主稿、旧令牌、既有消费链和封存稿均保留。

本批派生新的独立续写候选，完整复制六章登记状态、增量账本、不可变对象、正文及实际来源依赖，而不是 init 后重新登记六章。新协调目录仅用于保留基线、原始动笔前清单、授权证据和新会话。新候选仅允许追加一章；不实现发布、合并主稿、修订旧章、升级原作品或第八章创作。

## 接口及保护

- `revision continue --project <旧候选> --input <JSON>`：显式所有者令牌、候选 revision、候选 state 哈希、旧 session 哈希、全新目标目录、单章范围、作者原话证据、已有稿及动笔前清单哈希。
- 源候选和原协调目录加锁后核对 CAS、旧构建、基线及全部声明来源；复制后再次核对，目标必须不存在。不刷新旧基线，不变更旧会话。
- 新会话使用当前构建和独立令牌，冻结旧六章前缀以及来源。拒绝旧章修改、越界授权、私有来源旁路、旧构建写入和 prepare/commit。
- `revision adopt`：在正常公开来源细纲建立后，显式采纳封存正文，产生绑定当前上下文的采纳凭据；凭据分别保留旧清单和当前登记上下文，不把后来建立的正式细纲说成动笔前模板。
- `.writer/drafts` 中的旧准备材料只能显式列为审计附件；不得成为正常创作来源。其他私有目录仍拒绝。

失败保留源和候选；目标不覆盖、不自动重试或删除。未成功创建的目标保留供核查，换新目标前先阅读错误。令牌防误操作，不承诺同用户文件系统隔离；作者证据是原话记录，不是身份认证或时间认证。

新目录初始化仅提供新工具资源，业务树由原候选完整复制，原候选没有的初始化占位文件会从新副本移除。旧 state 原字节另行冻结，六章登记行、事实基线和 journal 不重建。新副本开启独立的工具控制账，旧控制历史仍在冻结原 state 中，旧登记行的 tool_build_id 保持原值；这不宣称原工具已经升级。

## 真实接入补充：未消费规划新增

原主稿 state/构建和旧基线1995文件未变，只有一份后来保存的未来规划新增时，首包严格库存比较会拒绝。补充可选 acknowledged_parent_additions，精确绑定新增原路径/哈希与原写前清单材料；只限直属大纲 Markdown、最多16项，无目录/通配承认。主稿和候选 state 的任何已有引用均拒绝。修改、删除、state变化、未列明新增仍拒绝，普通修订提交策略不改。

实际主稿规划与候选私有准备附件同字节，和公开细纲字节不同。允许以原清单中的显式审计附件证明对应关系，保持附件身份，不升级为公开创作来源。新候选保留原件冻结对象、原基线身份和完整接受库存，采纳凭据绑定该审计；结束时做完整库存 CAS。原主稿、新增规划、旧会话及旧候选均不变。

后续验证与新固定包另记在 `acceptance/20261024-candidate-parent-addition-fix-z/`；上一轮 Y 包及验证记录保持原字节。

## 未消费下一章计划及现有派生接管

实际Z派生继承了未登记0007.json，官方plan7改写后context成功，adopt被错误当旧前缀漂移拒绝。仅当旧六章和原始写前清单均未消费时，此精确计划路径可在写前变化；旧章、其他来源保护不放宽。登记后绑定新章实际计划哈希，改写拒绝；已消费计划在plan写入之前拒绝。

continue-repair限于尚未登记新章、state原字节未变且仅此计划不同的可编辑续写候选。按所有者与state/session/base/plan CAS、原协调目录/工具完整性、当前context及公开来源核查后复制到全新协调区，冻结旧计划、旧基线、当前状态和接管审计，保持原派生/工具/基线原字节。新候选继续原范围，不授权8、不提供发布或全面升级。复制后再核两侧库存、原session/base，失败不注册活跃新会话。

本窄修复与接管记录另存 `acceptance/20261024-candidate-plan-handoff-fix-aa/`。Y/Z包及封存证据均不改写。

## 验收

使用独立测试作品覆盖六章旧候选到第七章采纳、跨进程恢复和事实承接；核对正文、摘要、来源哈希、journal 链及旧六章记录逐字节不变。原主稿及原候选前后库存一致。

异常覆盖缺授权、错误令牌、修订号/state/session CAS 漂移、来源漂移、未声明私有附件、正文哈希不符、重复目标、缺采纳凭据、旧章写入、第八章、prepare/commit 和普通修订回归。另运行 npm test、npm run doctor，对最终打包制品解压后实跑。脚本检查仅证明机械边界，实读报告另记，不宣称真人审稿。

交付固定制品及 SHA-256、完整命令及失败记录、变更范围和操作步骤。真实作品由小说会话核实备份与来源后操作，本会话不安装、不写入真实作品，不自动提交或推送。
