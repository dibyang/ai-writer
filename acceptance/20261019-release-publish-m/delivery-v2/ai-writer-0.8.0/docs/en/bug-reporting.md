# Bug reports

[中文](../bug-reporting.md)

Use the [GitHub issue form](https://github.com/dibyang/ai-writer/issues/new/choose). Search existing reports first. Include the package version, resource profile/content ID, OS, Node version, Codex or CLI entry, expected and actual behavior, and an anonymous minimal reproducer. For concurrent editing, include the operations, number of sessions, frequency and first failure.

Prefer a test in a new anonymous directory. Keep error codes, exit codes and call order. Do not paste complete tool output, manuscripts, author rules, research, state, tokens or private paths. For updates, include both old and new build identities; matching version numbers do not establish identical content. Preserve failures and backups rather than editing state or deleting locks.

Follow the [security guide](SECURITY.md) for sensitive reports and [contribution guide](CONTRIBUTING.md) for changes. The Chinese guide is authoritative.
