# 小说局部诊断：开篇、转场、对白与章末

只用于小说相应局部问题。先完整读取受影响场景及相邻承接，核当前人物状态和作者目标；有因果或知情错误先修它，再处理词句。需要作者授权的核心改变照原流程处理。只审查时不改正文，已登记稿走独立修订；审查者性质和范围如实记录。

## 先判断哪里断了

| 读者遇到的问题 | 应检查的证据 | 最小处理方向 |
| --- | --- | --- |
| 开篇热闹但不知为何跟随 | 当前处境、人物想要的事、题材承诺如何进入事件 | 让已有设定影响一次具体选择，不靠追加设定介绍 |
| 换场以后像换了故事 | 两场的时间地点/视角、未完事项和当下目标 | 补必要定位或后果；空间与身体移动要可行 |
| 台词很多但谁说都一样 | 双方知道什么、想促成什么、顾忌谁、选择何种回应 | 调整请求、回避或行动，让信息服务于当前关系 |
| 章末很响，下一章没接 | 本章实际变化、留下的待办及下章第一场 | 接住原问题，允许有限回答后开启自然新问题 |

“第二天”、空行、评论、长句、抒情和温和对话本身均非错误。不要从命中词或固定字数直接下结论；一个确定的连续性错误也值得处理，不等凑够两项。

## 开篇与长度承诺

按作者的阅读目标看开场是否建立人物与具体处境，信息是否足以理解其行动。商业连载可检查主要期待是否及时进入事件；慢热、日常和文学小说允许先靠声音、观察与关系吸引读者。保留有效天气与生活描写，不固定前几百字必须出事故，不为“抓人”透支后文真相。

## 两场之间怎样接

对照上一场最后的动作/决定与下一场刚开始的情况：相隔多久，谁在何处，哪些伤势、物件、关系和信息仍然有效，变化靠哪件已写或可合理省略的事发生。只补读者确实缺的环节；正常省略不需要逐步写赶路。

原创例：旧段“她扶着右臂离开诊室。第二天，她搬起柜子。”若已写右臂不能负重，问题是行动限制丢失；增加“晨光里”无效。可以在授权内改成她请同伴搬柜，保留伤情，仍让她负责找钥匙。若两章间已有明确康复时间，则不应硬加受伤反应。

情绪承接允许克制、掩饰和暂时搁置；不能为证明连续而每段重复疼痛或愤怒。视角切换用足够的定位，回忆/梦境进入与回归要能辨认，不要求每次借物件或蒙太奇。

## 对白为何发生

看此刻说话者希望对方做什么，以及他会说、不会说、暂时不知道什么。信息可以清楚讲出；双方已知的背景若仍需说，应有此刻的理由。合作、安慰和玩笑不必改成彼此施压，声音差异也不靠给每人贴口头禅。

原创例：两位合作修表的朋友无需互相解释“游丝是计时部件”。一人说“这只归我，你去吃饭”，另一人把饭盒推近，可以保留照顾与分工；若来的是第一次修表的顾客，必要解释则有价值。先核关系和受众，再决定是否删去说明。

## 章末与下一场是同一次承接

章末可以落在决定、关系改变、问题的有限解决或情绪余韵。把末段与下一章开场一起读：上一章提出的紧迫任务是否被处理，时间跨度是否合理，转向是否有来由。硬问题不能靠“下章更大危机”掩盖。

原创例：本章她终于把未寄的信放进邮筒，下一章可以写回家后少摆一只杯子，让决定留下生活后果；不必立刻出现匿名电话。若章末答应天亮去接人，下一章先交代接人与否，再换新任务，不能无故重置。

下一章尚未写时，只检查计划是否能接，不把未来落实说成已通过。保留开放结尾或余韵的理由，不能把每章改成危险/疑问句。表达专项继续按deslop流程，保留作者声音，不统一改为短句或对白。

## 交付给作者

普通局部任务只需说明真实问题、最小改动及应保留项，不强制新建整套表格。修稿前后核对人物所知、身体限制、物件去向、阶段结果和声音；如果只是偏好建议就标可选。正文变化后重新阅读受影响承接，复用原报告哈希与意见闭环，不能拿修前报告替新稿通过。
