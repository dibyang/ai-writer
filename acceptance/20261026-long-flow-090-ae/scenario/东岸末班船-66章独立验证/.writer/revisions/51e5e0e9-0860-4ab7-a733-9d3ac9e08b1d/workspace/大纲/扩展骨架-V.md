# 《东岸末班船》扩展骨架 V

这是从第4章起显式引用的未来规划。前三章及其《全书大纲》、V1/V2契约保留原三章试验的历史意义：寻找受托收还人、点清八件、交箱、退款和分联已经有限兑现。箱在赴铺途中是叙事停处，不是失踪谜面。扩展从这些人第二天还要过的生活生长，不以推翻旧结局延长悬念。原有长期定位、文风、人物声音和权威规则继续适用。

## 新阶段想写什么

停航使从前顺路能办的事变远。沈禾不能总在下工后替别人追着跑；周岸也不能把每件帮忙都塞进回家前；许蓉习惯把人安置好，却要学着让别人按自己的办法继续走。三个人通过营业、走路、修家具和交班，尝试把善意做成有时限、有报酬、能轮换的小安排。有人吃亏或改口，也有人终于能及时吃自己的饭。父辈全史不承担这一段的答案。

## 人物的目标、阻力和变化

| 人物 | 眼前想要 | 会付的代价与变化 |
| --- | --- | --- |
| 许蓉 | 停航期间仍把来渡口的人指到能走的路，交班后回家 | 自己走一次、发现旧图不好用；从亲自领每个人改成和同事分担。只知道亲见或实际获告的事。 |
| 沈禾 | 按时完成点心铺的活，少为重复跑腿赔掉休息 | 为一小批提前取货调整工序，承担少量试做的时间与售不掉的风险；说清自己能做多少，不许诺包送。 |
| 周岸 | 有工可做，也能按约收工和收钱 | 为家具实际测量、排出时间；必要时推迟一件帮忙，损失一个方便的人情。工具用自己的包，不把归还旧箱变成常备道具。 |
| 沈成林 | 装回柜门，重新参与家务 | 脚未好，不能靠逞强站高；学会问女儿怎么放碗、怎么用那一层，不用自白替代生活里的让步。 |
| 谭老板 | 停航客少仍卖得掉当天的糕，按时收摊 | 和沈禾试一个很小的取货时段，承认工时与余货有成本；不是无限善款来源，也不是苛刻反派。 |
| 梁伯、老何 | 各自把铺子和交班的事接住 | 只处理自己实际知道且能承担的一段；不隔空替所有人完成手续或做结论。 |

原V1为1—2，V2为3。新增V3为4—6、V4为7—9、V5为10—12。以下7—12仅为远期骨架，标题和具体时刻尚不锁定。

| 章 | 计划中的主要行动与选择 | 新增的处境及保留项 |
| --- | --- | --- |
| 4《少蒸的两笼》 | 先在周岸视点写原箱实际入铺，再换场到翌晨米糕店。沈禾照减量单做事，看到绕桥赶工的人取糕不便，与老板试着安排一小批提前取货。许蓉在自己到岗途中接上这条生活线。 | 箱入铺须真实动作与获告分开；试份、价格和时段在场协商后才成立。不在本章宣布稳定营业。 |
| 5《门板靠墙》 | 周岸用自己工具到沈家量柜口；沈父坐着参与，沈禾实际摆碗，发现“装回原样”并不好用。先安排可承担的修理，不一天奇迹式做完。 | 把女儿常用那层的位置作为未完选择留下。脚伤不凭空痊愈，80元与新支出分开。 |
| 6《走一遍再画》 | 许蓉和老何实际核走绕行路线，看看纸上站名与街上入口能否对应；抽一次自己有空的时段去试，不能离岗不交代。 | 修正的图须经真实走路才有用；把需绕台阶的入口问题传到后卷。V3结束时小安排存在，耐用与否未证明。 |
| 7 | 提前取货撞上店内正经活计，沈禾和老板缩减试份或调整交接，承认一回不便与实际损耗。 | 不把多跑一趟永久变成沈禾的义务；细节留到该章前滚动规划。 |
| 8 | 老顾客在取货时段实际取走试份，余份怎样处理、谁收钱和谁承担工时均在场落实；一回真实营业使沈禾能准时离店办另一件自己的事。 | 回收4章的取货线索。只承认本次有效，不称永久商业成功。 |
| 9 | 周岸与许蓉各自推掉一件方便却不能兼顾的事，用明确排工、交班承担后果；他得以去完成已约的柜门活。 | 承接V3测量与V4时间成本，为末卷留实际可执行安排，普通材料/费用尚待写时确定。 |
| 10 | 到月底核付原西门维修35元，用实际交款和收款收束，不能从旧小票推定早已付清。别人能接班，许蓉才腾出时间完成自己的晚饭或家中小事。 | 35元原报价不改；付款主体与方式在现场写明，和80元不串账。 |
| 11 | 实际装柜门并摆回碗，沈父询问沈禾意见，调整她常用的一层；两人一起承担其中一项活计和时间。 | 回收5章的使用位置线索。不是强行和解，旧往事不补全，脚伤仍按实际时间写。 |
| 12 | 一位需要绕行的人实际用过图上的入口与取货安排；许蓉按时交班、沈禾留住休息、周岸做完承诺的一段，各人能继续走自己的路。 | 回收6章入口线索，落在可见出行与关系后果。轮渡是否已复航尚未选，不能以一声船响证明复航。 |

## 终局储备与未决

留给末卷的是：35元实际结算、柜门实际可用、一回无需所有人再熬夜兜底的出行与交班。不给某个人“把所有人的困难都解决”的结局。回收允许范围有限、效果不完美。父辈未讲的年月继续有空白；八十元退款不重开，旧箱不藏机关。

复航日期、末章是否有真实复航场景、提前取货的长期频次与价格、柜门新材料/工费、配角姓名仍未决。7—12不预写细纲；近期只正式细化4—6。本阶段字数、执行停点、后续修订权限以workflow和交接为准，不是故事事实。
