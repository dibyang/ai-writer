# 根控制器对语言实跑的实读复核

根实际读完baseline-first全部252行、baseline-report全部92行、updated-first全部365行、updated-report全部94行；最终cases与首轮是否逐字段一致另由verify-language-eval核验，不能只依据模型自报。两版输入相同，规则来源分别冻结v2与v4。v4五个审查资源与最终v5包须逐字节核对后才能计入最终版本证据。

观察到的变化集中在L07：旧版已指出“许他熟悉的分量”等疑点，但把整个样本归为context-needed；新版确认许可句中许可动作与数量关系被压缩，给出动宾和补主干的阅读代价，同时把所托物、消耗/补充对象及对白身份单列待核。没有猜药物、灵力、剂量或新增设定。这里应描述为“局部问题被明确区分”，不能说旧版完全没发现疑点，更不能把其余句子全部升级为硬错。

L02、L05、L09、L11、L14两版均定位了许可/计量压缩、场景不符的空泛对白、竞争指代、需要去路却只写心理空间、需要安排结果却只有泛指。根核理由均引用了该样本明确给出的任务及前文边界，未借假想更早说明消解问题，处理方向也没有擅自增加事实。

8个保留控制两版都保留：L01有明确铜珠与运动，L03有掌柜资金用途，L04有具体动作承载克制收束，L08身份与公堂支持正式措辞，L10收支与技术余量有定义，L12比喻有场景和声音支撑，L13数量及回收动作明确，L15医学对白仅审语言且要求具体。它们证明本组没有按“抽象词/对称句/正式话/计算安排”一律判错，不代表所有正常文风都绝不会误伤。

L06、L16两版都保持待核：单独截出的指代不能证明原稿遗漏。新版L07虽case标签为issue，也只确认许可搭配的局部问题，其他部分仍保留相同缺证边界。根认可这种拆分；不以用户已经感觉别扭为由强行给全部原句定错。

首轮到复核均无判定变化，不虚构复核“修复了几个漏检”。与预先保存的根判据相比，基线case标签15/16一致，新版16/16一致；该数字仅是这16个定向回归样本的标签一致性，不是泛化准确率。L01/L07与教学表达复现或相近，其他样本也有共同设计结构，不称独立未见测试集或真人盲评。统计必须结合上述局部理由，不只看标签。
