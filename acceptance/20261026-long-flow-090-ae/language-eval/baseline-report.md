## 真人语言别扭句

本次逐条明确检查：有没有哪句话意思能够看懂，却让人觉得别扭、像为了写得漂亮硬拼出来，或者不像一个人当面会这样说？叙述以给定声音检验，不能强行套日常聊天标准。

四项测试在两个 JSON 的每条记录中均有实质说明。这里的朗读改口测试仅是模型对文字节奏与辨义停顿的检查，没有真人发声、听觉实验或真人无意识改口记录。没有把单纯“我想换一种说法”当问题证据。

### 真人语言硬问题

- **L02**：“师父准他能承受的重量，他一次也没有多来。”许可动作被压缩，多来的动作或计量对象不清；随后补回的内容也未落地。动宾拆分与具体落地共同支持：读者无法还原规定的实际搬砖做法。最小方向是补清已有动作及对象，不自行添加重量或次数。
- **L05**：“你现在的承受情况、后面需要保留的空间，都得统一考虑，别只顾眼下这一项。”当面说话与具体落地测试共同指出：已知直白的母亲在烫伤当下像在统筹事项，孩子也不知道这句话要求自己做什么。文字节奏检查进一步确认书面议事口吻。只调整语气及指向，不提供医疗处置，不补严重程度。
- **L09**：“她拿起她的钥匙，塞进自己的外套口袋，等她出门，才把门锁上。”动宾拆分中的主语、领属与回指检查，加上具体落地，支持同一问题：可生成不同的角色分配，读者无法确定谁把谁锁在门外。补必要姓名，不替作者决定归属。
- **L11**：“他把心里的重量往前递了一些，给下一步留出能够转圜的份额。那份不足还在，只是不再占据原来的位置。”具体落地与文字复读检查共同支持：原应交代的可选去路没有出现，那份不足也难从前句找到明确对应。问题是所需现场被抽象转移遮蔽，不能由此推出一切心理比喻都应删除。先补已有空间与选择事实，不擅自安排跳桥或涉水。
- **L14**：“她把能给的那些补到该有的地方，余下的按原先的分寸留住。如此一来，父亲缺的总算有了着落。”动宾及回指检查与具体落地共同支持：在给定全部前文下，施予、保留和父亲的需要没有具体对象，宣布结果却不交代结果。补清已知安排，不猜钱、住处或药物。

以上均有至少两项测试指向同一具体损害，且在给定文体和人物语境下仍成立。不是依抽象词、排比或省略的出现次数判定。
