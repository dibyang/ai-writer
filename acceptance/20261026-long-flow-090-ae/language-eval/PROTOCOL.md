# 语言规则实跑范围与限制

本组是根控制器设计的定向回归样本，目标是复现用户指出的含混压缩问题，同时观察正常文风是否被误伤。它不是独立第三方题库、真人盲评或普遍检出率实验；样本与规则由同一维护过程设计，不能由此声称对所有小说有效。

16条中L07是用户原例、上下文缺失；其余15条是独立合成片段，包含同句式的明确前文反例、其他问题变体、专业与正式对白、修辞及缺前文情形。预期6项issue、8项keep、2项context-needed在expected-root-only.json中先保存；原例内部也须分别说明，不能把首句和未知设定一概判错。受测Codex不读取预期或另一版本输出；基线用冻结v2，更新版用最终候选v4，均保留首轮与复核稿。新版规则明确执行漏检与误伤复核；基线提示也要求依据原规则复核，避免仅因要求多想一轮而声称规则有收益。

每条判断须人工性质的模型实读核查理由，不以标签匹配替代：检查原句引用、阅读代价、对象/因果是否凭空补造、保留理由是否有上下文依据。根控制器另逐条读最终报告。可计算与事先判据的一致数、漏检/误伤及复核变化；若两版均通过，必须明确未观察到本组检出率提升，不能把规则补充描述成实验证明的提升。

公开CLI事件、指定资源与样本SHA、输出原件、真实退出和失败日志全部保留。第一次language-baseline在读任何文件前网络连接失败，由根核验子进程身份后结束，实际退出4294967295；它不计作已运行的语言审查。language-baseline-retry是新的隔离原生会话，不冒称失败会话已审查；外层联网权限调整并不扩大子会话的工作范围。
