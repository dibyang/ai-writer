# 散文与一般非虚构

使用 essay 文体与 writer-project 工作区。历史事件为主要论证基础时改用 writer-history 的证据规范；虚构小说使用 writer-novel。

从作者真正想看见的人、处境或问题出发，确定叙述关系与声音。结构可以循事件、感受、意象、空间或论证展开，不强制冲突升级、爽点、反转和章末悬念。

真实叙事区分亲历记忆、受访者说法、可核事实、推断与作者观点；不虚构采访、引语、数据、到访经历或证据。缺资料时完成资料清单或明确标注的构思稿。涉及隐私的真实人物按用户授权与素材可公开范围处理，不扩展收集无关个人信息。

先用能支撑全文的观察、事件或论述推进形成细纲。抽象思考要与具体经验发生联系，但不要求每句都有动作；允许回望、联想、停顿和有功能的修辞。结尾可留余味或回应核心问题，不固定使用“升华”或强制动作收尾。

润色先找真实阅读阻力，再判断改法是否损失节奏、个性和情感。检查跨段重复、泛泛感慨、假亲历和模板论证；不能为“去 AI”批量添口误、短句或无据感官。

登记 summary 与 timeline 可描述本篇论述推进和已核事实；characters 可为空。正式审查使用 writer-review，分别报告表达质量与事实待核项。
