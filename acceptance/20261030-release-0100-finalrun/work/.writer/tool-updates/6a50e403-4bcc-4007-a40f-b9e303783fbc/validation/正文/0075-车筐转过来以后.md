# 第七十五章 车筐转过来以后

第四十五日九点二十，沈禾在旧站外看见范勤将一小铲湿叶倒进门内桶。沟口今天没有前日那团软纸，他仍拿铲沿贴着外侧走了一下，刮出一层薄灰，才把工具放回去。她到时这一下正在做，前面清过多少，没问便不知道。

乔平已经在门边，夹板收在臂下，眼镜上的胶带比昨日多翘一个角。他伸手想压，手套还脏，改用腕侧碰了一下。范说不如换条新的，乔答回去再弄，今早不想满手都是胶。

邹秀琴从街口推过来，两侧空筐各绑一只，主筐上盖着布。她没有将车推到人中间，先在平处刹住，拧开自己的杯盖喝一口，才问哪位是管车的。乔报名字，说自己先接这边材料车，不管所有从街上过的。

“我也不找你管街上。别你的车一来，我就没地方走。”

她说着将杯扣紧。沈让到车侧，看见朝外那只空筐的底沿比车把还宽一点，绳尾收在结里，没有为今天见人特意拆掉。邹问是不是先从前面过一回，乔说再等一小会儿，车已经到巷口。

“我九点半那边要接菜。”邹看他，“几分钟，不是你一车卸完。”

乔点头，去门边接电话。九点二十多，一辆装板的车慢慢靠近，车尾遮住外路一截光。司机探头问停这里行不行，乔叫他再往前一点，又转头看门，没让轮子一路往前滚。车停稳，两名接货的人从门内出来，先将地上的垫木放好。

原来准备留的是一条直缝。司机站进去试了一下，侧身能过，便朝邹招手，说她从这边慢推。邹没有松刹，指自己最外头的筐：“你那肩膀会收，我这只收不了。”

乔走到她旁边，顺着车把往前看。沈退开，人不挡了，前轮确实能朝那条缝去，车身转正以前，右侧筐却先碰上货车尾端要经过的位置。邹将前轮只摆出一点便收回，没真擦着车来证明。

“到这儿还得拐。你别只给我留一个前轮。”

司机从尾板上下来，蹲着看了一回，问能不能把空筐叠到上头。邹掀开布角，底下青菜露出来，说叠了会压，到了店还得再拿下来；不是今天给大家看完，就能每天多长出这一只手。

布合上，她摸了一下最外头那把菜，不再拉车试第二回。沈本想从自己站的位置比个宽度，手抬起来，又放下。她那两条胳膊量出的空处，到车尾还得弯一次，邹已经用自己的轮子给他们看了。

门内一个人开始解板外的带子，另一人抓住板捆一端，想先往里送。乔叫住他们。只要板捆横在门口，哪怕车再前半个轮，也会把刚腾的弯挡住。他让两人先别抬，将松开的一道带收回车上，自己问司机若车向前移，尾板还能不能对门。

司机看了一眼，说再前就斜，得先卸到外头，再倒手进去。邹的脸一下沉下来：“倒外头，那不还是我等？”

“先不卸。”乔说。

那人手停在带上。乔请司机将尾板暂收，让接货的人退回门内，又指了门口原来摆垫木的位置，叫范把空架往里收齐。范没有将架子一下往后拖，底下有一截线，他先拾到架脚上，才同另一个人抬稳。

门口那一块终于空出。司机在车侧等，乔站到能看见车道的地方，让邹先退半步，车把转正以后，再沿外路过。她没去踩两块暗红砖，前轮从砖旁走，右侧筐转过尾板收起的位置，后轮随过来，原来那条绳结也没有蹭开。

沈站在门内边线之外，没有替她推。邹到了前面干一点的平处才刹住，回头看看，手没有离开车把，问乔刚才这是让自己先过，还是以后碰上都得等收一回尾板。

乔被问住，没说现在不就过了。他走过来，在她车边蹲了一下，眼睛终于同筐底差不多高：“不是叫你天天等这个。车要接，得先让这里有能放下来的地方，不该卸一半再想你怎么过。”

邹没急着夸，问这个地方今天空了，明早是不是又堆满。范朝门内看，说架子本来能放，昨天临时有几件退的，占了外头；今天得试那一捆放进去，若真放不下，不能在纸上写都收门里。

“那你们试。我得走了。”邹说。

沈看过时间，还没到九点半。她把刚才想问邹每天几点那一页合住，只说以后若遇到，先找乔或范，不必先打给自己。邹答今天认得人了，过两天若换人，别又拿一句没听说让她在雨里重新讲。

乔将自己的联系号码给她，邹没让沈代存，自己掏手机，拨了一下，听见乔那边真响，才收好。她说早上来这边有时九点、有时快九点四十，不是每天都给人留九点二十；乔答记住这个范围，不能拿今日这一点去赶她。

她将布边按好，自己解刹推走。沈没有跟着送到下一家，也没为了让她能讲完一句话，替她给店里回个已经快到。菜从她眼前过去，筐仍两只，谁也没把卸下来一只当成今日能走的办法。

再回门边，接货的人已经将第一捆板抬到架上。架子往内收过，尾端却抵着原来装小件的箱，两人不能同时松手。范让先落到垫木，自己进去将那只箱换到上层，箱盖一开，螺钉的小袋歪在里头，他没抓着盖子就往高处提。

“这不是空箱。”他朝乔说。

乔将夹板挂回钩，进去同他搬。一个扶底，一个先把滑到边上的两袋放回中央，箱子上架以后，下面那一层才真能接住板。站在外头看，门内只是多了半步，里头却得腾开两只手，再给每只零件找一次落处。

沈留在门外，替他们看见一个纸角被车轮压住。她叫司机先别动，等车停稳才用手指出位置，没弯身钻到轮旁取。司机自己下来拿走，纸边少了一小块，他沿轮侧找过，碎片也装回袋。范出来看时，沟口没有多出这片新纸。

最后一捆放稳，司机要签，乔先问下一车是不是还这样长。对方说第四十六日小件，第四十八日还有一车板，什么时候能到得先看前一家，不敢报全一样。乔拿自己的货单翻过，没把这句写成每天九点半。

“那就先试这两车。”他说，“到街口先给我打，门内没摆位，我出来说，别直接开尾板。你若早到也一样。”

司机说不能一停又半小时，乔答不让他蒙着等，真收不进，自己得当场去找位置，不能叫他一个人卸到外路便算交完。范在旁边说，每车卸完散带碎纸由自己这边收口，早上先看沟，遇到仍往外兜水就得停下来找，不等推车的替他们报坏。

沈问这两次要不要自己来。乔摇头，笑了一下：“你站着，我这箱也不会自己上去。车是我接，你别替我接电话。”

范也说不用等她来才开门。沈便把自己本子上原来想写的到场两个字留白，只记明白谁接司机、谁收口。司机收好单子，问她是来拍什么的，她说今天没拍，刚才大家都在动，自己站在这里看过，不想让一张车走后的空地照片替他们讲完。

九点四十多，车从门前离开。地上仍有车轮带出的浅印，范提扫帚收了门边几粒木屑，沈避开等他扫净，才走过那一截。两块红砖没换，白罩也还在围挡里；今天能过的是这一车、一副筐，不是一条从此不用再看的路。

街口小店外，矮凳上压着一只装瓶子的筐。沈站着买水，手里的本子无处放，只能夹到腋下。她原想坐片刻，老板让她等收完瓶，后头却又有人来换汽水。她说不必，拿水站到树边，才想起读报老人要的靠背，不能只凭刚才车过去，就替他把这一件也算好了。

她拧瓶盖时，本子顺着胳膊往下滑，只好先将水夹在膝间。瓶身冰凉，裤腿慢慢洇出一小块深色。老板收走筐，隔着门喊凳子空了，她这次没有再说不用，过去问能不能坐十分钟。

“坐就是了，我还等它下蛋？”老板把凳旁的瓶盖踢进簸箕。

凳面比她想的低。坐下去，膝头抬高，本子倒有地方搁了，瓶子却得放在脚边。她喝了几口水，才松开一直夹着本子的左臂，肩膀跟着往下落。店里有人要买两听凉啤酒，老板忙着找零钱，也没有再看她。她坐着听那人说午饭不在家吃，想起自己灶上还没下锅的半篮菜，便把本子合起，等腿缓过这一阵酸，才扶着凳沿站起来。
