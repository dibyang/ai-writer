# 去 AI 味专项：保留内容边界的表达审修

适用于“去 AI 味”“太像模型写的”“语言机械/模板化”等明确任务，及写作中已发现的同类问题。不是外部检测器规避流程，也不替代结构或史实审查。

## 版本、作者意图与范围

读取 writer.json、文风、相关设定和指定正文；长篇还要核对角色知情与相邻章节。确定只诊断或已授权改写。保存原稿 SHA-256、路径、追踪修订号、阅读范围及要保留的文气/人物资产。仅诊断时不写正文；已授权去味或润色时直接完成范围内修改。

未指定风格时沿用当前作品，不把参考项目的网文偏好套给所有作者。新稿边写边自检不必每段输出分类表。

## 候选与实读

可用主项目 `node bin/ai-writer.mjs style-scan --project 目录 --draft 正文/文件.md`；独立作品用 `node .writer/tool/bin/ai-writer.mjs`。报告只给候选，必须完整阅读原文。输出中的 advisory、零命中或某个词出现次数都不是文学结论。不存在的模式不要凑数。

逐处考虑以下问题，按实际需要选择，不要求每类都有修改：

| 观察方向 | 判断依据 | 典型保留情形 |
| --- | --- | --- |
| 套式词和微动作 | 是否成片重复，是否替代了人物具体反应 | 有实际物理动作、人物习惯或情节功能 |
| 句式与排比 | 是否重复同一意思、遮挡主动作或拖慢理解 | 辨认、辩解、对比论证、有效情绪递进 |
| 情绪空转 | 诱因、身体/语言反应与后果是否属于这个人 | 直接情绪陈述有信息，克制、沉默或迟钝也成立 |
| 节奏均匀 | 连读是否单调，长短是否服务场景 | 舒展叙述、刻意节拍、散文回环，不能按段长机械拆分 |
| 含混压缩/对象缺失 | 许可、用量、补充和结果的对象及关系能否从实际上下文接上 | 指代明确的省略、已交代后的简短总结；缺前文则待核 |
| 概括式对白 | 是否以无具体顾虑的管理结论替代人物当面要说的话 | 职业与情境成立、对象明确的安排和计算 |
| 对白趋同 | 身份、目的、关系、惯用语是否影响说法 | 同职业共享术语；不靠给每人加口头禅制造区别 |
| 收尾重复 | 是否连续预告、总结或再解释已兑现内容 | 有内容的议论、回望、悬念或动作收束 |
| 解释过满/视角越界 | 是否重说已知内容，是否泄露当前角色/读者不该知道的信息 | 必要背景、操作说明、历史推断的限定词 |

小说可结合 natural-language-authenticity 和 psychology-readability；剧本看行动与对白，不补小说式内心独白；历史散文遵守事实卡边界，不补现场、对白或心理；散文保留真实经历、回望与作者节奏。引用原文不为降低模式命中而改写。

## 诊断与处理强度

每个确认问题给位置、原句、具体阅读代价和最小修改方向。独立错误直接指出；文风问题需上下文支持。分开列局部高置信问题、连续模板风险、风格偏好和待核项。不要用每千字词频或固定删字率推导轻中重等级。

局部问题只改局部；同一模式连续影响多个段落时，在授权内重整相关段落。若要改变情节、核心设定、作者明确选择或历史结论，单列原因与影响，不用去味授权代替该决策。

## 修改事务

1. 修改前将实际原文按原始字节复制到 `审查/去味-单元-原哈希前8位-before.md` 等全新文件，记录其哈希。不要覆盖原备份或把备份放回正文目录。
2. 已登记章节先按 writer-project 核实影响范围；schema 4 先 revision begin，在独立区使用当前修订号和所有者令牌 rewind、实读改稿与重登，完整尾段复核后 prepare/commit，不直接编辑主稿。旧协议保留原 rewind；未登记正文不需要回退。
3. 清理重复解释与空转，调整不自然的搭配和对白；最后连读恢复自然节奏。优先小改。能保留的句子保留，不追求扫描清零，不按比例删字。
4. 不新增原文未有的情节、关系、数字、时间和事实。必要的澄清只依据已确认材料；不确定的归待核。历史细节即使更生动，也必须有来源支持。
5. 对照前后文本，核对人名、数字、否定/推断限定、人物知识、物证交接、因果与情绪承接。改变措辞不能悄悄改变主张。跨章任务完整连读；原来成立的修辞和叙述若被损伤，应恢复。
6. 用真实最终稿填写写前模板，按实际状态重新登记受影响单元。报告另存并绑定新哈希；需要长篇覆盖时再通过 review 登记。未完成的后续核对如实报告。

## 报告

报告包含范围、审查性质、前后 SHA-256、实际问题、少量代表性的改前改后对照、保留理由、保护项复核和未覆盖项。没有需要修改的内容，可以给出不改的结论。不能虚构对照、把扫词冒充全文阅读、把脚本通过称为去味完成。

改稿后说明已登记范围与未登记正文；导出时核对 excluded_drafts。质量结论属于本次实读与具体版本，不代表真人盲读、市场表现或 AI 检测器概率。
