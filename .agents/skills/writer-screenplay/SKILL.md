# 剧本创作与改编

作品文体为 screenplay。先确定媒介、时长或集数、受众、制作规模，以及原创还是改编；未明确的可逆细节作合理假设并说明。用户只要剧本文字时，不自动扩展成图像或视频生成。

## 结构

故事核心 → 人物目标与对抗 → 故事弧/分集纲 → 场次卡 → 场次剧本。短剧可围绕短时冲突和阶段钩子；电影按完整人物变化组织；系列剧区分本集问题与季级悬念。不要把 60/90 秒试制模板套在所有剧本上。

场次卡记：内/外景、地点、时间、在场人物、进入状态、谁争取什么、阻碍、可见转折、出场状态、预计时长与资源限制。unit 可按一场或一集统一编号，不在中途混用。

常规创作及写后自检先核对本场相关的观众/人物获知路径、前事留下的合作条件、场面独特收益与行动所需资源；不等待作者点名四项。详细方法按下文共享指引加载，不强制每场新增冲突、反转或独立表格。

规划或检查信息投放、情绪余波、场景功能/篇幅及能力资源时，按需读[信息、情绪、场景及能力边界](../writer-project/references/narrative-causality.md)。核对观众实际可见可听、角色获知路径、后场合作条件和关键行动代价，写后按实际场面登记；不凭心理括号、字数或场次卡宣称已经兑现。

## 人物底色与语言行为指纹

规划人物、关系或跨场/跨集接续时，按需读[人物、关系及状态接续](../writer-project/references/character-dynamics.md)，核对关系动态、变化因果、场面策略、群像互相影响及状态召回；使用剧本的可表演证据标准。

重要人物在既有角色卡中按需记录欲望、害怕失去什么、底线、常见误判，以及平常和受压时的选择；区分面对不同关系的开口、拒绝、求助、沉默与行动先后。写倾向、触发条件和可能破例的原因，次要人物可简记，不强制填表。作者未确认的推测标为候选，角色卡不是已发生事实。

落到场次时，把底色转成可见、可听、可表演的选择：人物向谁争取什么，表面说什么，隐瞒什么，用怎样的行动或对白策略，受阻后是否改变。停顿、回避、打断和动作须有此刻的对象与目的，不把口头禅、固定动作或括号内心理说明当作人物差异；不同人物也允许在共同处境中采取相同做法。

例如同样想留住同伴，甲直接问“你几点回来”，顺手收起备用钥匙；乙说“门没锁”，把钥匙留在桌边。具体选择须符合关系、信息和处境，不作为每场重复的模板。成长、伪装和受压破例可以改变表达，重要变化在实际场面中给出足够依据。

写作前按本场/集相关人物读取已确认角色卡与必要旧场正文，把实际使用的卡片路径列入计划的 `setting_refs`，使 context 与写前模板追踪来源哈希。已有作品沿用原卡片，不自动添加或迁移；调整已消费的卡片按 writer-project 的设定影响和修订流程处理。写后按实际场面登记人物所知、关系及物件变化，不把潜台词推测或计划写成事实。

## 正文格式

```text
场 01  内景·旧车站值班室·夜

桌上的收件灯亮了。值班员把门反锁，拔掉打印机电源。

值班员
你听见了吗？

候车人把手机翻过来，屏幕上还在计时。
```

动作描述写能看见、听见或表演的事。心理、背景和说明若是关键内容，应转化为合适的场面、潜台词、声音设计或明确的画外音；不能只把小说段落加上角色名字。画外音并非禁用，需符合作品形式。

对白是人物在此刻向对方争取东西，不替观众讲完整设定。核对人物说话差异、空间位置、道具来去、动作可实现性和转场承接。时长估计只是排演前估计，按台词、停顿、行动及场面复杂度复核，不能按字数声称实际成片时长。

## 改编

先列原作不可丢失的因果、关系与情绪资产，再决定合场、减支线、信息视觉化。重大角色合并、结局或核心冲突变化超出授权时说明影响。保留原稿，改编落到独立作品目录。

分镜、镜头清单、道具表和制作清单仅在任务需要时生成。内置 story-gate-studio 的 screenplay-adapter 只承诺短剧试制，其结果不等于完整长剧、排演或拍摄验收。

写完用 writer-project 保存和登记，用 writer-review 按剧本标准审查；人物相关任务对照角色卡和实际场次，核对底色、对白策略与行动，区分合理变化、证据不足和真实冲突。
