# 小说与剧本的信息、情绪、场景及能力边界

用于规划、续写或审查信息投放、情绪后果、场景功能和人物行动可信度。按作品与本轮问题选用，不要求每章填四张表、每场反转、均分篇幅或统一情绪反应。与[人物、关系及状态接续](character-dynamics.md)共用角色卡、计划、正文和既有登记；后者负责人物倾向与事实接续，本文件核对信息和后果怎样形成可理解的故事。

## 信息投放与理解路径

规划关键揭示时，在既有 goal/change/beats 中按需写明：作者采用的事实、读者/观众此前实际得到的线索、各人物的获知途径、本单元先展示什么再改变哪种解释。作者候选真相仍是候选，不能因为做了推演就确立。角色说过、看见过、推测出和已证实应分开；叙述者不可靠时，同样核对作品选定的叙事契约。

小说按既定视角核对感知、回忆与推断，允许全知、有限视角及有意留白，不把某一视角规范套给所有小说。剧本核对镜头所在场面实际可见、可听或明确画外音承载的信息；作者说明和角色内心括号不能单独证明观众已得知。关键线索出现过，还须判断对象、指代、声音归属与时序是否足以让人理解；不凭词句命中声称线索公平。

悬念可以暂不解释，反转可以改变解释；若结论需要此前完全未提供的条件，先核作品承诺和揭示时机，不替作者补造旧线索。读者先知、角色后知也可成立；角色使用信息前仍须有亲见、告知或合理推断的路径。信息重述若改变听者、风险或含义可以保留，不按重复率直接删除。

## 情绪承接与关系后果

重大冲突后，下一次见面回读具体触发与伤害范围，核对称呼、距离、回避、合作条件、身体状态或实际选择有没有承接。压抑、装作无事、先办急事、和解与暂不处理都可以成立；关键是处境与行动足以支持，不强制补哭喊、内心独白或身体反应。

人物可以继续合作，同时保留未解决的信任损伤；道歉、理解原因、接受帮助、恢复信任不是自动相等。关系修复按本次实际发生的范围记录，不靠一句“误会解开了”抹去后果。长间隔、共同经历或新信息可以改变情绪，材料缺失先标待核，不把未写的愤怒或报复当必需情节。

计划写预计余波，写后按实际选择将仍有效的情绪处境记入人物状态；重要关系变化以已有 relationship 条目和正文 evidence 追踪。下一单元 context 中核对它是否进入本次决策。记录角色行为及有文本支持的解释，不把模型对心理的猜测登记为确定事实。

## 场景功能与篇幅分配

规划 goal/change/beats 或场次卡时，按需说明该场要提供的独特收益：信息、选择与后果、关系、情绪、人物日常、空间承接、节奏或意象均可。相邻场景功能相近不等于重复；实读后比较是否改变对象、代价、人物判断或读者体验。删改前核对待删部分是否独占必要线索、转场或情绪铺垫。

关键选择、犹豫、实施与后果应获得足以理解的展开；不能正文只写“终于决定了”，却在摘要登记复杂抉择已充分兑现。也不强制把每个过程写成操作手册。过场可以压缩，有效日常、慢热、合作和余韵可以保留；篇幅建议须说明具体缺失或冗余带来的阅读影响，不按固定字数或“每场必须改变命运”判错。

小说按阅读节奏、叙述距离和作品声音判断展开；剧本按可表演行动、停顿、空间和制作条件估计节奏。字数、模型朗读或固定页数不能证明实际排演/成片时长。计划功能是目标，审查须回到最终正文核对实际兑现，不能以计划自证。

## 人物能力与资源边界

重要行动前按需核对：已建立的技能与经验、当时可知信息、工具与材料、可调动的人及其意愿、权限/身份、钱与时间、伤情与疲劳。技能、工具、授权和资源可以分开具备；会操作不等于有权限，知道方法不等于眼下有工具，认识某人不等于能无条件调动他。

区分客观做不到与故事内制度不允许：人物可以有意违令、越权或承担风险，这本身不是逻辑错误。核对实际进入/操作路径、人物为何选择如此及本次情节中的影响，不把越权自动登记成已经获得正式权限，也不强制角色必须守规或受某种固定惩罚。帮手也可以自愿相助，是否需要交换条件由人物与处境决定。

角色卡可记录已确定能力、不会/做不到的边界、借助他人的条件及可增长方向；未确定部分保留候选。临时学习、合理迁移、试错、借工具、求助或付出代价都可以扩大行动范围，不把角色冻结成静态能力表。新能力第一次发挥决定作用时，核对既有铺垫或当场可理解的获得过程；证据不足不擅自编造训练史、身份或无限资源。

已使用/耗尽、受伤、欠账、借还与权限变化按既有 characters/timeline/ledger 登记和召回，保留实际获得、消耗及移交证据。续写时核查资源仍可用、帮手仍愿意、恢复时间确实经过。能力合理性与专业事实核验分开：涉及需要查证的具体技术时按任务研究，不把本模块当专业正确性的保证。

## 创作、登记与审查接入

1. 写前读取相关卡片、规则、必要旧正文和当前 context。计划使用现有 goal/change/beats、cast、setting_refs，长篇重要事实用 recall_ids；无需新增 JSON 字段或平行账本。四项不是每单元必填清单，按本次场面选择关键项。
2. 在正文中体现获知路径、余波、关键选择及可用资源；模型预测的读者反应只是判断，不冒充真人反馈。写后实读回对计划，区分已发生、可支持的推断、未定和未兑现。
3. 按实际正文填 summary/changes：人物的当前情绪处境和能力限制写入 characters，事件进 timeline_append；重要信息分层用 author_truth/reader_known/character_known，关系用 relationship，物件用 object/custody，未兑现事项用 thread。全部沿现有 schema 和 evidence 校验，不自创 emotions/skills/scene_functions 等结构化字段。schema1保持原协议，旧作品不自动迁移。
4. 审查完整读取本次范围并绑定版本；按需给出四项的计划/旧文依据、当前原句、具体理解或因果损害及最小修复方向。区分真实冲突、证据不足、合理留白/压抑/临时应对、可选节奏偏好；记录应保留内容。无适用情节说明理由，不为填表制造问题。
5. 合并或删场前回查独有信息、人物资产、情绪与空间承接，授权范围内才修改。已登记正文或已消费设定调整继续走原影响与独立修订流程，不刷新哈希追认旧稿。只读审查不改正文，也不把建议当作者已采纳。

## 简例

前场有人擅自翻动同伴的信件；后场同伴仍愿借梯子，但要求对方先问、自己在旁。借梯本身不能自动证明原谅；若角色明确接受道歉或有其他修复依据，则按实际范围记录和解，不为保留余波强加怨恨。信封上的退件戳可以先让观众看见；缺席人物若已从照片、记录、告知或合理推断获知，可以使用相应信息，区分推断与证实，不因缺席就一律判为未知。人物不会修线路，可以凭既有木工经验看懂梯子裂纹并换梯，但不能因此突然成为电工。把“是否信任对方扶梯”的选择与付出的时间写清，比在摘要中直接宣称已和解更有依据。
