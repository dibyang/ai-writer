# 小说与剧本的人物、关系及状态接续

用于人物规划、续章/跨场/跨集写作和人物专项审查。按本次人物和情节选用，不要求全员填表、每场冲突或每章人物转变。小说允许符合本书声音的内心叙述，剧本须用可见、可听、可表演的证据承载关键变化。

## 规划与事实各归原处

角色卡写作者已确定的倾向：欲望、害怕失去什么、底线、误判、压力选择、对不同关系的说话和行动方式，以及破例条件。未确认部分标 candidate/待定；在授权内由代理确定的合成设定说明来源，不伪称作者逐项确认。指纹不是口头禅、动作配额或人格测评分数。

关系按方向理解：甲信任乙，不代表乙同样信任甲。按需记信任、依赖、亏欠、权力位置及其具体表现，预计会改变关系的事件仍是计划。已有正文发生的变化须从原文核实，不能用新卡片倒改旧事实。

沿现有差量协议记录，不新增平行事实账本：

| 内容 | 现有位置 | 写入与使用边界 |
| --- | --- | --- |
| 稳定底色、表达倾向、预期变化 | 角色卡；计划 `setting_refs` | 按实际采用读取；候选与未来计划不进入事实 |
| 当前所知、位置、伤情、持物、关系处境 | `changes.characters` 的人物状态文本 | 更新时保留仍有效信息；对象缺项是未登记，不等于痊愈、遗失或遗忘 |
| 关系发生的具体变化 | 稳定 ID 的 `changes.ledger`，`type: relationship` | `statement` 写方向、触发事件和当前影响，`cast` 写相关人物，`evidence` 引实际正文 |
| 重要转变的因果链 | 人物状态、`timeline_append`，必要时 `fact`/`relationship` 条目 | 触发事件 → 当时可知信息 → 选择 → 代价/后果；区分一时应对与稳定改变，允许渐变、反复和不变 |
| 作者真相、读者所见、各人所知 | ledger 的 `author_truth`、`reader_known`、`character_known` | 写已登记的边界，不能让人物直接使用作者真相；没有条目时实读补核 |
| 物品与交接 | `type: object`、`custody`、同级 `previous_holder` | 正文证据支持持有人、位置、状态，交接遵守原校验 |
| 未兑现承诺及后续影响 | `type: thread`，`status`、`cast`、必要时 `due_unit`/`pinned` | 兑现、拒绝、延期均需实际证据；不要因到期而强制兑现或当作自动失败 |

字段形状以当前 CLI 帮助和手册为准。不要自创 `relationships`、`injuries` 等未知 JSON 字段；schema 1 按原 snapshot 协议，不能手改版本或为此自动迁移现有作品。细纲、卡片和状态分别承担计划、设定和已发生事实。

## 从人物到场面

按需要在 beats/场次卡中明确：谁希望谁做什么，双方各自掌握什么、表面表达什么、实际采用什么策略，遭拒或误解后如何调整。潜台词由对象、处境、对白及行动共同支持，不要求每句话藏秘密；直接表达、合作、沉默和低压场面都可有效。写前策略是计划，写后按实际场面回查。

群像逐人核对自身目标、信息、可选行动及代价，同一事件如何改变彼此判断和下一步选择。配角可以帮助主角，也可以暂不行动；不要为区分声音强加冲突、怪癖、方言或均分戏份。判断同质化须比较具体立场和选择，不靠字词重复率。

## 续写与接续

1. 计划 `cast` 写实际相关人物，`setting_refs` 引实际使用的角色卡；重要旧事件通过已有 `recall_ids` 或定位后实读旧原文恢复。
2. 读取 context 与写前模板，检查人物所知、伤情、持物、关系及未兑现承诺是否足以支持本单元。标准模式读取完整 snapshot；长篇召回是切片，核对 `continuity.recall.omitted_ids`，必要条目显式召回，不能把缺席当不存在。跨场/跨集编号与当前作品单元口径一致。
3. 信息不足先读相关已登记原文，不凭空填补。写作只能使用人物合理可知信息，身体状态和物件位置须能承接；承诺不必每场提及，但不能无依据抹去其后果。
4. 写后按实际正文填 summary/changes，重大转变保留触发、知情、选择及代价的引文；未变字段沿用。预览差量后登记，再检查下一单元 context 是否实际带入关键状态。已消费来源变化按既有影响分析与独立修订流程处理，不能刷新哈希追认。

## 审查

完整读取本次范围、相关角色卡和必要旧原文，报告绑定路径与 SHA256。每项结论给角色卡/旧文依据、当前原句和处境、实际阅读影响及最小修复方向。分别识别真实冲突、合理破例/成长、候选未定、证据不足；未发生的未来计划不能判为漏写。

按本次范围核对六项：底色与语言行为倾向；关系方向及后续兑现；重要变化因果；场面策略与潜台词；群像独立目标和互相影响；所知、伤情、物品、关系、承诺的接续。可以记录无适用情节及理由，不制造问题。跨单元审查特别核对旧事件是否改变后续判断与行动，不把“报告提及过”当作正文已兑现。

剧本将“观众能否从表演理解”与“作者说明写了什么”分开判断，缺表演依据不必然等于人物底线冲突。小说不强制改为剧本动作。审查仅授权时不改正文；修订授权内按既有版本保护处理。机械一致性、模型自检、真人阅读、排演和发布状态分别报告。
